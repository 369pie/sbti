| 模式 | FPS 玩家黑话 | 人格映射空间 |

| **战术装备** | 无人机、闪光弹、烟雾、C4 | 战术思维/莽vs苟 |
| **社交生态** | 语音沟通、键盘侠、报点、捡队友 | 社恐/社牛/话痨/静音 |

### 2.2 FPS 原生"行为原型"（用户自嘲共识）

FPS 玩家圈已有的行为 meme，是天然的人格映射锚点：

- **舔包怪**：打完人第一时间趴下舔包，被第三方打死
- **蹲狗/阴比**：永远在角落等人，一动不动蹲到天荒地老
- **莽夫**：不管三七二十一就冲，冲完就倒
- **装备党**：枪还没打好，配件已经改了 17 遍
- **报点王**：嘴上全是信息，手上一枪没开
- **扶不起的队友**：被救起来 3 秒又倒了
- **打药上瘾**：不管满血不满血，先打一针再说
- **撤离焦虑症**：包快满了但不舍得走，总想再舔一个
- **枪声恐惧**：听到枪声就跑，从不主动交火
- **静音挂机**：全程不说话不报点，打完就走

这些行为原型和 WTFTI 的 29 人格天然高度匹配。

## 五、文案体系

### 5.1 命名规范

```
三角TI #001（战术指挥部）
三角TI #018（蹲点大师）
三角TI #028（边打边吃）
```

保持 WTFTI 体系编号不变，宇宙名前缀改为"三角TI"。

### 5.2 语气定调

| 维度 | 王者TI 语气 | 三角TI 语气 |
|------|------------|------------|
| 称呼 | "队友""峡谷" | **"兄弟""战区""战场"** |
| 自嘲风格 | 可爱式自嘲（"又是我来辅助"） | **硬核式自嘲（"又被蹲了 这游戏有毒"）** |
| 情绪色彩 | 温柔吐槽 | **直球互嘲、带点糙** |
| 梗密度 | 中等 | **高密度**（FPS 圈本身就是梗文化重灾区） |
| 参考语料 | 王者峡谷玩家社区 | **B站FPS区、三角洲行动贴吧、抖音FPS博主** |

```

  wtfHit:       // 一击命中的场景描写，让用户"卧槽这不就是我"

  symptoms:     // 5条"你有这些症状吗"清单
```

## 六、视觉风格规格

### 6.1 基底：充气乙烯手办 (Inflatable Vinyl Toy)

与班TI·HP / 王者TI**完全同源**的材质体系。

```
An inflatable oversized vinyl toy figure,
shiny smooth PVC plastic surface with glossy reflections
and subtle seam lines where inflatable sections meet.
The character has soft bulging proportions of a large
air-filled balloon figure — chunky rounded limbs,
slightly oversized head, everything looks pumped full of air.
Smooth glossy plastic skin with bright highlight reflections.
```

### 6.2 三角洲特化规则

| 规则 | 说明 |
|------|------|
| **视觉参考** | 军事装备元素（战术背心、头盔、night vision、枪械轮廓），但**Q化到充气玩偶级** |
| **抽象化处理** | 不复制任何三角洲行动游戏内的具体角色/皮肤/UI |
| **混搭日常元素** | 军事装备 + 日常道具混搭（泡面+战术背心、薯片+夜视仪） |
| **道具规则** | 2–3 个悬浮充气道具：一个军事向 + 一个生活向 = 反差萌 |
| **配色** | 偏**军事色系**（军绿、沙漠黄、深灰、暗红）但保持充气塑料的高饱和感 |
| **人物基本穿着** | 统一穿战术背心/军事外套，但充气膨胀化，看起来像气球人穿军装 |
| **绝对禁止** | 画面中出现任何文字、游戏 logo、真实枪械细节（简化为Q版道具） |

### 6.3 与王者TI的视觉区分

| 维度 | 王者TI | 三角TI |
|------|--------|--------|
| 色调 | 古风高饱和（紫金、粉紫、月白） | **军事暗调**（军绿、沙漠黄、枪钢灰） |
| 服装 | 古风铠甲/仙裙 | **战术背心/头盔/迷彩** |
| 道具 | 古风武器 + 奶茶手机 | **枪械配件 + 泡面薯片** |
| 情绪基调 | 峡谷趣味、软萌 | **硬核反差、军事萌** |
| 整体观感 | "Q版王者手办" | **"充气特种兵公仔"** |

### 6.4 Prompt 示例 — 蹲点大师 (sexy)

```
An inflatable oversized vinyl toy figure, shiny smooth PVC plastic surface
with glossy reflections and subtle seam lines. Soft bulging balloon proportions,
2.5 head-body ratio, pumped full of air look.

A soldier character in olive green tactical vest and oversized helmet
covering the eyes, crouching pose with both hands steady as if holding
a sniper rifle. Calm, patient expression with a tiny sly smirk.
Camouflage pattern on the puffy inflated vest in a cute, simplified style.

Floating inflatable props: a miniature ghillie leaf, a tiny "shhh" finger
gesture sign, a small crosshair reticle.

Clean single-color background (deep olive to dark green gradient).
Soft even studio lighting with bright highlight reflections on PVC surface.
The material is clearly shiny inflatable vinyl, NOT matte, NOT fabric.
ABSOLUTELY ZERO TEXT in the image.
```

## 七、题目设计方向

### 7.1 题目世界观

所有题目情境锚定在**三角洲行动玩家的日常**：

| 场景类型 | 示例题目方向 |
|---------|------------|
| **撤离决策** | "背包快满了，附近还有枪声，你？A)立刻撤 B)再舔一个 C)蹲着等" |
| **队友互动** | "队友倒了但距离很远，你？" |
| **武器改装** | "新赛季出了新枪，你？A)第一天就买 B)先看数据 C)等别人测完我再说" |
| **被击杀反应** | "被同一个人蹲了两次，你？" |
| **语音沟通** | "开黑时队友语音很吵，你？" |
| **通行证进度** | "赛季快结束了任务还没做完，你？" |

### 7.2 题型混合比例

遵循 [question-design-guide.md](question-design-guide.md) 的 6 种题型：

| 题型 | 占比 | 三角洲化示例 |
|------|------|-------------|
| 场景题 | 35% | "撤离点倒计时30秒，你包里有一把金M4和半管血…" |
| 填空题 | 15% | "你的三角洲搭档吐槽你最多的一句话是：___" |
| meme题 | 20% | "对面在语音里说'别跑 互相伤害啊'，你在想___" |
| 荒诞题 | 15% | "你穿越到三角洲世界发现自己是一个NPC…" |
| 盲选题 | 10% | "「消焰器」vs「补偿器」不给你思考时间 3秒选一个" |
| 标准题 | 5% | "你觉得蹲点是一种有效战术：同意/中立/不同意" |

### 7.3 语言示例

> **题目**：你在撤离模式里刚灭了一队，地上一大堆箱子闪闪发光。这时候你听到脚步声越来越近——
>
> A) 先舔完再说，死了也值了
> B) 拿最值钱的两件立刻跑
> C) 不管了，直接架枪等第三方

> **题目**：你的搭档给你的三角洲之旅写了一行墓志铭——
>
> A) "他很勇，但也很傻"
> B) "他蹲了一整局，很快乐"
> C) "他改枪改了十分钟，然后被踢了"

## 十、风险控制

| 风险 | 概率 | 对策 |
|------|------|------|
| **IP 侵权** | 中低 | 16 个干员作为隐式参考（operatorRef），不在 UI 显著展示；充气手办高度 Q 化 |
| **男性受众转化率低于预期** | 中 | 加大抖音投放（男性用户更集中）；联动 FPS 博主 |
| **与王者TI同质化** | 低 | 干员+行为双映射（三角TI）vs 纯英雄映射（王者TI），底层逻辑有差异 |
| **FPS 梗过于小众** | 低 | 三角洲行动已是国民级游戏；蹲点/莽夫等梗全民认知 |
| **图片风格混淆** | 中 | 军事色调做严格区分，王者TI是古风色 vs 三角TI是军事色 |
