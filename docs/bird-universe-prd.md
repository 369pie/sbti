## 一、为什么是鸟TI

### 1.1 赛道验证

| 论据 | 数据 |
|------|------|
| 需求已验证 | 3.3 万赞 + 2295 评论 = 用户非常想测，但无处可测 |
| 天然传播力 | "你是什么鸟" 比 "你是什么人格" 更有趣,更容易开口 |
| 鸟 = 天然圈子 | 观鸟圈/鸟类科普/萌宠圈/表情包圈 = 多圈层渗透 |
| 视觉天赋 | 鸟类低多边形 = 我们现有风格的天然延伸 |
| 谐音梗 | "禽况" = "情况"，"什么禽况" = "什么情况" — 自带语言病毒 |
| 场景丰富 | "你今天什么禽况" = 日常化表达，可衍生日签/心情 |

### 1.2 爆火底层拆解

这个测试为什么炸了？套用 SBTI 爆火的「四力模型」：

| 力 | 「什么禽况」怎么做到的 |
|---|----------------------|
| **标签力** | "你是一只乌鸦 · 大叫者" — 鸟类本身就是高辨识度标签，比抽象人格类型更具象 |
| **许可力** | 鸟 = 无攻击性自嘲载体（"我就是一只只会叫的乌鸦"比"我是 sb"更柔和但同样有效）|
| **货币力** | 低多边形鸟 + 一句话标语 = 截图即社交货币（跟 SBTI 同款逻辑）|
| **裹挟力** | "所有人都在测自己是什么鸟" = FOMO 效应 |

**第五力：鸟本身的 meme 基因**
- 鸟在中文互联网 = 天然表情包素材（鸽子、乌鸦、猫头鹰、鹦鹉…）
- 每种鸟自带刻板印象 = 不需要解释就能 get 到梗
- "鸟格" = "鸟 + 人格" 造词直觉好，读起来顺口

## 二、产品定义

### 2.1 模块定位

```
WTFTI 多宇宙架构：
├── 经典宇宙 (WTFTI Classic)
├── 社畜宇宙 (班TI)
├── 发疯宇宙 (疯TI / WTFTI 毒舌版)
├── 🆕 鸟类宇宙 (鸟TI) ← 本模块
├── 修仙宇宙 (仙TI)
└── ...后续扩展
```

### 2.2 核心差异：鸟格 ≠ 人格换皮

不同于班TI（人格换职场皮）、仙TI（人格换修仙皮），鸟TI 的核心创新是：

**将 29 种人格直接映射到 29 种真实鸟类。**

每种鸟不是随机分配的，而是基于鸟类的真实习性来映射人格特征：
- 乌鸦（记仇、聪明、群居、大嗓门）→ 映射高表达欲 + 高社交 + 强记忆的人格
- 猫头鹰（独居、夜行、冷静）→ 映射低社交欲 + 高洞察力的人格
- 鸽子（随遇而安、到处蹭吃）→ 映射佛系/躺平型人格
- 鹦鹉（模仿、话多、色彩斑斓）→ 映射高表达欲 + 社交蝴蝶型人格

**这种"真实生物习性 × 人格维度"的映射是核心知识资产。**

### 2.3 路由设计

```
/bird/                    → 鸟TI 落地页（鸟格星球视觉 + 入口）
/bird/test/               → 鸟TI 测试页（30 题鸟格倾向题）
/bird/result/[type]/      → 鸟TI 结果页（29 种鸟格详情 + 分享图）
/bird/types/              → 鸟格图鉴墙（29 种鸟全览）
```

## 三、29 种鸟格设计

### 3.1 鸟格映射原则

每种鸟格需满足：
1. **真实习性映射** — 鸟的行为特征与人格维度对应
2. **一听就懂** — 鸟名自带刻板印象（乌鸦=吵、鸽子=鸽、猫头鹰=智慧&独居）
3. **中国用户认知** — 选中国人熟知/能叫出名的鸟（不选学术冷门种）
4. **视觉差异化** — 29 种鸟在低多边形风格下辨识度高、颜色各异
5. **梗化潜力** — 每种鸟都能变成一句可传播的标签

### 3.3 鸟格命名公式

每个鸟格的「五件套」：

| ③ 代号 | 拟声词/叫声（全大写） | AHHH |
| ④ 一句话标语 | 10-20 字人格金句 | "无所谓，我会大叫。" |
| ⑤ 低多边形插画 | 几何纸艺风格鸟类全身像 | 黑色棱角乌鸦立姿 |

**命名风格：**
- 鸟格名称 = 动词化/状态化（大叫者、碎碎念、鸽王本鸽、开屏狂魔）
- 代号 = 该鸟类的拟声词或最具辨识度的声音/行为
- 标语 = 第一人称金句，用鸟的口吻说人话

## 四、题目设计

### 4.1 题量与维度

| 参数 | 值 |
|------|---|
| 总题数 | 30 题 |
| 维度 | 复用 WTFTI 15 维体系 |
| 每维度 | 2 题 |
| 选项数 | 3 选 1（A/B/C → 1/2/3 分）|

### 4.2 鸟格题目风格

**核心原则：题目里要有"鸟味"。**

不是把普通人格题换个鸟主题，而是让用户在答题过程中就觉得"好像真的在鸟的世界里"：

**示例题目（场景类）：**

> **Q: 你是一只刚睡醒的鸟，窝被风吹歪了。你的第一反应是？**
>
> A. 先把窝修好再说，不然今晚怎么睡（AC1-计划性 +3）
> B. 歪就歪吧，反正我也没啥东西（A1-世界观 +1）
> C. 去隔壁鸟窝蹭住一晚（SO1-社交欲望 +3）

**示例题目（梗类）：**

> **Q: 有只鸟在树枝上对你疯狂叫，你觉得它在说什么？**
>
> A. "这是我的地盘！滚！"（E3-边界 +3）
> B. "帅哥/美女你好好看啊！"（E2-情感投入 +3）
> C. "叫就叫了，不一定有什么含义吧"（S2-自我清晰度 +2）

**示例题目（荒诞场景类）：**

> **Q: 你被选为全森林鸟类大会的发言代表，你会？**
>
> A. 准备 PPT，排练 3 遍，提前 2 小时到（AC1 +3, AC2 +3）
> B. 飞上去说两句就行了，发挥嘛（SO2-表达欲 +3）
> C. 装死，假装翅膀受伤了来不了（SO1 +1）

**题型配比（遵循 question-design-guide）：**
| 类型 | 数量 | 占比 |
|------|------|------|
| 鸟世界场景题 | 10 | 33% |
| 鸟梗/拟声词题 | 4 | 13% |
| 荒诞鸟场景 | 4 | 13% |
| 填空续写题 | 4 | 13% |
| 盲选题 | 2 | 7% |
| 标准态度题 | 6 | 20% |

## 五、视觉设计

### 5.1 鸟格插画风格

**直接沿用 SBTI 核心视觉语言：低多边形纸艺风格（Low-Poly Paper Craft）。**

从竞品截图看，「什么禽况」用的也是低多边形鸟类插画——这**不是巧合**，而是因为这个风格天然适合鸟类：
- 鸟的体型轮廓（喙、翅膀、爪子）在几何化后辨识度极高
- 不同鸟种的颜色差异大（黑/白/红/蓝/绿），图鉴感很强
- 纸艺质感 + 鸟 = 折纸鸟 = 在中国文化中自带的童年记忆和美感

**与竞品的差异化：**
| 竞品（什么禽况） | 我们（鸟TI） |
|-----------------|-------------|
| 只有单张结果图 | 完整测试流程 + 互动体验 |
| 静态图文 | 动态网页 + 维度雷达图 |
| 无法实际测试 | 30 题科学评分 |
| 无分享卡片系统 | 奶油卡+QR 分享闭环 |
| 鸟种有限（第一期+第二期） | 一次性发布 29 种鸟格图鉴 |
| 无社交玩法 | 后续可接入 CP 鸟配对 |

```typescript
  /** 一句话标语 */
  tagline: string;
  /** 3 个鸟格标签（emoji + 短语） */
  tags: [string, string, string];
  /** 鸟格金句 */
  quote: string;
  /** 主色 */
  color: string;
  /** emoji */
  emoji: string;
  /** 四段式文案 */
  copy: {
    opening: string;    // "恭喜您" 开头的荒诞开场
    strengths: string;  // 鸟格优势（用鸟的习性来描述人的优点）
    weaknesses: string; // 鸟格弱点（用鸟的缺陷来自嘲）
    relationships: string; // 与其他鸟格的关系
  };
  /** 映射逻辑（鸟类习性如何对应人格维度） */
  mappingNote: string;
}
```
