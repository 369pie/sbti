# CPTI 结果页 / 关系页“认领资产”登录转化方案与文案稿

> 日期：2026-04-15
> 状态：Draft v1
> 目标：在不打断 `CPTI` 主流程的前提下，把结果页与关系页变成账号化与留存的转化入口
> 相关页面：
> - `src/app/cpti/result/[type]/CptiResultContent.tsx`
> - `src/app/cpti/relationship/CptiRelationshipResult.tsx`
> - `src/app/card/CardContent.tsx`

---

## 0. 先给结论

`CPTI` 的登录转化，不应该做成“注册页”，而应该做成：

> **认领资产。**

也就是说，用户点的不是：

- 注册
- 登录

而是：

- 保留这份结果
- 把这段关系收进 `WTF CARD`
- 认领我的总图鉴谱

这两个页面的核心动作优先级应该是：

### 结果页

1. 看懂“我是什么角色”
2. 分享 / 邀请他人参与
3. 认领这份结果到 `WTF CARD`

### 关系页

1. 看懂“我们是什么关系”
2. 复制回传 / 分享
3. 认领这段关系到 `WTF CARD`

因此：

- 认领 CTA 不能早于结果出现
- 认领 CTA 不能打断分享动作
- 认领 CTA 必须用“保存价值”的语言，而不是“完成认证”的语言

---

## 1. 用户心理与转化时机

## 1.1 为什么这时转化最有效

用户在这两个页面上的心理不是“我要登录”，而是：

- 这份结果我不想丢
- 这段关系我想保留
- 我已经解锁了某种价值
- 如果以后还能继续累计，会更有意思

所以最有效的触发，不是在开始测试前，而是在：

- 情绪峰值之后
- 用户已经确认结果有价值之后

## 1.2 不该做的事

- 不在答题中途弹登录
- 不在首页先要求注册
- 不在邀请前把登录设成门槛
- 不把“快速分享”替换成“登录保存”

增长主链还是：

> 先测出结果 -> 先完成分享/配对 -> 再把资产认领到账号

---

## 2. 状态机

页面文案和 CTA 不能一套写死，必须跟身份状态走。

## 2.1 State A：Local Guest

定义：

- 没有 Supabase session
- 结果还只在本地

文案目标：

- 告诉用户“这份结果可以保住”

按钮方向：

- `认领这份结果`
- `保存到 WTF CARD`

## 2.2 State B：Anonymous Asset User

定义：

- 已匿名保存到云端
- 还没绑定正式账号

文案目标：

- 告诉用户“你已经保住了，现在可以把它认到正式账号”

按钮方向：

- `已保存，继续认领账号`
- `绑定邮箱/微信`

## 2.3 State C：Claimed User

定义：

- 已完成正式登录

文案目标：

- 引导继续探索与收集

按钮方向：

- `已同步到我的 WTF CARD`
- `去看我的总图鉴`
- `继续解锁更多关系`

## 3. 结果页方案

## 3.1 页面位置建议

最适合放的位置：

- Hero 结果区块内
- 角色名 / rarity 之后
- `角色速写` 之前

原因：

- 这是“我在关系里是什么角色”的情绪峰值
- 用户还没被后续模块分流
- 也还没离开页面去分享或 cross-test

次优位置：

- 五维画像之后
- 分享区之前

不建议的位置：

- `CptiQuiz` 内
- 结果页太靠下、等用户已经开始分享以后
- InviteAndStealthCTA 里面作为唯一登录入口

## 3.2 模块形态

建议采用：

- 一张轻量 inline asset card
- 不是全屏 modal
- 支持直接跳过

结构：

- 标题
- 1 行价值文案
- 主按钮
- 次按钮
- 小字说明“先继续分享也可以”

## 3.3 结果页文案稿

### Variant A：偏“结果保留”

标题：

`认领这份 CPTI 结果`

正文：

`收进你的 WTF CARD，换设备也不会丢。以后再来配对、收集图鉴，都会继续累计。`

主按钮：

`保存到 WTF CARD`

次按钮：

`先继续分享`

辅助说明：

`不影响你继续发给 ta 配对。`

### Variant B：偏“图鉴累计”

标题：

`先把这个角色收起来`

正文：

`登录后可永久保留这份 CPTI 角色卡，并同步到你的总图鉴谱。`

主按钮：

`认领这份结果`

次按钮：

`稍后再说`

### Variant C：偏“账号心智更弱”

标题：

`这份结果可以永久保留`

正文：

`先认领到你的 WTF CARD，下次回来不用重测，还能继续收集关系图鉴。`

主按钮：

`立即保留`

次按钮：

`先看看别的角色`

## 3.4 结果页二次提示

当用户完成“生成邀请链接 / 六位码”后，可以加一条更轻的提醒：

`认领后，你后面解锁的关系会自动收进同一个 WTF CARD。`

按钮：

`去认领`

这条只适合：

- 已经触发邀请动作
- 但还未认领的用户

## 4. 关系页方案

## 4.1 页面位置建议

最适合放的位置：

- Hero 内
- 关系名 / tier / 契合度之后
- `关系速写` 之前

这是整个链路里最强的账号化节点。

因为用户刚得到的不是单人结果，而是：

- 我和某人的一段关系命名
- 一段更稀缺、更不想丢的资产

## 4.2 为什么关系页要更强推

关系页比结果页更适合强推的原因：

- 情绪价值更高
- 收藏价值更高
- 稀缺性更强
- 与榜单和关系图鉴直接相连

所以关系页可以用比结果页更明确的价值表达。

## 4.3 关系页文案稿

### Variant A：偏“关系保留”

标题：

`把这段关系收进你的 WTF CARD`

正文：

`认领后可永久保留这次匹配、累计关系图鉴，并继续统计你的灵魂伴侣数和稀有关系数。`

主按钮：

`认领这份关系`

次按钮：

`先复制回传链接`

### Variant B：偏“图鉴与榜单”

标题：

`这段关系已经生成`

正文：

`登录后，这次匹配会同步到你的关系图鉴和总图鉴谱，后面还能上榜、继续收集。`

主按钮：

`登录并同步`

次按钮：

`先看看图鉴`

### Variant C：偏“轻一点”

标题：

`这次匹配可以保留下来`

正文：

`先认领到你的 WTF CARD，之后和不同人配对时，系统会继续帮你累计。`

主按钮：

`先保留下来`

次按钮：

`先继续分享`

## 4.4 `fromLink` 场景特殊文案

当用户是通过回传链接打开关系页时，文案要更明确：

标题：

`把这段关系同步到你的卡片`

正文：

`认领后，你看到的这段匹配会收进自己的 WTF CARD，并计入你的关系图鉴。`

主按钮：

`同步到我的 WTF CARD`

次按钮：

`先只看结果`

## 5. 交互流程

## 5.1 Local Guest 点击主按钮

### 行为

1. 静默 anonymous sign-in
2. 调 `/api/cpti/claim`
3. 同步本地结果/关系到云端
4. 把 CTA 状态切成“已匿名保存”

### 成功反馈

toast：

`已保存到你的临时 WTF CARD`

页内 success card：

标题：

`这份资产已经保住了`

正文：

`现在去绑定邮箱 / 微信，之后换设备也能继续看。`

主按钮：

`继续认领账号`

次按钮：

`去看我的 WTF CARD`

## 5.2 Anonymous Asset User 点击主按钮

### 行为

打开 bottom sheet：

- 邮箱
- 手机
- OAuth

### 成功反馈

toast：

`已认领到你的正式账号`

页内 success card：

标题：

`已同步到你的 WTF CARD`

正文：

`之后的新关系、新图鉴和排行榜记录都会继续累计。`

主按钮：

`去看我的总图鉴`

次按钮：

`继续解锁更多关系`

## 5.3 Claimed User

不再展示“登录保存”。

改为展示：

- `已同步到 WTF CARD`
- `去看我的总图鉴`
- `继续邀请更多人配对`

## 6. 不打断主流程的规则

## 6.1 分享按钮仍然保留最强可见度

结果页：

- `复制分享文案`
- `复制链接`
- `快速分享`

关系页：

- `复制回传链接`
- `复制分享文案`
- `复制链接`

这些增长动作都不能因为登录转化而消失。

## 6.2 认领卡片不抢主视觉

建议视觉等级：

- 比分享区轻
- 比英雄结果弱一级
- 但比底部普通 CTA 强

## 6.3 不用“注册/登录”做主词

尽量少写：

- 注册
- 登录

多写：

- 认领
- 保存
- 同步
- 收进 `WTF CARD`
- 保留这段关系

## 9. 页面级实现建议

## 9.1 `CptiResultContent`

推荐插入位置：

- Hero 区 `tagline` 后
- 或五维画像区块后、分享区前

后续按钮状态：

- `Local Guest`：`保存到 WTF CARD`
- `Anonymous`：`继续认领账号`
- `Claimed`：`去看我的总图鉴`

## 9.2 `CptiRelationshipResult`

推荐插入位置：

- Hero 区 `tier/compatibility` 后
- `关系速写` 前

如果 `fromLink = true`：

- 文案切成“同步到我的 WTF CARD”

## 9.3 `CardContent`

认领完成后，必须让用户在 `WTF CARD` 里能看见：

- `CPTI` 结果 slot
- 关系图鉴变化

否则“认领资产”这件事的承诺会落空。

当前仓库里还有一个先要修掉的感知问题：

- `CPTI` 已经会写入卡片结果
- 但 `resolvePersonality()` 里没有 `cpti` 分支

所以在真正强推“认领资产”前，至少要先保证：

- `CPTI` 在 `WTF CARD` 里能正确显示
- 认领后用户能立刻看到资产变化

---

## 10. 一句话版本

这套转化设计的核心不是“怎么让用户登录”，而是：

> **在用户最不想丢结果的时刻，让他顺手把价值认领下来。**
