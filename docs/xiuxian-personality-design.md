# 修仙萌物图鉴 — 36 人格全设定表

> 世界观：在一个叫"人间修仙界"的平行小世界里，住着 36 种小妖怪/灵兽/灵植/器灵。它们各有各的修炼方式、看家法术和离谱的修仙经历。每个人类灵魂都对应一种灵物——你以为你在做人格测试？不，你在认领你的本命灵体。

## 修为境界体系（搞笑版）

| 稀有度 | 对应境界 | 吐槽注释 |
|--------|---------|---------|
| 传说级 | 大乘期 | 马上渡劫飞升了——但天劫已经劈了 108 次还没劈死 |
| 超稀有 | 元婴期 | 元婴已结，就是长得比较抽象 |
| 稀有 | 金丹期 | 丹是结了，歪的 |
| 较少见 | 筑基期 | 地基打了，偏了 30 度 |
| 常见 | 炼气期 | 气倒是在炼，就是不知道炼的是灵气还是废气 |

### 女性向设计重点

1. **高分享欲 TOP 6**（首批推广优先）：
   - 🦊 媚灵狐·引（SEXY）— "啥也没做路过就有人心动"，女生最爱自居
   - 🌸 花灵·春（LOVE-R）— 少女感拉满，头顶永远开花
   - 💧 泪灵·雨（EMO）— 共鸣度最高，"我就是这样"
   - 🐚 缩壳灵·躲（SHY）— i人直呼内行
   - 🌿 躺平仙草·卧（Dior-s）— 搞笑度最高，十万年没挪窝
   - 🐕 护主灵犬·不离（SIMP）— 自嘲型，制造讨论

2. **每个灵物必须满足**：
   - 画出来想保存到手机相册 ✓
   - 一句话就能让人联想到自己 ✓
   - 发到群里朋友会 @ 另一个人 ✓
   - 配上名字就能当头像/壁纸 ✓

3. **古风美术关键词统一规范**：
   - 整体基调：水墨淡彩 × Q版圆润 × 贱萌表情
   - 衣着：缩小版汉服/道袍/仙门弟子服，但歪歪扭扭穿不对
   - 法宝：每个角色有一件标志性法宝握在手里
   - 背景：纯白/极简仙雾，不要复杂背景（保证截图分享效果）
   - 表情是重点：贱萌 > 可爱 > 酷 > 严肃（严肃不要）
   - 线条：圆润饱满，没有尖锐棱角
   - 色彩：每个角色有专属2色（见每条设定的视觉关键词）

### 修仙体描述文案风格

统一开头模板：
> "恭喜施主渡劫成功——" 或 "恭喜，天道已确认你的灵体为——"

统一叙事手法：
- 用"修仙世界的逻辑"翻译"现代人的日常行为"
- 例：摸鱼="在瑶池打杂"，社恐="对群体法术过敏"，emo="以泪修道"
- 保持"荒诞文学"基调——越正经越好笑
- 拒绝鸡汤、拒绝说教，结尾可以留一句温柔的反转
