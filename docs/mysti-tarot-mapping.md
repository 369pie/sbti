# 灵鉴 · 29 型人格 × 22 张大阿卡纳映射规则

> *"人格是灵魂的面具，塔罗是潜意识的镜子。当 WTFTI 的 29 种灵魂振动遇见大阿卡纳的 22 道原型之光，映照出的不只是你是谁，还有你尚未认领的那部分自己。"*

---

## 一、映射理念概述

「灵鉴」模块并不试图用塔罗"预测"你的未来，而是借由 22 张大阿卡纳的古老符号系统，为每一种 WTFTI 人格提供一个**神秘学视角的镜像**：

- **主牌（Major Arcana）**：代表你外显的能量特质——你最像哪一张牌，你的灵魂以什么样的频率振动。
- **Shadow 牌**：代表你的潜意识或隐藏面——那张你不太愿意承认、却又在深夜悄然浮现的牌。
- **灵鉴副标语**：一句比 tagline 更神秘学化的短句，用于灵鉴结果卡片的副标题，兼具氛围感与传播性。

映射逻辑基于以下能量维度的统一分组：
- **控制与秩序**（权威、计划、效率）
- **情感与付出**（关怀、牺牲、联结）
- **独处与内省**（内向、观察、边界）
- **表达与创造**（沟通、表演、心流）
- **反叛与打破**（反骨、颠覆、看透）
- **享乐与沉溺**（感官、欲望、躺平）
- **幸运与松弛**（顺势而为、乐观、无为）

由于 29 型人格多于 22 张牌，部分大阿卡纳会对应多个人格——这不是随意的"共享"，而是同一原型在不同人格身上的**光谱显化**。

## 四、映射逻辑说明

### 4.1 主牌分配原则

主牌的分配遵循**能量原型匹配**而非字面联想。例如：
- **BOSS** 与 **CTRL** 都带有强烈的控制欲，但 BOSS 更偏向"统御与权威"（皇帝），CTRL 更偏向"执行与推进"（战车）。
- **MUM**、**SEXY**、**FOOD-IE** 共享皇后牌，分别对应皇后的三种丰饶面向：**母性滋养**、**魅力吸引**、**感官享受**。
- **SOLO** 与 **SHY** 共享隐者牌，但 SOLO 是"主动选择的孤独智慧"，SHY 是"被动防御的内向观察"。
- **GAME-R** 被授予世界牌，因为"肝帝"的本质是对"完成感"的追逐——世界的通关与圆满，正是心流体验的神秘学隐喻。

### 4.2 Shadow 牌设计逻辑

Shadow 牌的选取遵循**对立与压抑**原则：
- 通常是主牌能量的**过度延伸**或**被压抑的反面**。例如：
  - 恋人（SIMP）的过度投入 → 恶魔（失去自我的沉溺）
  - 太阳（PARTY）的过度外放 → 隐者（散场后的孤独空虚）
  - 隐者（SHY）的过度退缩 → 太阳（对社交光芒的渴望与恐惧）
- Shadow 不是"坏牌"，而是**人格尚未整合的潜能**。当用户看到自己的 Shadow 时，我们希望传递的信息是：*"这不是你的缺陷，这是你还没认领的力量。"*

### 4.3 灵鉴副标语风格指南

灵鉴副标语在 WTFTI 原有 tagline 的基础上，向以下方向转化：
- **意象化**：用自然或神秘学意象替代直白描述（如"丰饶之土，忘了给自己浇水"替代"全世界都管了，除了自己"）。
- **对立张力**：在主牌与 Shadow 之间制造诗意冲突（如"王座之上，风暴无声"——皇帝的稳定 vs 塔的崩塌）。
- **年轻化语气**：避免过度玄学腔，保留"可以发朋友圈"的传播性（如"心跳是鼓点，理性是失踪的乐谱"）。

### 4.4 塔罗牌复用说明

22 张大阿卡纳对应 29 种人格，**7 张牌被复用**，复用逻辑如下：

| 主牌 | 复用人格 | 复用逻辑 |
|:---|:---|:---|
| **皇后** | MUM / SEXY / FOOD-IE | 母性滋养 / 魅力丰饶 / 感官享受，共享"丰饶"原型 |
| **恋人** | SIMP / LOVE-R | 全情投入的爱 / 高频心动感知，共享"联结"原型 |
| **隐者** | SOLO / SHY | 主动独处智慧 / 被动内向观察，共享"孤独"原型 |
| **命运之轮** | CHILL / LUCK-Y | 顺势而为的松弛 / 周期中的好运，共享"流动"原型 |
| **正义** | OH-NO / WOC! | 灾难预判的清醒 / 旁观吃瓜的洞察，共享"观察者"原型 |
| **愚者** | DRUNK / JOKER | 酒后放下束缚 / 小丑隐藏悲伤，共享"面具下的真实"原型 |
| **魔术师** | TALK-er | 言语即魔法，单独使用但代表沟通的显化力 |

其余 15 张牌均为**一对一专属映射**，以保证每张牌的独特能量不被稀释。

## 五、结语

> *"29 种人格是 29 扇门，22 张大阿卡纳是 22 把钥匙。不是每一扇门都只有一把钥匙，也不是每一把钥匙只能开一扇门。灵鉴要做的，是帮你在推门之前，先看看门上的纹路——以及门后那道，你熟悉又陌生的光。"*

本映射规则为「灵鉴」模块的**内容规范文档**，后续如需新增人格或调整牌意，应遵循上述能量分组与 Shadow 设计逻辑，保持整体神秘学叙事的一致性。
