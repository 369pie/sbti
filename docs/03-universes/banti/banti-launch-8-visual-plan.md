> 目标：先做一批最容易在小红书被截图转发的班TI卡图，不追求一次做完 29 张，先把“社畜宇宙”的脸打出来。

## 一、首发策略

- 首发批次先上 8 张，覆盖“管人 / 被管 / 混日子 / 社交 / 反骨 / 边界感”六类高共鸣办公室情绪。
- 视觉切换到 `Clean flat geometric + 纯色 / 简单背景`，主动拉开与 WTFTI 经典 3D 玩具感的差异。
- AI 负责生成“角色主视觉插画”，卡面文字结构由站内代码统一排版，避免 AI 直接生成错字或不好看的版式。
- 卡面文案统一结构：中文名 → 4 字母代号 + backronym → 一句话 → 3 个 emoji 标签 → 底部金句。

## 二、统一视觉方向

- 风格：Clean flat geometric / Editorial Flat，2D 几何色块人物，不要 3D，不要纸艺，不要材质感。
- 角色：半身或三分之二身优先，只要人物辨识度更强；不强求全身。
- 背景：纯色或极简背景，只用 1 到 2 个形状建立空间，不做复杂房间透视。
- 色彩：每张卡一个主色调，大面积铺底，再用 1 到 2 个强调色点题。
- 排版感：像“杂志专题页”而不是“角色海报”，要有留白和信息层级。
- 传播点：别人滑过时 1 秒能看懂人设，3 秒能记住颜色和轮廓。

## 四、单张卡图细化要求

### 1. 人形甘特图 `boss`
- 姿势：身体前倾，一手指向空中漂浮的排期表，一手捏着红笔。
- 表情：不是愤怒，是“我已经提前替你着急了”的高压控制感。
- 道具：甘特图、倒计时钟、checklist 三件套必须同框，但都要图标化、扁平化。

### 2. 人形KPI `ctrl`
- 姿势：站得非常正，像一根被拉直的考核尺。
- 表情：轻微抬眉，像刚看完别人做的表。
- 道具：对勾清单、流程图、秒表；画面要有“精准到分钟”的规整感。

### 3. 操心项目办 `mum`
- 姿势：双手抱满东西，身体微微塌，但还在往前冲。
- 表情：嘴在安慰别人，眼下已经有黑眼圈。
- 道具：药盒、充电线、热水杯、会议纪要，突出“别人缺啥她都有”。

### 4. HR头痛源 `rebel`
- 姿势：踩着半卷员工手册，手势干脆利落。
- 表情：不是坏，是“不服且懒得装服”。
- 道具：考勤卡、规章制度、警告便签，读图重点是“制度天敌”。

### 5. 茶水间情报局 `party`
- 姿势：身体前倾在说悄悄话，另一只手稳稳端着咖啡。
- 表情：热情、发光、信息量巨大。
- 道具：咖啡杯、聊天气泡、信息卡片，全部做成简洁几何符号。

### 6. 会议隐形人 `shy`
- 姿势：缩在会议椅边缘，像一团尽量不占空间的空气。
- 表情：有点紧张，有点想发言，但还是没举手。
- 道具：静音图标、未开麦耳机、小小姓名牌，强化“存在感过低”。

### 7. 准点蒸发器 `chill`
- 姿势：半转身冲向画外，背包已经背好，脚步带风。
- 表情：不是快乐，是一种“总算活过来了”的轻松。
- 道具：18:00 时钟、电梯上行箭头、工牌甩动轨迹。

### 8. 班味代言人 `malo`
- 姿势：工位站着，身体在这，魂已经去地铁上了。
- 表情：空、麻、疲惫但习惯了。
- 道具：地铁扶手、外卖袋、皱掉的工牌、电脑包；要有“通勤末班车”质感。

## 五、执行方式

- 提示词资产：见 [scripts/banti-launch-prompts.mjs](../../../scripts/banti-launch-prompts.mjs)
- 生成命令：`npm run images:banti-launch -- all --dry-run`
- 小批量试跑：`npm run images:banti-launch -- boss mum party malo`
- 生成方式：`text-to-image`，不再使用旧的低多边形参考图做风格锚点。
- 建议先 dry run 审 prompt，再挑 2 张试生图。
- 第一轮建议顺序：`boss` → `mum` → `party` → `malo`。
- 这 4 张如果张力够，剩余 4 张再批量扩。

- 缩略图：后续统一生成到 `/public/images/types/banti/thumbs/{slug}.webp`。
