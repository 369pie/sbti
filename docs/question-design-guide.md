# SBTI 题目设计规范

> 本文档用于指导所有 SBTI 产品线（人格测试 / 职场测试 / CP 测试等）中  
> **题目（Question）与选项（Option）** 的内容设计，确保风格统一、品牌调性一致。

---

## 1. 核心原则

| 原则 | 说明 |
|------|------|
| **整活优先** | SBTI 定位「娱乐向人格测试」，答题过程本身要好玩，而不是像做卷子。 |
| **拒绝千篇一律** | 禁止所有题都用「认同 / 中立 / 不认同」。每道题的选项必须**量身定制**。 |
| **真实 > 抽象** | 场景化的选项比抽象的态度量表更能暴露用户真实倾向。 |
| **可截图传播** | 好题目 = 用户看到就想截图发给朋友的题目。 |

---

## 2. 题目类型分类（至少混用 3 种以上）

### 2.1 情景题（Scenario）
把维度藏在具体场景里，用户根据本能做选择。

```
题目：对象超过5小时没回消息，说自己窜稀了，你会怎么想？
A - 拉稀不可能5小时，也许 ta 隐瞒了我。
B - 在信任和怀疑之间摇摆。
C - 也许今天 ta 真的不太舒服。
```

**设计要点：**
- 场景要具体到细节（"5小时""窜稀"），越具体越有代入感
- 三个选项对应维度的 L / M / H 三档
- 选项措辞要像用户**自己会说的话**

### 2.2 填空题（Fill-in）
题干留空，选项补完整句。

```
题目：我做事常常有计划，____
A - 然而计划不如变化快。
B - 有时能完成，有时不能。
C - 我讨厌被打破计划。
```

**设计要点：**
- 题干结尾用逗号或破折号，暗示未完成
- 选项是对题干的自然续写

### 2.3 玩梗题（Meme）
用互联网梗、流行文化、夸张文案制造笑点。

```
题目：我不仅是屌丝，我还是 joker，我还是咸鱼，这辈子没谈过……（长段自嘲文案）
A - 我哭了。。
B - 这是什么。。
C - 这不是我！
```

**设计要点：**
- 题目可以很长（制造荒诞感），但选项一定要短
- 需要紧跟当下互联网语境，定期更新
- 不要低俗，要有梗但不冒犯

### 2.4 荒诞场景题（Absurd）
用戏剧性或荒谬的场景让用户放下戒备。

```
题目：你因便秘坐在马桶上已长达30分钟，此时你更像——
A - 再坐三十分钟看看，说不定就有了。
B - 用力拍打自己的屁股并说：「死屁股，快拉啊！」
C - 使用开塞露，快点解决才好。
```

**设计要点：**
- 场景越离谱越好，但仍然要能映射到某个维度
- 选项反映真实的行为倾向差异

### 2.5 盲选题（Blind Pick）
没有题干或故意模糊，测试决策风格。

```
题目：此题没有题目，请盲选。
A - 反复思考后感觉应该选 A？
B - 啊，要不选 B？
C - 不会就选 C，闭眼冲了。
```

**设计要点：**
- 只能用 1 道，位置放在中后段
- 选项本身就在暗示用户的决策风格

### 2.6 标准态度题（Standard） — 作为补充
极少数题可以使用「认同 / 中立 / 不认同」格式，但占比不超过 **20%**。

```
题目：我渴望和我信任的人关系密切，熟得像失散多年的亲戚。
A - 认同
B - 中立
C - 不认同
```

**使用条件：**
- 题干本身已经足够有趣 / 有画面感
- 该维度不好用场景表达

## 3. 选项设计铁律

### 3.1 三原则

| 规则 | ✅ 正确示范 | ❌ 错误示范 |
|------|-----------|-----------|
| **像人话** | "我能纠结到宇宙热寂。" | "我的决策倾向偏犹豫型。" |
| **有性格** | "必须的，生命不息卷不止。" | "非常认同此观点。" |
| **短而有力** | "三秒决定，绝不回头。" | "我通常能在较短时间内做出决策，且不会反复修改。" |

### 3.2 映射关系

所有选项必须与维度打分对应。三选项结构下：

| 选项位 | 含义 | 打分 |
|--------|------|------|
| A 选项 | 维度低分端（或反转题的高分端） | `value: 1` 或 `value: 3`（反转） |
| B 选项 | 中间态 | `value: 2` |
| C 选项 | 维度高分端（或反转题的低分端） | `value: 3` 或 `value: 1`（反转） |

**注意：** `value` 值代表计分，不是显示顺序。反转题在 Question 上标 `reversed: true`。

### 3.3 反转题设计

反转题的选项 `value` 在数据层直接写出实际计分值，与 `reversed` 标记配合使用。

```ts
{
  id: 1,
  text: '我不够好，周围的人都比我优秀。',
  reversed: true,
  options: [
    { value: 3, label: '确实，我经常这么觉得。', key: 'A' },  // 高分 = 该维度低
    { value: 2, label: '偶尔吧，看状态。', key: 'B' },
    { value: 1, label: '谁说的？我觉得我还挺行的。', key: 'C' },  // 低分 = 该维度高
  ],
}
```

## 4. 语气与调性

### 4.1 品牌人设
SBTI 的语气像是**一个会整活但不油腻的互联网朋友**。

| 维度 | 偏好 |
|------|------|
| 正式 ← → 口语 | ████████░░ 偏口语 |
| 严肃 ← → 戏谑 | ███████░░░ 偏戏谑 |
| 精悍 ← → 啰嗦 | ██░░░░░░░░ 精悍，但偶尔在玩梗题放长 |
| 冒犯 ← → 安全 | ░░░████░░░ 有梗但不冒犯 |

### 4.2 用词规范
- ✅ 可以用：ta、整活、窜稀、摸鱼、苟、梭哈、蓝屏、口嗨
- ❌ 避免：脏话（含谐音）、涉及种族/性别/地域歧视的梗、过时超过 2 年的梗
- ⚠️ 慎用：网络黑话需确认目标受众能看懂

## 5. 数据结构约定

### 5.1 Question 接口

```ts
interface Question {
  id: number;           // 唯一 ID
  text: string;         // 题干文案
  dimension: string;    // 维度 ID (S1, E2, W3...)
  model: ModelType;     // 所属模型
  reversed: boolean;    // 是否反转计分
  options?: AnswerOption[];  // 自定义选项（无则回退默认）
  isDrinkTrigger?: boolean;  // 触发隐藏分支
  isDrinkBranch?: boolean;   // 隐藏分支题
}

interface AnswerOption {
  label: string;        // 选项文案
  value: 1 | 2 | 3;    // 计分值
  key: string;          // 快捷键 & 显示字母 (A/B/C/D)
}
```

### 5.2 默认选项回退

如果 Question 没有 `options` 字段，组件会使用默认选项：
```ts
const DEFAULT_OPTIONS = [
  { value: 1, label: '不认同', key: 'A' },
  { value: 2, label: '中立',   key: 'B' },
  { value: 3, label: '认同',   key: 'C' },
];
```

但**新题应当尽量都提供自定义 options**，默认选项仅作兜底。

## 6. 配比建议

一套 30 题的测试，建议类型配比：

| 类型 | 数量 | 占比 |
|------|------|------|
| 情景题 | 8–10 | 27–33% |
| 填空题 | 3–4 | 10–13% |
| 玩梗题 | 3–4 | 10–13% |
| 荒诞场景题 | 3–4 | 10–13% |
| 盲选题 | 1 | 3% |
| 标准态度题 | 5–6 | 17–20% |
| 触发/分支题 | 1–2 | 3–7% |

## 7. 新增题目 Checklist

为新产品线设计题目时，逐条检查：

- [ ] 每道题题干读完后，能让人笑或产生"这说的是我"的感觉
- [ ] 选项像朋友聊天时会说的话，不像心理量表
- [ ] 三个选项之间有明确的维度梯度差异
- [ ] 至少混用了上述 3 种以上题型
- [ ] 标准态度题占比 ≤ 20%
- [ ] 玩梗题的梗确认没有过时
- [ ] 选项的 `value` 与维度方向对应正确
- [ ] 反转题的 `reversed` 标记已设置
- [ ] 读出声朗读一遍，确认不拗口

## 8. 示例评审

**Bad:**
```
题目：我认为自己的社交能力较强。
A - 不认同  B - 中立  C - 认同
```
**问题：** 太正经，像调查问卷，用户答完就忘了。

**Good:**
```
题目：茶水间遇到不太熟的同事，你会？
A - 假装看手机，避免眼神接触。
B - 点头微笑，礼貌但不展开。
C - 主动搭话，「哟，今天喝什么？」
```
**优点：** 场景具体有画面感，选项有性格差异，读完会心一笑。
