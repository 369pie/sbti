## Phase 1: 定位 & 市场语境

### 1.1 Geoffrey Moore 定位声明

**价值主张：**

> **For** 18-30岁中国女性用户，主要在小红书/微信/抖音活跃
> **that need** 一种低门槛、高情绪价值的方式来理解自己、表达自我、制造社交谈资
> **WTFTI（WTF我居然是这种人）**
> **is a** 多宇宙人格测试娱乐平台
> **that** 通过 10+ 个风格迥异的主题宇宙（修仙、鸟格、花语、恋爱XP、职场等）让同一个人格呈现出无限面向，每次测试都能产出一张"值得保存和分享"的人设卡

**差异化声明：**

> **Unlike** MBTI（过于严肃/理性）、16personalities（纯文字/英文）、趣测类小程序（一次性/视觉粗糙）
> **WTFTI**
> **provides** 一个持续收集、不断解锁新宇宙的"人格图鉴游戏"体验，用自嘲幽默 + 精致插画 + 病毒式命名（"sb测试"语言病毒）让人格测试从"测一次、发一次、走人"变成"每个宇宙都想测、每张卡都想存、每个结果都想发"

**定位压力测试：**

| 检验维度 | 结果 | 状态 |
|---------|------|------|
| 目标用户能认出自己？ | ✅ 小红书做人格测试的女生 = 清晰 | Pass |
| 需求有证据支撑？ | ✅ "什么禽况" 3.3万赞 = 品类热度验证 | Pass |
| 品类锚定明确？ | ⚠️ "多宇宙人格测试平台"概念新，需教育 | 需优化 |
| 差异化可证明？ | ✅ 10个宇宙实打实存在，视觉风格完全不同 | Pass |
| 能指导取舍？ | ✅ "不是严肃心理测评" = 自动过滤功能边界 | Pass |

### 1.2 Proto-Personas

#### Persona A: 「社交货币型」小红书女孩
- **年龄**: 20-26岁，大学生/职场新人
- **行为**: 首页刷到测试 → 做完 → 截图 → 发朋友圈/小红书/微信群 → "你也来测测"
- **核心JTBD**: "给我一块新的社交货币，让我能在群聊里有话题"
- **情感需求**: 被看见 + 自嘲安全感 + 轻松感
- **触发场景**: 刷小红书看到朋友发了测试结果 → FOMO → 立即扫码测
- **忠诚度驱动**: 新宇宙上线 = 新话题可发

#### Persona B: 「自我探索型」精神女孩
- **年龄**: 22-30岁，文艺/神秘学爱好者
- **行为**: 认真做测试 → 细读结果描述 → 比对不同宇宙的差异 → 收藏结果 → "这也太准了吧"
- **核心JTBD**: "帮我理解自己，用好看又准确的方式"
- **情感需求**: 被理解 + 自我确认 + 收集感
- **触发场景**: 深夜emo → 搜"人格测试" → 找到WTFTI → 连做3个宇宙
- **忠诚度驱动**: 完整度（27/27 收集全）+ 准确度（"比MBTI准"）

#### Persona C: 「关系互动型」社交连接者
- **年龄**: 18-28岁
- **行为**: 收到CP链接 → 做测试 → 看对比结果 → 再发给另一个朋友 → 病毒链传播
- **核心JTBD**: "通过测试结果，跟朋友/暗恋对象产生话题连接"
- **情感需求**: 亲密证明 + 互动乐趣 + 暧昧工具
- **触发场景**: 收到朋友发的"帮我鉴定" → 做完鉴定 → 自己也测一个
- **忠诚度驱动**: CP配对 + 好友鉴定 + 组局功能

## Phase 2: MITRE 问题框架画布

### Look Inward

**核心问题（症状）：**
产品已验证PMF（病毒传播成功），但用户生命周期价值极低——绝大多数用户「测一次→截图→分享→离开→永不回来」。

**为什么还没解决？**
1. 纯前端 + localStorage = 无用户系统 = 无法追踪/触达/召回
2. 前期聚焦"做出来+病毒传播"，留存优化被推后
3. 假定"多宇宙=自动留存"，但用户可能根本不知道还有其他宇宙
4. 免费产品没收入 → 无法投入付费获客或召回

**我们可能是问题的一部分：**
- 假定用户会自己发现10个宇宙，实际大多只测完一个就走
- 只看到分享的活跃用户，没看到沉默流失的大多数
- 先实现了10个宇宙，而不是先验证"用户是否真的想跨宇宙收集"

### Look Outward

**谁经历这个问题？** 18-30岁女性，社交feed刷到→测完→5分钟后再无理由返回
**谁没有这个问题？** 有push能力的app（抖音/小红书/原神）、有社交关系链的产品（微信）
**谁被忽略了？** 男性用户（CP中的参与者）、群组用户（3-5人闺蜜团）
**谁从现状获益？** 竞品（WTFTI教育市场后用户流向更成熟产品）

### Reframe

> WTFTI核心用户在完成第一次测试后缺乏返回的结构性理由：(1) 纯前端无法主动触达, (2) "多宇宙收集"需要用户自主发现, (3) 单次测试已满足社交货币需求。每次新宇宙上线都需从零获客。

**How Might We:**
> **HMW** 在不建后端的前提下，把"测完一个宇宙"变成"开始一段持续的人格收集旅程"
> **as we aim to** 7日留存从<5%提升至20%，人均测试宇宙数从1.3提升至3+？

## 战略核心洞察

### ❶ 本质是情绪基础设施
WTFTI不是"测试工具"，是Z世代女性的情绪镜子。每个宇宙不是新产品，是新面镜子。

### ❷ 最大风险：无召回能力
纯前端=每次新宇宙从零获客。微信小程序是生存必需（P3优先级提至P2）。

### ❸ 护城河 = IP × 语言病毒 × 宇宙深度
270+独立角色IP + "sb测试"传播层级 + 10宇宙体系 = 竞品不可复制。

### ❹ 变现路径：B端优先
品牌IP合作宇宙(¥5-20万/次) > C端付费(¥10 ARPU) > 广告(¥3 ARPU)

### ❺ 国际化潜力
"WTF"是全球文化符号，视觉语言超越文字。K-pop/anime/astrology girlie = 10亿+海外市场。
