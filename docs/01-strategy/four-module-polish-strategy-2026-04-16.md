## 核心战略判断：先精品后注册，用"舍不得丢"倒逼登录

> 登录注册不应该是"门槛"，而应该是用户"舍不得丢"时的自然选择。
> 四模块的精品化目标只有一个：**让用户在每个模块都产生"这东西我不想丢"的时刻。**

当前平台状态：
- **前端完成度 95%**，后端/账户/付费均未落地
- 15个宇宙、270+人格卡、8套人格模型——内容资产极度丰富但留存极弱
- 7天留存 <5%，平均每人只测 1.2 个宇宙——内容浪费率超过 90%
- 零付费收入，零账户体系

**战略核心逻辑：**

```
精品体验 → "我的结果太准了/太好看了" → 分享（裂变） → 朋友来做 → 
对比/配对/收集 → "这些数据我不想丢" → 认领账号（登录）→ 
深度解锁（付费）→ 持续回访（留存）
```

## Phase 1: 四模块独立定位与协同分工

### 1.1 Geoffrey Moore 定位矩阵

| 模块 | 定位声明 | 核心情绪 | 裂变机制 | 登录触发点 |
|------|----------|----------|----------|------------|
| **SOULTI** | 给那些深夜自我怀疑的女性，SoulTI 是分层自我关系镜像测试，让你看见白天的你、深夜的你、受伤后的你——不是一个标签，是三层叠加画像 | 被深度理解 | "测完哭了"式UGC | 深度报告/灵魂信付费解锁 |
| **CPTI** | 给那些想知道"我和TA到底是什么关系"的人，CPTI 是6维关系翻译器，把暧昧、友谊、对手……所有说不清的关系变成一个精准的名字 | 关系命名的确认感 | 配对码邀请（1→1→N） | 关系图鉴保存/跨设备同步 |
| **灵鉴** | 给那些想"鉴定"身边人的好奇玩家，灵鉴是好友人格鉴定书，你来定义TA是什么人——然后看TA服不服 | 评判的快感 + 被评判的好奇 | A鉴定B→B被好奇→B鉴定C | 鉴定记录永久保存 |
| **WTF CARD** | 给那些做过多个测试的收藏玩家，WTF CARD 是你的多宇宙人格衣橱——所有宇宙的你、所有关系、所有鉴定，汇成一张社交资产卡 | 收藏的满足感 | 展柜分享（"我集齐了你呢"） | 跨设备同步/云端图鉴 |

**分工逻辑：**
- **灵鉴 + CPTI** = 裂变双引擎（自带邀请机制，天然 1→N）
- **SOULTI** = 付费转化引擎（深度情绪价值，付费意愿最高）
- **WTF CARD** = 资产沉淀层（所有资产汇聚地，登录的最强理由）

## Phase 2: 问题框架与验证（MITRE Problem Canvas）

### 2.1 向内看（Look Inward）

**核心假设清单：**

| # | 假设 | 验证状态 | 如果错了会怎样 |
|---|------|----------|----------------|
| H1 | "用户做完测试会主动探索其他宇宙" | 🔴 已证伪（平均1.2个） | 15个宇宙的内容投入全部浪费 |
| H2 | "好内容自然会被分享" | 🟡 半对半错（分享率OK但回流率极低） | 裂变只有新增没有留存 |
| H3 | "CPTI配对是最强裂变" | 🔴 未验证（后端未上线） | 可能高估了配对的社交压力 |
| H4 | "灵鉴的鉴定→被鉴定链能自发传播" | 🟡 前端OK但缺乏通知机制 | 被鉴定方可能永远不知道 |
| H5 | "SoulTI深度报告能转化付费" | 🔴 未验证（付费链路为零） | 可能定价或内容深度不够 |
| H6 | "WTF CARD能驱动收藏回访" | 🔴 已证伪（回访率<5%） | 收藏机制缺乏进度感和稀有度 |
| H7 | "登录注册应该尽早做" | ⚠️ 需重新判断 | 过早做会增加摩擦降低新增 |

**为什么四模块的体验还不够"精品"？**

| 模块 | 体验断裂点 | 根因 |
|------|-----------|------|
| SOULTI | 三层自我（白天/深夜/受伤）在代码里计算了但被压成单维度输出 | scoring.ts 把三幕得分合并了 |
| CPTI | 配对结果存 sessionStorage，关掉浏览器就没了 | 后端持久化 0% |
| 灵鉴 | 鉴定完 TA 不知道被鉴定了，链条断裂 | 无通知/推送机制 |
| WTF CARD | 15个宇宙只显示已测的，未测的没有引导 | 空卡位系统未实现 |

**我们的偏见：**

1. **"先做新宇宙"偏见**：过去12周做了15个宇宙，但几乎没有投入回流和留存机制
2. **"后端可以后面做"偏见**：导致关系数据、鉴定历史、收藏进度全在客户端，一清缓存全没
3. **"登录做了就完了"偏见**：实际上登录的产品设计比技术实现复杂10倍——关键是"什么时候弹、弹什么理由"

### 2.3 重新框架（Reframe）

**原始问题**：平台没有登录注册，四个模块需要打磨精品

**重新框架**：

> 四模块的"精品化"不是让每个模块更好看或更多内容——而是让每个模块都能在用户手中产生一个"我不想丢掉的东西"。
>
> 当四个模块都能产出"不想丢"的资产时，登录注册就不再是"请先注册"的硬门槛，而是"帮你保住这些"的自然服务。
>
> 社交裂变的核心不是"分享出去"——而是"分享出去之后，朋友也做了，然后你们之间产生了新的关联"。

**How Might We 问题（聚焦四模块精品化）：**

- **HMW-S** 让 SoulTI 的三层镜像真正被用户"看见"（而不是被压成一维）？
- **HMW-C** 让 CPTI 的配对结果成为用户"想反复查看"的关系档案（而不是一次性截图）？
- **HMW-M** 让灵鉴的"鉴定链"不断裂——A鉴定B后，B一定会知道并想反击？
- **HMW-W** 让 WTF CARD 从"结果汇总页"变成"每次打开都有新发现"的活资产？
- **HMW-L** 让登录注册出现在"用户最舍不得丢东西"的精确时刻？

## Phase 3: 四模块精品化方案（Teresa Torres OST）

### 3.1 北极星指标

**平台级**：周活跃持久资产用户数（Weekly Active Persistent Asset Users）
- 定义：一周内至少产生1次资产写入（新结果/新关系/新鉴定/新收藏）的去重用户
- 当前：~0（所有数据在客户端）
- 目标-90天：访客的5%
- 目标-180天：访客的12%

**模块级北极星：**

| 模块 | 模块北极星 | 当前 | 90天目标 |
|------|-----------|------|----------|
| SOULTI | 深度报告打开率（付费/免费） | 0%（深度未上线） | 15%免费，3%付费 |
| CPTI | 配对完成→关系保存率 | 0%（后端未上线） | 40%完成配对，60%保存 |
| 灵鉴 | 鉴定链延续率（A→B→C） | ~10%（B不知道被鉴定） | 35% |
| WTF CARD | 回访率（7天内再次打开Card） | <3% | 15% |

### 3.2 机会解决方案树

```
北极星：周活跃持久资产用户数
│
├── 机会 S: SoulTI 深度不够，付费无门
│   │
│   ├── S1: 三层镜像拆分展示
│   │   → 把 scoring.ts 的三幕得分独立输出
│   │   → 结果页分三个tab：「白天的你」「深夜的你」「受伤后的你」
│   │   → 免费看第一层，登录看第二层，付费看第三层
│   │
│   ├── S2: 灵魂信 — 写给用户的私人信件
│   │   → 基于三层人格 + 历史女性原型生成一封信
│   │   → 付费解锁（¥9.9），但让用户先看到信封+开头一行
│   │   → 信件可保存为图片分享（高质量UGC）
│   │
│   └── S3: 修复处方 — 从"你是什么人"到"你可以怎么做"
│       → 每种人格类型生成3条具体的"修复行动"
│       → 例："你的保护模式是'壁'——试试这周说一次'不'"
│       → 付费解锁，但免费看到1条预览
│
├── 机会 C: CPTI 关系数据蒸发，裂变链条断裂
│   │
│   ├── C1: 后端持久化 + 三态账户
│   │   → Supabase 关系表上线
│   │   → Local Guest → Anonymous → Claimed 三态
│   │   → 关系结果页出现时触发匿名登录（静默）
│   │
│   ├── C2: 关系图鉴墙 — 我的所有关系都在这里
│   │   → 每次配对都变成一张"关系卡"
│   │   → 关系卡有稀有度（灵魂共振S级、宿命对手A级、塑料朋友C级）
│   │   → 图鉴墙嵌入 WTF CARD
│   │
│   └── C3: 配对邀请优化 — 把6位码变成故事
│       → 邀请页不只是输入码，而是："TA正在等你揭晓你们的关系"
│       → 配对等待页有"心跳动画" + 对方状态
│       → 结果揭晓有3秒倒计时 + 关系名字渐入
│
├── 机会 M: 灵鉴鉴定链断裂，被鉴定方不知道
│   │
│   ├── M1: Challenge 落地页情绪升级
│   │   → 被鉴定方收到链接时看到："有人用21个维度分析了你……"
│   │   → 先展示鉴定结果的"剪影"（模糊版），点击"自己也来做一个"解锁
│   │   → 鉴定方的评价和被鉴定方的自测结果对比
│   │
│   ├── M2: 鉴定历史 + 被鉴定通知
│   │   → 灵鉴页增加"我鉴定过的人"列表
│   │   → 被鉴定方打开平台时看到"有人新鉴定了你"
│   │   → 需要登录才能看到"谁鉴定了我"→ 登录触发点
│   │
│   └── M3: 反向鉴定 — "TA鉴定了你，你服不服？"
│       → 被鉴定方看到结果后可以"反鉴定"鉴定方
│       → 双向鉴定完成后生成"互鉴报告"
│       → 互鉴报告自动进入 WTF CARD
│
├── 机会 W: WTF CARD 无回访动力，空卡位无引导
│   │
│   ├── W1: 空卡位系统 — "?"遮罩 + 呼吸动画
│   │   → 15个宇宙全部显示，未测的显示神秘剪影
│   │   → 点击空卡位直接跳转对应宇宙测试
│   │   → 进度环："你已点亮 3/15 个宇宙"
│   │
│   ├── W2: 资产汇聚 — 不只是测试结果
│   │   → WTF CARD 同时显示：宇宙人格 + CPTI关系 + 灵鉴鉴定
│   │   → 三个标签页：「我的人格」「我的关系」「我的鉴定」
│   │   → 每个标签页有独立进度和成就
│   │
│   └── W3: 展柜分享 — 你的人格衣橱分享给全世界
│       → 精选3-5张卡置顶
│       → 一键生成展柜分享图（宇宙数+关系数+鉴定数）
│       → 展柜URL可分享，朋友看完可以"和TA比一比"
│
└── 机会 L: 登录时机精准化
    │
    ├── L1: CPTI 关系保存时触发
    │   → "保存你们的关系到图鉴？" → 匿名登录 → 静默
    │
    ├── L2: 灵鉴"谁鉴定了我"时触发
    │   → "有人鉴定了你，登录查看是谁" → 登录
    │
    ├── L3: WTF CARD 跨设备时触发
    │   → "你在其他设备上有3个宇宙结果，登录同步？" → 登录
    │
    └── L4: SoulTI 深度解锁时触发
        → "你的灵魂信已生成，登录后永久保存" → 登录 + 付费
```

### 4.3 登录注册策略详解

**核心原则：登录永远出现在"你快要丢东西"的时刻**

```
 时机                               弹出方式                    转化预期
 ──────────────────────────────────────────────────────────────────────
 CPTI 配对结果出来时               "保存你们的关系？"            35%
 灵鉴 "谁鉴定了我"               "登录查看谁分析了你"          40%
 WTF CARD 第3个宇宙点亮时         "你的衣橱越来越丰富，保存？"   25%
 SoulTI 深度报告预览时             "你的灵魂信已生成"            50%
 跨设备访问检测到本地数据时        "在其他设备发现你的数据"       60%
```

**登录方式优先级：**

1. **微信 OAuth**（核心用户在微信生态，一键登录最低摩擦）
2. **手机号+验证码**（微信外场景兜底）
3. **匿名登录**（静默，用户无感知，只做数据绑定）

**绝对不做：**
- ❌ 首页登录弹窗
- ❌ 测试前要求登录
- ❌ 邮箱+密码注册（目标用户不用这个）
- ❌ 任何"不登录就不能看结果"的门槛

## 社交裂变最大化：四模块裂变漏斗合并

```
入口层（新用户从哪来）
├── 灵鉴鉴定链接 (35%) → "有人分析了你"
├── CPTI配对邀请 (25%) → "TA在等你揭晓关系"
├── 分享卡片截图 (25%) → 小红书/朋友圈看到好看的卡
└── WTF CARD展柜 (15%) → "这人集齐了12个宇宙"

转化层（新用户做了什么）
├── 做了第一个测试 (100%)
├── 分享了结果 (40%) → 产生下一波新用户
├── 做了第二个测试 (35%) → 进入收集路径
└── 触发了配对/鉴定 (20%) → 产生1:1邀请

沉淀层（用户留了什么）
├── WTF CARD 展示收集进度 → "还有12个没测"
├── CPTI 关系图鉴 → "我不想丢这些关系"
├── 灵鉴 鉴定记录 → "有人鉴定了我要看看"
└── SoulTI 深度报告 → "灵魂信太好了想保存"

登录层（用户为什么留下来）
├── CPTI "保存你们的关系" → 匿名登录（最高转化35%）
├── 灵鉴 "谁鉴定了你" → 登录查看（转化40%）
├── WTF CARD 跨设备同步 → 登录同步（转化60%）
└── SoulTI 灵魂信保存 → 登录+付费（转化50%）
```

**核心裂变公式：**

```
裂变系数 K = 邀请率 × 邀请转化率 × 分支系数

灵鉴: K = 40%(分享率) × 30%(回流做测试) × 1.5(反鉴定+新鉴定) = 0.18
CPTI: K = 25%(发配对) × 70%(接受配对) × 1.2(结果分享新增) = 0.21
展柜: K = 15%(分享展柜) × 20%(新用户进入) × 2.0(做多个宇宙) = 0.06
合计: K ≈ 0.45

若精品化后提升至:
灵鉴: K = 50% × 45% × 2.0 = 0.45
CPTI: K = 35% × 80% × 1.5 = 0.42
展柜: K = 25% × 25% × 2.0 = 0.125
合计: K ≈ 0.995 → 接近病毒式增长阈值
```

> **当 K > 1.0 时，每个用户平均带来超过1个新用户，增长变成自传播。**
> 四模块精品化的终极目标就是把 K 从 0.45 推到 1.0 以上。
