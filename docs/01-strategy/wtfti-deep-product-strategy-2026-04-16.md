## 一、产品现状诊断（State of Play）

### 1.1 资产盘点

| 维度 | 现状 | 评估 |
|------|------|------|
| **宇宙皮肤** | 15个已上线（标准/修仙/WTF毒舌/班TI/疯TI/王者/鸟/花/三角/SoulTI/XPTI/CPTI/灵鉴/日签/醉人格） | ✅ 丰富度极高 |
| **人格类型系统** | 8套独立模型（29+32+25+22+20），共270+人格卡 | ✅ 内容深度领先 |
| **测试系统** | 40+组件，多模式（solo/peer/stealth） | ✅ 引擎成熟 |
| **分享卡片** | 40+生成器，Canvas导出，QR嵌入，多主题 | ✅ 社交传播链完整 |
| **收藏系统** | WTF Card图鉴 + 灵鉴抽卡 + 70+卡池 | ✅ 收藏机制已搭建 |
| **关系匹配** | CPTI 6维模型，25种关系原型，6位码配对 | ✅ 社交配对核心完成 |
| **后端持久化** | Supabase配置完成，API就绪，localStorage回退 | 🟡 70%完成 |
| **账户系统** | OAuth+匿名→注册流程框架就绪 | 🟡 50%完成 |
| **付费体系** | SoulTI深度报告架构设计完毕，¥9.9/¥19.9定价 | 🔴 0%实现 |
| **数据分析** | 事件追踪桩代码存在，无后端聚合 | 🔴 10%完成 |

### 1.2 核心优势（真正的护城河）

1. **内容密度壁垒**：270+人格卡 × 8套人格模型 × 15个宇宙皮肤 = 竞品难以复刻的内容体量
2. **病毒式传播基因**：自嘲型命名（"操心破产户"、"emo怪"）+ 搞怪低多边形纸艺风格 = 天然截图分享动机
3. **多宇宙框架**：不是"做更好的MBTI"，而是"每周一件新衣服"——每个宇宙都是独立传播事件
4. **关系图谱雏形**：CPTI的6位码配对 + 双向资产同步 = 从"个人测试"到"关系社交"的跃迁起点

### 1.3 核心短板（真正的卡点）

| 短板 | 严重度 | 影响 |
|------|--------|------|
| **7天留存 <5%** | 🔴 致命 | 用户测完即走，无回流机制 |
| **平均每人只测1.2个宇宙** | 🔴 致命 | 15个宇宙的内容资产被严重浪费 |
| **CPTI后端未完成** | 🟡 高 | 关系数据留不住 = 社交网络建不起来 |
| **0付费收入** | 🟡 高 | 无法验证商业模型 |
| **无数据驱动能力** | 🟡 高 | 无法做A/B测试和漏斗优化 |
| **题目只有62道（应90道）** | 🟡 中 | 默认偏差导致人格分布不均 |
| **无账户体系** | 🟡 中 | 跨设备跨次访问数据断裂 |

## 二、Phase 1: 定位与市场语境（Positioning & Market Context）

### 2.1 Geoffrey Moore 定位声明

```
给那些 想在社交场景中展示"有趣的自我认知"、
      同时渴望被深度理解的 22-30岁城市女性，

WTFTI 是一个 多宇宙人格图鉴收藏平台，

它能 每周用一种全新的叙事语言重新定义"你是谁"，
     并将你的多面人格变成可收藏、可配对、可炫耀的社交资产。

不同于 16Personalities（一次测完就走的严肃量表）
      和 准了/测测（传统玄学咨询工具），

WTFTI 提供 无限风格的人格衣橱 + 关系图谱收藏机制 + 
           病毒式自嘲叙事，让人格测试从"做一次"变成"一直玩"。
```

|-----|-----------|------|

#### 社交性任务（Social Jobs）

| Job | 重要度 | 当前满足度 |
|-----|--------|-----------|
| 展示"我是有趣且有深度的人" | ⭐⭐⭐⭐⭐ | ✅ 分享卡视觉好 |

#### 情绪性任务（Emotional Jobs）

| Job | 重要度 | 当前满足度 |
|-----|--------|-----------|
| 被理解的感觉（"说的就是我！"） | ⭐⭐⭐⭐⭐ | ✅ 荒诞文学描述击中用户 |
| 不确定时获得慰藉/指引 | ⭐⭐⭐⭐ | 🟡 日签+灵鉴有覆盖但深度不足 |
| 关系中的安全感确认 | ⭐⭐⭐⭐ | 🟡 CPTI给出关系命名，但缺后续 |
| 收集满足感（"又解锁一个！"） | ⭐⭐⭐⭐ | 🔴 收藏进度缺乏可视化和激励 |
| 神秘体验的仪式感 | ⭐⭐⭐ | 🟡 灵鉴有但未深入 |

#### 痛点（Pains）

1. **"做完就走"综合征**：95%用户完成一次测试后不再回来——产品缺乏回流钩子
2. **"孤岛效应"**：15个宇宙互不联通，用户完成一个后不知道还有其他的
3. **"关系数据蒸发"**：CPTI配对结果存在localStorage，换设备即丢失
4. **"深度断层"**：SoulTI等深度内容有架构无实现，认知型用户得不到满足
5. **"社交FOMO缺失"**：缺乏排行/稀有度/限定机制，用户没有"被落下"的紧迫感

#### 收益（Gains）

1. **多面人格映射**："原来在不同宇宙里我是不同的人" → 自我发现的惊喜
2. **关系命名权**："我们是'灵魂共振'型！" → 给暧昧关系一个名字
3. **收藏成就感**："我已经集齐12个宇宙了" → 游戏化驱动
4. **社交话题弹药**："你测了这个没有？！" → FOMO驱动的病毒传播
5. **情绪价值交付**：荒诞文学式描述 + 塔罗式神秘感 → "被读懂"的满足

## 三、Phase 2: 问题框架与验证（MITRE Problem Canvas）

### 3.1 向内看（Look Inward）

**我们的假设是什么？**

| 假设 | 验证状态 | 风险 |
|------|----------|------|
| "更多宇宙 = 更多传播事件" | 🟡 部分验证（每次新宇宙确实带来一波流量） | 单次传播无回流 |
| "关系配对是留存杀手锏" | 🔴 未验证（CPTI后端未上线，无数据） | 可能被微信/QQ原生替代 |
| "收藏机制能驱动回访" | 🔴 未验证（WTF Card低使用率） | 收藏≠回访 |
| "女性用户为主" | ✅ 已验证（小红书传播数据确认） | 需防止调性偏移 |
| "自嘲式命名是病毒引擎" | ✅ 已验证（截图分享核心驱动力） | 需持续创新不能重复 |

**为什么这个问题至今没有被解决？**

- 传统人格测试（16P/MBTI）定位为"科学量表"，不认为"娱乐性"和"病毒传播"是产品核心
- 玄学产品（准了/测测）定位为"工具+咨询"，不做"收藏+社交"
- 没有产品将"人格测试"框架升级为"人格图鉴收藏平台"——WTFTI占据了空白位

**我们的偏见是什么？**

1. **工程师偏见**：倾向于不停增加新宇宙/新功能，而非打磨回流和留存机制
2. **内容创作者偏见**：认为"好内容自然传播"，忽视了分发和回流的系统设计
3. **完美主义偏见**：后端/账户系统想做到"完美"再上线，导致核心留存机制迟迟未落地

### 3.2 向外看（Look Outward）

**小红书女性用户对人格测试的真实态度**

基于市场调研数据：
- 塔罗测试月搜索量500万+，情感解答类点赞均值3200
- **核心发现**：女性用户不是在"做测试"，她们在"表演自我"——测试结果是社交舞台上的道具
- 18-22岁（大学生35%）：社交驱动，"测了发闺蜜群"是核心场景
- 23-26岁（职场新人30%）：情感驱动，"他心里有我吗"是高频搜索词
- 27-30岁（轻熟女20%）：深度驱动，愿意为"被理解"付费

**当前小红书女性在玩什么测试？**

| 类型 | 代表 | 为什么火 | 对WTFTI的启示 |
|------|------|----------|---------------|
| MBTI二创测试 | "你的MBTI在古代是什么身份" | 旧框架+新皮肤=新传播 | ✅ WTFTI的多宇宙就是这个逻辑 |
| 情感配对测试 | "测测你和他的缘分指数" | 关系好奇心+FOMO | ✅ CPTI精准对标 |
| 塔罗人格牌 | "选一张牌看你的灵魂" | 神秘感+仪式感+美图 | ✅ 灵鉴(Mysti)已覆盖 |
| 盲盒式人格 | "你是哪款潮玩" | 收藏心理+稀有度 | 🟡 WTFTI有收藏但缺稀有度机制 |
| 关系标签测试 | "你在关系中是哪种角色" | 关系命名需求 | ✅ CPTI+SoulTI可组合 |
| AI生成式测试 | "AI画出你的灵魂肖像" | 个性化+视觉冲击 | 🔴 WTFTI暂无AI生成模块 |
| 恋爱XP测试 | "你的恋爱原型是什么" | 恋爱场景代入感 | ✅ XPTI已实现 |
| 限定/节日测试 | "2026你的运势签" | 时效性FOMO | 🟡 日签有但缺节日限定 |

**谁被忽略了？谁从现状中受益？**

- **被忽略的**：希望长期"经营人格档案"的深度用户（Persona B）——她们做了测试但没地方存放和回看
- **从现状中受益的**：16Personalities靠一次测试+付费报告年收千万美元，但它不做社交，不做中文本地化的"荒诞叙事"

### 3.3 重新框架（Reframe）

**原始问题**：如何让更多用户来做人格测试？  

**重新框架后的问题**：

> **如何将"一次性人格测试"转变为"持续经营的人格社交资产"，让用户从"测了就走"变成"每周回来收集、配对、炫耀"？**

**How Might We 问题**：

- HMW 让用户发现"原来还有这么多宇宙可以探索"？
- HMW 让"收集人格卡"变得像拆盲盒一样上瘾？
- HMW 让关系配对结果成为用户想反复查看和炫耀的资产？
- HMW 用"限定/稀有"机制制造真正的社交FOMO？
- HMW 让深度解读成为用户愿意付费的"被理解"体验？

## 四、Phase 3: 解决方案探索（Teresa Torres 机会解决方案树）

### 4.1 目标成果（Desired Outcome）

**北极星指标**：周活跃持久图鉴用户数（Weekly Active Persistent Atlas Users）

定义：一周内至少回访WTF Card/灵鉴收藏页或完成第2+个宇宙测试的去重用户数

**目标**：
- 当前：~0（无回流机制）
- 90天：5% of total visitors
- 180天：12% of total visitors

### 4.2 机会树

```
北极星：周活跃持久图鉴用户数
│
├── 机会1: 用户不知道有更多宇宙可探索
│   ├── 解决方案 A1: 测完后"多宇宙导航" → 显示其他宇宙的人格预览
│   ├── 解决方案 A2: "人格衣橱进度条" → 结果页显示"你已解锁 1/15 个宇宙"
│   └── 解决方案 A3: "人格异世界推荐" → 基于当前人格推荐最匹配的下一个宇宙
│
├── 机会2: 收藏没有成瘾性和社交展示价值
│   ├── 解决方案 B1: "盲盒抽卡系统" → 每日抽卡+稀有度+限定卡+节日卡
│   ├── 解决方案 B2: "人格图鉴展柜" → 可分享的个人收藏页（类似Steam成就页）
│   └── 解决方案 B3: "稀有度FOMO" → S/A/B/C级人格 + 隐藏款 + 闪卡
│
├── 机会3: 关系数据留不住、无法积累社交图谱
│   ├── 解决方案 C1: "关系图鉴墙" → 后端持久化所有配对结果 + 关系画廊
│   ├── 解决方案 C2: "关系稀有度" → 灵魂共振/宿命对手等稀有关系类型
│   └── 解决方案 C3: "私密排行榜" → 你和谁最契合？闺蜜排名？
│
├── 机会4: 缺乏时效性内容驱动回访
│   ├── 解决方案 D1: "每周灵魂频率" → 每周推送你的人格在本周的状态
│   ├── 解决方案 D2: "节日限定宇宙" → 情人节/七夕/圣诞专属测试+限定卡
│   └── 解决方案 D3: "每日塔罗翻牌" → 灵鉴每日抽卡机制（已有基础）
│
└── 机会5: 深度用户无法获得付费级情绪价值
    ├── 解决方案 E1: "灵魂信" → SoulTI深度人格信（¥9.9）
    ├── 解决方案 E2: "双人深度报告" → CPTI关系深度解读（¥12.9）
    └── 解决方案 E3: "人格年度报告" → 年度/季度人格变化总结
```

## 附录A: 小红书女性用户人格测试核心洞察

### 她们真正在寻找什么？

1. **不是答案，是表演**：测试结果是社交舞台上的道具，"准不准"没有"好不好笑"重要
2. **不是诊断，是共鸣**：她们想听到"说的就是我"，不是"你的得分是72"
3. **不是一次，是持续**：她们愿意反复做测试（每次换一个宇宙），只要每次都有新鲜感
4. **不是独自，是社交**：配对测试（和闺蜜/对象/暗恋）是最强传播驱动力
5. **不是免费就好，是值得付费**：为"被深度理解"的体验付费（不是为功能付费）

### 2026年小红书人格测试市场关键趋势

1. **"AI+人格"交叉兴起**：AI塔罗/AI画灵魂肖像增长300%
2. **"双人测试"成为标配**：单人测试的分享率(8%)远低于双人测试(15%)
3. **"收藏+盲盒"心理渗透**：Pop Mart审美 + 人格卡收藏是未开发的蓝海
4. **"显化/灵性"新叙事**：从"你是什么人格"到"你的灵魂想要什么"
5. **"限定/节日"驱动回访**：时效性内容（节日测试、周运势）是唯一被验证的回访触发器
