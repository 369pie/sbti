## 0. 一句话结论

**「人格宇宙」输在概念税，不在执行。** 它要求用户先学会一套自造词汇（宇宙/神域/主神/Sigil/五感/月相），而中国大众互联网从不教育用户——SBTI 一秒看懂，旅行青蛙一秒看懂，偷菜一秒看懂。方向：**把已有的全部技术资产（测试引擎/信件/星灵/树洞后端）保留，把外壳从「神秘浪漫编辑宇宙」整体翻译成中国网民的母语——梗、宠物、漂流瓶、日签。**

---

## 1. 诊断：为什么市场不买单

1. **概念税**。用户落地页看到「人格神域 · 召唤主神 · 灵魂印记 · 月相日课」——每一个词都要学。SBTI 爆火时用户看到的是「你是死者」「你是草伙」——零学习成本，直接笑出声。概念系统是给团队自己爽的，不是给用户爽的。
2. **调性错位**。editorial 神秘浪漫 = 精致但冷。中国 18-32 大众网络文化的底色是**自嘲、热闹、发疯、玩梗**——牛马文学、已老实、那咋了。我们的文案在念诗，用户在玩梗，根本不在一个频道。
3. **品牌资产的自我抛弃（关键洞察）**：**SBTI 本身就是爆过的品牌**。仓库还叫 sbti，域名却换成了 wtfti.com——把有病毒性资产的旧名换成需要重新教育的 WTF 缩写（还带英文脏话联想），等于把最值钱的东西扔了。当年爆的是 SBTI 的梗感，不是「WTF Type Inside」的宇宙感。
4. **视觉先行、玩法滞后**。四个月里我们在视觉规范上投入巨大（design-system-v2、token 治理、暗色宇宙），但真正带来过流量的从来是玩法锋利度（SBTI 的标签、疯TI 的梗）——SBTI 的视觉从来不精致，它的锋利在段子里。

## 2. 成功案例的本质拆解

| 案例 | 表面玩法 | 底层机制 | 一句话启示 |
|---|---|---|---|
| **SBTI 爆火** | 31 题自嘲人格 | 情绪宣泄 + 社交货币：标签即段子，晒图即表态 | **测试即梗**。结果必须是能发朋友圈的 punchline，不是诊断 |
| **旅行青蛙** | 放置养蛙 | 无压力的牵挂：它出门、寄明信片、你只是想念 | **陪伴的最低配置**。星灵的正确打开方式——去义务化，游历+寄回明信片 |
| **QQ秀** | 装扮虚拟形象 | 身份展示 + 收集欲 + 廉价炫耀性消费 | **星灵要能穿衣服**。装扮是养成系的变现主引擎 |
| **QQ宠物** | 喂食养成 | 陪伴感（旧时代的饥饿/死亡机制属于前焦虑时代） | 现代版必须**去焦虑**——星灵「不会死，别怕」是对的 |
| **农场偷菜** | 种菜/收菜/偷菜 | 每日义务回路 + 好友互动的正当借口 | **串门即社交**。喂好友的星灵、收自己的菜，义务要轻、互动要熟 |
| **微信漂流瓶** | 扔瓶子/捞瓶子 | 匿名倾诉 + 陌生人随机温情 | **本产品最该做而没做的功能**（见 §4 漂流瓶立项） |
| **Soul** | 灵魂测试匹配 | 孤独经济：先测后配、匿名头像 | 测试天然是**社交的入场券**——我们的测试量这么大，社交转化却是零 |
| **抽象文学/牛马** | 梗与发疯文学 | 集体性自我解构宣泄 | **全站文案的声调基准**：不念诗，说梗话 |

### 2.1 五条共同本质（重设计的验收尺）

1. **一秒看懂**——零概念税，不需要说明书；
2. **情绪出口**——自嘲、牵挂、倾诉、炫耀，四选一必占；
3. **社交货币**——结果可晒、宠物可秀、瓶子可聊；
4. **轻**——3 秒参与，绝不要用户「学习一个系统」；
5. **说人话·说梗话**——用中国网民的母语，不用翻译腔。

用这五条尺回测现产品：全站只有疯TI（自发形成）和 V6 首页文案（昨天改的）及格。

## 3. 重定位方案

### 3.1 新定位一句话

> **测测你是啥，养只小东西，跟陌生人说说话。**
> ——一个说中国话的年轻人情绪游乐场：梗人格测试 × 电子宠物 × 漂流瓶树洞 × 每日运势。

（内部保留「情绪价值阶梯」作为产品逻辑，但**永不出现在用户面前**。）

### 3.2 词汇表替换（全站用户可见面）

| 现词汇（用户可见） | 替换为 | 理由 |
|---|---|---|
| 人格宇宙 | ——删除，说「测测你是啥」 | 概念税第一来源 |
| 人格神域 | 我的小窝 | 「神域」要解释，「小窝」不用 |
| 召唤主神 | 测我的本命 | 「召唤」仪式感是自我陶醉 |
| 主神/主星 | 本命 | 本命是饭圈原生词，零解释 |
| 灵魂印记 Sigil | 我的印记 | 去英文 |
| 五感档案 | 我的说明书 | 口语 |
| 月相日课 | 每日小任务 / 跟月亮打卡 | 「日课」像修行 |
| 星尘信 / 封缄 | 时间胶囊 | 「胶囊」全民秒懂（B 站/知乎都有先例） |
| Stardust Letters | 时间胶囊 | 同上 |
| 灵魂月报 | 我的小报告 | 去玄学腔 |
| HER AURORA / 极光 | 树洞 / 漂流瓶 | 极光是翻译腔的顶峰 |
| 灵鉴 / Mysti | 今日运势 | 老黄历文化是本土最大公约数 |

| 星灵 Star Sprite | 电子小宠 / 名字待定（候选：小星宠、灵宠、电子蛙系） | 「星灵」仍是自造词，需更土 |
| 宇宙（17 Universes） | 玩法 / 专题（17 种玩法） | 同第一条 |

**执行口径**：内部代码、数据库、API 不改名（成本与风险不可接受）；只改 UI 文案层与路由的显示名。SEO 热词按「mbti / 人格测试 / 塔罗 / 运势 / 时间胶囊 / 树洞」重排。

### 3.3 SBTI 品牌问题（需要单独裁决）

- 选项 A（推荐）：**双品牌**——病毒性投放物料（小红书/抖音）回归 SBTI 名义（它是被验证过的爆款名），站内主品牌维持现名；成本最低，直接复用历史认知。
- 选项 B：全站回滚 SBTI 品牌，wtfti.com 做 301。
- 选项 C：维持 WTFTI，靠玩法重振。
- 事实参考：当年 SBTI 的爆是标签梗的爆；无论品牌怎么定，**梗人格必须是门面**。

### 3.4 六大门的更名与门面重排

| 旧门 | 新门（人话） | 门面玩法 | 现状资产 |
|---|---|---|---|
| 人格测试 | **测测你是啥** | 疯TI 式梗人格为主推（29 梗型），WTFTI 29 型做深度款 | 疯TI 已存在，把 feng 提为主入口 |
| 恋爱测试 | **测测你们俩** | 有伴契合度 / 单身取向 | CPTI/XPTI 已存在 |
| 抽象文学 | **抽象文学部** | 发疯文学生成器、牛马语录、发圈文案 | share-templates 已存在，需升级为生成器 |
| 玄学预测 | **今日运势** | 每日一签 + 塔罗日牌 | mysti 已存在，改名为「今日运势」 |
| 星灵养成 | **我的电子宠物** | 旅行青蛙化：游历寄明信片 + QQ秀化：装扮 | 星灵引擎已完成，只差游历/装扮 |
| 轻社交树洞 | **漂流瓶 · 树洞** | 真漂流瓶（见 §4）+ 匿名树洞 | hermosa 后端可复用，漂流瓶需新建 |

### 3.5 视觉策略调整

- 暮紫品牌底**保留**（已成资产且 V6 已达 8.7 分），但**提高活泼度**：梗向贴纸、贴脸表情化结果卡、结果页直接放大字号 punchline；
- 视觉精致度降权为第二优先级，**玩法与文案锋利度升为第一**（SBTI 启示）；
- 结果分享卡回归「大标签 + 大梗图」式，而非现在的藏书票式（分档策略保留，但 Free 档必须足够好晒）。

## 4. 漂流瓶立项建议（本轮最重要的新功能）

微信漂流瓶被下线是产品原因（监管），不是需求消亡——**匿名倾诉 + 陌生人随机回应**是被反复验证的国民级需求（漂流瓶 → Soul → 树洞号）。我们已有匿名后端（hermosa whispers）与情绪内容运营能力（编辑部）。

**MVP 形态**（复用度 ~70%）：
1. **扔瓶子**：写一句匿名心事（≤100 字），扔进海里；可选附上自己的梗人格标签（SBTI 式社交货币：瓶子先看到标签再看到内容）；
2. **捞瓶子**：每日可捞 3 个，看到标签+心事，可「回一句」（匿名，走 whisper 后端）或「抱抱」（点赞变体）；
3. 内容安全：先审后发池（编辑部关键词 + 人工抽审），深夜时段限流；
4. 埋点与转化：捞瓶子需完成任一测试（测试是入场券——Soul 逻辑）。

预期作用：给「测完即走」装上第一个真正的日活理由，且与树洞/回声内容池打通。

## 5. 分阶段改造

| 阶段 | 内容 | 量级 |
|---|---|---|
| **P0（1 周）** | 全站 UI 文案按 §3.2 替换；首页六门更名与门面重排（疯TI 提主推）；V6 人话声调铺到导航/今日/结果页 | 文案层，无架构变更 |
| **P1（2-3 周）** | 漂流瓶 MVP；电子宠物旅行青蛙化（游历+明信片，复用 stardust 卡池）+ 装扮系统一期（QQ秀 化）；「时间胶囊」改名落地 + 提醒邮件话术同步 | 一个新功能 + 两个已有功能升级 |
| **P2（1-2 月）** | 农场化轻社交（串门喂宠/赠星尘）；测试→社交的匹配入口（Soul 逻辑）；SBTI 双品牌投放物料 | 增长层 |

## 6. 不变的东西

- **技术资产全保留**：测试引擎、时间资产云化、星灵引擎、hermosa 后端、支付——四个月的工程全部复用；
- **情绪价值阶梯**仍是内部产品逻辑（被看见→被陪伴→被记住→被回应），只是外壳换成母语；
- **女性向基调**保留（漂流瓶/树洞/宠物的主力人群本来就是女性）；
- design-system 的工程纪律（token/对比度）保留——它们是质量底线，不是风格枷锁。

## 7. 诚实的风险提示

1. **大众化 ≠ 平庸化**。借鉴的是机制（一秒看懂/情绪出口/社交货币），不是抄皮——如果只是把文案改土而玩法不锋利，等于换一种方式继续平庸；
2. **改名有 SEO/存量用户成本**，建议文案层灰度 + 关键路由 301/别名双跑一周；
3. **树洞/漂流瓶的内容安全是生死线**（海外运营也绕不开应用商店与支付渠道的审核），先审后发池必须在上线日就有；
4. 团队沉没成本心理：四个月建立的「宇宙」叙事推翻是痛的，但数据不撒谎——保留感情，保留代码，替换外壳。
