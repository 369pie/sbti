# WTFTI 平台战略刷新 · 现状诊断报告

> 诊断目标：为 6 月平台战略刷新建立事实基线，识别定位、产品、技术、数据、商业化五层的关键张力与机会。
> 诊断方法：代码/路由审计、Supabase schema 与埋点审计、5-6 月战略文档交叉审阅、竞品桌面研究、首页与子页体验走查。
> 诊断日期：2026-06-17

---

## 0. 一页纸结论

WTFTI 已经从「测试工具集合」成功演进到「为『她』的多宇宙人格社区」，三大支柱（KNOW HER / WALK WITH HER / WRITE WITH HER）已在首页代码层落地。但平台当前最大的矛盾是：**前端体验已经升级到 v3 叙事，而后端架构、数据基建、商业化路径仍停留在 v2 甚至 v1 的惯性中**。

本次战略刷新需要解决的不是「再做一个新宇宙」，而是三件事：
1. **统一身份与数据底座**：把 4 套身份标识收敛为以 Supabase `auth.users` 为中心，结束 localStorage 作为事实来源的状态。
2. **收敛模块，明确主引擎**：从 40+ 路由中选出 3-5 个拳头产品，把资源集中在「获客 + 留存 + 变现」的闭环上。
3. **把「女性精神宇宙」从首页文案变成全站一致的产品语言**：目前首页 metadata、部分旧模块、分享链路仍停留在「测试平台」语境。

---

## 1. 定位层：叙事已升级，但执行层仍有裂缝

### 1.1 当前定位（5 月已确认）

> WTFTI 是为 18–32 岁中文女性打造的多宇宙人格社区 —— 用人格测试认识自己，用玄学陪伴日常，用女性共写沉淀。

### 1.2 已落地的部分

- 首页 `HomeContent.tsx` 已完成三支柱叙事：
  - Ⅰ KNOW HER · 认识自己
  - Ⅱ WALK WITH HER · 陪每一天
  - Ⅲ WRITE WITH HER · 写下时代
- 首页已加入「适合 / 不适合」边界段，明确排除严肃诊断与男性向圈层。
- 已存在 `/start/` 90 秒新生引导页。
- HER-VOICE 已按 5 月 9 日命名修正为 **HER AURORA / 她的极光**（URL 仍保留 `/her-voice/`）。

### 1.3 未对齐的部分

| 位置 | 现状 | 问题 |
|---|---|---|
| 首页 `<title>` | `WTFTI 多宇宙人格测试平台 — 测测你是哪种抽象人格` | 仍用「测试平台」+「抽象人格」，与 v3 定位冲突 |
| 首页 `description` | `WTFTI 多宇宙人格测试平台：先从经典 SBTI 人格测试开始……` | 强调测试入口，而非女性社区 |
| FAQ schema | 回答仍围绕「多宇宙人格测试平台」 | SEO 与首访认知仍为工具视角 |
| `/test/classic/` 等旧路径 | 品牌仍为 SBTI/经典版 | 与 WTFTI 旗舰宇宙并存，用户认知分裂 |
| 部分风格宇宙 | 未注册进 `src/lib/universes.ts` | daily / drunk / love / identify 等完成度高但首页不可见 |

**诊断结论**：定位已经正确，但**产品语言、SEO、路由结构没有全部跟上**。这是风险最低、影响最大的快速修复点。

## 2. 产品层：模块丰富但拳头产品不够突出

### 2.1 一级产品路由审计

当前 `src/app/` 下约有 **40+ 个产品路由**，可分为七大类：

| 类别 | 代表模块 | 完成度 | 战略重要性 |
|---|---|---|---|
| 核心人格测试 | `/wtfti`, `/soulti`, `/cpti`, `/xpti` | 高 | ⭐⭐⭐ 获客主入口 |
| 玄学陪伴 | `/mysti`, `/daily`, `/gacha` | 高 | ⭐⭐⭐ 留存主入口 |
| 共创与沉淀 | `/her-voice`, `/card`, `/types`, `/creator` | 高 | ⭐⭐⭐ 护城河 |
| 风格化宇宙 | `/bird`, `/flower`, `/hogti`, `/fanrenti`, `/work`, `/love`, `/drunk` | 中高 | ⭐⭐ 传播事件 |
| 关系社交 | `/cp`, `/squad`, `/puzzle`, `/rank`, `/combo` | 中 | ⭐⭐ 裂变工具 |
| AI/付费实验 | `/mirror`, `/lingjian` | 中低 | ⭐ 待验证 |
| 营销与合规 | `/about`, `/guide`, `/privacy`, `/terms` | 高 | ⭐ 基础设施 |

### 2.2 关键发现

1. **核心四大模块（WTFTI / SoulTI / CPTI / XPTI）已经成熟**，具备完整的落地页、测试、结果、分享、深度报告链路。
2. **Mysti 是留存主引擎**，已有订阅、礼物卡、每日抽牌、星图档案等完整付费链路。
3. **HER AURORA 是共创主引擎**，代码量已超过 9K 行，但入口仍深藏在 `/her-voice/`，首页虽有面板但社区感弱。
4. **风格化宇宙存在「完成但不可见」问题**：`/daily`、`/drunk`、`/love`、`/identify` 都有完整页面，但未在 `universes.ts` 注册，首页切换器找不到它们。
5. **AI 功能存在定位漂移**：`/mirror`（AI 风格实验室）与平台核心「人格 / 玄学 / 共写」关联较弱，更像独立变现实验。
6. **空目录与薄壳页**：`/jueti` 为空，`/weekly` 是薄壳委托页，应及时清理或补齐。

### 2.3 产品层最大张力：工具流量 vs 社区沉淀

平台同时在做两件事：
- **测试工具**：不断出新宇宙获取流量（鸟格、花语、修仙、班 TI、酒后人设等）
- **社区沉淀**：希望用户通过 HER AURORA、WTFCard、Creator 留下内容

但两者之间的转化链路不清晰。用户测完一个宇宙后，**没有被明确引导到「收藏 → 分享 → 参与共写」的下一步**。

## 3. 技术层：身份、存储、Schema 三座大山

### 3.1 身份模型碎片化（P0）

同一平台并存 **4 套身份标识**：
1. Supabase `auth.users.id`
2. `device_id`（Mysti / XPTI）
3. `share_token`（XPTI / CPTI / Identify）
4. `client_hash`（HERMOSA / SoulTI 许愿池）
5. 大量 localStorage / sessionStorage 作为业务事实来源

**后果**：
- 换设备/清缓存数据丢失
- 无法做用户生命周期分析
- 付费权益可能被本地绕过
- 跨模块推荐与关系匹配难以实现

### 3.2 账号化现状

| 模块 | 账号化状态 |
|---|---|
| CPTI | 已账号化（匿名+真实双轨，有 merge-existing） |
| XPTI Couple | 半账号化（device_id 为主） |
| Mysti | 设备中心（device_id，登录回填） |
| WTFTI Classic / Galaxy | 未账号化（localStorage） |
| Museum / WTFCard | 未账号化（localStorage + base64url 快照） |
| SoulTI | 弱账号化（本地测试 + 匿名许愿） |
| HER AURORA | 匿名贡献（client_hash） |
| Creator / UGC | 必须真实账号 |

**诊断结论**：CPTI 已经跑通账号化 + 合并流程，应作为模板推广到其他核心模块。否则「社区/档案馆」定位无法真正沉淀用户资产。

### 3.3 Schema 与迁移治理（P0）

- 迁移文件分散在 `db/migrations/`、`src/lib/supabase/migrations/`、`src/lib/ugc/migrations/`、`src/lib/mysti/migrations/`，约 30 个。
- SKU 约束在数据库 check、TypeScript 枚举、迁移文件、脚本中多处硬编码，容易漂移。
- 大量 API 路由绕过 RLS 使用 service_role，安全依赖应用层校验。
- 当前工作区有 **160 个未提交文件**，部署基线不稳定。

### 3.4 埋点体系（P0）

**已做**：
- Vercel Analytics 全局注入
- `product_events` 自定义 durable 事件表
- `perf_metrics` RUM 表
- 通用漏斗抽象 `funnel.ts`

**缺口**：
- `product_events` 服务端白名单未包含 `galaxy`、`wtfti`、`xpti`，这些战略模块的 durable 事件会被丢弃
- 事件不带 `user_id`，只有 `device_id`/`session_id`
- 服务端支付成功、分享被打开、邀请回流完成等关键事件未自动记录
- 缺少 A/B 实验 ID 字段

## 4. 数据层：基线缺失，无法验证 5 月改版效果

5 月执行计划中列出的关键验收指标：
- 首页 60 秒跳出率下降 30%
- 7 日回访 +50%
- `/start/` 转化率 +30%
- HER SALON 当周问题留言数 ≥ 50

**诊断**：这些指标在代码层大部分**没有对应的埋点或 dashboard** 支撑。`admin/funnel` 和 `admin/hermosa` 存在，但缺少统一的数据看板与基线记录。

**建议**：战略刷新必须把「可观测性」作为 Q3 第一优先级，否则所有迭代都在盲飞。

## 5. 商业化层：三条线并行，但主引擎未明确

### 5.1 已有变现尝试

| 模式 | 代表 | 状态 |
|---|---|---|
| 一次性深度报告 | WTFTI 深档、SoulTI 深镜、CPTI 关系深测、XPTI 深度 XP | 已上线 |
| 订阅/通行证 | Mysti ¥19/月通行证 | 已上线 |
| 单次付费 | Mysti 星图档案 ¥39、WTFCard 解锁 | 已上线 |
| 礼物卡 | Mysti 礼物卡 | 已上线 |
| AI 付费 | Mirror 风格实验室 | 已上线但关联弱 |
| B 端联名 | 品牌定制宇宙 | 4 月战略重点，5 月后缺少执行细节 |

### 5.2 商业化关键决策

4 月战略把 B 端品牌联名宇宙作为「核心壁垒」，5 月总执行计划却把 Mysti 订阅/星图档案作为落地重点。两者并非互斥，但**资源分配与组织节奏需要明确**。

**市场研究启示**：
- 测测靠真人咨询年入 3 亿+，但 WTFTI 不应复制重咨询模式（监管/供给/客诉风险）
- 16personalities 靠付费深度报告 + 企业授权，模式清晰但同质化
- Co-Star / The Pattern 靠订阅 + 关系洞察，是更契合 WTFTI 的参照

**建议**：以 **C 端订阅 + 一次性深度报告** 为 12 个月内主引擎，B 端联名宇宙作为季度性大单补充，AI 陪伴作为长期储备。

## 6. 市场层：机会真实，竞争窗口存在

### 6.1 市场判断

- 18-32 岁中文女性是人格测试、玄学消费、女性社区的核心重叠人群。
- 现有产品要么太工具（MBTI 小程序）、太重（测测咨询、KY 心理治疗）、太泛（小红书话题），中间存在一个 **「轻玄学 + 自我叙事 + 女性社区」的蓝海交叉地带**。
- WTFTI 的差异化不是「更准」，而是**「更美、更可分享、更可沉淀」**的女性人格宇宙。

### 6.2 最重要的 5 条市场启示

1. **测试结果必须是社交货币发动机**：视觉、文案、分享体验决定裂变效率。
2. **避开重咨询，主打轻陪伴**：订阅、报告、虚拟商品、AI 陪伴更安全可规模。
3. **社区沉淀优先于工具流量**：人格测试获客成本低但留存低，必须设计「留下并创作」的机制。
4. **圈层细分大于大而全**：先打透一个高识别度女性圈层，再向外泛化。
5. **小红书是获客场，WTFTI 是关系场**：用爆款测试在小红书获客，在 WTFTI 完成关系与沉淀。

## 7. 战略张力清单

| 编号 | 张力 | 现状 | 需要做的决策 |
|---|---|---|---|
| T1 | 工具 vs 社区 | 首页讲社区，但大量路由仍是测试工具 | 明确 12 个月内主叙事，收敛低价值工具模块 |
| T2 | 匿名 vs 账号 | CPTI 已账号化，其他模块仍本地存储 | 是否以 CPTI 为模板推进全站账号化？ |
| T3 | B 端 vs C 端 | 4 月推 B 端，5 月推 Mysti C 端 | 明确主引擎与资源分配 |
| T4 | 扩张 vs 克制 | 12+ 宇宙 + 多个实验模块 | 哪些模块该下架/合并/冻结？ |
| T5 | AI 共写 vs 反 AI slop | 品牌承诺「女性共写」，但工具依赖 AI | 她词条的内容生产模式是什么？ |
| T6 | 女性专属 vs CPTI 男性 | 定位为「为她」，但 CPTI 需要男性参与 | 男性用户边界与 CPTI 邀请体验如何设计？ |
| T7 | 文档 vs 落地 | 战略文档丰富，但部分数据基线缺失 | 建立可验证的指标体系与 dashboard |

## 8. 对 Phase 2 战略刷新的输入

基于以上诊断，Phase 2 战略刷新文档应重点回答以下 6 个问题：

1. **WTFTI 的「第一宇宙」是什么？** 如果只能让用户记住一个产品，应该是哪个？
2. **从测试到社区的最小闭环是什么？** 用户测完后，下一步最自然的动作是什么？
3. **账号化的推进顺序是什么？** 是否以 Mysti → WTFTI → SoulTI → XPTI 的顺序迁移？
4. **C 端付费的主 SKU 是什么？** Mysti 通行证、星图档案、WTFCard 解锁、关系深测，哪个是核心？
5. **社区内容的供给模式是什么？** HER AURORA 的内容来自用户投稿、编辑部策展还是 AI 辅助？
6. **Q3 的必赢战役是什么？** 在资源有限的情况下，哪 1-3 件事必须做成？

## 9. 建议的 MVP 方向

基于诊断，建议 Phase 4 优先落地 **「首页 Hero + 全站 SEO/文案一致性刷新」**，原因：

- **纯前端改动**，不涉及账号化/Schema 等重工程
- **影响最大**：首页是所有流量的第一触点
- **直接验证定位**：把 metadata、Hero、FAQ 全部切到 v3 女性社区语言，可快速用 60 秒复述测试验证
- **为后续改造开路**：先让用户/团队看见「新 WTFTI」长什么样，再推进账号化等重改动
