# WTFTI 平台战略刷新 v3.1

> 一句答案：
> **WTFTI 是 18–32 岁中文女性的人格宇宙与灵魂生活社区——测一次看见自己，每天打开有一点 sign，和无数「她」一起把生活过成想要的样子。**

---

## 0. 为什么需要刷新

5 月 8 日的平台重新定位方向正确，但 6 周后的代码审计显示：**前端叙事已经升级到 v3，而后端架构、数据基建、商业化路径、模块治理仍停留在 v2**。具体表现为：

- 身份系统碎片化：4 套身份标识 + localStorage 事实来源
- 埋点体系不完整：战略模块 `galaxy`/`wtfti`/`xpti`  durable 事件被服务端丢弃
- 模块扩张过快：40+ 路由中拳头产品不突出
- 商业化主引擎漂移：B 端联名 vs Mysti 订阅，资源优先级未明确
- 社区内容模式模糊：HER AURORA 的供给机制、AI 边界、反 slop 承诺未落地

本次刷新不是推翻 5 月定位，而是**把定位翻译成可执行的产品策略、技术路线、商业模型和增长路径**。

## 1. 平台定位（确认并 sharpen）

### 1.1 One-liner

**WTFTI 是为 18–32 岁中文女性打造的人格宇宙与灵魂生活社区。**

三件事：
1. **人格宇宙** — 用 17+ 个宇宙的人格测试，把「我是谁」翻译成属于她的语言。
2. **灵魂陪伴** — Mysti 玄学 × 她成长（读书/知识/投资意识），陪她过每一天。
3. **灵魂碰撞** — HER AURORA 轻社交共创，让她找到同频的她。

### 1.2 Geoffrey Moore 定位语

```
For 18–32 岁、相信「自己值得被认真对待」的中文女性
  who 想看清自己、想在不确定的日常里找到一点温柔确定感、也想和同类轻轻碰撞
  WTFTI
  is a 人格宇宙 × 灵魂陪伴 × 灵魂碰撞的女性生活社区
  that 把人格测试、轻玄学、女性成长内容，变成她会每天打开的灵魂生活指南。

Unlike MBTI 的四个字母 / 测测的重咨询 / 小红书的零散测试图鉴
  WTFTI
  provides 一个更接地气、更女性视角、更有日常陪伴感的人格宇宙 ——
  在这里，你不只是被分类，你是被理解、被陪伴、也被听见。
```

### 1.3 边界声明

| 适合 | 不适合 |
|---|---|
| 想被以女性视角认真讲述自己的女生 | 寻求严肃心理诊断或精神科建议的人 |
| 想要日常小预兆、情绪陪伴和轻成长的人 | 只想算财运/婚姻/事业「准不准」的人 |
| 愿意写下自己的经验、与同类轻轻碰撞的人 | 投资人圈层、硅谷精英沙龙导向的人 |
| 把人格测试、玄学、成长当社交货币的人 | 把女性内容当流量猎奇消耗的人 |

**关于男性用户**：WTFTI 为女性设计，但不排斥男性在 CPTI 中作为「被邀请的关系对象」出现。CPTI 邀请流程需明确告诉男性：「这是她用来理解你们关系的语言，不是诊断你。」

## 2. 三大支柱与拳头产品

把 40+ 路由收敛为 **3 个支柱 × 每个支柱 1 个拳头产品 + 2 个支撑模块**。

### 支柱 Ⅰ · 人格宇宙 · KNOW HER

**拳头产品**：**WTFTI 人格宇宙 / Galaxy**
- 90 秒召唤主神
- 17+ 风格宇宙的翻译入口
- WTFCard 多宇宙档案的锚点

**支撑模块**：
- SoulTI 灵魂镜像（深度自我）
- CPTI 关系深测（双人关系）
- XPTI 恋爱 XP（亲密偏好）

**战略意图**：WTFTI 是获客入口，其他三个解决特定场景。避免继续把每个风格宇宙都当成独立拳头产品推。

### 支柱 Ⅱ · 灵魂陪伴 · WALK WITH HER

**拳头产品**：**Mysti 灵鉴**
- 每日抽牌
- 星图档案（¥39 一次性）
- 月度通行证（¥19/月）
- 灵魂信 / 节气 / 月报

**支撑模块**：
- 她成长：读书、知识分享、投资意识（她财富 IP）
- 玄学工具矩阵：宝宝起名、解梦、灵签、每日运势、八字精批等轻玄学功能

**战略意图**：Mysti 是留存和订阅主引擎。自研命理引擎是护城河，但用户体验应始终是「编辑部语言」，不是「算命黑话」。她成长让「陪伴」不止于玄学，也包含现代女性的自我成长。

### 支柱 Ⅲ · 灵魂碰撞 · WRITE WITH HER

**拳头产品**：**HER AURORA / 她的极光**
- 极光时刻（每周编辑部问题）
- 接光（回声链）
- 极光来信（月报精选）
- 她词条（长期共建词典）

**支撑模块**：
- WTFCard 多宇宙档案（收藏与沉淀）
- Creator UGC 平台（创作者供给）

**战略意图**：HER AURORA 是轻社交护城河。它不是另一个留言墙，而是「让她找到同频的她」的灵魂碰撞空间。

## 3. 用户模型与核心旅程

### 3.1 四类角色（保留并细化）

| 角色 | 占比 | 入口 | 核心需求 | 我们的抓手 |
|---|---|---|---|---|
| **A. 大学/初职场探索者**（19–24） | 35% | WTFTI / SoulTI / 风格宇宙 | 搞清楚我是谁 | 90 秒测试 + 分享卡 + 集邮 |
| **B. 都市清醒姐姐**（25–32） | 40% | CPTI / Mysti / WTFCard | 被看见、被记录、被陪伴 | 深度报告 + 月报 + 星图档案 |
| **C. 玄学日常陪伴者** | 20% | Mysti / Daily / Gacha | 每天一句温柔的 sign | 订阅 + 每日抽牌 + 灵魂信 |
| **D. 共写者 / KOC**（机会） | 5% | HER AURORA / Creator | 留下自己的话 | 署名 + 收录 + 创作者徽章 |

### 3.2 核心旅程（新用户）

```
发现（小红书/朋友圈分享卡）
  → 首页 6 秒：这是为「她」的（Hero + 三支柱）
  → /start/ 90 秒引导测
  → 完成第一次测试（WTFTI / SoulTI / CPTI / XPTI）
  → 结果页：保存 + 分享 + 看其他宇宙
  → 注册/登录（轻触，非强制）
  → 进入 WTFCard 档案 或 Mysti 每日抽牌 或 HER AURORA
  → 7 日内回访：今日运势 + 未测宇宙 + 极光时刻
```

### 3.3 核心旅程（回访用户）

```
登录后首页 = 我的档案首页
  → 最近的我（最新测试结果）
  → 今日 Mysti 抽牌
  → 还没测的宇宙推荐
  → HER AURORA 本周问题
  → 我的 WTFCard 进度
```

## 4. 商业化主引擎

### 4.1 明确 12 个月内的主次

| 优先级 | 模式 | 代表 SKU | 判断 |
|---|---|---|---|
| **P0 主引擎** | 订阅制陪伴 | Mysti 月度通行证 ¥19/月 | 高频、低客单、高复购，最契合「陪伴日常」 |
| **P0 主引擎** | 一次性深度报告 | 星图档案 ¥39、关系深测、SoulTI 深镜 | 中客单、强分享、验证付费意愿 |
| **P1 补充** | 档案/解锁 | WTFCard 解锁、限定宇宙 | 低客单、促留存 |
| **P1 补充** | 礼物卡 | Mysti 礼物卡 | 社交送礼场景 |
| **P2 季度大单** | B 端品牌联名宇宙 | 5–20 万/宇宙 | 不依赖、但能建立品牌背书 |
| **P3 长期储备** | AI 陪伴 / 实物出版 | 她词条出版物、AI 姐姐 | 需要社区规模支撑 |

### 4.2 为什么放弃重咨询模式

测测靠真人咨询年入 3 亿+，但 WTFTI 不应复制：
- **监管风险**：占卜/命理咨询灰色地带
- **供给瓶颈**：达人网络难以规模化
- **客诉风险**：黑猫投诉等舆情
- **品牌冲突**：与「反 AI 算命师」定位冲突

我们的商业化应是 **「内容/AI 替代部分真人咨询」** 的安全路径。娱乐玄学可以卖订阅、卖报告、卖工具，但不卖「真人开示」。

### 4.3 男性用户在 CPTI 中的付费边界

CPTI 男性被邀请者可以免费查看关系结果，但深度解读、关系档案、月报等增值服务仍需由女性用户购买后分享。避免把男性作为独立付费用户运营。

## 5. 技术路线：统一身份与数据底座

### 5.1 技术战略一句话

**以 Supabase `auth.users` 为唯一身份中心，本地存储只作为缓存，所有持久化业务表必须带 `user_id`。**

### 5.2 账号化推进顺序

```
Phase A（Q3 必做）：
  1. Mysti 设备 → user 回填机制完善
  2. WTFTI Classic / Galaxy 测试结果写入服务端
  3. Museum / WTFCard 收藏云端化

Phase B（Q3-Q4）：
  4. SoulTI 测试历史云端化
  5. XPTI Couple 统一用 Supabase auth
  6. HER AURORA 留言与用户绑定（保留匿名显示选项）

Phase C（Q4-Q1）：
  7. 全站 anonymous → claimed 合并流程统一
  8. 跨模块推荐引擎
```

### 5.3 埋点与数据治理

- **以 `product_events` 为唯一 durable 真相源**，Vercel Analytics 仅作实时预览
- 立即补齐 `galaxy`、`wtfti`、`xpti` 白名单
- 所有事件必须带 `user_id`（匿名用户用 `auth.users.id`）
- 增加 `experiment_id` 字段支持 A/B 测试
- 服务端自动记录：支付成功、分享被打开、邀请回流完成、Codex 归档

### 5.4 Schema 治理

- 合并 30 个分散迁移为一个 canonical schema dump
- 建立 CI 强制 `pnpm run db:schema-smoke`
- 所有新表必须过 schema check 与 RLS 策略 review
- SKU 统一收敛到 `lib/payments/skus.ts`

## 6. 玄学工具矩阵（参考菩提苑）

### 6.1 设计原则

参考菩提苑「九大善门」，但做女性友好、娱乐化、轻承诺的版本：

| 功能 | 形态 | 付费点 | 女性场景 |
|---|---|---|---|
| **宝宝起名** | 输入父母信息 + 八字喜忌 → 推荐名字 | 单次解锁 ¥9.9–39 | 备孕/怀孕/新手妈妈 |
| **每日运势** | 基于生日/星座/人格类型的每日 sign | 免费 + 订阅解锁详细版 | 每天上班前 |
| **周公解梦** | 输入梦境关键词 → 女性视角解读 | 免费 + 深度解读 ¥9.9 | 醒来后的焦虑 |
| **关帝灵签 / 每日一签** | 每日抽一支签 | 免费 | 日常小仪式 |
| **八字精批** | 输入出生时间 → 命格概述 | 一次性报告 ¥39–99 | 人生节点参考 |
| **关系合盘** | 双人八字/星座合盘 | 一次性报告 ¥39 | 恋爱/婚姻决策 |
| **手相/面相** | 上传照片 → AI 识别 + 编辑部解读 | 单次 ¥9.9 | 好奇娱乐 |
| **她财富每日一句** | AI 量化情绪 + 投资意识提醒 | 免费 | 建立投资意识 |

### 6.2 上线顺序

- **Q3 必上**：每日运势、宝宝起名、周公解梦、她财富每日一句
- **Q4**：灵签、八字精批、关系合盘
- **明年**：手相/面相等更重 AI 的功能

## 7. 她财富内容 IP

### 7.1 定位

> 她财富不是理财课，而是「用女生听得懂的语言，建立投资意识」。

### 7.2 内容形态

- **她财富每日一句**：结合 AI 量化交易引擎的市场情绪信号，输出一句女性视角的投资提醒
- **她读书**：每周一本与女性成长/财富/心理相关的书摘
- **她知识**：图文/短视频形式的投资基础知识（基金、ETF、资产配置）
- **她故事**：真实女性的理财/职业成长故事

### 7.3 AI 量化交易引擎的角色

- **不是直接卖工具**：先作为内容 IP 和信任背书
- **内容钩子**：「AI 帮你算市场情绪，但决策权在你」
- **与 Mysti 联动**：「今日财运签」+「市场情绪温度」
- **分发为主**：小红书/公众号输出，站内沉淀

### 7.4 商业化路径

- **免费**：每日一句、书摘、基础图文
- **付费**：深度市场解读报告、投资意识训练营（远期）
- **B 端**：女性向金融机构内容合作

## 8. HER AURORA 内容生产模式

### 8.1 反 AI slop 承诺

> HER AURORA 的每一句话都源自真实女性的经验，AI 只做编辑部的翻译、润色与归档助手。

### 6.2 内容三层结构

| 层级 | 来源 | 呈现 | 示例 |
|---|---|---|---|
| **极光时刻** | 编辑部每周发布 1 个问题 | 首页 + HER AURORA 首页置顶 | 「你最近一次为自己花钱，是什么时候？」 |
| **接光** | 用户投稿 + 编辑部精选 | 回声链展示 | 用户分享自己的故事 |
| **极光星图 / 她词条** | 编辑部基于接光内容提炼 + 用户共创 | 可搜索的女性词典条目 | 「边界感」「体面撤退」「电子榨菜」 |

### 6.3 激励机制

- **署名**：每条接光显示用户昵称与印记（Sigil）
- **收录**：被收录进极光来信或她词条的用户获得「守光人」徽章
- **Halo 印记**：基于参与次数和命格生成视觉印记，替代头像
- **创作者通道**：高质贡献者可申请 Creator，发布自己的宇宙

## 9. 模块治理：收敛 + 玄学工具扩展

### 9.1 模块分级

| 级别 | 模块 | 策略 |
|---|---|---|

| **玄学工具层** | 宝宝起名、解梦、灵签、八字精批、每日运势 | Q3-Q4 重点建设 |
| **她成长层** | 她财富、她读书、她知识 | 先内容 IP，后轻工具 |
| **风格层** | bird、flower、hogti、fanrenti、work、daily、drunk、love、identify | 作为传播事件，统一注册进 `universes.ts`，但不单独推首页 |

| **清理层** | jueti（空目录）、weekly（薄壳） | 立即清理或补齐 |

### 7.2 反膨胀原则

- **2026 年内不再新增独立拳头模块**
- 新宇宙必须有明确的支柱归属和传播目标
- 任何新模块上线前必须通过：用户旅程图、埋点方案、商业化路径 review

## 10. 北极星指标与 Q3 目标

### 10.1 北极星指标

- 体现「测试 → 玄学/成长陪伴 → 回来 → 灵魂碰撞」的完整循环
