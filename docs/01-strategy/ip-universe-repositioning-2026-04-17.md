# IP 宇宙重定位策略：把 IP 热度真正"吃"进产品里

> 用 Geoffrey Moore / JTBD / MITRE / Teresa Torres OST / Amazon Working Backwards 的六段式产品策略框架做一次深度评估。
> 覆盖两个现存宇宙的重定位：**班TI（本应是哈利波特）、修仙 2.0（本应是凡人修仙传）**；同步梳理资产回收路径。

---

## 0. 诊断 · 目前为什么"借不到 IP 的风"

### 0.1 班TI 的真相（硬证据）
- 名称："班TI"、emoji `💼`、slug `banti`、路径 `/wtfti/work/`
- 数据层 `src/lib/banti/personalities.ts` 自述是 "WTFTI 社畜宇宙 — 29 型**职场版**人格映射"
- 29 型命名全是职场语境：**职场舔王 / 工位结界 / 工位休眠仓 / 内耗打工人 / 碎了又粘的打工人 / Client Director / 酒桌型人格 …**
- 完全检索不到 `哈利 / 赫敏 / 斯内普 / 霍格沃茨 / 格兰芬多` 任何关键词

**→ 结论：班TI 不是"哈利波特主题宇宙"，它是一个纯粹的"打工人 MBTI"被贴了一个带"班"字的马甲。** 用户直觉是对的，班TI 跟"打工人独立测试"高度重叠——**它本身就是那个打工人独立测试**。

### 0.2 修仙 2.0 的真相
- 按 `xiuxian-2-brand-direction.md` 现行定位：女性向「仙门怪可爱 / 白底 / 故事道具 / 情绪关系场景」
- 问题：它的"修仙"只是**语境包装**（门派、金丹、渡劫），**没有任何真实 IP 角色锚点**
- 凡人修仙传是起点白金顶流 + B站动画百亿级流量（韩立、南宫婉、银月、墨大夫、紫灵、厉飞雨 …），自带巨型梗库（"稳健"、"散修心态"、"道友请留步"、"老六"），**但我们没有把任何一个角色人格化进产品**

### 0.3 症状归因（MITRE Canvas · Look Inward）
| 认知偏差 | 表现 | 代价 |
|---|---|---|
| "IP 只是皮肤" | 把 IP 当视觉主题、不当内容锚点 | 热度借不到、用户没有"入坑对号入座"瞬间 |
| "29 型是圣经" | 所有宇宙硬塞 29 个 MBTI 变体 | 角色选择被迫稀释、失去 IP 原生辨识度 |
| "名字谐音即 IP" | "班" = 哈利波特？ | 用户根本 get 不到，SEO 也失败 |
| 抽象 > 具体 | "修仙人格"而不是"韩立 / 南宫婉人格" | 用户没法截图分享"我是韩立"这种硬通货 |

### 0.4 为什么现在必须改（外部信号）
- 小红书 tarot 赛道调研 (`xiaohongshu_tarot_market_research.md`) 结论：**IP 角色映射类（甄嬛传人格 / 红楼梦人格 / 原神角色测试）完播率 + 转发率 > 抽象人格测试 2×+**
- 用户分享硬通货 = **"我是 XX 角色" > "我是 INFP" > "我是 XX 型"**（具名角色自带社交认同、自带粉丝圈子）
- 真正"吃 IP 红利"的产品（网易云角色测试、抖音甄嬛人格）头部案例都有一个共同点：**角色是主角，人格是副本**——我们把这个顺序搞反了

## 1. Phase 1 · 定位 & JTBD（两个宇宙分别打）

### 1.1 霍格沃茨TI（班TI 替代方案，代号 `hogti`）

**Geoffrey Moore 定位**
> 为**想在社交中被一眼看懂的哈利波特粉丝**
> 她们想要**用 HP 角色说清自己是谁**，
> 「霍格沃茨TI」是一款**魔法人格图鉴**，
> 把你对号入座到**15+ 标志性角色 + 4 学院**，
> 给出一张可以发小红书 / 朋友圈的**分院人格卡**。
> 相比**九型、MBTI、抽象人格测试**，
> 「霍格沃茨TI」提供**「我是谁」而不是「我是第几型」的答案**。

**Proto-Personas**
1. **"魔法圈 10 年老粉"（22-30 女）**：看了 10 年电影+书，想要一个比网传 BuzzFeed 更本土、更懂中国语境的测试。JTBD：社交自证"我就是那种赫敏型人格"。
2. **"入坑 2 年新粉"（16-22 女）**：通过新作舞台剧/动画入坑，还在补设定。JTBD：一个带科普感的角色测试、测完顺便学设定。
3. **"非粉路人"（通用泛人格用户）**：没看过 HP 但听过卢娜、斯内普。JTBD：图个好玩截图、结果能被 HP 粉看懂。

**JTBD 三维**
- 功能性：3 分钟内得到"你是 {角色}、属于 {学院}"的结论
- 社会性：截图能让朋友圈一眼认出 IP、参与讨论、自带话题
- 情感性："原来我是斯内普"这种"被理解 + 被浪漫化"的双重满足

### 1.2 凡人修仙传TI（修仙 2.0 替代方案，代号 `fanrenti`）

**Geoffrey Moore 定位**
> 为**凡人修仙传 / 网文修仙老读者**
> 她们想要**用"韩立 / 南宫婉 / 银月"这种具名角色自比**，
> 「凡人修仙传TI」是一款**散修人格图鉴**，
> 把你对号入座到**10-14 个标志性角色 + 修为阶段 / 道心倾向**，
> 给出一张自带"稳健 / 老六 / 散修"梗的人格卡。
> 相比**抽象的修仙人格 / 四象五行人格**，
> 「凡人修仙传TI」提供**一个能被弹幕 / 起点书评区秒懂的结果**。

**Proto-Personas**
1. **凡修起点老读者（25-35 男女均有）**：追更 6-10 年，朋友圈全是道友。JTBD：社交硬通货"我是韩立型"。
2. **凡修动画党（18-28）**：通过 B 站动画入坑，梗文化重度用户。JTBD：测完能玩梗、能在弹幕里用。
3. **泛修仙女性用户**：吃我乘风 / 默读 / 凡人长生等网文女频读者。JTBD：在"稳健 vs. 激进"、"道侣向 vs. 孤修向"这些维度上自证。

**JTBD**
- 功能性：给出"你对应 X 角色、修为像 Y 阶段、道心是 Z 倾向"的三层结论
- 社会性：截图能在书评区 / 动画弹幕直接被识别
- 情感性："稳健"这个梗的情感释放 + "我也是老六"的自嘲归属感

## 2. Phase 2 · MITRE 问题重构

### 2.1 Look Outward（谁受影响）

| 群体 | 对现状的反应 |
|---|---|
| HP / 凡修核心粉 | 刷到我们的测试时 **完全不知道这是一个 IP 测试**（因为班TI 没有 HP 符号、修仙 2.0 没有凡修符号） |
| 泛人格测试用户 | 看到"班TI"以为是职场测试；看到"修仙 2.0"以为是抽象修仙壳子 |
| 被我们错过的 KOL | HP 书迷博主、凡修 UP 主 不会转发一个"看上去和他们圈层无关"的测试 |
| 同类竞品 | 直接做"哈利波特人格测试"的小红书账号涨粉速度 > 我们 |

### 2.2 Reframed Problem
> **现状问题**："班TI" 把哈利波特 IP 当谐音马甲、"修仙 2.0" 把凡人修仙传 IP 当抽象氛围，两者都没把 IP 角色作为第一人格锚点，失去 IP 的社交引流和搜索红利。

### 2.3 How Might We（HMW）
1. HMW 把"{IP 角色} 人格图鉴"做成一眼可识别的宇宙名、落地页、结果页？
2. HMW 在保留 29 型原始人格资产的前提下，让每个 IP 宇宙**只绑定 10-15 个真正具备辨识度的 IP 角色**？
3. HMW 把旧的"打工人/抽象修仙"内容回收进"轻松一测"等低权重入口，释放一线位置给 IP 宇宙？

## 3. Phase 3 · Teresa Torres 机会-方案树（OST）

**Desired Outcome（可度量）**
- 核心：IP 宇宙上线 30 天 **分享率 ≥ 18%**（现班TI 大约 7-9%）
- 辅助：落地页到结果页完成率 ≥ 65%；小红书 / B 站站外带 IP 关键词 UGC ≥ 200 篇 / 30 天

### 3.1 霍格沃茨TI OST

```
Outcome: 分享率 ≥18%
├── 机会 A：结果页没有"IP 角色硬通货"
│   ├── 方案 A1：15 主角 + 4 学院双层结果（双维度结果页）
│   ├── 方案 A2：纯 10 主角制，单层但更深度
│   └── 方案 A3：29 原型 × "最接近的 HP 角色"合成结果  🔥 POC
├── 机会 B：入口不像 HP 测试
│   ├── 方案 B1：宇宙名改"霍格沃茨TI"，emoji ⚡，学院色系
│   ├── 方案 B2：首页做"分院帽入场"动画作为钩子  🔥
│   └── 方案 B3：落地页放 HP 官方风格 typography + 羽毛笔
└── 机会 C：没有粉丝圈冷启动抓手
    ├── 方案 C1：10 个角色对应 10 张可分享卡片（预埋朋友圈主图）
    ├── 方案 C2：小红书"我测出自己是斯内普"种子内容 30 篇  🔥
    └── 方案 C3：联动 HP 博主 / 同人画师做卡面授权
```

**POC 选定**：A3 + B2 + C2 组合（可行性 × 影响力最高，复用现有 29 型资产避免重建）

### 3.2 凡人修仙传TI OST

```
Outcome: 分享率 ≥18%
├── 机会 A：没有具名角色锚点
│   ├── 方案 A1：12 核心角色映射 + "修为阶段"作副标签  🔥 POC
│   ├── 方案 A2：纯角色不加修为
│   └── 方案 A3：按"凡修关键选择题"分岔（稳健派 vs 激进派）
├── 机会 B：梗没用起来
│   ├── 方案 B1：结果页嵌入"稳健""老六""散修心态"梗文案  🔥
│   ├── 方案 B2：分享卡用起点/动画配色致敬（不侵权的前提下）
│   └── 方案 B3：弹幕风格背景图
└── 机会 C：起点/B站书评区没有种子
    ├── 方案 C1：B 站动画弹幕高峰期投 20 篇短视频  🔥
    ├── 方案 C2：知乎"韩立 MBTI"长尾词卡位
    └── 方案 C3：联动一个腰部凡修解说 UP 主
```

**POC 选定**：A1 + B1 + C1

## 5. Phase 5 · 资产回收 & 旧宇宙下沉方案

### 5.1 班TI 的处理（不重做、不删除，**重新命名 + 迁移**）
1. **改名**：`banti` → `worker`（或 `打工人TI`），保留所有 29 型数据
2. **入口下沉**：从首页一级宇宙 → "轻松一测"聚合页 + 个人中心"你可能也喜欢"
3. **URL 兼容**：保持 `/wtfti/work/*` 不动、做 301 别名入口 `/worker/*`
4. **与新霍格沃茨TI 关系**：**并行共存、用户路径互相推荐**——打工人TI 结果页底部加"你的霍格沃茨人格是？"CTA
5. **内容上不动手**：29 个职场人格完全保留，是高质量原创资产

### 5.2 修仙 2.0 的处理
1. **并行策略**：不立刻下架，而是在首页位置把"修仙 2.0"和新"凡人修仙传TI"**两者并列 30 天 A/B**
2. 若新宇宙 30 天内完成率 + 分享率双超现有，**再把修仙 2.0 降权到"轻松一测"**
3. 修仙 2.0 现有插画资产（仙门怪可爱）可作为**凡人修仙传TI 的角色配图占位 / fallback**

### 5.3 与"轻松一测"的内容整合
- 建议在 `/test/` （初见）或独立 `/fun/` 路由下建立"轻松一测"聚合：
  - 现 WTF 毒舌版
  - 现 花TI / 鸟TI
  - 迁入：打工人TI（原班TI）、抽象修仙（原修仙 2.0 降权版）
- 首页一级位置只留 **IP / 强主题宇宙**：初见 / 标准 / 霍格沃茨TI / 凡人修仙传TI / 王者TI / SoulTI / XP

## 8b. 视觉-UX 差异化评估（Landing → Test → Result 全链路）

### 8b.1 核心命题
当前所有宇宙的 Landing / Test / Result UI **几乎完全同构**：
- 同一套 `bg-bg-elevated`、`border-border-subtle`、`text-text-primary`
- 每个宇宙只变 accent hex（0ea5e9 / f59e0b / a855f7），字体、排版、背景、动效全部复用
- Quiz 引擎统一灰卡 + 渐变进度条；Result 统一 hero + 4-part copy + radar

**这对"通用人格测试 (WTFTI/班TI/初见)"是对的**——复用节奏、降低认知负担。
**但对"IP 主题宇宙 (hogti / fanrenti / kings)"是错的**——IP 最大价值就是"一打开就知道是哪个 IP"，**3 秒内视觉识别**。一个长得跟班TI 一样的"霍格沃茨TI"，等于白借 IP。

### 8b.2 分级策略：Universe Visual Tier 分层体系

| Tier | 适用宇宙 | 差异化层级 | 投入 |
|---|---|---|---|
| **Tier 0 · 统一体系** | 初见、标准、WTFTI、班TI、打工人TI、轻松一测各子宇宙 | 仅换 accent + emoji | 已有 |
| **Tier 1 · 半主题** | 花TI、鸟TI、三角TI、XP、SoulTI | + 专属配色 + Hero 背景渐变 + Emoji 符号系统 | 已部分有 |
| **Tier 2 · 强 IP 主题**（🎯 新加） | **hogti / fanrenti / kings / mysti** | + 专属字体（衬线/楷书）+ 专属纹理背景 + 入场动画 + Result hero 风格 + Share 卡版式 | **新投入** |
| **Tier 3 · 沉浸级**（未来） | 旗舰级 IP 宇宙 | + 完整进场动画（如分院帽场景）+ 专属题卡皮肤 + 独立音效 | 未来 |

**关键判断**：目前 Kings 是假 Tier 2——有 accent、有英雄画但没有字体/纹理/入场差异。这次把 hogti 和 fanrenti 直接做到**真 Tier 2**，顺带给 Kings 补齐。

### 8b.3 Tier 2 视觉差异化规范（hogti / fanrenti 落地标准）

| 触点 | hogti（魔法学院） | fanrenti（仙侠墨卷） |
|---|---|---|
| **Hero 字体** | 衬线英文 (`serif`) + 羊皮卷金色 | 楷体/宋体 (`font-serif`) + 水墨黑 |
| **背景纹理** | 暗夜蓝底 + 星芒点点 + 羊皮卷边缘晕染 | 米白宣纸底 + 远山水墨晕染 + 淡竹影 |
| **主色调** | 4 学院色系切换（格兰芬多绯红/斯莱特林墨绿/拉文克劳深蓝/赫奇帕奇金黄） | 按角色定：韩立墨青、南宫婉胭脂、银月银白、墨大夫赭红 |
| **Accent 装饰** | 魔杖、羽毛、院徽 SVG | 竹叶、云纹、玉佩 SVG |
| **Landing Hero 动效** | 羽毛笔落款+星光微动 | 水墨滴落晕染入场 |
| **题卡调性** | "魔法课本情境题"——场景化、英伦腔 | "散修修行场景题"——文言混白话、带梗 |
| **Finishing Overlay emoji** | ⚡ `分院帽正在推算你的学院…` | 🪷 `灵镜推演你的道心倾向…` |
| **Result Hero 标题** | `你是：{角色名} · {学院}` | `你是：{角色名} · {修为·道心}` |
| **Result 角色卡** | 学院色边框 + 院徽水印 + 角色名衬线大字 | 宣纸纹理卡 + 印章式角色名 + 竖排标语 |
| **Share 卡** | 录取通知书风格（羊皮卷 + 红蜡印） | 卷轴风格（水墨卷轴 + 朱红印章） |

### 8b.4 技术实现路径（尽量不碰底层）

1. **本 sprint 落地**（无需改基础组件）
   - 每个 Tier 2 宇宙自带一个 `{universe}Theme.tsx` wrapper 组件，给 Landing/Result 页根节点加主题 class + 自带背景 SVG/渐变
   - 通过 Tailwind `font-serif` + inline style + SVG backdrop 实现字体和纹理，**不新增 font 文件、不新增 CSS 变量**（降低回归风险）
   - Quiz 页**暂不换皮**（Tier 2.5）——只通过 `finishingOverlay` 换 emoji + 文案，保持答题节奏一致
2. **下 sprint 扩展**
   - 抽取 `<UniverseTheme>` 通用容器，支持 `variant: 'parchment' | 'ink' | 'arena' | 'sigil'`
   - 把 Kings 迁移到这个容器
3. **更远期**
   - 专属题卡皮肤、专属入场过场动画、专属 Share 图模板工厂

### 8b.5 Anti-pattern（避免重蹈覆辙）
- ❌ 不要为每个 IP 宇宙都开一套 CSS tokens（维护爆炸）
- ❌ 不要在 Tier 2 上强行加入场动画，必须保证**首屏 LCP < 2.5s**
- ❌ 不要为了差异化而牺牲无障碍（对比度、focus-ring 保留）
- ❌ 不要让 Tier 2 的"沉浸"感压过"入场到答题"的转化率——题页保持冷静
