# WTFTI 4 轴场景投射题样本（30 题）

> **目的**：跑通新题库语法，验证「场景题 + 选项即角色反应 + 多轴打分」是否可以替代旧 SBTI 陈述句体感。
> **结构**：30 题 = 4 轴 × 6 题主测 + 6 题反差/隐藏触发。
> **算法约定**：每个选项对每个轴贡献一个 -3 到 +3 的向量；总分 = ∑选项向量；最后归一化到 -3..+3 的轴向画像。
> **风格**：保留 SBTI 的"荒诞文学 + 三选项"体感，**不学术化**。题目本身就该是梗、能做投放素材。

---

## 轴向速查（出题前对齐）

| 轴 | 高极 (+) | 低极 (−) |
|----|---------|---------|
| **W** Wired (触发反应) | 易点燃，行动派 | 钝感，先观察 |
| **T** Tilt (情绪倾斜) | 外倾，向外释放 | 内倾，向内消化 |
| **F** Flex (应对弹性) | 可塑型，快速切换 | 稳定型，认准用到底 |
| **I** Imprint (印记锚点) | 自洽型，参照系在自己 | 关系型，参照系在他人 |

> 每个选项标注 `[轴: ±数值]`，例：`[W:+2, T:+1]` = 该选项给 W 加 2 分、给 T 加 1 分。
> 单选项最多影响 2 轴，避免过度耦合。

---

## ▍W 轴 · 触发反应（6 题）

### Q1 · 凌晨 1 点群消息 ✦
**场景**：你已经躺下，凌晨 1 点工作群突然 @ 你说"明早 9 点要交一版方案"。

- **A**. 立刻坐起来打开电脑，反正是被点名了 → `[W:+3, F:+1]`
- **B**. 心里咯噔一下，刷半小时手机才睡，明早再说 → `[W:+1, T:-1]`
- **C**. 看一眼，关消息提醒，原计划睡觉 → `[W:-2, I:+2]`

### Q2 · 地铁陌生人凝视
**场景**：地铁里你抬头，一个陌生人正盯着你看了大概 3 秒。

- **A**. 直接对视回去，看谁先撤 → `[W:+2, I:+2]`
- **B**. 低头看手机，但心里开始想"我哪里有问题" → `[W:+1, T:-2]`
- **C**. 没什么感觉，可能 ta 在发呆 → `[W:-3]`

### Q3 · 朋友突然消失三天
**场景**：很要好的朋友连续三天没回消息。

- **A**. 直接打电话过去："你死了吗？" → `[W:+2, T:+2]`
- **B**. 默默想这事一整天，但不主动联系 → `[W:+1, T:-2]`
- **C**. ta 大概在忙，不至于的 → `[W:-2, F:-1]`

### Q4 · 外卖出错
**场景**：点的麻辣香锅送来是麻辣烫，价格还多扣了 5 块。

- **A**. 立刻投诉 + 申请退款 + 给差评 → `[W:+3]`
- **B**. 心里骂一句，但懒得弄 → `[W:+1, F:-1]`
- **C**. 5 块就 5 块，将就吃了 → `[W:-3, I:+1]`

### Q5 · 久违的朋友圈点赞
**场景**：暗恋对象/前任突然给你 3 个月前的朋友圈点了一个赞。

- **A**. 立刻分析这个赞背后的潜台词，截图发闺蜜群 → `[W:+3, T:+2]`
- **B**. 假装平静，但反复回看自己那条朋友圈 → `[W:+1, T:-2]`
- **C**. 哦，可能手滑 → `[W:-2, I:+2]`

### Q6 · 新闻里的世界
**场景**：刷到一条让你不舒服的社会新闻。

- **A**. 立刻转发 + 写长评 → `[W:+2, T:+2]`
- **B**. 难受一下午，但什么都不发 → `[W:+1, T:-2]`
- **C**. 划走，世界本来就这样 → `[W:-2]`

## ▍T 轴 · 情绪倾斜（6 题）

### Q7 · 被批评后的 24 小时
**场景**：今天被领导/老师/伴侣不留情面地批评了一次。

- **A**. 立刻找朋友吐槽，喝两杯，吐完就好了 → `[T:+3, W:+1]`
- **B**. 在心里反复回放那段对话，分析自己哪里错了 → `[T:-3]`
- **C**. 吃顿大的，明天继续 → `[T:+1, F:+1]`

### Q8 · 周日晚上的情绪
**场景**：周日晚上 10 点，明天要上班/上课。

- **A**. 已经在朋友圈/小红书发"周一恐惧"段子了 → `[T:+2, W:+1]`
- **B**. 默默躺在床上想人生意义 → `[T:-3]`
- **C**. 列好明天 to-do，洗漱睡觉 → `[T:0, F:+2, I:+1]`

### Q9 · 一首老歌
**场景**：耳机里随机到一首跟前任有关的歌。

- **A**. 立刻发动态："这首歌真应景" → `[T:+2, W:+1]`
- **B**. 切歌，但 ta 的影子在脑子里转一晚 → `[T:-2, F:-1]`
- **C**. 听完了下一首继续 → `[T:0, I:+1]`

### Q10 · 陌生人的善意
**场景**：早高峰，前面陌生人帮你按住了电梯门。

- **A**. 笑着说谢谢 + 觉得今天会顺 → `[T:+2, I:-1]`
- **B**. 谢谢之后开始想"我是不是应该也帮别人" → `[T:-1, I:-1]`
- **C**. 点头进电梯，没什么特别的 → `[T:0, I:+2]`

### Q11 · 朋友的喜事
**场景**：朋友升职/恋爱/出书/搬新家。

- **A**. 真心高兴，张罗一顿庆祝 → `[T:+2, W:+1]`
- **B**. 嘴上恭喜，心里有一点说不清的复杂 → `[T:-2]`
- **C**. 发个红包/礼物，不刻意凑热闹 → `[T:0, I:+1]`

### Q12 · 雨天等人
**场景**：约好的人迟到 30 分钟还没到，外面在下雨。

- **A**. 一边发信息催 ta，一边发朋友圈"等人ing" → `[T:+2, W:+2]`
- **B**. 静静站着，想"是不是 ta 不想来" → `[T:-2, W:+1]`
- **C**. 找个咖啡店坐下，ta 来了再说 → `[T:0, F:+1]`

## ▍F 轴 · 应对弹性（6 题）

### Q13 · 方案被全否
**场景**：花了两周做的方案，被一句话全否。

- **A**. 立刻问"那您觉得方向应该是什么"，下午就改 → `[F:+3, W:+1]`
- **B**. 嘴上同意，回去原方案改个标题再交 → `[F:-2, I:+1]`
- **C**. 接受，但需要一晚消化情绪后才能动 → `[F:+1, T:-1]`

### Q14 · 健身计划第 7 天
**场景**：你立了 30 天健身 flag，第 7 天突然不想去。

- **A**. 换一种运动，今天去跳 keep → `[F:+2]`
- **B**. 硬着头皮也去，flag 不能倒 → `[F:-3, I:+1]`
- **C**. 直接放弃，下个月再立新 flag → `[F:+1, W:-1]`

### Q15 · 关系反复
**场景**：跟伴侣/暧昧对象，吵架→和好→吵架→和好，已经第 5 轮。

- **A**. 第 5 轮后开始想"是不是该换个相处方式" → `[F:+2]`
- **B**. 反正每次都和好，下次还会和好 → `[F:-2, I:-1]`
- **C**. 第 5 轮直接断，没必要再循环 → `[F:+2, I:+2]`

### Q16 · 通勤路堵死
**场景**：通勤路上突发事故，导航说要堵 1 小时。

- **A**. 立刻下车，换地铁/共享单车 → `[F:+3, W:+1]`
- **B**. 算了认命堵着，反正下车也未必快 → `[F:-2]`
- **C**. 边堵边在车里开线上会议 → `[F:+2, W:+1]`

### Q17 · 学了一半的东西
**场景**：你买课/报班学的某项技能，学到一半发现没那么有用。

- **A**. 立刻停损，转去学别的 → `[F:+2, I:+1]`
- **B**. 既然花了钱，硬学完再说 → `[F:-3, I:+1]`
- **C**. 学一半就放着，以后说不定用得上 → `[F:0, W:-1]`

### Q18 · 旅行计划被打乱
**场景**：旅行第二天，原计划景点临时关门。

- **A**. 立刻打开小红书重排路线 → `[F:+3]`
- **B**. 那今天就酒店躺一天 → `[F:0, W:-2]`
- **C**. 还是去，至少在门口拍张照 → `[F:-2, I:+1]`

## ▍I 轴 · 印记锚点（6 题）

### Q19 · 父母不同意你的选择
**场景**：你想做的事（换工作/恋爱对象/搬城市），父母强烈反对。

- **A**. 还是会做，但内心会愧疚很久 → `[I:0, T:-2]`
- **B**. 重新考虑一下，ta 们也是为我好 → `[I:-3]`
- **C**. 听完，按原计划继续 → `[I:+3]`

### Q20 · 朋友圈点赞数
**场景**：你刚发的朋友圈，1 小时只有 3 个赞。

- **A**. 删了重新发 → `[I:-3, T:-1]`
- **B**. 心里有点失落，但不删 → `[I:-1, T:-1]`
- **C**. 没注意，本来发了就忘 → `[I:+3]`

### Q21 · 一个人吃火锅
**场景**：周末想吃火锅，没人陪。

- **A**. 一个人去吃，根本无所谓别人怎么看 → `[I:+3, W:+1]`
- **B**. 一个人去吃，但选个角落不显眼的位置 → `[I:0]`
- **C**. 点外卖在家吃，避免那个场面 → `[I:-2, T:-1]`

### Q22 · 三个人的群里
**场景**：三个人的小群里，另外两个人在聊一件你完全不感兴趣的事。

- **A**. 直接说"换个话题吧" → `[I:+3, W:+2]`
- **B**. 默默看完，刷别的 → `[I:0]`
- **C**. 跟着附和几句，不想被排除在外 → `[I:-3, T:-1]`

### Q23 · 一个让你心动的"反潮流"选择
**场景**：身边所有人都在做 A，你心里其实想做 B。

- **A**. 做 B，并且很坦然地说出来 → `[I:+3]`
- **B**. 做 B，但对外说在做 A → `[I:-1, F:+1]`
- **C**. 跟着做 A，毕竟大家都这样 → `[I:-3, F:-1]`

### Q24 · 镜子里的你
**场景**：早上出门前最后照一次镜子，发现今天状态不太行。

- **A**. 算了，反正自己舒服最重要 → `[I:+3]`
- **B**. 换件衣服，不能让别人看到这个状态 → `[I:-2, F:+1]`
- **C**. 一边出门一边想"今天会不会被吐槽" → `[I:-2, T:-2]`

## ▍反差 / 隐藏触发题（6 题）

> 这些题用来识别"主人格 vs 反差人格"差值，触发隐藏卡机制。

### Q25 · 醉酒后的你 [DRUNK 触发]
**场景**：你喝了点酒，跟刚认识的人聊天 1 小时后。

- **A**. 已经开始讲自己的童年 → `[T:+3, I:-2]`【触发：跨轴反差，候选 DRUNK 人格】
- **B**. 比平时话多了一倍，但内容差不多 → `[T:+1]`
- **C**. 跟没喝一样 → `[F:-2, I:+2]`

### Q26 · 独处 vs 群体的反差
**场景**：你一个人在家时的状态，和你跟 5+ 朋友在一起时的状态。

- **A**. 几乎是两个不同的人 → `[F:+2]`【触发：F+1 反差权重】
- **B**. 状态有变化，但内核一致 → `[I:+2]`
- **C**. 一模一样，从不掩饰 → `[I:+3, F:-2]`

### Q27 · 工作 vs 生活
**场景**：工作中的你和私底下的你。

- **A**. 工作我是另一个皮肤，下班立刻切回来 → `[F:+3]`【触发：F+1 反差权重】
- **B**. 工作严肃一点，私下放松一点，差别不大 → `[F:0]`
- **C**. 没区别，工作就是我 → `[I:+3, F:-2]`

### Q28 · 你最近一次"破防"
**场景**：最近一次哭/失控/情绪崩塌的触发点。

- **A**. 一件小事，但勾起了一连串旧账 → `[T:-2, W:+2]`
- **B**. 真的发生了大事 → `[T:-1]`
- **C**. 想不起来，已经很久没破防过 → `[F:+1, I:+2]`

### Q29 · 你最讨厌的那种人
**场景**：你最受不了哪种人？

- **A**. 没主见、看人下菜碟的 → `[I:+3]`
- **B**. 太有主见、不顾别人感受的 → `[I:-2, T:-1]`
- **C**. 没什么特别讨厌的，每个人都有理由 → `[T:0, F:+2]`

### Q30 · 五年后的你
**场景**：5 年后的你，最可能在做什么？

- **A**. 完全不同的事，到时候再看 → `[F:+3, W:+1]`
- **B**. 跟现在差不多，把现在的事做更好 → `[F:-2, I:+2]`
- **C**. 不敢想，怕想完就更焦虑 → `[T:-3, F:-1]`

## 算法验证脚手架（伪代码）

```ts
type Axis = 'W' | 'T' | 'F' | 'I';
type AxisVector = Partial<Record<Axis, number>>;

interface ScenarioOption {
  key: 'A' | 'B' | 'C';
  label: string;
  vector: AxisVector;
}

interface ScenarioQuestion {
  id: number;
  text: string;
  category: 'main' | 'contrast' | 'trigger';
  primaryAxis: Axis;
  options: ScenarioOption[];
}

// 计分：累加所有选中选项的向量
function scoreAnswers(answers: ScenarioOption[]): Record<Axis, number> {
  const sum: Record<Axis, number> = { W: 0, T: 0, F: 0, I: 0 };
  for (const opt of answers) {
    for (const [axis, v] of Object.entries(opt.vector)) {
      sum[axis as Axis] += v ?? 0;
    }
  }
  // 归一化到 -3..+3
  const counts: Record<Axis, number> = { W: 6, T: 6, F: 6, I: 6 }; // 主测题数
  for (const a of ['W','T','F','I'] as Axis[]) {
    sum[a] = Math.max(-3, Math.min(3, sum[a] / counts[a]));
  }
  return sum;
}

// 反差识别：contrast 题的 F 高极 → 触发"反差人格"标记
function detectContrast(answers: ScenarioOption[]): boolean {
  // 简化：第 26-27 题 A 选项即触发
  return answers.some((o) => o.vector.F !== undefined && o.vector.F >= 2);
}
```
