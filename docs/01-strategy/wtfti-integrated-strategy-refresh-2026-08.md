## 1. 定位（沿用 v3.1，一字不改）

> WTFTI 是 18–32 岁中文女性的人格宇宙与灵魂生活社区——测一次看见自己，每天打开有一点 sign，和无数「她」一起把生活过成想要的样子。

三件事：人格宇宙（KNOW HER，获客）× 灵魂陪伴（WALK WITH HER，留存/订阅）× 灵魂碰撞（WRITE WITH HER，共写护城河）。

边界不变：不做严肃心理诊断、不做重玄学、不做男性向圈层。

## 2. 核心诊断

wtfti 不缺战略，缺收敛；不缺功能，缺「日常」；不缺视觉资产，缺一套被执行的系统。

1. **战略层**：25 份战略文档两个月改 5 次定位，两份 Q3 计划并存且互不 supersede，执行面对的是一个战略考古现场。
2. **产品层**：40+ 路由是工具集市不是社区。首页说「灵魂生活社区」，实际路径是「测完即走」——没有收藏、没有明天再来的理由、没有「她」的在场感。首页 metadata 仍是旧的「多宇宙人格测试平台」语言。
3. **前端层**：landing class 体系与 galaxy inline-style 体系双轨并行；v2 迁移普遍没收尾；199+ 处硬编码 hex；深色模式冷灰化丢了暮紫仪式感。视觉分裂直接稀释品牌一致性——而品牌一致性恰是对测测/Co-Star 的核心差异化。

## 3. 整合 Q3 计划：一棵指标树

### 3.1 北极星

**7 日活跃灵魂用户**（一个「她」每周至少回来一次，且完成一次被陪伴动作：抽牌 / 收信 / 读词条 / 合盘）。

裁决逻辑：5 月计划的三个北极星（词条 ≥50 条、MingLi-Bench ≥50%、出版物 ≥200 册）全是供给量指标，供给量不创造留存；6 月计划的北极星是行为指标，行为才是社区成立的证据。

### 3.2 三战役

```
战役 1｜人格宇宙重构（KNOW HER）
  首页三支柱叙事重做 + 首测 90 秒引导 + 结果页瘦身
  指标：首测完成率 +50%、结果页分享率 ≥12%、首页跳出率 -30%

战役 2｜每日灵魂仪式（WALK WITH HER）
  Mysti 每日抽牌 + 玄学工具矩阵（女性友好版善门）
  指标：D1/D7 留存、Mysti 通行证转化 ≥4%
  └─ 子项目：命理引擎 v3 —— 先内部 dogfood，主观评分 ≥4/5 才对外，不进北极星

战役 3｜灵魂碰撞（WRITE WITH HER）
  HER AURORA（极光时刻 / 接光 / 极光来信）+ 她词条
  指标：共写参与率、周 UGC 产出
  └─ 子项目：她词条 ≥50 条（战役 3 的内容供给指标，不是独立北极星）
      生产模式：真人供稿 + AI 只做翻译/润色/归档，过 humanizer 检测 + 编辑部硬关卡
```

### 3.3 砍掉与冻结

- **砍掉（Q3 不碰）**：纸质出版物 200 册目标——与 C 端主线无因果关系，叠加「反 AI slop」红线后执行成本极高，是典型的供给端浪漫。
- **冻结新功能**：cp / squad / puzzle / rank / combo（仅作 CPTI 裂变辅助）；不再开新风格宇宙。
- **下架 gate**：`mirror` / `lingjian` 设 2026-09-30 决策点——验证与核心定位的关联，不达标则下架或转型。

### 3.4 节奏

- W1–W2：埋点基线周（无埋点不上线，先建可观测性）+ 首页 metadata/产品语言修复
- W3–W6：战役 1（首页 + 首测 + 结果页）
- W4–W8：战役 2（每日仪式 + 玄学工具）
- W6–W10：战役 3（HER AURORA + 她词条供给爬坡）

## 4. 路由收敛：「3 + N」

- **3 个支柱路由**：`/wtfti`（获客入口）、`/mysti`（陪伴主引擎）、`/her-aurora`（共写）——只有这三个配拥有完整叙事首页。
- **N 个传播事件层**：bird / flower / hogti / fanrenti / work / daily / drunk / love / identify 等统一注册进 `universes.ts`、共用 landing 模板、不在首页单独露出，只作为小红书投放落地页。
- **清理**：删 `HomeContent.tsx`（V2 已转正）、两个无引用的 `ShrineLongCard*`、`?bank=v2` 运行时切换（v2 题库转正后删旧库）、816MB 的 `out/` 历史残留。

## 5. 身份与数据底座

4 套身份标识（auth.users / device_id / share_token / client_hash）并存是所有留存叙事的隐形杀手——没有统一身份，「收一辈子」「30 天后的星尘信」都是空话。

- 以 **CPTI 已跑通的账号化 + 合并方案**为模板全站推广；
- localStorage 降级为匿名缓存，不再当事实来源；
- 登录保持轻触非强制：「保存你的多宇宙档案」触发轻登录，不做强制登录墙；
- 埋点先行：任何重构页面上线前必须带齐事件埋点，否则不予上线（写进验收标准）。

## 6. 七大张力裁决

| # | 张力 | 裁决 |
|---|---|---|
| T1 | 工具 vs 社区 | 工具是获客形态，社区是留存形态。不假装首页是社区，而是让「测完 → 明天回来抽一张牌」成为唯一被设计的下一步 |
| T2 | 匿名 vs 账号 | CPTI 模板全站推广（见 §5） |
| T3 | B 端 vs C 端 | C 端为主、B 端联名 P2；前端资源 100% 投 C 端体验 |
| T4 | 扩张 vs 克制 | Q3 冻结新宇宙；mirror/lingjian 走 9 月 gate |
| T5 | AI 共写 vs 反 AI slop | 她词条走窄路：真人供稿 + AI 只做归档；宁慢勿滥 |
| T6 | 女性专属 vs CPTI 男性 | 男性被邀请者免费看结果，付费点永远开在女性侧 |
| T7 | 文档 vs 落地 | 「无埋点不上线」写进重构验收标准 |

## 7. 变现收敛

维持 v3.1 裁决不动摇：

- **P0**：Mysti 月度通行证 ¥19/月 + 星图档案 ¥39（一次性）
- **P1**：WTFCard 解锁 / 限定宇宙、Mysti 礼物卡
- **P2**：B 端品牌联名宇宙
- **不做**：重咨询、信息流广告、自动续费

前端纪律：结果页瘦身后留下的收口位**只通向这两个 P0 付费点**，不再做「每个组件都导流」的摊大饼。

## 8. 对前端重构的传导

本轮前端深度重构三条线，全部服务于上述战略：

1. **体验线**：首页按「6 秒原则」重做为三支柱叙事 → 首测 90 秒引导 → 测试流程接入仪式语法（神殿之门 / Sigil 勾勒 / 星尘封信）→ 结果页从导流集市瘦身为「叙事 + 双付费收口」。
2. **视觉线**：产出 `design-system-v2` 权威规范（supersede `brand-spec.md` 与 6 月配色评估的冲突口径），文档落点 `docs/04-design-growth/design/wtfti-design-system-v2-2026-08.md`。
3. **工程线**：全站 token 治理（硬编码 hex 199+ → ≤40）、galaxy inline-style 体系收敛进 class 体系、v2 迁移收尾、深色暮紫回归。

## 9. 验收标准

- 产品语言：首页 title / description / FAQ 全部切换到 v3 定位语言；
- 首页：随机 5 位首访者 60 秒内能复述平台是给谁的、能做什么；
- 首测：完成率较基线 +50%；
- 视觉：正文对比度 ≥7:1、Lighthouse a11y ≥95、硬编码 hex ≤40；
- 数据：所有重构页面埋点齐备，北极星与战役指标可读出周趋势。

## 10. 2026-08-16 裁决合入：情绪价值阶梯与底座优先级

依据 [wtfti-emotion-value-research-and-redesign-2026-08.md](wtfti-emotion-value-research-and-redesign-2026-08.md) 的市场调研与六项提案，founder 裁决如下，作为对本文的增量修订（定位、三战役、「3 + N」、北极星均不变）：

1. **情绪价值阶梯成为三支柱的用户侧总纲**：被看见（KNOW）→ 被陪伴（WALK）→ 被记住（时间资产）→ 被回应（WRITE）。所有重构页面验收新增一条自检——「她此刻在哪一层、上一层的入口是否在场」。
2. **时间资产云端化提为战役 2 前置工程**：`stardust_letters` / `moon_chapters` / `duet_sessions` / `galaxy_results` 四表落 Supabase（全部带 user_id），localStorage 降为缓存并静默迁移；先于一切新内容供给。§5「无埋点不上线」同步适用。
3. **「一个今日」**：新增 `/today` 统一每日仪式入口（天象签 × 抽牌 × 月相进度 × 待拆的信），收敛 `wtfti/daily`、`mysti` 每日抽牌、`wtfti/moon` 三套并行日常；登录后默认首页指向它。
4. **黄金 7 日旅程 + 付费露出后移**：付费收口从「结果页立刻弹墙」后移至 D7（第一周仪式完成）与 D30（星尘信拆封）两个情绪高点。对 §7 的增量：深档统一 ¥9.9、通行证增设首月 ¥9.9 诱饵档；所有付费点在测试开始前明示。
5. **mirror 维持 §3.3 的 2026-09-30 gate 不变**：裁决依据为商业证据——AI 陪伴品类付费率 <1%、大厂退出（星野/猫箱/X Eva）；「AI = 内容引擎」保留为资源纪律。海外运营主体不适用国内《AI 拟人化互动服务管理暂行办法》。
6. **运营前提：海外运营**。玄学话术不设合规前置，工具矩阵恢复 v3.1 的 Q3-Q4 上线顺序；触达通道以服务号（海外华人触点）与邮件并行评估；小红书 KOC 仍是 P0 渠道，仅投放物料侧保留迷信类限流词纪律；免责声明与付费前置透明保留为用户信任实践，非法务要求。

执行序列：上述第 2/3/4 项插入战役 1/2 的执行序列，形成 Phase 0（免责 + 付费前置 + 埋点基线）→ Phase A（云端化 + /today + D0-D1 旅程）→ Phase B（触达 + 首月 ¥9.9 档 + mirror gate）→ Phase C（社交绑定 + 她词条 + 年度灵魂年鉴）的节奏，详见调研文档 §7。
