## 0 · 战略升维：从"星图"到"神谱与灵魂"

### 旧战略缺陷（用户洞察）

> "**卫星是人造的**——这个概念对女性没有任何吸引力。"

一针见血。"Moon / Satellite / Shadow" 来自 NASA 工程师词汇，对**目标人群（25-35 岁、文艺、女性向、小红书重度）**毫无叙事勾力。她们要的不是 SpaceX，是 **Persephone 的石榴籽、女娲补天的五色石、吸血鬼的契约与黄昏**。

### 新战略一句话

> **WTFTI 是一份用宇宙物理学起草、由众神和灵魂共同签名、写给女性的情书。**

四个变量同时升维：

|---|---|---|
| 叙事框架 | 太阳系（家用） | **多神谱系**（神圣） |
| 关系判定 | G 引力（物理） | **G 引力 ⊕ S 灵魂共振**（物理+艺术） |

## 5 · 灵魂共振 S（Soul Resonance Index）

### 战略缺口
现有 G 引力**只测人格相似度**，不测"灵魂电波"。但用户洞察告诉我们：
> "如果两个人在'你最爱的歌'/'你最爱的句子'上回答得一样，他们更接近**灵魂伴侣**。"

这是**音乐/文学/视觉的美学共振**，是 G 之外的独立维度。

### 设计

#### Soul-Probe Questions（灵魂探针题，6 题）
插在 60 题主测中，**不显式标注**，对单人结果不影响 W/T/F/I/S 五轴打分，但**结果存档供配对时用**。

| # | 题型 | 选项形式 | 例子 |
|---|---|---|---|
| 1 | 音乐 | 4 段 8 秒音频 | 古典 / 民谣 / 电子 / 氛围 |
| 2 | 文学引语 | 4 句金句 | Calvino / 张爱玲 / 余华 / Plath |
| 3 | 颜色情绪 | 4 个色块 | 玫瑰陶土 / 暮紫 / 苔绿 / 灰蓝 |
| 4 | 电影画面 | 4 张静帧 | 王家卫 / 侯麦 / 北野武 / Lynch |
| 5 | 气味 | 4 个文字描述 | 雨后柏油 / 旧书页 / 海风 / 烟草 |
| 6 | 触觉 | 4 个文字描述 | 丝绒 / 粗陶 / 冷玻璃 / 旧木 |

#### S 公式

```
S = (1/6) × Σ exact_match(answer_a[i], answer_b[i])
```

> 完全相同的选择计 1，否则 0。S ∈ [0, 1]。

#### 双层叙事（G ⊕ S）

| G | S | 命名 | 文案模板 |
|---|---|---|---|
| 高 | 高 | **灵魂双星** ⚭⚭ | "你们的人格相似，灵魂频率也共振——这种相遇 0.3% 概率。" |
| 高 | 低 | **共轨陌生人** | "你们看起来像同一种人，但听的歌、爱的句子完全不同——值得深聊。" |
| 低 | 高 | **隔星相认** | "你们性格相反，但你们爱的东西**惊人地一致**。这是最奇怪也最深的连接。" |
| 低 | 低 | **平行宇宙** | "你们活在不同的时区。互相敬意，互不打扰。" |

**关键：S 是新的爆品弹药**——它解释了"我喜欢的人怎么和我 MBTI 不合却让我心动"这种**用户长期未被解答的困惑**，会带来一波内容裂变。

## 6 · 灵魂印记 Sigil（神秘学符号 · 终极结果资产）

### 概念
基于用户的人格神域 + 灵魂答案，生成一个**独一无二的几何符号**（sigil），盖在最终图鉴底部。

### 视觉构造

```
[外层] 椭圆轨道环（W 轴极性 → 椭圆离心率）
[二层] 6 角星（T 轴 → 角度旋转 0-60°）
[三层] 神圣几何（F 轴 → 三角/方/圆 三选一）
[四层] 三色光晕（S 轴 → 玫瑰/金/紫的混合权重）
[中心] 主神 sigil 字符（8 选 1 · Hecate ☽ / Athena ⚒ / Persephone ⚜ ...）
[外圈] 12 道刻度（每道 = 用户当日 1 月相位）
```

全部用 SVG 程序生成，**无 AI 图片成本**。每个用户拿到**唯一**的图，可作头像 / 印章 / 纹身参考。

### 增长杠杆
- "**这是只属于你的灵魂印记**" → 99% 转发率
- 长按下载高清 PNG（带 WTFTI 暗水印）
- 提供"另存为壁纸 1080×1920"按钮 → 锁屏曝光 30+ 次/天/用户

### 实施纪律
- 纯 SVG / `<canvas>` 程序生成，0 依赖。
- 与 cc-design 颜色 token 完全一致。
- "神秘学符号"的拣选限定在**已进入公共领域 800+ 年**的（炼金术、占星十二宫、北欧符文、八卦），**不抄袭实体宗教正在使用的标志**（如十字架、星月、卐）。

## 7 · 90 秒情绪编排（Emotional Choreography）

### 用户洞察
> "整个过程应该是有情绪起伏的、然后结果也是非常有创意的、多样化的。"

这是产品**最被忽视的体验设计**。下面是逐秒级的情绪曲线 spec。

### 情绪节拍表

| 阶段 | 时长 | 主导情绪 | 设计动作 |
|---|---|---|---|
| ① **Big Bang** | 3s | 敬畏 + 好奇 | 黑屏 → 奇点爆炸 → 主神召唤词 |
| ② **众神点名** | 5s | 庄严 + 期待 | 8 主神剪影流过屏幕，**最后一句幽默**："今天哪一位会认领你？" |
| ③ **W 轴问题** | 15s | 平静 + 自我审视 | 提问严肃，选项是诗意意象 |
| ④ **T 轴 + 幽默剧情** | 15s | 笑出声 | **嵌入 1 题"meme 题"**："凌晨 3 点你的脑子里在演一部电影 — A. 王家卫 B. 周星驰 C. 黑泽明 D. 蔡明亮" |
| ⑤ **F 轴 + 暗示性** | 12s | 心动 + 危险 | 用第二人称："如果今晚有人对你说……" |
| ⑥ **I 轴 + 哲学** | 10s | 沉思 | "你和谁更像？" |
| ⑦ **S 轴 + 灵魂探针** | 12s | 直觉 + 微震颤 | 音乐题播 8s 实音 → 突然安静 → "选" |
| ⑧ **召唤动画** | 4s | 紧张 + 惊喜 | 屏幕震动 → 暗下去 → "你的暗面正在苏醒……" |
| ⑨ **结果揭晓** | 6s | 顿悟 + 共鸣 | Big Bang 第二次（小型）→ 主神 + 三神侍 + 异能者 + 印记 一次性出现 |

### 节拍审核 checklist
- [ ] 每 30 秒至少有 1 次"小惊喜"（动画/音效/文案反转）
- [ ] 至少 1 处幽默（不超过 1 处，避免破坏神圣感）
- [ ] 至少 1 处"被温柔击中"（一句让她想截屏的引语）
- [ ] 至少 1 处"危险感"（暗面/塞壬/伯爵）
- [ ] 结尾必须**回归温柔**（避免用户带着不安离开）

## 8 · 多学科叙事链 (Discipline Stack)

整条体验链 = 7 个学科的对话，每章都让用户感觉"啊原来这也算"：

| 章节 | 主导学科 | 副学科 | 用户感受 |
|---|---|---|---|
| Big Bang 开场 | 物理学 | 哲学 | "原来宇宙学可以这么浪漫" |
| 主神点名 | 神话学 | 比较宗教学 | "我居然懂希腊和山海经" |
| W/T/F/I 测题 | 心理学 | 行为科学 | "好像在做严肃测试" |
| S 灵魂探针 | 美学 + 音乐学 | 色彩学 | "这题我从没见过" |
| 暗面召唤 | 奇幻文学 | 民俗学 | "我变成了一个角色" |
| 引力 G | 经典物理 | 数学 | "靠，匹配度居然有公式" |
| 灵魂共振 S | 信息论 | 美学 | "这才是我和 ta 的真相" |
| Sigil 印记 | 几何 + 占星 | 平面设计 | "这是我专属的咒符" |

**爆品逻辑**：女性用户在小红书发的不是「我是 INFJ」，而是
> 「我是**湘夫人化身 · 暴雨港湾 · 灵魂印记 ☽⚜△**，
> 我和 ta 的引力是 G=0.84，灵魂共振 S=0.83。
> 我们是**灵魂双星**。
> ——这一切都是 90 秒测出来的。」

→ **这种文案的转发率会是普通 MBTI 截屏的 5-8 倍**，因为：
1. 包含罕见词汇（湘夫人 / sigil / 灵魂双星）→ 评论区会问"这是啥"
2. 有数字（0.84, 0.83）→ 可信
3. 有符号（☽⚜△）→ 视觉记忆点
4. 有故事钩子（"灵魂双星"）→ 想分享 / 求测

## 12 · 人格碎片宫殿（Fragment Palace · 与 SoulTI 自然之力 + 历史伟人融合）

> 灵感源：用户洞察 ——
> *"引入一个'人格碎片宫殿/黑洞'，里面有很多碎片，每枚像镜子一样照出一位历史伟人或学者。我有 3 个特点就对应 3 位伟人，宫殿中至少 3 枚碎片显化内容。"*
>
> 这是**身份归属感**的最强承载——比"我是 INFJ"高 10 个量级。

### 12.1 · 战略定位
- **与 SoulTI 的桥**：SoulTI 已有"自然之力 + 历史人物"四层命名（WAVE=浪=海浪=伍尔夫）。WTFTI 把这一行小字**空间化**为一个可探索的"宫殿/黑洞"，让历史伟人不只是标签，而是**镜面碎片**。
- **与 Pantheon 的关系**：
  - **Pantheon 主神**（神圣 / 神话 / 永恒原型）= 你"是哪一位神的化身"
  - **Fragment Palace 伟人**（人间 / 真实 / 可考证）= 你"和哪些真实凡人共享精神基因"
  - 一神一人，**神性 + 人性**双锁定，避免叙事完全悬浮于神话。
- **跨模块复用**：碎片池一次构建，**SoulTI / WTFTI / Mysti 三模块共用**，是平台级 IP 资产。

### 12.2 · 视觉概念：宫殿 vs 黑洞
两种隐喻，同一个机制，按用户暗面强度自动切换：

| 隐喻 | 触发 | 调性 | 视觉 |
|---|---|---|---|
| **碎片宫殿 (Hall of Mirror Fragments)** | shadow 弱 / 主导轴温和 | 博物馆 · 庄严 · 米白金箔 | 椭圆穹顶大厅 + 24 面金边镜框悬浮 |
| **碎片黑洞 (Mirror Black Hole)** | shadow 强 / 主导轴极端 | 引力坍缩 · 神秘 · 暮紫玫瑰 | 中心吸积盘 + 镜面碎片绕奇点公转 |

**统一规则**：
- 整片空间陈列 **24 枚碎片**（4 轴 × 6 槽位）
- 用户的人格点亮其中 **3-7 枚**（最少 3 / 最多 7，按特征显著度）
- 未点亮的碎片为暗影轮廓 + 一行小字「未与你共振」
- 鼠标 hover / 长按点亮的碎片 → 翻转出该伟人的**一句箴言 + 一个共振点**

### 12.3 · 24 枚碎片矩阵（4 轴 × 6 人）

每轴 6 位伟人，覆盖**东方 + 西方 + 不同时代 + 不同领域**，避免只有"诺奖科学家 + 文豪"的精英偏见。

| 轴 | 极性 | 6 位历史共振者（领域） |
|---|---|---|
| **W (向外⇄向内)** | 极外向 | 苏轼 · Hemingway · Frida Kahlo · Bourdain · 张爱玲（少时） · Sagan |
| | 极内向 | 王维 · Emily Dickinson · 顾城 · Tarkovsky · Paul Klee · Tu Youyou |
| **T (理性⇄感性)** | 极理性 | Marie Curie · 张衡 · Hannah Arendt · 钱学森 · Hypatia · 屠呦呦 |
| | 极感性 | Simone Weil · Anaïs Nin · 三毛 · Rumi · Yayoi Kusama · 林徽因 |
| **F (利他⇄独立)** | 极利他 | 特蕾莎修女 · 林徽因 · 杨绛 · Schweitzer · 邓丽君 · Carl Rogers |
| | 极独立 | Nietzsche · 鲁迅 · Camille Claudel · 嵇康 · Diogenes · Octavia Butler |
| **I (秩序⇄混沌)** | 极秩序 | 康德 · 王安石 · Hilma af Klint · Glenn Gould · Borges · 司马迁 |
| | 极混沌 | Frida · Patti Smith · 王小波 · David Bowie · Pina Bausch · 庄子 |

**遴选纪律**：
- 50% 女性 + 50% 男性（女性向产品的硬约束）
- 30%+ 东方人物（中/日/印/中东）
- 涵盖 ≥ 8 个领域（科学、哲学、文学、艺术、音乐、舞蹈、电影、宗教、医学、政治改革、烹饪、登山）
- **不放在世活着的人**（避免代言/政治风险）
- **不放争议性历史人物**（避免被骂）
