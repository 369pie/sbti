# WTFTI 变现模式深度策略

> 一句话结论：**WTFTI 的最优变现结构是「轻订阅打底（¥19/月） + 高频单点付费（¥4.9 / ¥9.9 / ¥12.9） + 礼赠/藏品长尾（¥39.9 / ¥69）」的三层混合体，而不是单一会员制，也不是纯散点解锁。**
>
> 核心理由有三个，对应小红书女性用户三个真实心理：**情绪即兴消费 > 长期承诺**（→ 单点）、**"我想要一直被看见" 的轻仪式归属感**（→ 轻订阅）、**送礼/收藏 = 自我表达**（→ 礼赠/藏品）。

## 1. Phase 1 · 定位 & 用户：为什么要先想清楚"她是谁、她为什么会掏钱"

### 1.1 把 WTFTI 当作"变现产品"重新定位（Geoffrey Moore）

> 为**小红书 18-30 岁、刚经历或正在经历一段情绪/关系/选择的女性**
> 她们想要**用一种比塔罗专业、比 MBTI 时髦、比朋友圈不尴尬的方式，把自己的状态翻译成可分享、可收藏、可送人的东西**，
> 「WTFTI」是一套**多宇宙人格 / 关系 / 神谕 / 收藏 IP 矩阵**，
> 提供**"3 分钟玩、9 块 9 解锁、19 块订阅一个月仪式感、39.9 送朋友"的消费阶梯**。
>
> 不像**准了（专业重、价格高、男频偏多）、测测星座（广告污染严重）、星座女神（女性向但内容深度浅）、16Personalities（无社交、无收藏、无变现钩子）**，
> 「WTFTI」是**唯一在"自我 + 关系 + 鉴定他人 + 收集"四维都做到爆款级、又允许用户自由组合「免费玩 / 单次买 / 订阅 / 送朋友」**的产品。

**关键含义：变现不是"加一个付费墙"，是"把现有 4 模块各自的高潮时刻明码标价"。**

### 1.2 三个 Proto-Persona（围绕**变现意愿**重写，不是围绕"用户画像"）

| Persona | 占比假设 | 核心心理状态 | 最强付费触发 | 最该卖她什么 | 不能卖的 |
|---|---|---|---|---|---|
| **A. 深夜情绪购买者「林夏」**（22-26，互联网/快消/教培） | 35% | "今晚特别难受，想被一个东西好好理解" | 22:00-1:00 看完测试结果 → 灵魂信 paywall | 灵魂信 ¥9.9、SoulTI 三层修复处方 ¥12.9 | 月卡（情绪过去就忘）|
| **B. 仪式感订阅者「小满」**（25-30，设计/品牌/留学/HR） | 25% | "我希望生活有点仪式感，不要每天像 NPC" | 每日翻牌连续打卡 5 天后 / 月底月报推送 | **灵魂月度通行证 ¥19**（每日翻牌 + 月报 + Plus 分享卡） | 单笔 ¥39+ 一次性内容（觉得不持续）|
| **C. 关系送礼者「Yumi」**（24-32，已工作 + 朋友圈密集） | 25% | "想送闺蜜/对象一个有意思的小东西，但不要送俗的" | 闺蜜生日 / 七夕 / 圣诞 / 复合纪念 | **灵魂礼品卡 ¥39.9**、CPTI 双人报告 ¥12.9、藏品分享卡 ¥19.9 | 普通月度订阅（不是为自己买） |
| **D. 测试收藏家「樱桃」**（18-23，学生 + 高黏性 KOC 苗子） | 15% | "我想集齐所有宇宙人格卡，做出独一无二的'我'" | 解锁第 5 / 第 10 个宇宙；触达稀有度门槛 | 藏品分享卡 ¥19.9、年度通行证 ¥299 | 单宇宙小额解锁（嫌烦，要"All in"）|

> **Insight A：4 个 Persona，分别对应 4 种变现机制——单次、轻订阅、礼赠、年卡。任何一个都丢不得，所以"单一变现模式"必然漏掉 25-35% 的钱。**

### 1.3 JTBD · 用户雇佣 WTFTI 来"完成"什么

| 维度 | Job Statement | 当前竞品如何完成 | WTFTI 的钱怎么收 |
|---|---|---|---|
| **功能性** | "帮我把今天的混乱状态翻译成一个我能 get 的标签 / 故事 / 建议" | 准了：付费咨询师 ¥199-999；星座女神：每月付费栏目 ¥9.9 | **灵魂信 ¥9.9（单次） + 合盘 ¥12.9（单次） + 月报 ¥6.9** |
| **社会性** | "我要在小红书 / 朋友圈发一个'我是 XX'的截图，让别人秒懂我并搭话" | 16P 截图全网烂大街；MBTI 票友自截，毫无收益 | **分享卡 Plus ¥4.9（爆款 SKU）+ 藏品 ¥19.9 + 礼品卡 ¥39.9** |
| **情感性** | "在情绪低谷时被一个'懂我但不打扰我'的存在陪一阵子" | 冥想 App ¥218/年；小红书塔罗博主咨询 ¥30-200/次 | **轻订阅 ¥19/月 = 每日翻牌 + Plus 分享卡 + 月报** |

**关键发现：** 小红书女性把 WTFTI **同时雇佣**做三件事——而这三件事**对应三种完全不同的支付偏好**：
- 翻译状态 → 即时单次（情绪窗口窄，<10 分钟）
- 社交截图 → 微付费冲动消费（<¥10）
- 长期陪伴 → 轻订阅（拒绝高承诺，但接受"先订一个月")

> **这是为什么"纯订阅"或"纯单次"都是错答案。**

## 2. Phase 2 · MITRE 问题画布：变现做不起来到底卡在哪

### 2.1 Look Inward · 我们的偏见

| 偏见 | 表现 | 真实代价 |
|---|---|---|
| **"先做内容、再做变现"** | 15 个宇宙、420 张卡，付费链路只有 1 个模块（Mysti）做了 | 90% 流量进了"零变现宇宙"，CAC 永远高于 LTV |
| **"会员就是 All-Access Pass"** | 想做 ¥29/月 解锁所有付费内容 | 直接对标准了/星座女神，价位被压死，且与"轻仪式"调性矛盾 |
| **"单次解锁太累，做一次会员一劳永逸"** | 把希望全押在订阅上 | 小红书女性对"自动续费"的天然抵触会让转化率 < 1% |
| **"先做付费 paywall，后做账号"** | 已经在做（Mysti unlock 用 localStorage）| 用户清缓存 / 换设备 = 凭证全丢；付费用户的 NPS 必崩 |
| **"有支付链路就够了"** | `xunhupay` 集成了，但没有「订阅扣款 / 退款 / 客服流程」| 第一笔退款投诉就能上小红书黑稿 |
| **"广告 / 电商带货能填收入空缺"** | 过去内部讨论过开屏广告、塔罗周边带货 | **直接污染"灵性"品牌资产**，且小红书女性对"测试里跳广告"反感度极高 |

### 2.2 Look Outward · 谁在替我们教育市场，谁在挡我们的路

| 玩家 | 收入结构 | 对我们的启示 |
|---|---|---|
| **准了 App** | 咨询 50% + 会员 30% + 电商 15% | 高客单、高 LTV；但门槛太高，小红书冷启用户够不着 |
| **测测星座** | 广告 40% + 会员 35% + 电商 20% | 广告污染严重，但证明**"会员 35%"的盘子真实存在** |
| **星座女神** | 电商 45% + 广告 30% + 会员 20% | 女性向 ARPU 偏低（¥150）；电商带货能做但**会拉低品牌调性** |
| **小红书塔罗 KOC**（200+ 粉丝以上） | 私域咨询 ¥30-200/次 + 课程 ¥99-499 | 用户**愿意为「被理解的关系」付费**，**单次 ¥30 是甜蜜点** |
| **小宇宙 / Keep / Forest 等"轻仪式 App"** | 订阅 ¥19-25/月 + 年付折扣 30-40% | 证明**"轻订阅 ¥19"对小红书女性是接受带** |
| **泡泡玛特 / 一番赏** | 单抽 ¥59-79 + 整套溢价 | 证明**"收藏 + 稀有度"驱动复购**，可迁移到藏品分享卡 |
| **网易心遇 / Soul** | 月卡 ¥18 + VIP ¥58 + 单次 ¥6-30 | **三层定价已经被市场验证**：18 / 58 / 单次散点 |

**结论：在"塔罗 + 人格 + 收藏"赛道，¥19 月卡 + ¥9.9 单次 + ¥39.9 礼赠的价格带，是用户已经被教育好的"舒适区"。**

### 2.3 Look Outward · 谁被我们漏掉了

| 漏掉的群体 | 为什么漏 | 怎么变现 |
|---|---|---|
| **B 端 KOC / 中小博主** | 现在创作者中心是免费的，没有变现激励 | **创作者 Plus 通行证 ¥39/月**：解锁高级题库、Plus 分享卡水印授权、销售分润 30% |
| **送礼场景的"非用户"** | 礼品卡只能从已登录用户买 | **小红书直链购卡、不需注册即可送出**（关键流量入口）|
| **企业 / 团建 / 心理咨询师** | 完全没接触 | **B 端测试解锁包 ¥199-999 / 月**（次年再做，先记入 backlog）|
| **海外华人女性** | Stripe 已 ready，但定价、文案都没本地化 | **Mid-Year P2**，先验证国内模型再说 |

### 2.4 Reframed Problem

> **现状问题：** 我们已经有 6 个 SKU、4 个模块、15 个宇宙，但**没有一个"用户旅程级"的变现策略**——付费点是孤立的，没有让用户在"第 1 次惊喜 → 第 5 次回访 → 第 30 天留存 → 送朋友"的全链路上**自然升级到下一档付费**。

### 2.5 How Might We

1. **HMW** 让一个第一次看测试结果的用户，在 3 分钟内**自然"跨过 ¥4.9 门槛"**？
2. **HMW** 让一个买过单次解锁的用户，在第 7 天**自然"跨过 ¥19 月卡门槛"**？
3. **HMW** 让一个订阅用户，在第 30 天**自然"跨过 ¥39.9 送礼门槛"**？
4. **HMW** 让所有付费用户，在退订/退款时**愿意保留账号、转为自然 Advocate**？
5. **HMW** 让创作者**主动帮我们做付费分销**，而不是只做免费曝光？

> **混合的本质：**
> - L1 抓**冲动**——决策 < 30 秒、< ¥15、不需要承诺
> - L2 抓**关系**——30 天陪伴、可视化进度、随时可退
> - L3 抓**意义**——节日/送礼/收藏，价格带可上探至 ¥69+

### 4.3 为什么不是"纯订阅"——四个硬证据

1. **小红书女性月度可支配娱乐预算 ≤ ¥150**（多平台分配）：每多一个订阅就要替换一个，新订阅获取成本极高
2. **WTFTI 现有数据：7 天留存 < 5%**——没有日活/周活基础的产品做订阅，必爆退订
3. **塔罗/人格内容的"消费节奏"是事件驱动**（分手 / 跳槽 / 闺蜜聚会），不是日常驱动——单点付费天然契合
4. **小红书爆款词云里"测试 ¥9.9"高频出现，"测试 ¥29 月卡" 几乎为零**——市场已用脚投票

### 4.4 为什么不是"纯单次"——四个硬证据

1. **单次付费 LTV 难超 ¥30**（用户买完即走），LTV:CAC 在小红书投流环境下 < 2:1
2. **没有订阅 = 没有"每日翻牌"理由**，留存永远卡在 5%
3. **创作者 Plus 通行证、藏品月限定**这些"内容供给端"的玩法，必须依赖订阅基本盘
4. **送礼/年卡 SKU 单价 ¥39+**，没有订阅信任作为"温和爬坡"，直接卖 ¥39 转化必崩

## 7. Anti-Patterns · 这次必须避开

| 反模式 | 表现 | 防御 |
|---|---|---|
| **All-Access 会员**（解锁全部内容 ¥29/月） | 锚定竞品定价 + "看起来公平"的诱惑 | 用 ¥19 通行证 + "解锁 + 折扣 + 独家 + 仪式"的 30/30/30/10 结构替代 |
| **自动续费默认开** | 看上去 LTV 高 | 退款投诉直接上小红书黑稿；改成"到期手动续" |
| **测试中跳广告** | 短期收入诱惑 | 直接污染品牌；坚决不做 |
| **塔罗周边带货** | 看上去毛利高 | 物流退换问题会拖垮客服；改成"灵魂礼品卡 + 数字藏品" |
| **付费内容深度不够** | "9.9 块就给这？" 退款 | 灵魂信必须 ≥ 5 屏，且包含至少 1 段"为你写的信" |
| **付费链路只跑 Mysti** | 90% 流量浪费 | Sprint 1 必须把 paywall 复用到 SOULTI / CPTI / WTFTI |
| **过早做 B 端** | 销售周期长 | 推迟到 Q3，先把 C 端 LTV 跑通 |
