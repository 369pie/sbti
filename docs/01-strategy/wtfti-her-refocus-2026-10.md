## 2. 外部调研要点

- **留存最强的是情绪社交**：Soul 月留存 80%、付费率约 6.5%、ARPPU ¥104/月，90% 收入来自「情绪价值服务」（虚拟物品 + 会员）。
- **玄学的打法已被验证**：Co-Star（MAU 430 万）、Nebula（掌纹 + 星盘 + 塔罗 + 真人咨询）= 每日个性化运势 + 好友合盘 + 深度报告付费。
- **美妆是窄而稳的订阅**：美图订阅率 6.1%；YouCam 付费订阅约 100 万且增长停滞。
- **AI 试衣独立做会死**：Google Doppl 上线不到一年即关停。试衣是一次性尝鲜，只能做附属功能。
- **陌生人匿名社交风险最高**：Yik Yak 关停、7 Cups 被曝成年人接触青少年。15-17 岁 + 匿名 + 陌生人互动，是本项目风险最高的组合。
- **可借鉴的留存机制**：Finch（宠物 + 每日小任务）D1/D7 = 54%/37%；Co-Star 用个性化每日推送召回。

## 3. 定位

### 3.1 一句话

> **WTFTI：懂你的女生私人顾问——帮你看清自己、变好看、有地方说心里话。**

对外不用任何自造词（宇宙、神域、主神、Sigil 一律不出现）。

### 3.2 核心机制：「她的档案」

所有功能都往一份个人档案里写数据，所有每日内容都从档案里读：

```
       测我（输入）                美我（输入）              懂我（输入）
  人格类型 · 塔罗 · 掌纹        色彩季型 · 脸型 · 风格       心情记录 · 树洞
  八字/星座 · 「我和他」         妆容偏好 · 身材比例
            └───────────────┬────────────────┘
                        【她的档案】
                            │
                   【今日】每天一张个性化卡片
       今日运势 + 今日幸运色穿搭 + 一句妆容建议 + 今天想说点什么？
```

为什么是这个结构：
1. **留存**：档案越完整，「今日」越准越像为她写的。这是她每天回来的理由，也是离开的沉没成本。
2. **登录**：保存档案是自然的注册理由，用来解决 97% 匿名的问题。
3. **变现**：深度报告和 AI 变美都是在档案上加一层，付费有上下文，不是孤立地弹墙。
4. **收敛**：新功能只有一条准入标准，就是能不能写进档案、或者能不能让「今日」更好。不能的不做。

## 6. 粘性设计（按优先级）

1. **召回通道（前置，没有它其它都白做）**：Web Push（PWA）+ 邮件；如果主体合规，再评估微信服务号。每天只推 1 条「你的今日卡到了」。
2. **身份跟人走**：手机号或邮箱一键登录，匿名数据静默合并（CPTI 已有 merge 方案，推广到全站）。
3. **今日卡**：由档案驱动，每天不一样，确定性生成（同一天打开多次结果不变），不靠 LLM 实时生成，成本接近零。
4. **连续天数 + 档案完整度**：连续 7 天解锁一份免费深度报告。只奖励，不惩罚断签。
5. **树洞的「被回应」**：她发出的内容一定会得到回应（先由 AI，后有真人「抱抱」），回应到达时召回她。
6. **「我和他」双人循环**：配对码使用率只有 4%，要重做邀请页，这是唯一的免费增长来源。

## 8. Founder 裁决（2026-10-16）

1. **年龄：14 岁以上全功能开放。** 配套的底线保护（不额外限制功能，但必须做到）：
   - 全站不做陌生人私信，树洞只能用结构化回应（抱抱 / 我也是）；
   - 树洞公开内容先审后发，自伤风险内容自动转私密并展示援助热线；
   - 人脸/掌纹/全身照只用于本次生成，处理完即删除，不入库、不公开展示；
   - 未满 18 岁：AI 换装不提供泳装/内衣类服饰，不展示他人照片类 UGC；
   - 注册时填写出生年份（同时为八字/星座建档所用），用于以上判断。
2. **运营地区：继续海外运营。** 审核用 OpenAI moderation + LLM 风险分级；召回通道用 Web Push + 邮件，不依赖微信。
3. **品牌：保留 WTFTI。**
4. **节奏：P0-P3 全部按计划执行。** 第一步：新首页 + 今日页高保真原型，确认后再改线上代码。
