## §2 · 8 种问答仪式语法（Format Library）

### F1 · Either/Or 双行星
- **适用**：二元对立轴（E vs I、A vs P 等）
- **交互**：屏幕中央两颗发光行星缓慢悬浮，点击其中一颗 → 该行星放大 → 另一颗淡出
- **触感**：选中后短促 haptic + 玫瑰光晕
- **调性**：太空 · 极简
- **示例题**：
  > "在派对上，你会更想……"
  > 🪐 [被注视的中心 · WTFI-AUR] / 🌑 [角落里和一个人深谈 · WTFI-LIT]

### F2 · Polaroid Stack 拍立得叠
- **适用**：价值观排序、"哪张最像你"
- **交互**：4 张反面叠在一起的拍立得，用户上滑丢掉不要的，最后留下 1 张就是答案
- **触感**：滑动惯性 + 翻页声
- **调性**：复古 · 文艺
- **示例题**：
  > "把这 4 张拍立得照片排出顺序——最舍不得丢的留到最后。"
  > [童年家门口 / 大学最后一晚 / 第一次加班到天亮 / 一个人去过的最远的地方]

### F3 · Mirror Slider 镜面滑杆
- **适用**：连续光谱题（避开 1/2/3 的离散感）
- **交互**：屏幕上下两端是对立陈述，中间一根金线 + 一颗发光的圆球，左右拖动决定倾向位置
- **触感**：拖动时金线发亮 + 弱阻尼
- **调性**：浪漫 · 暧昧
- **示例题**：
  > 上："我一个人能走得很远"
  > 下："我需要被一个人深深认住"
  > [拖动球 → 0.0 ←→ 1.0]

### F4 · Tarot Pull 抽签
- **适用**：决策风格 / 命运感题 / 暗面题
- **交互**：5 张反扣的塔罗扇形展开，用户抽 1 张 → 翻面动画 → 才显示题目+选项
- **触感**：翻牌 0.6s flip 动画 + 金箔粒子
- **调性**：神秘 · 仪式
- **示例题**：抽到 The Tower → "你最近一次主动让某段关系结束，是因为……"

### F5 · 2 AM Text 凌晨短信
- **适用**：关系类 / 触发型题（情感投入 / 边界）
- **交互**：题目伪装成手机锁屏通知 — "你前任凌晨 3 点发来：『睡了吗？』"
- **下方 3 个 iMessage 风格回复气泡**可点
- **触感**：通知滑入 + 打字气泡 ...
- **调性**：戏剧 · 幽默 · 真实
- **示例题**：
  > 📱 [Mom · 11:47 PM] "我跟你爸吵架了。"
  > 💬 [立刻回电 / 装睡 / 隔天再说]

### F6 · Vinyl Drop 唱片
- **适用**：音乐 Soul Probe（仅）
- **交互**：4 张黑胶唱片摆在桌面，用户把唱针拖到一张上 → 播放 3s 静态封面 + 频谱动画 → 选择
- **触感**：唱针落下"咔哒" + 沙沙声 fallback
- **调性**：复古 · ASMR · 沉浸
- **当前替代**：没音频时显示静态封面 + 描述

### F7 · Color Drip 滴墨
- **适用**：颜色 Soul Probe（仅）
- **交互**：4 个色块漂浮，用户点选 → 该色滴入水中扩散 1.2s → 整个屏幕背景被这个色染上
- **触感**：水波 ripple + 余晖
- **调性**：视觉 · 治愈

### F8 · Whisper Input 私语输入
- **适用**：收尾开放题（不参与打分）
- **交互**：暗紫底 + 一根细金线下划线 + 24 字限制 + 字符计数旁边一颗呼吸的小星
- **触感**：键入时金线发光跟随
- **调性**：文艺 · 私密
- **示例题**："如果你能给 30 天后的自己留一句话，是？"

## §3 · 3 个章节仪式（Ceremony Moments）

### C1 · Sanctum Gate 神殿之门
- **时机**：进入测试前
- **交互**："请双手按住屏幕 1.5 秒，让神殿认出你的频率" → 长按 → 金线一笔写出 "WTFTI" → 解锁
- **目的**：把用户从"做测试"心态切到"参与仪式"心态；同时过滤低意愿用户提升完成率

### C2 · Sigil Sketching 印记勾勒
- **时机**：答完 ⅔ 题（当人格五轴已经确定）
- **交互**：屏幕中央 Sigil SVG 一笔一画程序绘出（4 秒），底部文字 "你的几何咒符正在被写下…"
- **目的**：中段奖励（防弃测）+ 把结果端的 Sigil 提前预告

### C3 · Stardust Sealing 星尘封信
- **时机**：答完最后一题
- **交互**：F8 写一句 → 文字飞起 → 装进信封 → "30 天后我会替你打开" → 收件箱写入
- **目的**：建立 30 天回访 hook + 收集 UGC（用于内容池）

## §7 · 工程约束

- **DB schema 不动**：所有新题型只是 UI 表现层，最终归一化为现有 dimension/answer 结构
- **Sigil/Sanctum 动画**：用 CSS + SVG `stroke-dasharray` 实现，避免 framer-motion 引入新依赖
- **触觉反馈**：仅在支持的设备上调 `navigator.vibrate?.()`；iOS Safari 不支持时静默
- **音频**：优先静态封面 + spectrum CSS 动画占位；M3 后再接 0.3s base64 sample
- **`react-hooks/set-state-in-effect`**：所有 URL/localStorage 水合放 `queueMicrotask`（已记入仓库 memory）

---

## §8 · 反模式（要避免的）

- ❌ "把所有题都改成新题型" — 同质化新形式 = 又一种统一性
- ❌ 动画过长（>1.2s）让用户失去节奏
- ❌ 仪式做成"必须看完不能跳过"，对老用户压迫
- ❌ 输入端华丽到掩盖结果端 — Sigil/Pantheon 仍是 hero
