## 零、为什么要再做一次重大升级

**04-16 深度战略**已完成定位、JTBD、OST、90 天路线图等内容沉淀，但回看实际产品，三个根本性问题**仍未被战略覆盖**：

### 问题 A — 视觉品牌割裂（用户反馈直接命中）

| 维度 | 主站 WTFTI | 灵鉴入口 `/mysti/` | 体感 |
|---|---|---|---|
| 主背景 | `#110f1c` soft midnight purple | `#0B0D17` 纯蓝黑 | 像跳到另一款产品 |
| 主强调色 | `#e8729c` 玫瑰粉 | `#C9A86C` 古铜金 | 调性断裂 |
| 文字色 | `#f5f2fa` 暖紫白 | `#F3EFE6` 偏暖象牙 | 微差但叠加割裂 |
| 字体倾向 | 中性现代 | 衬线 + 神秘 | 没有过渡 |
| 导航壳 | 主站统一 NavBar | mysti 直接裸露背景 | 没有"我还在 WTFTI 内"的锚点 |

**用户感知**："我从 WTFTI 主页点进灵鉴，像被传送到一个独立 H5——好看，但我会怀疑这是不是同一个团队做的。"

→ **04-16 战略默认了"暗黑神秘"的合理性，没有处理'与主品牌如何衔接'的问题。**

### 问题 B — 心流缺失"事件感"

当前用户路径：
```
进入 /mysti/ → 看到 dropdown → 选人格 → 点按钮 → 直接看到结果
                ↑                                    ↑
           零仪式                               高潮没铺垫
```

塔罗的核心情绪体验是"洗牌—抽选—揭晓"的**仪式戏剧**。当前实现把它压成了表单提交，**所有情绪势能在前 3 秒被泄掉**。

### 问题 C — 变现仍是"未来时"

04-16 文档列出了灵魂信 ¥9.9 / 合盘报告 ¥12.9 / 灵魂年鉴 ¥19.9，但：
- 代码层 0 实现（无 paywall、无 token 校验、无支付链路）
- 没有"先免费爽到 → 再付费深挖"的钩子节点设计
- 没有定义"什么样的用户在第几次访问、被什么内容触发付费"的转化漏斗

→ 战略层面把变现当成"后期再说"，工程层面就永远不会优先做。

### 1.1 升级版 Geoffrey Moore 定位

```

       同时把测试结果当社交货币的 18-30 岁城市女性，

灵鉴 是 WTFTI 多宇宙生态中的「神谕级人格镜像与亲密关系协议层」，

它把你的 WTFTI 人格翻译成一张灵魂塔罗牌、一张暗影牌、

不同于 04-16 战略中的定位（侧重内容深度与裂变），
v2 升级把灵鉴明确为：

  其他宇宙负责拉新（一次性测试爆款），
```

## 二、Phase 2: 问题框架（MITRE Canvas v2）

### 2.1 向内看 — 我们的三个核心假设升级

| 04-16 假设 | v2 修正 |
|---|---|
| "暗黑神秘 = 灵鉴专属皮肤" | **❌ 错。** 暗黑应该是"灵鉴模式"叠加在 WTFTI 主品牌之上的可切换层，不是替换品牌。 |
| "变现等内容深度做完再上" | **❌ 错。** 内容深度本身就是付费载体；二者必须同步上线，否则永远不会做。 |
| "塔罗仪式感靠 3D 翻牌动画就够了" | **❌ 错。** 仪式感是「时间结构」——3 秒洗牌 + 2 秒选牌 + 1 秒翻牌 + 5 秒文字逐句揭示，不是单独动画。 |

### 2.2 向外看 — 小红书女性 v2 调研补充

基于近 30 天对小红书"塔罗""灵魂测试""MBTI 之后""塔罗合盘"等关键词的爆款帖反推：

**爆款共性 5 条（v2 新增分析）**：

1. **"被命名"的爆款率 > "被分析"** — "你是月光型恋人"远比"你的依恋类型是焦虑型"传播力高 8x → 灵鉴的"灵魂牌名 + 副标语"必须**比塔罗牌名更前置、更大字号**
2. **"对照表/选项卡"格式天然涨粉** — "选一张牌看你的灵魂"4 选 1 视觉，互动率 18% → 灵鉴需提供**官方"选 1 看灵魂"卡组**给博主
3. **"暗面/Shadow"内容收藏率高于普通解读 2.4x** — 用户对"被看穿"的好奇 > 被表扬 → Shadow 内容必须**单独成卡**，不能作为附属
4. **"我和 TA 的"关系类内容评论数 > 单人内容 3x** — 合盘是天然的 UGC 引擎 → **必须降低合盘门槛到"3 步内完成"**
5. **22:00-2:00 是塔罗内容流量峰值** — 占全天 48% → **"夜间模式"不只是视觉切换，是产品形态切换**（更慢、更长、更深的内容呈现节奏）

**未被竞品占据的 3 个空白**：

| 空白 | 现状 | 灵鉴机会 |
|---|---|---|
| 「礼赠场景」 | 没有任何塔罗产品做"送朋友" | 灵魂信礼品卡 ¥39.9，附手写贺卡，扫码解锁 |
| 「关系档案」 | 测过就忘，无沉淀 | "我们的灵魂档案"页面，记录与每个人的合盘历史 |
| 「年度回顾」 | 网易云式年终内容只在 12 月出现 | 灵鉴每月生成"灵魂月报"，年底自动生成"灵魂年鉴" |

### 2.3 重新框架 — 5 个升级版 HMW

| 04-16 HMW | v2 升级 HMW |
|---|---|
| HMW 让神谕"准到哭" | **HMW 让神谕「分层揭示」**——前 30% 免费爽，后 70% 付费深读 |
| HMW 让合盘成为社交仪式 | **HMW 让合盘成为「3 步以内完成」的关系协议**——并自然导向"双人合盘报告 ¥12.9" |
| HMW 让每日翻牌成晨间仪式 | **HMW 让翻牌成为「每日心情日记的入口」**——并积累为月报/年报付费内容 |
| HMW 让分享图一秒抓眼球 | **HMW 让分享图本身就是「半个产品」**——看到的人可凭图直接生成自己的对照版 |
| HMW 让博主自发分销 | **HMW 让博主成为分销链的一环**——推荐链接 → 付费 → 30% 分润 |
| **🆕 HMW 让 mysti 视觉「既神秘又是 WTFTI」** | — |

### 2.4 🆕 视觉品牌统一框架

**核心原则：「灵鉴 = WTFTI 主壳 + 神秘仪式皮肤层」**

```
┌─────────────────────────────────────────┐
│  WTFTI 主导航条（玫瑰粉强调，不可替换）  │  ← 用户始终知道自己在 WTFTI
├─────────────────────────────────────────┤
│                                         │
│  [灵鉴皮肤层 — 可切换深/浅/夜模式]     │
│                                         │
│  - 主背景：从 #110f1c 渐变到 #0B0D17    │  ← 与主站颜色"对话"而非断裂
│  - 玫瑰粉 #e8729c 仍存在（作为 CTA 强调）│
│  - 古铜金 #C9A86C 作为「神秘层」叠加色  │  ← 主玫瑰 + 副金色
│  - 衬线字体仅用于"神谕段落"             │  ← 字体差异作为内容信号而非全局
│                                         │
└─────────────────────────────────────────┘
```

**新主题命名（替换原 celestial/pale）**：

| 主题 | ID | 主背景 | 强调色 | 适用场景 |
|---|---|---|---|---|
| **暮光（默认）** | `twilight` | `#1a1530`（主站紫黑 → 神秘紫的过渡） | 玫瑰粉 + 副金 | 全站默认，最大化品牌一致性 |
| **深夜（沉浸）** | `nocturne` | `#0B0D17`（现 celestial） | 金色为主 | 22:00-6:00 自动切换，长内容沉浸阅读 |
| **晨光（仪式）** | `aurora` | 米白 `#F7F4EF` + 玫瑰粉 | 玫瑰粉 + 暗紫 | 每日翻牌、轻量场景 |

→ 解决"割裂感"：默认主题与主站色彩家族同源，玫瑰粉是连接桥；深夜/晨光是用户主动切换的"模式"，而非被动承受的"另一个产品"。
