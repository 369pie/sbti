# WTFTI S 轴 · 12 道意识流投射题样本

> **目的**：跑通"投射 + 反应时 + 节奏"三种新题型，验证 S 轴可行性。
> **结构**：12 题 = 6 联想题 + 4 反应时题 + 2 节奏排序题。
> **使用位置**：主测 W-T-F-I 完成后，作为"暗面星球解锁" CTA 后出现。
> **预计耗时**：45-90 秒（每题 3-7 秒）。
> **算法约定**：每题给 S 轴一个 `[S: ±n]` 向量；反应时 < 1.5s 权重 1.0，1.5-3s 权重 0.7，>3s 权重 0.4。
> **风格**：保留荒诞文学体感；每题文案本身就是分享素材。

---

## 题型 A · 联想题（6 题）

> 给一个锚点（词 / 抽象图），3 秒倒计时内选第一反应。**没有正确答案**，提示语给到位。

### S-Q1 · 「窗」
**锚点**：屏幕中央一个发光的"窗"字。
**问**：你脑子里**第一个**冒出来的画面是？

- A. 凌晨没拉的窗帘 → `[S:+3]`
- B. 飞机舷窗外的云 → `[S:+2]`
- C. 朋友家厨房的小窗 → `[S:+1]`
- D. 一个没有特别画面的窗 → `[S:-2]`

### S-Q2 · 「红色」
**锚点**：一个抽象的红色色块。
**问**：你脑子里**第一个**冒出来的不是颜色，是什么？

- A. 一种声音（呼喊 / 心跳 / 警报） → `[S:+3]`
- B. 一个东西（消防栓 / 红包 / 番茄） → `[S:+1]`
- C. 一种情绪（生气 / 兴奋 / 喜庆） → `[S:+2]`
- D. 还是颜色，没别的 → `[S:-3]`

### S-Q3 · 「漂浮」
**锚点**：屏幕上一个轻轻上下浮动的几何形。
**问**：你**最先**联想到的画面是哪个场景？

- A. 海上漂着的小船，没人 → `[S:+3]`
- B. 太空里失重的宇航员 → `[S:+2]`
- C. 游泳池里的浮板 → `[S:+1]`
- D. 没什么场景，就一个浮的东西 → `[S:-2]`

### S-Q4 · 「门」
**锚点**：屏幕中央一扇半开的抽象门。
**问**：门后**最先**出现的是？

- A. 一段我没经历过的过去 → `[S:+3]`
- B. 一个具体认识的人 → `[S:0]`
- C. 一个房间，但是空的 → `[S:+1]`
- D. 没多想，门就是门 → `[S:-3]`

### S-Q5 · 「电话铃」
**锚点**：3 秒一段抽象铃声音效（可静音降级为文字"📞铃响了"）。
**问**：你**第一反应**是？

- A. 想象电话那头是谁 → `[S:+2]`
- B. 想象一个不接电话的场景 → `[S:+3]`
- C. 想接，但不知道说什么 → `[S:+1]`
- D. 没什么反应 → `[S:-2]`

### S-Q6 · 「白色房间」
**锚点**：一个抽象的纯白方形空间。
**问**：你**最先**想往里面放什么？

- A. 一个人，但看不清脸 → `[S:+3]`
- B. 一些植物 / 物件 → `[S:+1]`
- C. 不放东西，让它空着 → `[S:-1]`
- D. 想关掉这个房间 → `[S:-3]`

## 题型 B · 反应时题（4 题）

> 屏幕显示一个词或一组词，**5 秒内**点击你"觉得离自己最近"的那个。
> 反应时本身计入权重；超时降权而不是 fail。

### S-Q7 · 离我最近的"声音"
**问**：5 秒内点一个。

- A. 雨打窗户 → `[S:+2]`
- B. 地铁报站 → `[S:-2]`
- C. 远处吹的风 → `[S:+3]`
- D. 自己心跳的声音 → `[S:+1]`

### S-Q8 · 离我最近的"动作"
**问**：5 秒内点一个。

- A. 把头埋在被子里 → `[S:+2]`
- B. 划手机划到反应不过来 → `[S:+1]`
- C. 写一行待办划掉 → `[S:-3]`
- D. 站着发呆 → `[S:+3]`

### S-Q9 · 离我最近的"空气"
**问**：5 秒内点一个。

- A. 半夜的阳台 → `[S:+3]`
- B. 商场中央空调 → `[S:-2]`
- C. 长途车窗外的风 → `[S:+2]`
- D. 办公室打印机旁 → `[S:-3]`

### S-Q10 · 离我最近的"颜色"
**问**：5 秒内点一个色块（视觉以色块呈现，文字仅为辅助）。

- A. 雾蓝 → `[S:+3]`
- B. 暖米 → `[S:0]`
- C. 深绿 → `[S:+1]`
- D. 中性灰 → `[S:-3]`

## 题型 C · 节奏 / 排序题（2 题）

> 把一组词拖拽成"你觉得舒服"的顺序。**没有正确答案**。
> 算法记录最终顺序与犹豫次数（>2 次拖动 / 项 视为高犹豫）。

### S-Q11 · 把它们排成你"今晚"的顺序
**项**（拖拽排序）：
- 灯灭
- 一段没听完的歌
- 想起一件没回的消息
- 翻一下手机相册
- 真的睡着

> **打分逻辑**：
> - "想起没回的消息" 排在前 2 位 → `[S:+2]`
> - "翻相册" 排在前 2 位 → `[S:+1]`
> - "灯灭 → 真的睡着" 直接相邻且无中间项 → `[S:-3]`
> - 高犹豫（拖动总次数 ≥ 8） → `[S:+1]` 加成

### S-Q12 · 把它们排成你"理想周末"的顺序
**项**（拖拽排序）：
- 一个人散步 1 小时
- 和朋友吃一顿饭
- 看一部之前一直想看的片
- 睡到自然醒
- 写一段不发出去的字

> **打分逻辑**：
> - "写一段不发出去的字" 排在前 3 位 → `[S:+3]`
> - "和朋友吃饭" 排在第 1 → `[S:-2]`
> - "睡到自然醒" 排在第 1 + "一个人散步" 排在第 2 → `[S:+2]`
> - 高犹豫加成同 Q11

## 算法落地建议

```ts
// 伪代码：S 轴打分
type SOption = { key: string; sVector: number };
type SAnswer = { qid: string; option: SOption; latencyMs: number };

function latencyWeight(ms: number) {
  if (ms < 1500) return 1.0;
  if (ms < 3000) return 0.7;
  return 0.4;
}

export function scoreSAxis(answers: SAnswer[]): number {
  const sum = answers.reduce(
    (acc, a) => acc + a.option.sVector * latencyWeight(a.latencyMs),
    0,
  );
  // 12 题 × ±3 × 1.0 = ±36 范围 → 归一化到 -3..+3
  return Math.max(-3, Math.min(3, sum / 12));
}
```

> 排序题（Q11 / Q12）单独走"模式匹配 → S 向量"映射，再按 latency 加权。
> 推荐与现有 `src/lib/wtfi/scoring.ts` 同模式：tanh 软裁剪、单 axis 输出。

## 内测验收标准

- 12 题完成率 ≥ 85%（任意题超过 3s 仍可继续）
- 平均完成时长 ≤ 90s
- S 分数分布近似正态，左右长尾各 ≥ 8%（避免全员中性）
- A/B：暗面卡分享率 ≥ 主星卡分享率（验证"最 spicy"假设）
