## 零、战略前提：为什么是「野蛮生长」而不是"打磨"

### 0.1 时机判断（Now or Never）

小红书女性向人格测试赛道正处于**类目升温但尚未出现垄断级品牌**的窗口期：

| 信号 | 来源 | 含义 |
|------|------|------|
| MBTI 二创测试月搜索量 1200 万+ | 已验证（`xiaohongshu_tarot_market_research.md`） | 用户对"同一个人格，换一层皮"的需求不断在涨 |
| 塔罗测试月搜索 500 万+，AI 塔罗年增 300% | 已验证 | 神秘学+测试是最肥的流量池 |
| 情感/CP 配对测试互动率 8-15% vs 平台均 3-5% | 已验证 | 关系类测试的病毒系数已被证明 |
| sbti 在小红书的爆火（自嘲式 WTF 命名） | 用户观察 + 本仓库 WTFTI 分享卡真实反馈 | **"被说中的尴尬感"** 是 GenZ 女性新一代社交语汇 |
| herti 引发的"历史女性原型"热潮 | 已对标分析（`docs/02-modules/soulti/soulti-vs-herti-competitive-strategy.md`） | **"文学性人格叙事 + 女性主义标签"** 成为小红书新的身份货币 |
| cpti 6 位码在闺蜜群的收集裂变 | 产品已上线，观察中 | **关系命名权** 是下一代测试产品的杀手功能 |

**战略判断：**

> HERTI 把"文学性 + 历史女性原型"占住了，但她没有多宇宙、没有收集、没有关系、没有 UGC、没有深度付费；
> 测测星座/准了靠老用户吃老本，对 Z 世代的语感完全脱节；
> **没有任何一个竞品同时具备：多宇宙图鉴 × 神秘学仪式感 × 女性成长叙事 × CP 关系资产 × UGC 创作分成。**
> **WTFTI 正站在一个独占位的窗口前，不跑马圈地就是浪费。**

### 0.2 什么是「野蛮生长」定义（本文专用）

> **野蛮生长 ≠ 堆功能、堆宇宙、堆推广预算**
>
> **野蛮生长 = 每 7 天有一次"可被小红书博主自然使用"的产品事件，且每个事件都能同时完成以下三件事：**
> 1. **新增一批外部流量**（博主带来的粉丝 / 爆款帖子 / 新搜索词）
> 2. **留下可沉淀的用户资产**（图鉴卡 / 关系档案 / 深度报告 / UGC 创作者账号）
> 3. **产生下一个事件的种子**（新宇宙 / 新博主 / 新热点 / 新付费理由）

这是一个**内容-创作者-用户-资产**的四轮飞轮，而不是单轮的"搞推广"。

### 0.3 核心设计原则（不可违背）

1. **女性优先（Women-first, not women-only）** — 默认用户是 18-30 岁女性，所有叙事、视觉、文案、命名都先过"她会不会截图"这一关；男性以"被邀请的配对方"身份进入，不主动获客。
2. **女权叙事是骨（不是标签）** — "给自己浇水"、"拒绝被优化"、"关系里的主体性" 是文案内核；不喊口号，用人格描述/神谕/修复处方承载。
3. **神秘学是壳（不是科学）** — 塔罗/星座/月相/花语/鸟格是仪式外衣；底层是心理学评分，但前端呈现永远偏向"玄学般准"。
4. **浪漫叙事是皮** — 文学化散文、古风、影视剧代入、诗意命名优先于功利说明文。
5. **轻社交 > 重社区** — 不做陌生人社区（伪命题），全部走"闺蜜群/朋友圈/发给 TA 看"的熟人传播链。
6. **卡牌娱乐收集 > 专业心理测评** — 用户在"拆盲盒"不在"做问卷"；一切结果页都应是"卡"不是"表"。
7. **分享 FOMO > 推送通知** — 野蛮生长阶段不碰 push，只靠"她晒了这张我没有"制造回访。
8. **UGC 平台化是第二引擎** — 第一引擎是 PGC 官方宇宙，第二引擎是邀请制博主自建题库并按成交分成——两个引擎同时点火。

## Phase 1: 定位 & 市场语境（Positioning & JTBD）

### 1.1 Geoffrey Moore 定位声明（野蛮生长版）

```
For    18-30 岁、活跃于小红书/微信的中国女性，
       正在以"自我认知 × 关系命名 × 社交谈资"三件事喂养她的内容消费，

that need  一种同时能"被读懂、被收藏、被转发、被闺蜜拉进来"的人格体验
           ——比 MBTI 有温度，比塔罗有收集，比 HERTI 有剧情延伸，
           比测测星座有品味。

WTFTI  is a  女性向多宇宙人格图鉴 × 关系资产 × UGC 创作平台

that   用 15+ 宇宙（自嘲毒舌 / 修仙 / 塔罗 / 花语 / 鸟格 / 恋爱 XP / 班TI / ...）
       把同一个灵魂翻译成无数张可收集的卡牌；
       用 CPTI 把她和闺蜜/暗恋对象/老公的关系永久命名、归档、晒出来；
       用 SoulTI 在深夜给她一封"被彻底看见"的灵魂长信；
       用 UGC 平台邀请小红书博主把她们的创意 4 小时上线成付费主题宇宙，
       博主拿分成，用户拿新鲜感，平台拿规模化内容。

Unlike  HERTI（美但停在标签、无收集、无关系、无下一层），
        测测/准了（Z 世代语感断裂，像她妈会用的 APP），
        16Personalities（严肃工具，不好玩不好晒），
        趣测类小程序（粗糙、无品牌、无沉淀、做一次就关闭），

WTFTI  provides  "测 = 收集 = 关系 = 谈资 = 成长"的一条龙女性内容资产引擎
                 ——不是再多一个测试，是把"做测试"这件事产业化。
```

### 1.3 Proto-Personas（升级版，从 V2 3 个 → 5 个，贴近野蛮生长期）

#### P1 — 「社交货币猎人」小何（25%，**流量主力**）
与 V2 一致。核心行为：刷到→3 分钟做完→截图→发群。**野蛮生长期关键**：给她每 7 天新宇宙 / 新卡面；截图上必须自带"测了没？→ wtfti.com"病毒钩。

#### P2 — 「深夜神谕寻求者」小月（20%，**付费主力**）
与 Mysti 战略一致。22-24 点 DAU。**野蛮生长期关键**：SoulTI 灵魂信深度付费（¥9.9/19.9），她是首批¥付费人群；**不能靠 push，要靠日签邀请**。

#### P3 — 「关系解码者」糖糖（20%，**裂变主力**）
CPTI 的天然传播者。**野蛮生长期关键**：CPTI 账号化 + 二度鉴定（A+B 合盘 → 拉 C 来鉴定他俩）；关系图鉴永久保存 = 登录钩。

#### P4 — 「收集瘾患者」多多（15%，**留存主力，本期新增**）
| 维度 | 描述 |
|------|------|
| 画像 | 22 岁，泡泡玛特/Jellycat 重度玩家，已集齐 3 个宇宙 |
| 动机 | "我差一张隐藏款" / "我想把 15 个宇宙都测一遍" |
| 痛点 | 当前 WTF Card 只显示已测，空卡位不可视 → 不知道差啥 |
| 钩子 | 图鉴墙进度环 + 稀有度徽章 + "本周限定卡池" |
| 付费 | 愿为"解锁隐藏人格抽卡券"付 ¥3-6 |
| 战略价值 | ⭐⭐⭐⭐⭐ — 每日 DAU 主要贡献者 |

#### P5 — 「小红书测试博主」阿星（20%，**UGC 供给侧，本期放到第一梯队**）
与 UGC 平台战略 Persona C1 一致。**野蛮生长期关键**：首批 10 位内测博主 + 分成透明 + 4h 上线 SLA；她们每人发 3 条帖 = 30 条免费广告。

> **女性用户占比假设：P1+P2+P3+P4 = 80%（纯女性）+ P5 女性占 90% → 全量 95%+ 女性。男性用户作为"被邀请的配对方"存在，不主动获客。**

#### Pains / Gains（野蛮生长期关键痛点）

**Pains：**
1. 女性用户测完想把卡**永远保存**（换手机/清缓存归零）→ **必须登录，但不能在第一屏问**
2. 想**把 TA 拉来一起玩**但链路断裂（扫码→没耐心做完）→ **测试必须 3 分钟以内有结果**
3. 想**找到"和我一样的人"**但没有入口（社区是伪命题）→ **改成"同型金句墙"+"同型 3 张高质量图"**
4. 博主想**做自己的测试**但没工具 → UGC 平台必做

**Gains：**
1. 收集满足感 × 神秘仪式感 × 关系命名权 = 三重情绪复合（这是我们独占的）
2. 文艺写作质感 × 自嘲毒舌反差 = "又好哭又好笑"的新型内容体验
3. UGC 分成 × 博主专属宇宙 = **创作者把自己粉丝变成我们用户**的双赢飞轮

## 八、唯一的"必须守住"

1. **女性优先** — 任何"兼顾男性市场"的提议，野蛮生长期 90 天内一律 kill
2. **零付费投流** — 一分钱不投
3. **博主 UGC 平台先于所有新宇宙** — 不要再让团队去新建宇宙，让博主去
4. **CPTI 账号化不晚于 Day 35** — 这是裂变飞轮的钥匙
5. **SoulTI 散文化重写不晚于 Day 56** — 这是对抗 HERTI 的唯一武器
6. **每 7 天有一个"博主可用的产品事件"** — 新宇宙 / 新模板 / 新分成规则 / 新数据看板
7. **所有视觉/文案过"女权体检" checklist** — 不做无脑可爱化
8. **不做陌生人社区** — 只做熟人链
