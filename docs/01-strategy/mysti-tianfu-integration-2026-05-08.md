# Mysti × Tianfu Agent · 整合提案

## TL;DR

> **Tianfu Agent 给我们的，不是"一个更准的算命师"，而是一个可以反复调用的"确定性命理后端"。**
>
> Mysti 不去和准了 App 比"准"，**Mysti 用 Tianfu 当 backend，用编辑部当 frontend**，把命理的硬数据翻译成"她听得懂、想保存、愿意分享"的现代女性叙事。
>
> 战略地位：这是 Mysti 从「日抽卡陪伴」升级为 **「她的私人占星编辑部」** 的关键拼图，也是 WTFTI 平台支柱 Ⅱ「WALK WITH HER」第一个真正建立护城河的产品。

---

## 1. 为什么这件事值得做

### 1.1 Tianfu Agent 解决了什么
- 命理推理 = 排盘 + 飞宫 + 取用神 + 三方四正 + 大限流年，**衍生数据组合爆炸 + 空间关系拓扑 + 推理链长**
- 通用大模型基线 (Claude Opus 4.6) 在 MingLi-Bench 上 40% 截尾准确率
- Tianfu Agent 跑到 **50%**，逼近人类 Top-20 选手平均 **53.5%**
- 核心做法三件事：① 200+ 专用原子工具做确定性计算 ② 行业推理规则也写成函数 ③ 多流派合参 + Sub-Agent 自评量化"直觉"

### 1.2 这对 Mysti 意味着什么
当前 Mysti 的"每日抽牌 / 月度灵魂信 / 月报"内容生产，本质上还是 **prompt + 通用 LLM 拼凑**，三个结构性问题：

| Mysti 当前痛 | 根因 | Tianfu 解法 |
|---|---|---|
| 内容"看起来都差不多" | 没有真实命理底层 → LLM 泛化 | 用排盘数据做种子 → 每个用户/每天都是真实独特的 |
| 月度灵魂信无法承诺"为我而写" | 输入仅有用户填的几个字段 | 紫微/八字一次性算完，整月内容有连续性骨架 |
| ¥19/月订阅价值说不清楚 | 内容感知和免费抽卡差异不大 | 订阅版接 Tianfu 个性化命理流，免费版只看通用诗签 |

### 1.3 但绝对不能做的事
- ❌ **不变成准了 App** —— 不接占卜师、不接咨询、不收"问事"提问
- ❌ **不强调"准确率"** —— 数字一旦上首页，调性就崩了，违背"玩 > 信"
- ❌ **不让 Tianfu 的输出直出给用户** —— 命理黑话（用神、飞宫、化忌）全部要被编辑部翻译过
- ❌ **不打"AI 算命师"标签** —— 我们卖的是"她的现代神话"，不是"AI 比真人更准"

> Tianfu 只在后端跑，**前端永远是 Editorial Atelier × 暮光博物笔记的语气**。

## 2. 三条整合路径（按价值 × 可行性排序）

### 路径 A · "她的星图档案"——一次性深度档案（W2-W3 优先做）

**产品形态**
- 用户填出生时间 / 地点（可选）
- Tianfu 后端跑一遍紫微 + 八字 + 简版西占
- 输出一份 **「她的星图档案 · 现代女性版」** ：
  - 主星人格翻译（用 WTFTI 已有的"主神化身"语言系统包装紫微主星）
  - 流年三章（今年的三个关键时刻 + 编辑部叙事）
  - 12 月主题（每月一个 italic 短语，不写"宜忌"）
  - 一张可分享的 Shrine 长卡

**商业化**
- ¥39 单次解锁（一次性、永久保存、可下载 PDF）
- ¥19/月 通行证用户 **送 1 次** + 后续 ¥19 一次

**为什么先做这个**
- 一次性产品 = 调用成本可控（不是每天高频调）
- 价格锚点高 = 反向证明 ¥19/月 通行证"很便宜"
- 可分享 = 自带获客
- **不破坏 Mysti 现有日抽卡的轻盈感**

**Editorial 翻译范例**
> Tianfu 输出：紫微在命，化禄会照，三方四正格局清贵
> Mysti 翻译：
> > *她生来就站在台前，只是有时候忘了。*
> > 你的主星把"被看见"写进了你的命里 ——
> > 不是去争，而是允许那束光照过来。

### 路径 B · "今日的预兆"——日抽卡升级（W3-W4）

**产品形态**
- 当前免费版：随机塔罗 / 人格牌 + 一段编辑部短文
- 新订阅版：基于用户星图档案 + 当日干支 + Tianfu 流日推演 → 给"今日只属于她的一张签"
- 视觉沿用现有抽卡卡面，但 **底部加一行"今日宇宙坐标"**（金箔细字、不张扬）

**商业化**
- 免费版保留通用日抽卡（获客 + 留存）
- 通行证 ¥19/月：解锁"流日她信"（每日 80-120 字、命理为底、编辑部为面）

**关键克制**
- 不写"今天财运 X 分""今日不宜签合同"这类 App 化语言
- 一律改成 italic 提示句："今天她适合慢一点""今天有人会突然看见她"
- **绝不预测具体事件**，只给"心境提示"

### 路径 C · "她词条"共建素材源（W5+ 长线）

**产品形态**
- Tianfu 不仅给个体用户跑命盘，也作为 **平台知识基础设施**
- 节气、日蚀、行星逆行、流年大事件 → Tianfu 给出"今天对哪些主星 / 命格的女性最相关"
- 触发 HER-VOICE 定向征集：**"今天水逆，X 命格的姐妹来留一句"**
- 优质留言进入「她词条」共建百科

**战略意义**
- 把 Tianfu 的"确定性"和 HER-VOICE 的"真实经验" **结构化绑定**
- 形成 **"AI 给坐标 + 女性写经验"** 的双轮飞轮 —— 这才是创始人说的"AI 新时代知识共建"在产品上的真正落地
- 三年后看，「她词条」会变成中文女性的现代命理百科，而 Tianfu 是它的引擎

## 3. 技术与法律风险盘点

| 风险 | 严重度 | 应对 |
|---|---|---|
| Tianfu 是否开源 / 可商用 | 🔴 高 | 先去 GitHub 仓库读 LICENSE；如非商用，走合作 / 自研对标方案 |
| 调用成本（200+ 工具 + Sub-Agent） | 🟡 中 | 一次性档案高客单价覆盖；日抽卡只在订阅层调用 |
| 命理内容法规风险（中国大陆） | 🟡 中 | 始终用"娱乐 / 文学解读"语境；FAQ 明确"不构成建议"；不做问事 / 不做收费咨询 |
| 出生时间隐私 | 🟡 中 | 客户端加密；不强制；可选只填阳历日期，不填时分 |
| "准确率"被滥用比较 | 🟢 低 | 全站不出现"准确率""命中率"字样；对外只说"为她而写" |
| Mysti 现有日抽卡用户被迁移破坏 | 🟢 低 | 免费版完全不变；新内容只在订阅层叠加 |

## 5. 文案与定位措辞（直接可用）

**首页支柱 Ⅱ panel 的 italic 引言**（替代当前 Mysti 那行）
> *她的每一天，都值得被宇宙认真接住一次。*

**「她的星图档案」product 一句话**
> 不是算命，是你这一生的现代神话提纲。

**¥19/月 通行证价值说明三点（替代当前裸价格）**
1. 365 天 · 每天一句只属于她的预兆
2. 12 月 · 每月一封写给她当下的灵魂信
3. 1 次 · 价值 ¥39 的"她的星图档案"赠送

**FAQ 新增一条**
> Q：你们用 AI 算命吗？准吗？
> A：我们用了一个非常聪明的命理引擎做底层（它在专业测评里接近顶尖人类水平），但我们从不打算"算准你的命运"。我们只想用它给你一个起点，然后用编辑部的笔，把它翻译成一段你愿意保存、愿意分享、愿意明年再看一次的话。**算不算得准不重要，写不写得动你才重要。**

## 6. 决策点（已拍板 · 2026-05-08）

1. ✅ **「她的星图档案」定为 W2-W4 P0**。和首页改版同步上线，作为 Mysti 第一次有真护城河的产品。
2. ✅ **走自研对标路线**。不依赖 Tianfu Agent 仓库的 license / 调用成本 / 不可控演进；以 MingLi-Bench 为外部标尺，自研一套"确定性命理后端 + Editorial 翻译层"作为长期资产。W1 先用通用 LLM + 简版排盘出 v0 验证商业化，W3 起按 200+ 原子工具思路逐步迁移。
3. ✅ **「她词条」W5+ 试点，Q3 升级为战略级 epic**。这是平台支柱 Ⅲ「WRITE WITH HER」的真正答案，自研命理引擎是它的发动机，HER-VOICE 是它的活水。
