## 四、视觉风格规格

### 基底：充气乙烯手办 (Inflatable Vinyl Toy)

与班TI·HP 版**完全同源**的材质体系，仅换角色参考：

```
An inflatable oversized vinyl toy figure,
shiny smooth PVC plastic surface with glossy reflections
and subtle seam lines where inflatable sections meet.
The character has soft bulging proportions of a large
air-filled balloon figure — chunky rounded limbs,
slightly oversized head, everything looks pumped full of air.
Smooth glossy plastic skin with bright highlight reflections.
```

### 王者特化规则

| 规则 | 说明 |
|------|------|
| **角色参考** | 提取王者英雄的标志性元素（武器、特效色、服装轮廓），但**不复制皮肤原画** |
| **抽象化处理** | 充气手办本身就是高度 Q 化的，进一步降低 IP 侵权风险 |
| **混搭现代元素** | 和 HP 版混搭办公用品一样，王者版混搭**手机、耳机、奶茶**等日常物品 |
| **道具规则** | 2–3 个悬浮充气道具，一个来自王者（武器/特效），一个来自日常 |
| **配色** | 跟随英雄主色调，但偏马卡龙/高饱和（充气塑料感） |
| **绝对禁止** | 画面中出现任何文字、王者荣耀 logo、官方UI元素 |

### 单角色 Prompt 示例 — 妲己 × 倒贴甲方

```
An inflatable oversized vinyl toy figure, shiny smooth PVC plastic surface
with glossy reflections and subtle seam lines. Soft bulging balloon proportions,
2.5 head-body ratio, pumped full of air look.

A cute fox-ear girl character in a stylized ancient Chinese dress with
fluffy pink-purple accents, oversized sparkly eyes gazing upward with an
eager-to-please expression, small heart-shaped blush on puffy cheeks.

Floating inflatable props: a tiny glowing pink heart, a miniature approval
stamp, a small bubble tea cup.

Clean single-color background (soft pink-lavender gradient).
Soft even studio lighting with bright highlight reflections on PVC surface.
The material is clearly shiny inflatable vinyl, NOT matte, NOT fabric.
ABSOLUTELY ZERO TEXT in the image.
```

## 八、IP 风险控制

| 角色形象版权 | 充气手办风格高度抽象化，不使用官方原画 / 皮肤 |

| 腾讯律师函 | 产品定位为"粉丝致敬向人格测试"，如收到通知即时调整 |
| 长期策略 | 验证流量模型后，可考虑申请腾讯创作者/内容合作计划 |
