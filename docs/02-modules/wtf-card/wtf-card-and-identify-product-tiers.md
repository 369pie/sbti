## 一、模块定位

### WTF Card — 个人身份凭证
- 当前定位：多宇宙测试结果汇总看板（成就展示）
- 目标定位：平台核心社交资产，用户在 WTFTI 的一切身份、关系、收藏的载体
- 核心价值：用户每测一个宇宙、每鉴定一个朋友、每收藏一张卡，都在为这张卡增值

### 灵鉴 — 人格鉴定服务
- 当前定位：好友人格鉴定小游戏
- 目标定位：独立的鉴定入口，社交裂变核心引擎 + 付费转化场景
- 核心价值：A 鉴定 B → 分享给 B → B 被好奇心驱动来平台 → 裂变闭环

## 三、登录触发点设计（不强制，自然引导）

每个触发点都是"用户想要更多"的时刻，不是"平台要求你"：

| 场景 | 触发文案（示意） | 层级跳跃 |
|------|------------------|----------|
| WTF Card 有 3 个宇宙亮了，剩下灰的 | "登录解锁全宇宙图鉴，看看你还能点亮几个" | 匿名 → 登录 |
| 用户换设备访问 Card，数据为空 | "检测到新设备？登录同步你的卡牌数据" | 匿名 → 登录 |
| 灵鉴结果页，想保存鉴定记录 | "登录永久保存这次鉴定，不让它过期" | 匿名 → 登录 |
| CPTI 关系图鉴显示"本地存储" | "登录同步关系数据，换设备不丢失" | 匿名 → 登录 |
| 深度对比想看详细分析 | "登录查看完整逐维度对比报告" | 匿名 → 登录 |
| 卡面皮肤预览 | "解锁限定卡面 🌟 高级会员专属" | 登录 → 付费 |
| 鉴定结果想看专业解读 | "解锁深度专业解读（¥X）" | 匿名/登录 → 付费 |

## 四、信息架构建议

### 首页入口重构（目标 4 个核心入口）

```
首页
├── 🎯 去测试（含所有宇宙入口）
├── 💳 我的卡（WTF Card → 个人身份中心）
├── 🔍 鉴定 TA（灵鉴独立入口）
└── 🌟 探索（Mysti / Daily / UGC / 趣味模块）
```

### WTF Card 页面升级方向

```
WTF Card 页
├── 卡片展示区（昵称、ID、进度环、徽章网格）
├── 展柜区（置顶的 5 个结果）
├── 关系图鉴（CPTI 配对收藏）
├── 鉴定记录（灵鉴历史 — 登录后）
├── Mysti 收藏（卡牌收藏 — 登录后）
└── 分享 / 设置
```

## 五、数据架构变更需求

| 变更 | 当前 | 目标 |
|------|------|------|
| WTF Card 存储 | 纯 localStorage | localStorage（匿名）+ Supabase（登录同步） |
| 灵鉴结果存储 | sessionStorage（12h TTL） | sessionStorage（匿名）+ 永久存储（登录） |
| 关系图鉴 | 匿名 auth + 本地 | 绑定用户账号，持久化 |
| 用户系统 | 匿名 auth | 匿名 auth + 可选注册（社交登录 or 手机号） |

## 六、优先级排序

### Phase 1：独立入口 + 登录引导（不做新功能，只做入口重构）
- 首页信息架构调整，WTF Card 和灵鉴作为独立入口
- 匿名层功能保持不变
- 加入登录触发点 UI（文案引导，不做强制）

### Phase 2：登录层核心功能
- 用户注册/登录（社交登录）
- WTF Card 跨设备同步
- 灵鉴记录永久保存
- CPTI 关系图鉴云端同步

### Phase 3：付费层 MVP
- 高级卡面皮肤（最简单的付费点）
- 灵鉴深度专业解读（详细人格分析报告）
- 关系深度分析报告
