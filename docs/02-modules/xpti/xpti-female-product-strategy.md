> **背景**: 小红书 XPTI（XP人格测试）帖子爆火（2966赞/710收藏/437评论），原版为男性向20题，基于 D/V/P/F/S/E/N/R 8维度。SBTI 需迅速推出差异化女性向版本抢占窗口。

## 一、竞品拆解：原版 XPTI 做了什么

| 维度 | 原版设计 | 问题 / 机会 |
|------|---------|------------|
| 目标用户 | 专为男生打造 | **女性用户占小红书 >70%，但无女性版** |
| 维度体系 | 8维: D支配/V视觉/P纯爱/F幻想/S顺从/E情感/N混沌/R现实 | 维度命名偏学术，缺乏传播感 |
| 题量 | 20题 | 合理，不会太长 |
| 描述风格 | 偏正经心理测试口吻 | 缺乏 SBTI 式的荒诞自嘲 |
| 分享设计 | 无（纯文字帖子） | **无成品分享图 = 最大的空白地带** |
| 结果呈现 | 8维打分，无人格卡 | **没有人设卡 = 缺乏截图传播物料** |
| 内容安全 | 擦边，直球 xp | 容易被平台限流/举报 |

### 核心洞察
原版的火爆证明了需求存在，但它的产品化程度为 0（只是一个帖子+外链）。SBTI 可以用**更高的产品完成度 + 女性视角 + 自嘲人设卡**碾压式截胡。

## 二、战略定位：不做「性癖测试」，做「恋爱脑 XP 图鉴」

### 2.1 核心重新定义

| 原版叫 | 我们叫 | 为什么 |
|--------|--------|--------|
| XP人格测试 | **XP人设图鉴** / **你的恋爱XP是什么款** | "图鉴"是 SBTI 品牌基因；"款"暗示收集 |
| 性癖核心指数 | **XP 体质** / **恋爱DNA** | 去露骨化，保留好奇心 |
| 测你的真实 XP | **测测你在爱情里是什么体质** | 从"性"转向"恋爱偏好"，安全且女生爱测 |

### 2.2 品牌叙事（一句话定位）

> **"MBTI 测你是什么人，XPTI 测你爱上什么人。"**

备选：
- "你以为你是恋爱脑？测完再说。"
- "你的 XP 比你的 MBTI 诚实多了。"
- "恭喜您，您的恋爱DNA已解码。"

### 2.3 安全红线策略

| 层级 | 原则 | 示例 |
|------|------|------|
| 🟢 可以 | 恋爱偏好、审美取向、关系模式 | "你喜欢主动还是被撩"、"会被声音吸引吗" |
| 🟡 擦边但安全 | 用隐喻/自嘲包装 | "看到手臂青筋会多看两眼"、"对方认真做事的样子好帅" |
| 🔴 不碰 | 直球性行为描述、BDSM术语、露骨选项 | 绝对不用，平台秒删 |

**金句原则**：所有内容必须通过「截图发朋友圈不社死」测试。

## 三、维度体系：女性向重新设计

### 3.1 原版 8 维 → SBTI 女性向 4 对极轴

保留原版的对立结构，但重新命名，更贴合女性用户语境：

```
          主导型 D                    感官型 S
    ┌──────────┐              ┌──────────┐
    │  女王体质  │  ←────→     │  氛围体质  │
    │ 掌控/主导  │              │ 感官/细节  │
    └──────────┘              └──────────┘
    "我来安排"                  "灯光音乐氛围感"
    
          纯爱型 P                    刺激型 C
    ┌──────────┐              ┌──────────┐
    │  纯爱体质  │  ←────→     │  反转体质  │
    │ 专一/深情  │              │ 未知/冲突  │
    └──────────┘              └──────────┘
    "一辈子就你"                "吵完架更爱了"
    
          幻想型 F                    现实型 R
    ┌──────────┐              ┌──────────┐
    │  脑补体质  │  ←────→     │  务实体质  │
    │ 幻想/理想  │              │ 安全/稳定  │
    └──────────┘              └──────────┘
    "他还没来我已经想好婚礼了"   "有车有房再说"
    
          情感型 E                    理智型 L
    ┌──────────┐              ┌──────────┐
    │  心动体质  │  ←────→     │  清醒体质  │
    │ 共情/情绪  │              │ 分析/边感  │
    └──────────┘              └──────────┘
    "他难过我比他更难过"         "恋爱不影响我搞钱"
```

### 3.2 维度详细定义

| 轴 | 维度代号 | 极性 | 高分表现 | 低分表现 |
|----|---------|------|---------|---------|
| **权力轴** | X1 | D ↔ A | D(Dominant): 主导、安排、掌控节奏 | A(Adaptive): 配合、被带着走、enjoy被安排 |
| **感知轴** | X2 | S ↔ I | S(Sensory): 重氛围、五感细节、仪式感 | I(Intuitive): 重直觉、电光火石、化学反应 |
| **专注轴** | X3 | P ↔ C | P(Pure): 纯爱战士、排他、深度连接 | C(Chaotic): 来者不拒感、享受不确定性 |
| **想象轴** | X4 | F ↔ R | F(Fantasy): 脑补大师、理想化、造梦 | R(Real): 落地型、安全感导向、条件匹配 |

> **为什么砍到 4 轴 8 极？**
> - 原版 8 维独立 → 结果组合太多（256种），描述写不完
> - 4 对极轴 → 16 种结果，每个都能精心打磨
> - 和 MBTI 的 4 字母一样好记（如 DSPF、AICR）
> - 16 种 = SBTI 体系的甜区（work模块也是16种）

### 3.3 结果编码规则

每个轴取主导侧字母，组成 4 字母 XP 代号：

```
X1: D 或 A
X2: S 或 I  
X3: P 或 C
X4: F 或 R

示例：DSPF = 主导型 + 感官型 + 纯爱型 + 幻想型
     = "霸总体质" → 你想要的爱情是你说了算版的偶像剧
```

### 4.2 命名设计原则

- **3-6字中文名**：第一眼能「哈哈哈这就是我」
- **体质/人格** 后缀交替使用，不全用"体质"
- **Tagline**：4-8字，适合做微信状态
- **金句**：一句话截图素材，必须是"人话"
- **反转感**：每个人格都有"听起来很厉害 but 其实很搞笑"的落差

### 4.3 四段式文案结构（复用 SBTI 金标准）

以 **ASPF 恋爱氛围组** 为例：

```
【第一段：XP 一击】

【第二段：翻译你的恋爱DNA】
你的爱情不靠"条件匹配"启动，靠"氛围感"。
下雨天递伞 → 心动。
深夜发语音说"到家了吗" → 心动。
开车时把手搭在你座椅后面 → 直接原地结婚。

你不需要对方有多优秀，你需要的是那个"让你觉得被在乎"的瞬间。
问题是，这种瞬间来得太容易了，
所以你经常在"这是心动还是错觉"之间反复横跳。

【第三段：XP 症状清单】
✓ 看到对方认真工作侧脸就开始脑补未来
✓ 被摸头会当场死机三秒

【第四段：轻收口】

这不是缺点，只是有点费纸巾。
```

## 五、题目设计策略

### 5.1 题量与结构

| 参数 | 设定 | 理由 |
|------|------|------|
| 总题数 | **20题** | 和原版对齐，不超过3分钟 |
| 每轴题数 | 5题/轴 × 4轴 = 20题 | 统计可靠性最低要求 |
| 选项数 | 3选项（A/B/C） | 复用 SBTI 体系 |
| 计分 | 1-3分，部分反向计分 | 1→极性A, 3→极性B |

### 5.2 题型配比（复用 SBTI 题目设计指南）

| 题型 | 数量 | 比例 | 说明 |
|------|------|------|------|
| 情景题 | 6-7题 | 30-35% | 真实恋爱场景，选反应 |
| 二选一 | 4题 | 20% | "你更受不了 A 还是 B"，简单粗暴 |
| 完形填空 | 2-3题 | 10-15% | "男朋友突然冷淡了，你第一反应是____" |
| 梗题 | 3-4题 | 15-20% | 自嘲向，增加截图欲 |
| 盲选题 | 1题 | 5% | 无题目直接选，测直觉 |
| 标准题 | 2-3题 | 10-15% | 中规中矩的偏好题 |

### 5.3 示例题目（每轴各1）

**X1 权力轴（D↔A）**
```
约会地点通常谁定？
A. 我来安排，我的品味比你靠谱 → D(3)
B. 你选我选都行，看心情 → 中(2)  
C. "你说了算"但其实这句话本身就是一种掌控 → A(1)
```

**X2 感知轴（S↔I）**
```
让你瞬间心动的是？
A. 他精心准备的生日惊喜，蜡烛摆成爱心 → S(3)
B. 都可以吧 → 中(2)
C. 他随口一句话突然戳中了你，你自己都没想到会心动 → I(1)
```

**X3 专注轴（P↔C）**
```
刷到前任和新对象的合照，你的内心OS：
A. "我的人怎么能跟别人在一起" (即使分手了也要心梗一下) → P(3)
B. 有点酸但很快翻走了 → 中(2)
C. "哦，新的来了" *继续划* → C(1)
```

**X4 想象轴（F↔R）**
```
闺蜜问你"你理想型什么样"，你说：
A. "眼睛里有光、笑起来像少年、最好还会弹吉他" → F(3)
B. "看感觉吧" → 中(2)
C. "有正经工作、情绪稳定、身高不矮就行" → R(1)
```
