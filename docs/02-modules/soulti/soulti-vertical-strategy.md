## Phase 1: 重新定位 & 市场语境

### 1.1 Geoffrey Moore 定位声明（垂直化后）

**当前隐性定位（模糊的）：**
> SoulTI 是一个文艺风格的人格测试，风格内省、衬线字体、极简美感。

**问题**：用户第一秒不知道它和 Flower / XPTI / 标准版有什么本质差别——都是"测你是什么人"。

**垂直化后的定位声明：**

```
For  22-32岁女性，正在经历边界模糊、情绪透支、自我怀疑
  that need  一种安静的方式理解"我为什么总在受伤"和"我怎么保护自己"
  SoulTI
  is a  分层自我关系镜像测试
  that  通过三层自我探测（白天人格 → 深夜阴影 → 受伤修复方式），
       让你看见自己的保护机制和恢复模式，而不只是一个标签

Unlike  MBTI / 16personalities（告诉你"你是什么人"然后结束）
       和站内其他宇宙（给你一个搞笑/好看的身份标签）
  SoulTI
  provides  "你如何与自己相处"的深度镜像 — 不是一个结果，而是三层自我的叠加画像，
           配合历史女性灵魂共振，让你在被看见的同时被理解
```

**定位压力测试：**

| 检验维度 | 结果 | 状态 |
|---------|------|------|
| 目标用户能认出自己？ | ✅ "边界模糊+情绪透支"精准命中深夜emo女性 | Pass |
| 需求有外部证据？ | ✅ 小红书 #内耗 话题 30亿+浏览；#边界感 5亿+ | Pass |
| 品类锚定明确？ | ✅ "自我关系镜像测试" ≠ 人格测试 ≠ 心理咨询，是新品类 | Pass |
| 和站内宇宙不打架？ | ✅ 其他宇宙="你是什么"；SoulTI="你怎么跟自己相处" | Pass |
| 付费意愿有基础？ | ✅ 得到/KY/简单心理的深度报告¥9.9-¥29.9证明品类可付费 | Pass |
| 能指导取舍？ | ✅ "不是好笑标签"→不需要裂变爆文，需要深度内容 | Pass |

### 1.2 Proto-Personas（付费场景视角）

#### Persona A: 「深夜自查型」· 最高付费意愿

- **画像**: 24-30岁女性，大城市打工人，独居或和室友合租
- **触发场景**: 深夜1点钟，刚被朋友/恋人搞得很累但说不清为什么 → 搜"为什么我总是在付出" / "边界感测试"
- **现在怎么解决**: 刷小红书看"高敏感人群特征"列表，对号入座但没有体系化结论
- **SoulTI 给她什么**: 不止"你是高敏感"，而是"你在白天看不出问题，但深夜你的保护机制是X，你受伤后的修复方式是Y"
- **核心 JTBD**: "帮我理解我为什么累——不是因为我做错了什么，而是因为我的保护机制一直在默默运转"
- **付费触发**: 免费版看到三层镜像的概览，付费版看到 [暗伤解析] + [写给你的修复处方] + [历史女性深度共振]
- **单次付费意愿**: ¥9.9-¥19.9（"比一杯奶茶便宜，但比刷小红书有用"）

#### Persona B: 「关系复盘型」· 中等付费意愿

- **画像**: 22-28岁，刚分手 / 刚和闺蜜闹掰 / 刚被领导PUA
- **触发场景**: 关系结束后的空窗期，想搞清楚"是我的问题还是对方的问题"
- **SoulTI 给她什么**: "你的界限轴=壁（清晰边界），但你的火焰轴=烬（间歇爆发）——你不是不在意，你是在意到烧完了才走的那种人"
- **付费触发**: 深度报告里的"你在关系中反复出现的模式" + "你容易被什么类型的人消耗"
- **单次付费意愿**: ¥9.9

#### Persona C: 「收集探索型」· 低付费、高传播

- **画像**: 20-25岁，Persona B 的社交链中的朋友，因为"她发了个SoulTI结果好好看"来测
- **行为**: 做完免费版 → 截图 → 发圈 → 可能不会付费，但会把链接传给5个朋友
- **付费触发**: 付费内容不是她的目标，但如果有"解锁你的镜像人格"或"看看谁是你的灵魂反面"这种社交钩子，可能¥3.9

## Phase 2: MITRE 问题框架画布

### Look Inward

**核心问题：**
SoulTI 是站内情绪价值最高、私信质量最好的模块，但它的"深"停留在文案层面，没有被产品机制放大。具体来说：

1. **三幕结构被浪费**：`questions.ts` 已经把 50+ 道题分为 `act: 1`（白天）、`act: 2`（深夜）、`act: 3`（梦里），每幕 × 每轴分别抽样——但 `scoring.ts` 最终只算一个总均分。白天答 T、深夜答 S 的用户，被压成了 M。这个"白天和深夜不一样的你"是最有叙事张力的产品点，目前被完全压扁。

2. **五轴解读缺乏交叉**：结果页只展示了五条独立的轴向条，没有做"界限轴×火焰轴=你的保护模式"这种交叉解读。而这正是付费深度报告最有价值的内容。

3. **灵魂共振数据极其丰富但只用了一次**：`personalities.ts` 里的 32 位历史女性原型，每人都有年代、描述、引语——但它们只在结果页出现一次。这是天然的连续内容线（每周一位灵魂原型 → 复访理由），目前被一次性消费了。

4. **描述结构已为付费准备好了骨架**：每种人格都有【看见】【未见】【暗伤】【蜕变】【写给你】五个段落。免费层展示前三段，付费层解锁【蜕变深度解析】+【写给你的修复处方】= 自然的内容断点。

**为什么还没做？**
- 优先投入了宇宙数量扩展（横向），还没来得及做单宇宙深耕（纵向）
- 纯前端 + localStorage 架构限制了付费验证的动力
- SoulTI 的传播没有毒舌版猛，容易被优先级压后

**我们可能是问题的一部分：**
- 把 SoulTI 的成功定义为"传播量"而不是"深度指标"（停留时长、截图率、私信质量）
- 用和搞笑宇宙一样的结果页结构去承载深度内容

### Look Outward

| 视角 | 发现 |
|------|------|
| **谁经历这个问题？** | 22-32岁女性，尤其独居、城市、高敏感、处于关系转折期 |
| **谁没有？** | 男性用户（低情绪探索需求）、<20岁（还没积累够多的自我冲突） |
| **谁被忽略了？** | 心理咨询不可及的人群——¥500/次咨询太贵，但小红书自查清单太浅。SoulTI 可以填这个中间层 |
| **从现状获益的是谁？** | 简单心理/壹心理的付费报告（¥19.9-¥49.9），但它们风格严肃、缺美感、没有收藏欲 |
| **竞品的盲区？** | 竞品深度报告只有文字，没有"灵魂共振"、"三层镜像"、"收藏级美学"这些情绪体验层 |

### Reframe

> **精炼问题陈述：**
> SoulTI 已拥有体系里最深的内容资产（五轴×三幕题库、32位历史女性共振、暗伤/蜕变叙事结构），但产品机制仍在用"单层人格标签"来呈现——用户得到的是一张美丽的卡和一段好文案，而不是"关于我和自己关系"的深度镜像。结果是：高情绪价值被一次性消费了，而不是变成复访理由和付费触发点。

**How Might We:**
> **HMW** 把 SoulTI 从"一次测试得一个人格"升级成"三层自我镜像 + 持续修复内容"，
> **as we aim to** 首次付费转化率达 8-12%（深夜场景），30日复访率达 15%（周镜像回看），
> **without** 破坏当前极简美学体验和免费层的传播链？

## Phase 3: 机会-方案树 (Teresa Torres OST)

### 目标指标
- **北极星**: 付费转化率 ≥ 8%（从完成测试到购买深度报告）
- **护城指标**: 平均停留时长 ≥ 4分钟（结果页），30日复访 ≥ 15%

### 机会 1: "白天的我和深夜的我不一样"——分层镜像被压扁了

**代码证据**: `SOULTI_ACT_SAMPLE_COUNT = { 1: 2, 2: 2, 3: 1 }` → 白天10题、深夜10题、梦里5题，但 `calculateSoultiResult()` 把三幕的答案混在一起算总均分。

| 方案 | 可行 | 影响 | 适配 | 总分 |
|------|------|------|------|------|
| **S1: 分幕计分 → 三层人格画像** | 5（只需改 scoring.ts） | 5（独一无二的产品特性） | 5（完美匹配深度定位） | **15 ⭐** |
| S2: 每幕单独出结果页 | 3（需要大量新UI） | 4 | 4 | 11 |
| S3: 三幕仅做视觉化对比图 | 4 | 3 | 3 | 10 |

**→ POC: 改 scoring.ts，分别输出白天人格 / 深夜人格 / 梦境倾向，结果页展示"三面镜子"**

> **实现路径**：
> 1. scoring.ts 新增 `calculateSoultiLayeredResult()` → 按 act 分组计分，输出 `daySelf` / `nightSelf` / `dreamTendency`
> 2. 结果页免费层：展示三层人格名 + 一句话简述
> 3. 结果页付费层：三层之间的张力解读（"为什么你白天是涌泉，深夜变成琥珀"）

### 机会 2: "测完很美但然后呢"——缺乏修复方向和行动指引

| 方案 | 可行 | 影响 | 适配 | 总分 |
|------|------|------|------|------|
| **S1: 付费深度报告 "修复处方"** | 4（纯内容生产+前端展示） | 5（直接创收） | 5 | **14 ⭐** |
| S2: 免费版底部加"这周试试" | 5 | 2 | 4 | 11 |
| S3: 接入AI生成个性化建议 | 2（需后端） | 4 | 4 | 10 |

**→ POC: 付费报告包含"边界修复处方" + "轴间系统解读" + "写给你的长信"**

> **内容结构**：
> - 免费层（当前已有）：【看见】【未见】【暗伤】+ 五轴数据 + 灵魂共振卡
> - 付费层（新增）：
>   1. **三层镜像对比**："你白天的保护方式 vs 深夜真实的你 vs 梦境暗示"
>   2. **轴间交叉解读**："界限轴(壁) × 火焰轴(烬) = 你总是等烧完了才划线"
>   3. **修复处方**：基于蜕变轴(生/矿)给出不同的修复策略框架
>   4. **写给你的长信**：2000字，不是建议，是理解——"你不需要变好，你需要被允许"
>   5. **灵魂共振深度版**：历史女性的完整故事 + "她也曾像你一样"

### 机会 3: "没有理由回来"——一次性消费完所有内容

| 方案 | 可行 | 影响 | 适配 | 总分 |
|------|------|------|------|------|
| **S1: "每周镜像回看" 轻复访** | 4（localStorage + 日期逻辑） | 4 | 5 | **13 ⭐** |
| S2: 灵魂共振周卡（每周解锁一位女性） | 4 | 4 | 5 | 13 |
| S3: 季度重测对比 | 3 | 3 | 4 | 10 |

**→ POC: S1+S2 并行——每周一新的灵魂原型 + "你这周的轴还在这里吗"的一句话提示**

### 4.2 付费模型设计

**定价架构**（对标简单心理¥19.9报告 × WTFTI用户年龄 → 下调）

| 层级 | 内容 | 定价 | 理由 |
|------|------|------|------|
| **免费层** | 单层人格 + 五轴概览 + 灵魂共振卡 + 分享图 | ¥0 | 传播引擎、入口漏斗 |
| **深度镜像** | 三层镜像对比 + 轴间交叉解读 + 修复处方 | ¥9.9 | 一杯奶茶的心理价位；竞品最低¥9.9 |
| **灵魂长信** | 2000字定制化长信 + 历史女性深度共振故事 | ¥19.9（含深度镜像） | 情绪价值溢价；"测完哭了"的用户愿意为"写给我的"付费 |

**支付技术路径**（不建后端的约束下）：
- 方案 A: 微信小程序内付费 → 自然对接微信支付
- 方案 B: 爱发电 / 小报童链接跳转 → 0 开发成本，但体验断裂
- 方案 C: 接入 Stripe/Lemon Squeezy → 适合出海场景
- **推荐: A 先行，B 作为验证期过渡**

### 4.3 TAM/SAM/SOM（SoulTI 垂直线）

| 层级 | 定义 | 规模 |
|------|------|------|
| **TAM** | 中国22-32岁女性 × 对"自我探索/边界/内耗"感兴趣的人群 ≈ 2000万人 | ¥5/人 = **¥1亿/年** |
| **SAM** | 通过小红书/微信触达的、愿意做H5深度测试的 ≈ 300万人 | ¥8/人 = **¥2400万/年** |
| **SOM Y1** | SoulTI月活5万 × 付费转化8% × ¥12客单 | **¥58万/年** |
| **SOM Y2** | 月活20万 × 10% × ¥15客单（含灵魂长信） | **¥360万/年** |
| **SOM Y3** | 月活50万 × 12% × ¥18（含季度重测+订阅） | **¥1296万/年** |

**关键假设**：
- Y1 仍以 WTFTI 站内导流 + 小红书自然流为主 → 成本极低
- Y2 小程序上线后有 push 能力 → 召回成本降至 0
- Y3 品类心智建立 → "SoulTI" 成为独立搜索词

### 4.4 获客渠道评估（SoulTI 专属）

| 渠道 | CAC | LTV:CAC | 质量 | 可扩展 | 判定 |
|------|-----|---------|------|--------|------|
| 站内跨宇宙导流 | ¥0 | ∞ | 高（已是活跃用户） | 受限于总站流量 | **Scale** |
| 小红书 #内耗 / #边界感 话题 | ¥0 | ∞ | 极高（精准人群） | 高（30亿+话题浏览量） | **Scale** |
| "测完哭了"型 UGC | ¥0 | ∞ | 极高 | 中（依赖内容质量） | **Scale** |
| KOC 深度体验贴 | ¥1-3 | 5-15:1 | 高 | 中 | **Test** |
| 心理类公众号合作 | ¥2-5 | 3-8:1 | 高 | 中 | **Test** |
| 抖音情感博主 | ¥3-8 | 1-3:1 | 低-中 | 高 | **暂不推荐** |

**核心洞察**：SoulTI 的获客不该走"裂变爆量"路线，而该走"精准深度"路线。一篇 #内耗 下的走心UGC，比一条搞笑短视频带来的人群精准度和付费转化率高10倍。

## 战略核心判断

### ❶ SoulTI 在 WTFTI 体系中的角色重定义

```
WTFTI 宇宙矩阵：

                     高传播 ↑
                          │
         毒舌版 ●         │        ● 鸟TI
         班TI ●           │        ● 修仙
                          │
    ──────────────────────┼──────────────── 高深度 →
                          │
         花TI ●           │
         XPTI ●           │        ● SoulTI ← 唯一的深度×付费入口
                          │
                     低传播 ↓
```

SoulTI 不争最大流量，争最高 ARPU 和最长停留时长。它是漏斗底部的转化引擎，不是漏斗顶部的流量入口。

### ❷ 三层镜像 = SoulTI 的护城河

竞品无法复制的不是"32 种人格"（谁都能编），而是**分层计分机制 + 历史女性共振 + 暗伤/蜕变叙事结构**的组合。一旦三层镜像做出来，"测白天的你和深夜的你"就成了 SoulTI 的品类定义，后来者只能跟随。

### ❸ 付费验证路径：最小成本

```
            第一个月                    第二个月                    第三个月
              │                          │                          │
  [三层镜像免费层上线]  →  [付费毛玻璃CTA]  →  [点击率>3%?]
              │                          │           │
              │                    Yes → │     No → [调整内容断点]
              │                          │
              │                  [爱发电付费链接]  →  [转化率>5%?]
              │                          │           │
              │                    Yes → │     No → [降价到¥6.9]
              │                          │
              │                  [小程序内付费]  →  [LTV验证]
              │                          │
              │                    [决策: 规模化?]
```

### ❹ SoulTI 的终局想象

如果 Y1 数据成立：
- **Y2**: SoulTI 独立小程序 + 季度订阅（¥39.9/季 = 4份深度报告 + 每周灵魂共振卡 + 轴向变化追踪）

- **远期**: 不做心理咨询（太重），做"心灵护肤品"——轻量、持续、有美感、每天用一点
