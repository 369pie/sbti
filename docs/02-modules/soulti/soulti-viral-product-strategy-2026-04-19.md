## TL;DR — 一句话战略

> **SoulTI 不要做"更深的 HERTI"，要做"中国互联网第一个面向女性的『深夜自我仪式』产品"。**
> 把现有的"32 自然力人格 × 三层镜像 × 32 历史女性"重新打包为一场**有时间感、有声音、有仪式感、有情绪后续动作**的 8 分钟体验，并用『深夜模式』『一封灵魂来信』『撕裂度』三个高度差异化的钩子统治小红书深夜流量。

**3 个核心赌注（Bets）：**
1. **赌「深夜场景」**：22:00–02:00 单独做一个"夜灯模式"入口，全平台第一个把"测试时段"做成产品语言的人格测试。
2. **赌「灵魂来信」**：把测试结果 7 天内分 3 封信寄回邮箱/微信通知，让一次测试变成一段持续 7 天的关系，从一次性消费变 LTV 资产。
3. **赌「撕裂度（白夜差距）」**：把代码里已经做好但被藏起来的 `tearRate` 推到 hero 第一屏，做成"全网第一个能量化自我撕裂程度的测试"，制造可被截图的爆款数据点。

**北极星指标（90 天）**：
- 完成测试 → 7 日内回访率 ≥ 35%（行业基准 8–12%）
- 小红书带 `#深夜灵魂测试` 或 `#我的撕裂度` 自发笔记 ≥ 800 条
- 付费转化率（深度报告 ¥9.9 / ¥19.9）≥ 6%
- 单用户 LTV / CAC ≥ 4:1

## Phase 1 · 重新定位、Persona、JTBD

### 1.1 Geoffrey Moore 定位声明（爆品语境）

```
For    22-32 岁、白天端着、深夜内耗的中国都市女性
       — 她们不缺标签，缺一场被听见的仪式

That need  在不必登录、不必倾诉、不必付费的低成本下，
           完成一次"和自己之间的对账"

SoulTI is a  深夜灵魂仪式（nightly self-ritual）
             —— 32 种自然力人格、三层自我镜像、一封持续 7 天的灵魂来信

That  让你在 8 分钟里看见"白天的你"和"深夜的你"差了多远，
      并把这个差距翻译成一句你愿意截图发给最好朋友的诊断

Unlike HERTI（一次性的、文学化的、白天可分享的优雅）、
       MBTI/16personalities（冷冰冰四个字母）、
       塔罗 App（玄学话术，娱乐性 > 真实感）、
       站内其他宇宙（搞笑标签、轻量消费）

SoulTI provides  唯一一个把"时段"做成产品（深夜模式）、
                 把"撕裂度"做成可截图数据、
                 把一次测试做成 7 天关系的女性向自我对话产品。
```

**定位压力测试：**

| 维度 | 通过 | 关键证据 |
|------|------|---------|
| 用户能在 1 句话认出自己 | ✅ "白天端着、深夜内耗" 击中 [Persona D](docs/04-design-growth/growth/herti-competitive-strategy.md#L121) | 同样的人，HERTI 抢的也是她 |
| 品类锚定够独特 | ✅ "深夜灵魂仪式"，全网无对标 | 没有竞品在做时段产品 |
| 差异化能 1 秒解释 | ✅ 三个名词钩：深夜模式 / 撕裂度 / 灵魂来信 | 都可独立成抖音/小红书选题 |
| 能指导取舍 | ✅ 凡是不服务"深夜情绪刚需"的功能一律降权 | 例：白天的搞笑分享卡 → 不做 |
| 付费意愿支撑 | ✅ 类比 KY/简单心理深度报告 ¥9.9-29.9，灵魂来信第 3 封解锁 ¥9.9 自然 | 已在仓内有架构 |

### 1.2 三个 Proto-Persona（围绕"深夜情绪刚需"重排）

#### Persona A · 「深夜对账型」｜ 27 岁 · 上海 · 互联网产品经理 · 月入 25k｜核心付费人群

- **场景**：周日晚 23:40，刚结束和男朋友长达 2 小时的低气压对话；明天有重要 review。她不想哭、不想找闺蜜、不想发圈。她搜「为什么我总是先让步」。
- **现在用什么解决**：壹心理文章 → 小红书"高敏感人格 12 个特征" → MBTI INFJ 解析 → 都没用。
- **她的 JTBD**：
  - 功能：**5–10 分钟内得到一个比标签更深、比心理咨询更轻的『自我诊断』**
  - 社交：**生成一段她"愿意截图但不愿意发圈、愿意单独发给最好朋友"的话**
  - 情绪：**被一个不评判的声音轻轻接住，然后给她一个明天可以做的小动作**
- **痛点**：
  - 我的"内耗"无法量化，所以无法跟自己/伴侣解释
  - MBTI/HERTI 给的都是优点描述，没人告诉我"白天和深夜的我差在哪"
  - 想要"修复"，但所有解决方案都太重（咨询/课程）
- **收益期待**：
  - 一个**能截图**的具体数字（撕裂度 67%）→ 她可以拿去和男朋友说"这就是我累的原因"
  - 一封"7 天后再寄到的信"→ 让她觉得"有人在惦记我"，不是一次性消费
- **付费触发**：免费看到撕裂度 + 三层镜像概览 → 付费 ¥19.9 解锁「灵魂修复处方 7 日邮件」+「白夜双人镜像深度对照」

#### Persona B · 「关系复盘型」｜ 24 岁 · 杭州 · 设计师 · 刚分手 30 天 ｜中等付费、高传播

- **场景**：分手 30 天，刚发现前任已经有了新对象。她想搞清楚"是不是我有问题"。
- **她的 JTBD**：理解我在亲密关系中**反复出现的模式**，把"是不是我不值得被爱"翻译成"我是『焰』型不是『烬』型"。
- **关键差异**：她不会付费看自己的报告，但会**付 ¥3.9 看『前任和我的镜像配对』**（社交钩子付费）。

#### Persona C · 「灵魂猎奇型」｜ 21 岁 · 北京 · 大学生 ｜ 0 付费、5x 拉新

- **场景**：闺蜜在群里发了一张 SoulTI 的"涌泉/林徽因"卡片，说"咱们都来测"。
- **她的 JTBD**：纯粹想**收藏一个好看的人格 + 看自己稀有度排第几**。
- **价值**：她不付费，但她是**深夜场景外**唯一的稳定流量入口——白天闺蜜群裂变。

> **决策**：产品体验为 Persona A 做（不为 C 妥协深度），但分享卡 / 稀有度 / 闺蜜配对 三个组件为 C 优化。

### 1.3 JTBD 三维拆解（聚焦 Persona A）

#### 功能性 Jobs（Functional）
| Job | 当前满足度 | 升级方向 |
|-----|-----------|---------|
| 量化"我有多累" | ⭐ tearRate 已写但藏 | 🔴 **撕裂度推到 hero 第一屏，做成 SVG 动效的可截图数字** |
| 看见白天 vs 深夜的差距 | ⭐⭐ 三层镜像数据齐但 UI 平铺 | 🔴 改成"对照式"叙事："白天你是涌泉，深夜你变成黑曜" |
| 给一个明天能做的动作 | ⭐ 修复处方藏在 deep-report | 🔴 **免费版给 1 条"今晚就做"的具体动作**（喝水/写字/锁手机），付费版给 7 日 |
| 长期理解模式 | ❌ 一次性消费 | 🔴 **「灵魂来信」7 日邮件序列**：D+1 复盘 / D+3 镜像信 / D+7 修复信 |

#### 社交性 Jobs（Social）
| Job | 设计 |
|-----|------|
| 截图给最好朋友（不发公开圈） | "深夜专属"分享卡：暗色调、少字、一句金句 + 一个数字 |
| 闺蜜对比"我们的撕裂度" | 双人撕裂度对比页 `/soulti/pair/[a]/[b]/`（已有架构）+ 撕裂度 PK 视图 |
| 在小红书晒"被理解" | 灵魂来信第 3 封后弹"把这封信变成壁纸"分享卡 |

#### 情绪性 Jobs（Emotional）⭐ 决胜战场
| Job | HERTI 怎么做 | SoulTI 怎么做（升级版） |
|-----|------------|---------------------|
| 被看见 | 文学描述 | **三层镜像**：白天/深夜/梦里都被分别看见 |
| 被尊重 | 历史伟大女性投射 | **32 位女性 × 自然力双重隐喻**，更可被识别（不需要懂林徽因，能感受涌泉） |
| 被温暖 | "心里暖暖的" | **7 天来信**：把温暖延展为 7 天陪伴 |
| 被理解 | 测完即走 | **撕裂度 + 修复处方**：不只是"懂"，还告诉你"该怎么办" |
| 安全的宣泄 | 测试本身像倾诉 | **深夜模式**：暗黑模式 + 慢动效 + 留白音效 + 不评判的语气 |
| 群体归属 | "咱们女的做 HERTI" | **「同款灵魂」匿名树洞**：测出同人格的人共享一句匿名感悟 |

> **JTBD 核心结论**：HERTI 已经满足"被看见 + 被温暖"，SoulTI 必须 **同时满足"被量化 + 被指引 + 被陪伴 7 天"**，否则就是更深的 HERTI，不会爆。

## Phase 2 · 问题画布（MITRE）

### 2.1 向内看 (Look Inward)

**我们之前的假设（哪些已被打破）：**
- ❌ "做深内容 = 用户会感受到深度" → 错。深度不被编排到第 1 屏 = 不存在。
- ❌ "免费给完整内容更好" → 错。HERTI 全免费但**没有付费触发也意味着没有 LTV**。
- ❌ "三层镜像是技术差异" → 错。技术差异不是用户语言，"白天 vs 深夜的你"才是。
- ❌ "32 类型 + 32 女性 + 5 维度 = 内容丰富" → 错。**信息过载 = 没有焦点 = 没有传播点**。

**我们的偏见：**
- 创作者偏见：以为"散文级文案 = 用户会认真读" → 用户在小红书是滑动消费，**第 1 秒没有 hook 就走**。
- 工程偏见：以为"系统复杂度 = 产品差异" → 用户只会记一个名词钩。
- 性别偏见：以为"温柔 = 无音效、无动效、无颜色对比" → 错。深夜 emo 女性需要**仪式感**（暗色 + 慢动效 + 微音效），而不是"白纸黑字"。

### 2.2 向外看 (Look Outward)

**正在经历这个问题的人**：
- 小红书 #内耗 30 亿浏览，#边界感 5 亿浏览，#高敏感 8 亿浏览
- HERTI 4 天爆火证明"被温柔理解"是真实付费意愿背后的需求
- 简单心理 / KY / 壹心理深度测评 ¥9.9-29.9 验证了付费下限

**谁在受益**：
- HERTI（拿走"白天可分享的优雅")
- 小红书心理博主（拿走科普流量）
- 简单心理（拿走"想咨询但太贵"的转化）

**谁被遗漏**：
- **「深夜场景下的女性」**——目前没有任何产品为 22:00-02:00 这个时段专门设计
- **「想被量化但不想被分析」**的女性——咨询太重、测试太轻
- **「想要持续陪伴但不想加好友」**的女性——所有陪伴产品都需要社交关系

### 2.3 重新框定 (Reframe)

**旧问题**：
> "SoulTI 怎么做得比 HERTI 更深？"

**新问题**：
> **"如何让 SoulTI 成为中国都市女性『深夜 23 点想找个东西陪自己 8 分钟』时的第一选择？"**

**三个 How Might We：**
1. **HMW** 把测试时段做成产品语言（深夜模式 vs 白天模式），让用户从打开那一秒就感觉"这是为现在的我做的"？
2. **HMW** 把已经做好的撕裂度、三层镜像、修复处方，重新编排成 **一个 hook + 一个数字 + 一句话 + 一个动作**？
3. **HMW** 把一次性 8 分钟的测试，做成持续 7 天的"被惦记"关系，让用户既没有社交压力又有被陪伴的体感？

## Phase 4 · TAM/SAM/SOM + 渠道评估

### 4.1 市场规模

**TAM**（中国女性向自我探索 / 心理 / 灵性 / 测试 总市场）：
- 心理服务市场（壹心理/简单心理/KY 等）2025 年规模 ≈ ¥150 亿
- 性格测试 / 玄学娱乐 ≈ ¥80 亿
- 总盘 ≈ **¥230 亿/年**，对应活跃用户 ≈ **3 亿人次/年**

**SAM**（小红书 + 微信 + 抖音 18-32 岁都市女性，对深度自我探索内容有兴趣）：
- 小红书 18-32 岁女性月活 ≈ 1.2 亿

#### **SoulTI 推出「深夜灵魂仪式」—— 全网第一个为 23 点的你做的人格产品**

**上海 / 2026 年 5 月** —— WTFTI 旗下深度人格产品 SoulTI 今日宣布上线 v2 大版本「深夜灵魂仪式」，
这是中国互联网首个**把测试时段、情绪状态、持续陪伴**做成产品语言的女性向自我探索体验。

**问题**：当代都市女性白天端着，深夜内耗。她们不缺人格标签——MBTI 测过、HERTI 测过、塔罗算过，
但没有一个产品能告诉她："你今晚为什么这么累？"，更没有一个产品愿意在第 7 天**还记得她**。

**解决方案**：「深夜灵魂仪式」不是一次测试，是一场 8 分钟 + 7 天的对话。

- **第 1 秒**：打开页面，撕裂度（你白天的你和深夜的你之间的能量距离）以一个数字呈现在最前面。
  "你的撕裂度：67%。意思是，你白天像涌泉，深夜变成黑曜。"
- **第 8 分钟**：32 种自然力人格 × 三层镜像 × 一位历史女性灵魂共振。
  没有评分、没有标签焦虑，只有一封写给你的话。
- **第 1 / 3 / 7 天**：三封灵魂来信寄到你的邮箱或微信。
  D+1 复盘信、D+3 镜像信、D+7 修复信——让你知道，**今晚做的这次测试，有人记得你**。
- **22:00-06:00**：自动进入「夜灯模式」——暗色调、慢动效、微声场（雨/篝火/远风）。
  你不是在做一个测试，你是在和自己安静地待 8 分钟。

**用户怎么说**：
> "我凌晨 1 点做完，眼泪就下来了。不是因为说得有多准，是因为它在最后一屏告诉我'今晚先不要回那条消息，喝口水，把手机放远一点'。
> 我从来没想过一个测试会跟我说'今晚'。"
> —— 内测用户 @深夜面包房 27 岁 上海

**差异化**：
- 与 **HERTI** 比：HERTI 是白天可分享的优雅；SoulTI 是深夜不发圈、只发给最好朋友的对账。
- 与 **MBTI / 16Personalities** 比：我们不给字母，我们给数字 + 三层镜像 + 7 天关系。
- 与 **塔罗 App** 比：我们不卜卦，我们做镜像。
- 与 **心理咨询** 比：我们不是治疗，我们是一次有结构的"深夜独处"。

**行动号召**：今晚 23 点，打开 wtfti.com/soulti/，给自己 8 分钟。
然后等明天的第一封信。

### 6.3 反爆品的 5 个 Anti-Pattern（每周 review 一次）

1. **❌ 把撕裂度藏起来**："担心数字会让用户焦虑" → 错。数字是 hook，配套金句负责安抚。
2. **❌ 让来信变骚扰**：默认只发 D+1，剩下两封要用户主动勾选 + 一键退订。
3. **❌ 深夜模式做成 dark mode 切换器**：一定要**自动按时段触发** + 配音效，否则失去仪式感。
4. **❌ 付费墙挡在第 1 屏**：所有钩子（撕裂度 / 三层镜像概览 / 1 句金句 / 1 个今晚动作）必须免费。
5. **❌ 在小红书发"测测你是哪种自然力"**：太宽。要发"**我的撕裂度 67%，原来我白天和深夜是两个人**"——以数字为标题，永远以数字为标题。

## 〇〇、关键风险 & 红线

| 风险 | 缓解 |
|------|------|
| 撕裂度数字被解读为"心理疾病诊断" | 文案永远配"你不是有问题，你是在适应"；底部加"本测试不是医疗诊断"免责 |
| 深夜邮件 / 通知被定为骚扰 | D+3/D+7 需主动勾选；微信通知走小程序订阅消息合规通道 |
| 男性用户被排斥 → 公关问题 | 不强制男性看历史女性段落；首页文案不写"女性专属"，写"为深夜的你" |
| HERTI 反向抄袭 | 撕裂度 + 来信 + 深夜模式做成**整体仪式**而非单点功能，单抄一个失去价值 |
| 灵魂来信成本失控（邮件量）| 仅采集愿意填邮箱的用户，预计 25% 收入 → 月发件 < 50 万封 → Resend 成本 < $300/月 |
| 付费转化低于预期 | 7 日后再追一次"D+30 灵魂回访"再触发付费，提升 LTV |
