# Mysti 灵鉴 × 灵镜 双模块深度调研与战略升级

> Owner: Product Strategy
> Status: Strategic Upgrade Proposal
> Priority: P0
> Date: 2026-05-05
> Scope: `/mysti/*` 灵鉴、`/mirror/*` 灵镜、`/lingjian/` 灵笺人生档案承接层
> Framework: Product Vision + Product Strategy Canvas + JTBD + Competitive Scan + Compliance Review

---

## 0. 一句话结论

灵鉴和灵镜不应该继续作为两个松散的功能入口存在。它们应该升级为 WTFTI 的「内在镜面」与「外在镜面」：

> **灵鉴负责把用户心里的犹豫、关系和命题翻译成可被安放的内在答案；灵镜负责把用户对外在形象的模糊焦虑转化为可执行的风格方案；灵笺负责把这些答案和方案沉淀成持续生长的人生档案。**

新的战略主轴不是「塔罗工具 + AI 修图工具」，而是：

> **Ask · See · Archive**  
> 问心里的事，看外在的可能，把每一次选择都缮写成自己的暮光档案。

这会把当前的多入口、多 SKU、多本地存储状态，收束成一个更有复购与留存能力的产品系统。

## 1. 研究输入与关键假设

### 1.1 命名校准

本次用户说的「mysti 灵鉴模块」指 `/mysti/*`，不是 `/lingjian/`。

仓库里 `/lingjian/` 是「灵笺 · 人生档案」，它不是本次主评估对象，但它已经开始聚合 WTFTI 主神、灵镜形象档案、灵鉴命书、关系合盘与灵币余额，因此应作为战略升级中的档案承接层。

### 1.2 本地产品现状

| 模块 | 已有能力 | 关键观察 |
|---|---|---|
| Mysti 灵鉴 | 首页仪式、决策快卡、单人塔罗、双人合盘、每日牌、抽卡、图鉴、灵魂信、月报、节气年报、礼品卡、订阅、命书馆 | 功能丰富，但首页信息结构偏拥挤；核心定位从塔罗人格扩展到「私人女祭司 OS」，需要重新收束 |
| Mirror 灵镜 | 上传人像、变美报告、色彩诊断、风格对比、分享卡、挑战链接、历史、充值 | 价值点清晰但偏工具化；与美图/虚拟试妆大厂相比，独立竞争壁垒弱，必须绑定 WTFTI 身份与档案 |
| Lingjian 灵笺 | 聚合主神、灵镜历史、命书、合盘、灵币 | 非常适合作为长期留存资产层，但当前仍是 localStorage MVP |
| Ling-Bi 灵币 | 统一钱包雏形，支持镜像旧 `mirror-credits` 迁移，规划 `mirror-single`、`mirror-archive`、`destiny-once` | 代码已有方向，但 Mirror UI 仍在展示旧充值包，钱包与业务消费还未完全打通 |

### 1.3 外部市场信号

| 方向 | 信号 | 对 WTFTI 的含义 |
|---|---|---|
| 年轻人玄学消费 | 2025 年年轻人玄学报告显示，AI 算命、八字、塔罗、星座都已成为高频轻量行为，且女性样本热度更高 | 灵鉴要继续避开「迷信预测」，抓「情绪秩序、低羞耻自我观察、可截图表达」 |
| 小红书女性审美与搜索 | 小红书公开研究转述显示女性、年轻、高线城市用户占比高，搜索与生活方式决策强 | 灵鉴和灵镜都必须从「好玩」升级到「可保存、可搜索、可被转发」 |
| 海外占星产品 | The Pattern 强在「被看见 + 关系 Bonds」；Co-Star 强在每日推送和开放式提问；Sanctuary 强在真人专家和礼品卡 | 灵鉴可走「AI 低成本仪式 + 人工内容品质 + 关系/gift」的混合路线 |
| AI 形象工具 | Meitu 2025 年全球 MAU、付费订阅和 AI 功能增长很强；Perfect Corp 持续扩展美妆、发型、饰品与虚拟试穿 API | 灵镜不能只做「AI 变美图」，要做 WTFTI 专属「风格档案」和长期复购资产 |
| 国内合规 | 2025 年 AI 生成合成内容标识、人脸识别技术应用安全管理办法生效 | 灵镜必须明确用户授权、最小化存储、AI 生成标识、禁止身份识别/颜值评分 |

## 2. 产品现状评估

### 2.1 Mysti 灵鉴：优势

| 维度 | 当前优势 |
|---|---|
| 内容资产 | 29 型人格 × 22 张大阿卡纳映射已成体系，主牌、Shadow、标签、神谕副标语非常适合分享 |
| 情绪入口 | 决策快卡已把「该不该」做成 90 秒仪式，符合用户日常高频犹豫场景 |
| 社交裂变 | 双人合盘、邀请链接、礼品卡已经形成关系传播雏形 |
| 商业化 | 灵魂信、合盘、月报、礼品卡、通行证、决策包已有 SKU 基础 |
| 视觉调性 | 暮紫、玫瑰陶土、金箔、塔罗、章节徽章已经形成强识别 |

### 2.2 Mysti 灵鉴：主要问题

| 问题 | 证据 | 战略风险 |
|---|---|---|
| 入口过多，用户不知道先做什么 | 首页同时出现决策快卡、价位、洗牌、直选、随机合盘、每日牌、抽卡、档案、心情、节气、月报、纪章、礼品卡 | 新用户首屏焦点稀释，核心转化漏斗难以优化 |
| SKU 认知过碎 | 单次付费、订阅、礼品、分享卡、决策包、纪章并行 | 用户理解成本高，运营难以讲清楚「为什么付费」 |
| 命书馆信任还在 MVP | Prompt 自述没有典籍 RAG，使用 LLM 通用知识；前端展示「四家方法 + 典籍出处」 | 如果用户把它当严肃命理，可能出现信任透支 |
| 数据资产多数仍本地化 | 决策、档案、抽卡、命书等大量依赖 localStorage | 换设备丢失，无法形成真正长期档案与复购画像 |
| 情绪安全需升级 | 产品称「女祭司 OS」，未来若做拟人化互动，会进入更高合规与伦理风险区 | 需要限制人格化依赖、设置时长和重大决策护栏 |

### 2.3 Mirror 灵镜：优势

| 维度 | 当前优势 |
|---|---|
| 需求明确 | 上传照片后获得发型、色彩、妆容、穿搭建议，用户价值直观 |
| 付费门槛低 | 2 次免费，¥1/次充值可快速验证需求 |
| 生成与分享链路完整 | APIMart 图像任务、进度轮询、分享卡、历史、挑战链接已经具备 |
| 模式扩展快 | 变美、色彩、风格对比、报告类型已经拆分 |
| 合规意识已有 | 照片授权 checkbox、娱乐/审美参考 disclaimer 已存在 |

### 2.4 Mirror 灵镜：主要问题

| 问题 | 证据 | 战略风险 |
|---|---|---|
| 心智仍像「AI 生成工具」 | Hero 写「灵镜实验室」「发型 · 色彩 · 妆容 · 命纹」，结果页强调 GPT-Image-2 | 很容易被美图、妙鸭、AI 试妆、滤镜 App 淹没 |
| 命纹迁移不彻底 | UI 中旧 fortune mode 注释已迁移到命书馆，但页面文案仍有「命纹」 | 用户会混淆灵镜与灵鉴边界 |
| 商业化不一致 | `credits.ts` 已规划 `mirror-archive` ¥19.9 三页诊断卡，但 UI 充值 modal 仍只展示 10/30 次 | 核心客单价无法被用户理解 |
| 历史价值太短 | 灵镜历史 3 天过期，本地保存 | 不利于做「形象档案馆」，也不利于跨模块复购 |
| 社交层偏浅 | Challenge 只比较摘要；Leaderboard 是 mock | 容易成为一次性工具，而不是增长飞轮 |
| 隐私与人脸风险高 | 人像上传给第三方图像模型，结果图链接有过期时间 | 必须强化数据最小化、用户可删除、AI 标识和人像用途边界 |

### 2.5 双模块共同问题

灵鉴和灵镜现在已经互相出现，但还没有变成一个强闭环：

```
mysti 解决「我该不该、我是谁、我和 TA 怎么样」
mirror 解决「我该以什么样子出现」
lingjian 解决「这些答案是否留在我的人生档案里」
```

当前最大机会是把三者串成一个用户自然理解的循环：

```
在灵鉴问一个场景
  -> 在灵镜生成这个场景的出现方式
  -> 在灵笺沉淀成一章档案
  -> 下次回到灵鉴/月报/灵镜复盘
```

## 3. 产品愿景

### 3.1 愿景候选

1. **让每一次犹豫和每一次变美，都成为用户能保存、能回看、能送给朋友的人生档案。**
2. **为中文女性打造一面双重灵镜：向内看见自己的答案，向外看见自己的可能。**
3. **把神秘学的安放感、AI 形象的执行力和个人档案的长期价值，合成一套温柔可信的自我经营系统。**
4. **让用户不再只是测一次、修一张图，而是持续缮写「我是谁、我如何出现、我和谁相遇」的个人宇宙。**
5. **让每个中文女性都拥有一面温柔但不迷信的镜子：看懂心里的犹豫，看见外在的可能，把每一次选择都沉淀成自己的暮光档案。**

### 3.2 选定愿景

> **让每个中文女性都拥有一面温柔但不迷信的镜子：看懂心里的犹豫，看见外在的可能，把每一次选择都沉淀成自己的暮光档案。**

选择理由：

- 它同时覆盖灵鉴、灵镜、灵笺，不把产品限制在塔罗或图片生成。
- 「温柔但不迷信」能明确价值观和合规边界。
- 「犹豫、外在、档案」对应高频使用、付费转化、长期留存三件事。
- 对团队可执行：任何新功能都能被问一句，它是在帮用户看懂心里、看见外在，还是沉淀档案？

### 3.3 模块级愿景

| 模块 | 愿景 |
|---|---|
| Mysti 灵鉴 | 把用户每天说不出口的犹豫，转译成一张她愿意保存的内在答案卡 |
| Mirror 灵镜 | 把用户对「我适合什么样子」的模糊焦虑，转化成可执行的风格档案 |
| Lingjian 灵笺 | 把每一次测试、抽牌、形象实验、关系合盘，缮写成一本持续生长的人生书 |

## 4. Product Strategy Canvas

### 4.1 Vision

战略愿景：

> **WTFTI 要从「测完就走的人格娱乐平台」升级为「中文女性的自我经营档案系统」。**

灵鉴与灵镜是这次升级最适合先突破的双引擎：

- 灵鉴提供内在解释和情绪安放。
- 灵镜提供外在行动和视觉资产。
- 灵笺提供长期档案和复访理由。

### 4.2 Market Segments

按问题而不是人口属性划分：

| Segment | JTBD | Pain | Why first |
|---|---|---|---|
| S1 决策焦虑的都市女性 | 在约会、面试、换工作、关系推进前获得一个不羞耻的「内在提示」 | 朋友建议太吵，算命太重，自己想太久 | 灵鉴决策快卡已经覆盖 |
| S2 形象升级探索者 | 想知道自己适合什么发型、色彩、妆容、穿搭 | 小红书信息过载，线下顾问贵，AI 滤镜不具体 | 灵镜已有生成和报告能力 |
| S3 关系/闺蜜传播者 | 想和 TA 一起测、一起比较、一起保存 | 普通测试没有关系档案，分享后链路断 | 灵鉴合盘、灵镜挑战都有基础 |
| S4 内容创作者/KOC | 想低成本生产有审美、有互动的内容 | 手动做塔罗帖/变美帖成本高 | 灵鉴卡、灵镜前后对比天然适合内容化 |

第一优先段：

> **25-35 岁、审美要求高、有付费能力、在关系/职业/形象选择中反复犹豫的中文女性。**

理由：她们同时有灵鉴的高频情绪需求和灵镜的可见付费需求，且更可能为「档案」「礼物」「月度复盘」付费。

### 4.3 Relative Costs

不走低成本大水漫灌路线。

战略成本定位：

| 模块 | 成本定位 | 解释 |
|---|---|---|
| 灵鉴 | 低边际成本 + 高内容品质 | 塔罗/命书/决策可以低成本生成，但必须用人工内容规则与 RAG 提升可信度 |
| 灵镜 | 中高边际成本 + 强付费前置 | 图像生成有真实成本，必须从 ¥1 体验尽快导向 ¥19.9 档案 |
| 灵笺 | 低边际成本 + 高留存价值 | 档案本身不贵，但跨设备同步、数据治理、隐私保护是长期成本 |

### 4.4 Value Proposition

#### 灵鉴

| Before | How | After | Alternatives |
|---|---|---|---|
| 用户在关系、职业、每日状态里反复想「该不该」 | 90 秒决策快卡、塔罗人格、Shadow、合盘、命书、月报 | 她得到一句能安放情绪的答案，并沉淀为档案 | 准了、测测星座、Co-Star、The Pattern、小红书塔罗 |

#### 灵镜

| Before | How | After | Alternatives |
|---|---|---|---|
| 用户想变美，但不知道自己适合什么路线 | 上传照，生成发型/色彩/妆容/穿搭报告与风格对比 | 她得到可执行、可保存、可分享的形象方案 | 美图、BeautyCam、YouCam Makeup、个人色彩顾问、小红书变美帖 |

#### 灵笺

| Before | How | After | Alternatives |
|---|---|---|---|
| 用户做过很多测试和报告，但散落在各处 | 聚合主神、灵镜、命书、合盘、灵币 | 她拥有一本属于自己的 WTFTI 人生档案 | 相册截图、备忘录、Notion、小红书收藏 |

### 4.5 Trade-offs

明确不做：

| 不做 | 原因 |
|---|---|
| 不把灵鉴做成恐吓式算命 | 高风险、低品牌质感，也会损害长期信任 |
| 不让灵镜做颜值评分、身份判断、面相定命 | 违反女性友好调性，也触碰合规与伦理风险 |
| 不把所有入口堆在首页 | 功能多不等于价值清晰，首页只能服务一个主路径 |
| 不在 MVP 做无限 AI 女祭司聊天 | 可能进入拟人化依赖和监管风险，先做结构化仪式 |
| 不先做复杂社区 | 先把个人档案、分享、付费和复访跑通 |
| 不把灵镜变成廉价滤镜站 | 低价引流可以存在，但核心收入必须来自档案级报告 |

### 4.6 Key Metrics

平台北极星指标：

> **每周被创建且 7 天内被回看、保存或分享的暮光档案数。**

定义：

```
codex_entry_created
  -> within 7 days:
     codex_entry_revisited OR share_card_generated OR archive_saved OR gift_sent
```

模块指标：

| 模块 | OMTM | Guardrail |
|---|---|---|
| 灵鉴 | 决策快卡完成后保存/分享率 | 7 日回访率、付费转化率、退款/投诉率 |
| 灵镜 | ¥19.9 三页档案购买率 | 生成失败率、人像投诉率、照片删除请求处理时长 |
| 灵笺 | 档案页 7 日回访率 | 跨设备同步成功率、数据丢失率 |

建议目标：

| 阶段 | 目标 |
|---|---|
| 2 周 | 明确首页主路径后，`mysti_decision_entry -> reveal` 完成率提升 20% |
| 4 周 | Mirror `upload -> generate -> share_card` 转化跑通，¥19.9 档案购买率达到 3%-5% |
| 8 周 | 30% 以上的灵鉴/灵镜结果写入灵笺档案 |
| 12 周 | 双模块 7 日回访率达到 15%+，自然分享带来的新入口占比达到 20%+ |

### 4.7 Growth

增长不靠单次爆款，而靠四个飞轮：

| 飞轮 | 路径 | 主模块 |
|---|---|---|
| 决策飞轮 | 用户问一个场景 -> 得到金句卡 -> 发朋友圈/小红书 -> 新用户来问自己的场景 | 灵鉴 |
| 变美飞轮 | 上传照 -> 生成前后/多风格卡 -> 保存/转发 -> 好友来做对比 | 灵镜 |
| 关系飞轮 | 我测了 -> 邀请 TA -> 合盘/挑战 -> 双方都归档 | 灵鉴 + 灵镜 |
| 档案飞轮 | 每次结果写入灵笺 -> 月报/季报回顾 -> 再次触发灵鉴或灵镜 | 灵笺 |

渠道优先级：

| Channel | 策略 |
|---|---|
| 小红书 | 决策金句卡、变美前后对比、风格挑战、塔罗关系帖、创作者模板包 |
| 微信私域 | 礼品卡、合盘、闺蜜挑战、月报提醒 |
| 站内交叉入口 | Mysti 结果页推 Mirror 场景形象；Mirror 结果页推 Mysti 今日选择；Lingjian 作为统一回访页 |
| KOC | 提供「选一张牌」「三种风格对比」「我的月度灵笺」内容模板 |

### 4.8 Capabilities

必须补强的能力：

| 能力 | 为什么重要 | 优先级 |
|---|---|---|
| 统一档案数据层 | localStorage 无法支撑长期档案和跨设备复购 | P0 |
| Ling-Bi 钱包打通 | Mirror 和 Destiny 都有按次消费，灵币能降低 SKU 理解成本 | P0 |
| 灵镜隐私与删除机制 | 上传人像是高敏感操作 | P0 |
| AIGC 显式/隐式标识 | 国内 2025 标识规则已生效 | P0 |
| Mysti 命书 RAG/出处校验 | 否则「四家方法 + 出处」会被质疑 | P1 |
| 产品事件漏斗 | 当前 admin ops 已有规范，新模块需要完整事件 | P0 |
| 创作者素材生产 | 小红书增长需要可复用模板 | P1 |

### 4.9 Can't / Won't

防御性来自组合，而不是单点功能：

| 防线 | 说明 |
|---|---|
| WTFTI 人格基座 | 灵鉴和灵镜都可以绑定主神/persona，竞品难以复制整个多宇宙身份图谱 |
| 个人档案复利 | 每次决策、合盘、变美、命书都写入灵笺，越用越难迁移 |
| 女性审美与语气 | 暮光博物馆、金箔、玫瑰陶土、中文神谕语气构成差异化 |

| 合规可信 | 明确不做颜值评分、不做恐吓预测、不做身份识别，会成为长期信任资产 |

## 5. 战略升级方案

### 5.1 总体架构：三层系统

```
Layer 1: Ritual Entry
  灵鉴决策快卡 / 每日一牌 / 今日心情
  灵镜单图体验 / 色彩快速诊断 / 风格对比

Layer 2: Deep Artifact
  灵魂信 / 命书 / 月报 / 节气年报
  三页形象档案 / 发型专项 / 妆容专项 / 穿搭专项

Layer 3: Life Codex
  灵笺人生档案
  主神、关系、形象、命书、决策、灵币、礼赠统一归档
```

产品语言收束：

| 用户问法 | 产品回应 |
|---|---|
| 我现在该不该？ | 去灵鉴问一张决策卡 |
| 我适合什么样子？ | 去灵镜生成一份风格档案 |
| 这些结果以后还能看吗？ | 归档到灵笺 |
| 我想送给朋友 | 礼品卡/合盘/挑战 |

### 5.2 Mysti 灵鉴升级

#### 首页重构

从「入口陈列」改为「一个主路径 + 两个次路径 + 一个档案入口」。

建议信息架构：

| 层级 | 内容 |
|---|---|
| 主路径 | 今夜问一件事：决策快卡 |
| 次路径 A | 看见我是谁：塔罗人格/灵魂信 |
| 次路径 B | 看见我们怎样：合盘/礼品卡 |
| 长期入口 | 我的灵笺：档案、月报、纪章 |

首页不要让新用户第一眼看见 9 个平行按钮。她只需要知道：先问一件事，然后产品会带她去更深处。

#### 决策快卡升级

当前决策快卡已经有 30 天配额与 decision-pack。

建议升级：

| 升级 | 说明 |
|---|---|
| 场景从 5 个扩到 8 个，但首页只露 3 个高频 | 约会、面试、关系、离职、旅行、聚会、消费、创作 |
| 每张快卡写入灵笺 | 不只是本地决策 log，而是 codex entry |
| 结果后置行动 | 根据场景推荐下一步：约会前去灵镜做「约会玫瑰」；面试前生成「清冷通勤」 |
| 分享从复制文本升级为图卡 | 复制金句是轻量，真正传播需要 1080×1920 图片 |

#### 命书馆升级

命书馆要从「看起来很专业的 LLM 命理」升级为「可信的不确定性系统」。

必须保留的原则：

- 每条结论有出处。
- 四家方法有共识/分歧。
- 不确定就明说不确定。
- 不构成医疗、法律、投资、人生重大决策建议。

需要补的能力：

| 能力 | 说明 |
|---|---|
| 典籍 RAG | 当前 prompt 明确没有 RAG。正式收费前必须接典籍段落检索 |
| 盲断验证 UI | 用户提供关键事件时，要明确「先盲断、后验证」的流程，而不是暗示已经反推 |
| 风险语言管控 | 不允许「必定离婚」「大灾」「死亡」等恐吓性结论 |
| 付费前预览 | 先展示结构、可信度、示例结论，再进入 ¥39 单次 |

#### SKU 收束

把灵鉴 SKU 重新分为四类：

| 类别 | SKU | 价格心智 |
|---|---|---|
| 小仪式 | 决策包、每日额外牌、分享卡 Plus | ¥4.9-9.9 |
| 深档案 | 灵魂信、合盘报告、命书、月报 | ¥9.9-39 |
| 通行证 | 月度/季度/年度 | ¥19/月起 |
| 礼赠 | 礼品卡、闺蜜对箱、节日卡 | ¥39.9 起 |

首页只展示「小仪式」「深档案」「通行证」三个心智，不展示所有具体 SKU。

### 5.3 Mirror 灵镜升级

#### 重新定位

旧定位：

> AI Style Lab，上传照片生成报告。

新定位：

> **灵镜 Atelier：把一张照片变成你的风格档案。**

关键差异：

| 旧心智 | 新心智 |
|---|---|
| AI 帮我变好看 | 我获得一份可执行的风格档案 |
| 生成一张图 | 建立一章形象记录 |
| 玩一次 | 每个场景都可以回来更新 |
| 和美图竞争 | 和 WTFTI 主神、灵鉴场景、灵笺档案绑定 |

#### 产品层级

| 层级 | 产品 | 价格 | 目的 |
|---|---|---|---|
| L0 免费试用 | 新用户 2 灵币/2 次轻体验 | 免费 | 降低上传门槛 |
| L1 灵镜单图 | 单图生成 | 1 灵币 | 低价验证、引流、分享 |
| L2 三页诊断卡 | 色彩 + 妆发 + 穿搭 | 20 灵币 / ¥19.9 | 核心付费档案 |
| L3 场景风格包 | 面试/约会/旅行/年会等 | 39-69 灵币 | 复购 |
| L4 私人衣橱/长期档案 | 多次记录、对比、清单 | 订阅 | 留存 |

当前 `src/lib/mirror/credits.ts` 已有 `mirror-archive` 的价格设计，下一步应把 UI 和钱包消费打通。

#### 模式清理

建议把灵镜模式固定为三个：

| Mode | 定位 |
|---|---|
| 变美灵镜 | 综合形象改造，核心入口 |
| 色彩诊断 | 高保存率、低风险的实用报告 |
| 风格对比 | 高分享率，适合小红书传播 |

「命纹灵镜」应完全迁移到灵鉴命书馆。Mirror Hero 与结果文案中仍出现的「命纹」应清掉，避免用户把面相/命理和照片风格工具混在一起。

#### 隐私与信任升级

灵镜必须比普通 AI 修图工具更克制。

必须增加：

| 机制 | 说明 |
|---|---|
| 上传前清晰说明 | 上传给第三方模型、用于本次生成、不做身份识别、不做人脸库 |
| 结果页删除按钮 | 删除本地历史、清空图片链接、提示第三方链接有效期 |
| AI 生成标识 | 分享卡和下载图带「AI generated / WTFTI 灵镜」显式标识 |
| 未成年人提示 | 人像上传建议 18+ 或监护人授权 |
| 禁止项 | 不做颜值评分、种族/身份判断、医疗皮肤诊断、命运判断 |

### 5.4 Lingjian 灵笺升级

灵笺应从「聚合页」升级为「回访首页」。

建议章节：

| Chapter | 内容 |
|---|---|
| I 我是谁 | WTFTI 主神、多宇宙人格、核心标签 |
| II 我如何出现 | 灵镜形象档案、色彩、妆发、风格场景 |
| III 我如何选择 | 灵鉴决策卡、每日牌、月报、命书 |
| IV 我如何相遇 | 双人合盘、灵镜挑战、礼品卡 |
| V 我的资产 | 灵币、通行证、已购报告、可下载卡 |

灵笺的产品目标不是炫耀，而是让用户觉得「我在这里有东西」。这是长期 retention 和 switching cost 的核心。

## 10. 最终战略建议

### 10.1 战略主张

> **把灵鉴升级为「问心」入口，把灵镜升级为「现身」入口，把灵笺升级为「留痕」入口。**

三者组合后，WTFTI 的产品心智会从「测人格」升级成：

> **我每次不确定自己是谁、该怎么选、该以什么样子出现，都可以回到 WTFTI。**

### 10.2 P0 决策

| 决策 | 建议 |
|---|---|
| 灵鉴首页 | 主 CTA 改为决策快卡，其他入口进入「我的圣殿/更多仪式」 |
| 灵镜定位 | 从 AI Style Lab 改为灵镜 Atelier / 形象档案馆 |
| 命纹能力 | 从灵镜完全迁移到灵鉴命书馆 |
| 商业化 | Mirror 以 ¥19.9 三页档案为核心，¥1 单图只做引流 |
| 钱包 | 统一用 Ling-Bi 表达按次消费 |
| 档案 | 灵笺成为两模块共同的默认结果归档页 |
| 合规 | 立即补 AI 生成标识、照片删除、未成年人/人脸隐私提示 |

### 10.3 产品原则

1. **先安放，再解释**：灵鉴所有输出先给用户情绪落点，再给结构化解释。
2. **先可执行，再好看**：灵镜不是滤镜，结果必须能指导发型、妆容、色彩、穿搭。
3. **先归档，再复购**：每次结果都应自然进入灵笺，而不是停在一次性截图。
4. **先可信，再神秘**：神秘学调性不能压过免责声明、出处、不确定性和用户自主权。
5. **先女性主体，再算法能力**：语言不制造缺陷，不评价颜值，不把用户变成被算法审判的对象。

### 2026-05-07 · Iteration 5

- 灵镜生成前扣费从纯本地钱包升级为「云端优先」：登录用户调用 `/api/wallet/ling-bi` 执行服务端 Ling-Bi 消费。
- 保留匿名 / Supabase 不可用时的本机钱包兜底，避免新用户未登录时被阻断体验。
- 前端余额条新增钱包来源状态：`云端` 表示服务端账本，`本机` 表示 localStorage 兜底。
- 服务端消费使用 `mirror-generate:{spendId}` 幂等键；重复提交同一 spendId 不重复扣费。
- 验证结果：测试用户欢迎 2 灵币，执行 `mirror-single` 消费后余额为 1；重放同一幂等键余额仍为 1。

### 2026-05-07 · Iteration 6

- `/api/mirror/generate` 升级为登录用户的强制扣费入口：前端只传 `walletSpendId`，后端用同一幂等键执行服务端 Ling-Bi 消费。
- 直接绕过前端调用生成接口时，登录用户若缺少有效 `walletSpendId` 会被拒绝，避免免费调用生成能力。
- 前端生成前只做云端余额预检；真正扣费以生成 API 为准，避免前端先扣与后端再扣造成双写。
- APIMart 提交失败时，生成 API 会使用 `mirror-generate-refund:{spendId}` 幂等键自动退回本次服务端扣费。
- 验证结果：登录用户缺少 spendId 调用 `/api/mirror/generate` 返回 400 且余额仍为 2；stub 生成成功后余额从 2 到 1，重放同一 spendId 余额仍为 1。
