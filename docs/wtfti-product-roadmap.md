### 2.2 核心新模块：图鉴宇宙系统

这是 WTFTI 和 SBTI 的根本性差异。

**数据模型设计：**

```typescript
// 宇宙定义
interface Universe {
  id: string;               // 'classic' | 'xian' | 'meng' | 'feng' | ...
  name: string;             // '经典宇宙' | '仙门宇宙' | ...
  subBrand: string;         // 'WTFTI' | '仙TI' | '萌TI' | ...
  tagline: string;          // 'WTF我在仙门居然是这种仙'
  status: 'live' | 'coming' | 'limited' | 'locked';
  themeColors: ThemeColors;
  imagePathPrefix: string;  // 'classic' | 'xian' | 'meng'
  shareTemplate: string;    // 分享图模板ID
  launchDate?: string;
  endDate?: string;         // 限时宇宙
}

// 图鉴卡
interface CollectionCard {
  personalitySlug: string;  // 'emo' | 'ctrl' | ...
  universeId: string;       // 'xian' | 'meng' | ...
  imageUrl: string;
  cardNumber: string;       // 'WTF #017 · 仙TI'
  rarity: RarityTier;
  isUnlocked: boolean;
}

// 用户图鉴状态（localStorage，无需后端）
interface UserCollection {
  personalitySlug: string;           // 用户的人格类型
  unlockedUniverses: string[];       // 已解锁的宇宙
  gachaHistory: GachaRecord[];       // 每日抽卡记录
  totalCards: number;
  lastVisit: string;
}
```

**关键设计决策：不需要后端。**

所有状态存 localStorage：
- 用户的人格结果（测试完自动存）
- 已解锁的宇宙（访问过 = 解锁）
- 抽卡记录（每天一次免费抽）
- 图鉴墙状态

这样保持当前静态站点部署的优势（Next.js export），不需要数据库。

### 2.3 核心新功能：每日抽卡

**机制：**
- 每天免费抽一张图鉴卡
- 抽出的不限于自己的人格类型 — 可以是 36 种中的任何一个
- 抽出的宇宙也可以是任何一个已上线的宇宙
- 稀有度影响出率（传说级出率低）
- 抽到的卡进入图鉴墙

**为什么这个功能重要：**
1. 给用户每天一个回来的理由
2. 收集欲驱动留存
3. 每张卡都是潜在的分享素材（"WTF 我今天抽到了传说级拿捏者的仙门版"）
4. 不需要用户重新测试就能获得新内容

### 4.2 各宇宙设计规格

- 图片来源：当前 /images/types/ 下的已有图
- 品牌化改动：分享图模板换成 WTFTI 版
- 文案：升级为四段式结构
- 命名：换成 WTFTI 新名

#### 仙门宇宙（P0 · Phase 1）

> 已有完整策略（docs/xiuxian-2.0-strategy.md + visual briefs）

- 图片风格：仙门怪可爱（古风Q偶 + 失态/自嘲/嘴硬）

#### 萌物宇宙（P1 · Phase 2-A）

- 图片风格：棉花娃娃 / 软萌动物拟人 / 毛绒质感
- 设计关键词：圆、软、毛、嘟嘟脸、短手短脚、大眼睛
- 为什么女性吸引力 ★5：棉花娃娃是当下女性向收藏第一品类
- 每个人格对应一种萌物（不是动物图鉴，是"这个动物在做你会做的事"）

示例：
- 内耗永动机 → 一只仓鼠在跑轮上跑，但脸上写满了疲惫
- 编外保姆 → 一只母鸡翅膀下塞了太多小鸡，自己快站不住
- 被动钓鱼 → 一只猫在晒太阳，周围一群小动物在围观脸红

#### 发疯宇宙（P1 · Phase 2-B）

- 图片风格：纯黑底 + 荧光文字 + 极简发疯表情包
- 设计关键词：地狱笑话、丧、黑色幽默、99%文字感
- 为什么传播力 ★5：发疯文学 = 当下女性互联网最高频的情绪出口
- 这个宇宙的图鉴更像"表情包"而非"插画"——极度适合聊天转发

示例：
- 内耗永动机 → 纯黑底，中间一行荧光绿字："已在脑内开完第17轮复盘会"
- 佛到没电 → 纯黑底，中间一个极简笑脸，下面写："无所谓（真的无所谓）"
- 体面维持器 → 纯黑底，上面一个微笑emoji，下面一个崩溃emoji，中间写："表 / 里"

**重要：发疯宇宙几乎不需要绘图投入，以文案设计为主。** 这意味着可以极快速上线——用纯 CSS + 文字就能生成图鉴卡。

#### 塔罗宇宙（P2 · Phase 3）

- 图片风格：塔罗牌面 + 神秘学符号 + 星空底
- 设计关键词：金色线条、深蓝/深紫底、对称构图、神秘感
- 每个人格对应一张"WTF塔罗牌"
- 额外玩法：每周"WTF运势"——"本周你的内耗永动机会在周三达到峰值"

## 七、营销策略（WTFTI 专版）

### 7.1 传播三板斧

**第一板斧：品牌名本身就是传播**

"你测过 WTF 那个吗？" — 这句话本身就包含了品牌名+好奇心+禁忌感。

不需要额外解释，品牌名就是最好的广告语。

**第二板斧：新宇宙上线 = 新一轮传播事件**

每个新宇宙上线都自带话题：
- "WTF 仙门版来了！你在修仙世界居然是这种仙"
- "WTF 发疯版来了！你的发疯人格图鉴是什么"
- "WTF 萌物版来了！你变成萌物居然长这样"

每次都是一波新的截图-分享-测试循环。

**第三板斧：图鉴收集驱动自传播**

用户发图鉴墙截图 → 朋友看到说"这是什么" → 朋友来测 → 朋友也开始收集。

图鉴墙本身就是广告。

### 7.2 平台传播策略

## 八、关键成功指标（KPI）

### 8.1 北极星指标

**分享率 × 二次打开率**

- 分享率 = 完成测试后分享图鉴的人数 / 完成测试总人数
- 二次打开率 = 72小时内第二次访问的用户 / 首次访问用户

这两个指标乘积代表"传播引擎效率"。

### 8.2 各阶段目标

| 阶段 | 核心指标 | 目标值 |
|------|---------|--------|
| Phase 0 | 品牌切换后无流量流失 | 切换后 7 天 UV ≥ 切换前 7 天 UV × 90% |
| Phase 1 | 宇宙切换率 | ≥ 30% 用户在结果页切换到仙门宇宙 |
| Phase 2 | 二次打开率 | ≥ 15%（有图鉴收集动机的用户会回来） |
| Phase 2 | 新宇宙分享率 | 新宇宙上线 72 小时内分享量 ≥ 经典宇宙 × 80% |
| Phase 3 | DAU 留存 | 7 天留存 ≥ 10%（远高于一次性测试的 ~1%） |
| Phase 3 | 图鉴完成度 | 平均用户解锁 ≥ 3 个宇宙 |

## 九、风险预案

| 风险 | 影响 | 概率 | 预案 |
|------|------|------|------|
| wtfti.com 被微信屏蔽 | 失去微信传播渠道 | 中 | 666ti.com 做微信专用；分享图只印 666ti.com |
