## Phase 1: 重新定位 — 女性视角下的 SBTI

### 1.1 Geoffrey Moore 定位声明（HERTI 竞争语境修订版）

**当前 SBTI 定位漏洞：**

> SBTI/WTFTI 的品牌语言以"自嘲""毒舌""荒诞"为主调。
> 这在男女通吃时是优势（有趣 > 一切），但当市场出现"纯女性视角"竞品时，
> 我们的用语被归类为"男味""粗糙"——**不是因为我们做得差，而是因为品类期望被重新定义了**。

**新定位（女性宇宙专项）：**

```
For  18-30岁中文互联网女性用户
  that need  用自己的语言,被温柔而准确地理解
  [新宇宙名]*
  is a  专为她们设计的人格自我探索体验
  that  用[具体载体]让每个女生找到属于自己的那个"她"

Unlike  HERTI（单次体验/16种固定类型/无社交玩法/无持续内容）、
       SDTI（男味冲鼻/仓促上线）、
       普通MBTI（冷冰冰的四字母）
  [新宇宙名]*
  provides  一个可以反复回来、不断发现新面向的女性人格世界，
           同时继承 SBTI 的病毒式分享基因和精美视觉品质
```

### 1.2 JTBD 分析（女性人格测试品类）

|-----|-------------------|--------------|

| Job | 优先满足者 |
|-----|-----------|

#### 情感性 Jobs（🔑 关键发现）

| Job | HERTI 做到了什么 | SBTI 缺失的 |
|-----|-----------------|------------|
| **"被理解"** | ✅ 测试过程本身就像一次"被倾听" | ❌ 我们的语气是"骂你"不是"懂你" |
| **"被尊重"** | ✅ 历史伟大女性投射 = 你也很厉害 | ❌ 我们给的标签偏搞笑/贬义（"社畜""渣女预备役"）|
| **"被温暖"** | ✅ "测完心里暖暖的" | ❌ "测完哈哈大笑"——不同的情绪价值 |
| **"女性自我认同"** | ✅ "咱们女的做 HERTI" = 社群归属 | ❌ 我们没有明确的"这是你们的" |

> **核心JTBD 缺口**: SBTI 满足了"搞笑 + 社交货币"的 Job，但完全未满足"被温柔地理解 + 女性归属感"的 Job。
> HERTI 正是占据了这个空白。

### 1.3 Proto-Persona 补充：被 HERTI 击中的用户

#### Persona D: 「温柔内省型」文艺女孩 🆕

- **年龄**: 22-30 岁，有一定文化消费品味
- **行为**: 深夜或安静时做测试 → 仔细读每道题 → 在选项间犹豫 → 看到结果被戳中 → 截图保存 → 分享时附上自己的感悟
- **核心 JTBD**: "我不想被搞笑地贴标签，我想被认真地看见"
- **情感需求**: 被尊重 + 被理解 + 找到"同类" + 安静的自我确认
- **为什么 HERTI 赢了**: 文学调性 + 历史女性映射 + "精神马杀鸡"式体验 + 没有男性凝视痕迹
- **我们之前为什么没抓住她**: SBTI 的核心 DNA 是"自嘲""毒舌""荒诞"，这群用户觉得"太闹了"

## Phase 2: 问题画布 (MITRE Problem Framing)

### 2.1 向内看 (Look Inward)

**我们的假设：**
- 假设1: 有趣/自嘲 = 对所有人有吸引力 → **错。"被温柔理解"是另一个独立的高价值需求**
- 假设2: 多宇宙覆盖足够广 = 不用按性别做专门版 → **错。10 个宇宙但没有一个是"专为女性视角"**
- 假设3: XPTI（恋爱XP）已经覆盖了女性需求 → **错。XPTI 解决的是"恋爱偏好"Job，不是"自我认同"Job**
- 假设4: 分享图比结果文案更重要 → **部分错。文学性文案本身就是传播物料**

**为什么未解决：**
- SBTI 的品牌人格（毒舌/自嘲）从基因上不适合做"温柔"的事
- 团队（1人+AI）资源有限，优先在已验证方向叠加功能
- 缺少女性用户的负面反馈闭环（他们不说"SBTI 太男味了"，而是直接离开去测 HERTI）

**我们的偏见：**
- "搞笑 = 最高情绪价值" —— 这是男性编辑室偏见
- "社交功能多 = 用户黏性高" —— 但 HERTI 证明了"体验品质"本身可以创造口碑传播
- "女性版 = 粉色 + 恋爱题" —— XPTI 的做法恰恰是这个陷阱

### 2.2 向外看 (Look Outward)

**谁在经历这个问题？**
- 小红书 70%+ 女性用户中，"自我探索型精神女孩"（Persona D）约占 20-30%
- 这群人之前会做 MBTI → 16personalities → SBTI/类似测试 → 现在流向 HERTI
- 她们不是不做 SBTI，而是**做完后觉得"有趣但不够深"**

**谁在受益？**
- HERTI 的作者 Rhea：个人开发者级别的产品，AI 辅助（Claude），极低成本对标大平台
- 自媒体博主：HERTI 结果文案本身有文学性 → 截图+感悟 = 现成小红书万赞贴模板
- "反 SBTI" 舆论受益者：SDTI/HERTI 等替代品在"避雷 SBTI"叙事中获取免费流量

**谁被遗漏了？**
- 40% 的女性用户其实同时需要"搞笑"和"温柔" —— 目前没有产品能做到 both
- 年龄偏大（28-35）的女性：既不爱 SBTI 的学生腔，也觉得 HERTI 太文艺
- 非一线城市女性：文学调性门槛偏高，但"被看见"的需求一样强烈

### 2.3 重新框定 (Reframe)

**旧问题**:  
"如何让 SBTI 吸引更多女性用户？"

**新问题**:  
"'被温柔而准确地理解'是一个独立的高价值 Job，我们如何在 SBTI 的多宇宙架构内创造一个专门满足它的体验，而不破坏我们的品牌基因？"

**How Might We (HMW)**:  
> **HMW 让 SBTI 的一个宇宙既保持内容品质和视觉精致度（HERTI 水准），又继承我们独有的社交裂变 + 多宇宙收集机制？**

### 3.3 每个机会的解决方案

#### Opp A: 创造"她的宇宙" — 3 个方案

| 方案 | 概念 | 差异化点 vs HERTI |
|------|------|-----------------|
| **A1: 书中的"她"宇宙** | 16 种人格映射到文学/历史女性角色，文案风格温柔内省，视觉清冷文艺 | HERTI 只有 16 位历史女性固定类型。**我们可做成系列**：先"书中的她"（文学），再"画中的她"（艺术），再"歌中的她"（音乐） → 多季滚动出新 → 多宇宙收集优势碾压 |
| **A2: "她说"情绪宇宙** | 不映射公众人物，而是映射情绪状态/人生阶段。如"凌晨3点的她""下雨天的她""刚分手的她" | HERTI 做了"历史女性"，我们做"当下的你" → 更贴近当代女性日常，不需要知道居里夫人是谁 |
| **A3: 闻香识"她"宇宙** | 人格对应一种香水/花香/气味。每种人格是一个"气味人格"。如"白茶调""雪松调""焚香调" | 五感切入 → 全新品类。小红书"香水测试"是超高互动品类。分享卡天然好看。与现有花格宇宙互补但不重叠 |

#### Opp B: 提升体验温度 — 3 个方案

| 方案 | 概念 | 影响范围 |
|------|------|---------|
| **B1: 双调结果卡** | 每个人格结果页增加一个"温柔版"tab，和现有"毒舌版"并列。用户可以切换"看看毒舌怎么骂我" vs "看看温柔怎么夸我" | 现有 10 个宇宙 × 27种 = 270 个结果页都需增写 |
| **B2: "给自己写一封信"引导** | 测试完成后，结果页底部增加一个 CTA："写一段话给测试前的你" → 用户自生成UGC → 截图传播 | 轻量，但可能完成率低 |
| **B3: 结果文案语气升级** | 不改功能，纯文案优化。把最被传播的"毒舌金句"都增加一层"温暖底色" | 工作量大但零技术改动 |

#### Opp C: 女性视角社交玩法 — 3 个方案

| 方案 | 概念 | 裂变系数预估 |
|------|------|------------|
| **C1: "她和她"CP 闺蜜版** | 现有 CP 配对是恋爱向。增加"闺蜜配对版"：两个女生对比的维度不是"匹配度"而是"互补度""默契度""吵架概率" | K≈2.5（闺蜜群 2-4 人连锁测试）|
| **C2: "她的书架"收集页** | WTF Card 的女性版：不是"多宇宙人格卡"，而是"你在不同文学世界的角色收集页"。视觉做成书架/书页 | K≈1.5（收集驱动回访 → 间接分享）|
| **C3: "匿名树洞"随机匹配** | 测试完成后，匹配一个相同人格的陌生人，互相看对方的一句话感悟（匿名） | K≈3.0（好奇心驱动，但需谨慎处理安全）|

**上海 / 2026年4月** —— SBTI（多宇宙人格测试平台）今日宣布上线全新主题宇宙「书中的她」，
这是 SBTI 第 11 个宇宙，也是第一个**专为女性用户设计**的文学向人格探索体验。

**问题**: 当下最火的人格测试要么太搞笑（"测完哈哈大笑然后忘了"），
要么太冷冰冰（"你是 INFJ"然后呢？），要么太单一（"只能测一次"）。
女性用户需要一种**既被认真对待，又能不断发现新自我**的方式。

**解决方案**: 「书中的她」基于 SBTI 的 15 维度人格引擎，将每个人格映射为一位**经典文学作品中的女性角色**。
16 种结果，每一种都配备：
- 一段"像在写给你的信"的深度性格解析（500-800字，文学调性）
- 一句"你的灵魂金句"（适合做微信状态和小红书标题）
- 一张"书页风格"分享卡（精美到想打印出来）
- 该角色在其他 SBTI 宇宙中的"平行身份"对照表

**用户怎么说**:
"以前测 SBTI 觉得好笑但有点闹，这次「书中的她」测完我安静了好久。
结果说我是'雨中读信的人'，我当场哭了。然后我又去测了其他三个宇宙看我在那边是谁。太上头了。"
—— 小红书用户 @安静的三明治

**差异化**:
- 与 HERTI 比：结果映射更广（文学角色而非历史人物），有分享图，有社交玩法，有多宇宙联动
- 与 MBTI 比：没有四个字母的冰冷感，每个角色都有故事和画面
- 与 SBTI 其他宇宙比：这是第一个"拥抱模式"而非"吐槽模式"的宇宙 — 不骂你，理解你

### 6.3 维度体系（4 轴 × 2 极性 = 16 种组合）

```
轴1: 感受方式   —— [热烈型 H] ←→ [沉静型 Q]
    H: 像安娜/斯嘉丽/弗里达 → 爱得像烈火，伤得也用力
    Q: 像翠翠/宝钗/苏菲 → 水一样流过，不声不响地深

轴2: 面对世界   —— [闯入型 B] ←→ [守望型 W]
    B: 像简爱/娜拉/伊丽莎白 → 推开门走进风中
    W: 像玫瑰/林黛玉/白流苏 → 在原地，等一个看见她的人

轴3: 内在力量   —— [理性型 L] ←→ [直觉型 I]
    L: 像赫敏/宝钗/张爱玲 → 冷静地拆解世界，再决定爱不爱
    I: 像三毛/翠翠/苏菲 → 靠感觉走路，相信命运

轴4: 自我边界   —— [完整型 S] ←→ [融合型 M]
    S: 像娜拉/简爱/斯嘉丽 → "我即使爱你，也不会丢掉自己"
    M: 像玫瑰/安娜/林黛玉 → "爱到最后，我和你之间没有边界"
```

**编码规则**: H/Q + B/W + L/I + S/M → 16 种组合

示例：
- HBLS = 热烈 + 闯入 + 理性 + 完整 → **伊丽莎白·班纳特型**
- QWIM = 沉静 + 守望 + 直觉 + 融合 → **翠翠型**

### 关键结论

1. **HERTI 打的不是功能战，是情绪战** — 它证明了"被温柔理解"是一个 SBTI 完全空白的高价值 Job
2. **我们的系统优势依然碾压** — 多宇宙架构、社交玩法、SEO 矩阵、分享图系统，HERTI 一个都没有
3. **战略答案是"加一个宇宙"而非"改底层"** — 我们不需要改变 SBTI 的搞笑 DNA，只需要**用一个温柔的新宇宙填补空白**
4. **速度是一切** — HERTI 是一个人+AI 做的，我们也是。谁先占住"文学 × 女性 × 多宇宙"品类，谁就赢
5. **系列化是终极护城河** — HERTI 只能做一个"她的人格地图"，我们可以做"书中的她""画中的她""歌中的她"——无限扩展
