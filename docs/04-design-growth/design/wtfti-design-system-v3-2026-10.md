# WTFTI 设计系统 v3 · 奶油日记 × 丝绒夜 · 2026-10

> Status: Canonical（取代 design-system-v2 与 brand-spec.md 中的视觉口径）
> 依据：[wtfti-her-refocus-2026-10.md](../../01-strategy/wtfti-her-refocus-2026-10.md)；原型 `design/refocus-2026-10/WTFTI 视觉方向 v2.html`
> 代码落点：`src/app/skins.css`（`.skin-journal` / `.skin-velvet`）

## 1. 两套皮肤，各管一类页面

| 皮肤 | 用在 | 情绪 |
|---|---|---|
| **奶油日记 `journal`**（默认） | 首页、今日、美我、懂我、我的、测试流程 | 温暖、被记录、像自己的手帐 |
| **丝绒夜 `velvet`** | 掌纹、塔罗、星座/八字、深度报告（付费内容） | 深夜的仪式感、更深一层 |

切换规则：进入玄学内容 = 换到丝绒夜，回到日常 = 回到奶油日记。不提供用户手动切换的「暗色模式」。

## 2. Token

| Token | journal | velvet | 用途 |
|---|---|---|---|
| `--s-bg` | `#FBF6EC` cream | `#2A1020` merlot | 页面底 |
| `--s-bg-2` | `#F5ECDD` | `#351528` | 次级底、输入框、条带 |
| `--s-card` | `#FFFDF8` | `#3A1A2D` velvet | 卡片 |
| `--s-ink` | `#4A3628` cocoa | `#F6E9DF` ivory | 主文字（对比度 ≥ 7:1） |
| `--s-ink-2` | `#6E5646` | `#E2CBBF` | 次文字 |
| `--s-mute` | `#8A7362` | `#B9998F` | 辅助文字（≥ 4.5:1） |
| `--s-line` | `#E8DCC8` | `rgba(217,183,126,.32)` | 分割线、边框 |
| `--s-accent` | `#E8907A` peach | `#D9B77E` gold | 装饰、进度、选中 |
| `--s-accent-soft` | `#FADBD0` | `rgba(217,183,126,.14)` | 选中底、提示条 |
| `--s-accent-text` | `#B45C47` | `#E8C995` | 强调文字、链接 |
| `--s-cta` / `--s-on-cta` | `#4A3628` / `#FFF8EC` | `#D9B77E` / `#2A1020` | 主按钮 |
| 辅色 | sage `#A9C5A0` · butter `#F2CE7E` | rose `#E8B4B8` | 胶带、心情色、标签 |

规则：
- 小字和链接一律用 `--s-accent-text`，不用 `--s-accent`（对比度不够）。
- 组件里不写死 hex，全部走 token。
- 唯一允许的渐变：velvet 页面顶部的径向光晕。按钮、卡片、文字都不用渐变。

## 3. 字体

| 角色 | journal | velvet |
|---|---|---|
| 标题 | 站酷小薇 `--font-xiaowei` | 思源宋体 `--font-serif-sc` |
| 手写批注（每屏最多 1 处） | 龙藏体 `--font-longcang` | — |
| 英文 / 数字 / 日期 | Cormorant Garamond（velvet 用斜体） | 同左 |
| 正文 | 思源黑体 `--font-sans-sc` | 同左 |

字号：H1 36-38 / H2 22 / 卡片标题 21 / 正文 15 / 辅助 12-13 / eyebrow 11（大写、字距 0.32em）。正文行高 1.7 以上。

## 4. 组件与母题

| 组件 | journal | velvet |
|---|---|---|
| 主按钮 `.s-btn` | 胶囊形、墨色底、底部 4px 实色投影（像按下去的贴纸） | 直角金底、外圈双描边 |
| 卡片 `.s-card` | 6px 圆角，可选横线信纸底纹，可轻微旋转（±0.6°） | 4px 圆角，内描一圈细金线 |
| 胶带 `.s-tape` | 卡片顶部居中，三色轮换（butter / peach / sage） | 不用 |
| 拍立得 `.s-polaroid` | 首页拼贴、档案收藏，内容是真实产品内容，不放空占位图 | 不用 |
| 画框 | — | 拱门 `.s-arch`（塔罗、掌纹结果） |
| 分隔 | 点阵纸底 | 金色细线 + 中间斜体小字 |
| 编号 | 手写 i / ii / iii | 罗马数字 — I — |

禁用：emoji 当图标、紫粉渐变、大面积玻璃拟态、左侧色条卡片、通用星空背景。

## 5. 文案语气

- 像闺蜜说话：「早呀，小雨」「今天就穿这身吧」，不说「灵魂」「宇宙」「神域」。
- 玄学内容永远带「仅供娱乐与自我探索」。
- 付费点在点击前就写明价格。

## 6. 导航

- 移动端底部 5 个 tab：今日 · 测我 · 美我 · 懂我 · 我的。
- 桌面端顶部同样 5 项，加一个登录入口。
- 不再出现「宇宙列表」类的大菜单。
