## 一、风格选择：潮玩盲盒风（Chibi Vinyl Toy Style）

### 1.1 为什么选这个风格

**排除法：**

| 风格 | 排除原因 |
|------|---------|
| 低多边形纸艺 | ❌ 原作者的视觉母盘，无法建立差异化品牌 |
| 扁平插画 | ❌ 太常见，小红书人格图一半都是这种，没有辨识度 |
| 手绘涂鸦 | ❌ 显得不精致，女性用户保存意愿低 |
| 赛博潮酷 | ❌ 偏男性向，不够普适 |

**选择理由：**

潮玩盲盒风（3D 渲染感的 Q 版角色）命中了 WTFTI 的所有需求：

| 需求 | 潮玩盲盒风如何满足 |
|------|-------------------|
| 女性用户吸引力 | ★★★★★ — Pop Mart 的核心用户 80% 是女性，这个审美已经被验证 |
| 和原作者的差异化 | ★★★★★ — 3D 质感 vs 2D 纸艺，一眼就是不同产品 |
| 收集感 | ★★★★★ — 盲盒本身就是收集品类，天然适配图鉴收集系统 |
| 截图分享欲 | ★★★★★ — 精致但搞怪，值得保存到手机相册 |
| 表情/情绪承载力 | ★★★★ — 3D 角色面部可以做出丰富的崩溃/装死/发疯表情 |
| 道具叙事空间 | ★★★★★ — 可以围绕角色放大量小道具讲故事 |
| AI 生图可行性 | ★★★★ — 当前文生图模型对 "vinyl figure" 类 prompt 控制力很好 |

**一句话定义：**

> WTFTI 经典宇宙的图鉴风格是「互联网发疯版潮玩手办」—— 
> 看起来像 Pop Mart 的精致盲盒，但表情全是崩溃的、姿势全是狼狈的、道具全是社死的。
> 精致 × 搞怪 × 自嘲 = 值得收藏的社交货币。

### 1.2 风格坐标

```
精致度：★★★★☆（比涂鸦/纸艺精致得多，但不追求写实）
搞怪度：★★★★★（表情和道具必须好笑）
可爱度：★★★★☆（Q 版比例天然可爱）
体面度：★★☆☆☆（角色必须处于某种"失态"中）
女性向：★★★★★（潮玩审美 + 柔和配色）
辨识度：★★★★★（3D 渲染质感 vs 所有竞品的 2D）
```

## 二、统一视觉规范

### 2.1 角色基础设定

| 要素 | 规范 |
|------|------|
| **头身比** | 2~2.5 头身（大头小身，盲盒比例） |
| **材质感** | 哑光乙烯质感（matte vinyl），不要光滑塑料或金属 |
| **轮廓** | 圆润、无锐角、胖胖的手脚 |
| **眼睛** | 大而有神，但可以是死鱼眼/翻白眼/含泪/发光/放空 |
| **嘴巴** | 小嘴为主，情绪通过嘴型变化表达（蔑笑/瘪嘴/O 嘴/假笑） |
| **服装** | 现代休闲为主（卫衣/睡衣/格子衫/西装+拖鞋），衣着细节体现人格 |
| **站姿** | 不稳定——歪斜/瘫坐/硬撑/蹲着/趴着，从不端正站立 |
| **性别** | 中性偏可爱，不刻意区分男女，让所有用户都能代入 |

### 2.2 表情系统（品牌识别核心）

WTFTI 的图鉴辨识度不靠画法，靠表情语法。

**高频情绪表情库：**

| 表情代号 | 描述 | 适用人格类型 |
|---------|------|------------|
| 😐 **硬撑微笑** | 嘴角上扬但眼神空洞 | 体面维持器、陪笑护法 |
| 😵‍💫 **过载崩溃** | 螺旋眼 + 冒烟 | 内耗永动机、情绪过载器 |
| 😑 **死鱼眼** | 完全放空的佛系表情 | 佛到没电、班味永存 |
| 🥺 **嘴硬但快哭** | 嘴巴紧闭但眼眶泛红 | 情绪过载器、社恐晚期 |
| 😏 **无辜坏笑** | 似笑非笑的暧昧表情 | 被动钓鱼 |
| 🤯 **WTF 震惊** | 大张嘴 + 头顶冒出 !?? | 情绪旁观者、灾难预言家 |
| 😴 **断电** | 闭眼 + 灵魂出窍感 | 人间休眠仓 |
| 🔥 **假装没事但着火** | 微笑但身后冒火 | 编外保姆、感恩永动机 |
| 💀 **已死** | × × 眼 | 低欲望哲学家 |
| 🥴 **微醺失控** | 脸颊泛红 + 歪嘴 | 微醺真话器 |

### 2.3 道具叙事系统

每个角色必须携带 **3-5 个漂浮小道具**，道具是人格的视觉摘要。

**道具设计原则：**
- 道具不是装饰，是"一眼看懂这是什么人格"的关键
- 道具要有细节和幽默感（比如手机屏幕上显示"已读不回"）
- 道具风格统一为微缩卡通物件（和角色同一渲染风格）
- 必须有一件"出框"道具——比角色大或者位置特殊，制造视觉张力

### 2.4 构图规范

```
┌─────────────────────────────┐
│                             │
│     ○ [漂浮道具]            │
│         ○ [漂浮道具]        │
│                             │
│        ┌───────┐            │
│        │       │            │
│        │ 角色  │            │
│        │       │            │
│        └───┬───┘            │
│      [地面道具]             │
│             ○ [漂浮道具]    │
│                             │
└─────────────────────────────┘

- 纯白背景（#FFFFFF）
- 单角色绝对居中
- 留白充足（角色占画面 50-60%）
- 道具环绕角色漂浮，不遮挡角色面部
- 可选：极淡的地面投影（增加立体感）
- 无文字、无标题、无水印（文字在分享图模板中加）
```

### 2.5 配色系统

**不做统一色调。** 每个人格有自己的主题色，但统一在柔和/粉嫩的色彩范围内。

| 人格情绪类 | 配色范围 | 示例人格 |
|-----------|---------|---------|
| 恋爱/心动类 | 粉、桃、珊瑚、暖红 | 被动钓鱼、上头体质 |
| emo/内耗类 | 雾蓝、薰衣草紫、灰粉 | 内耗永动机、情绪过载器 |
| 佛/躺类 | 米白、灰蓝、淡绿 | 佛到没电、人间休眠仓、低欲望哲学家 |
| 社交/嗨类 | 明黄、薄荷绿、天蓝 | 气氛焊接工、嘴巴关不上 |
| 职场/控制类 | 深蓝、宝蓝、酒红 | 人形指挥部、人形KPI |
| 反骨/发疯类 | 黑+荧光、暗红、深紫 | 逆天小师妹、情绪放大器 |
| 温暖/付出类 | 豆沙粉、奶茶色、暖棕 | 编外保姆、人肉充电宝 |

**关键：背景永远是白色。** 颜色体现在角色服装和道具上，不影响截图传播的清爽感。

## 三、统一 Prompt 体系

### 3.1 正向 Prompt（Base Positive）

```
3D render style, chibi vinyl figure character, matte finish, Funko Pop meets designer toy aesthetic, 2 to 2.5 head-body ratio, big round head, small chubby limbs, exaggerated facial expression, meme-worthy self-deprecating humor, white background, centered full body, soft studio lighting, clean silhouette, tiny floating props and accessories around the character telling a story about their personality, pastel color palette with one strong accent color, cute but slightly pathetic, emotionally readable at first glance, NOT elegant NOT perfect NOT glamorous, like a collectible figure of someone having a rough day

3D渲染风格，Q版潮玩手办角色，哑光乙烯质感，2-2.5头身比例，大圆头小短胖手脚，夸张面部表情，自嘲搞怪感，纯白背景，单角色居中全身像，柔和灯光，干净轮廓，角色周围漂浮着讲述人格故事的微缩小道具，柔和粉彩配色搭配一个强调色，可爱但有点惨，一眼就能读出情绪，不优雅不完美不端庄，像是一个"今天过得很崩溃"的人的收藏手办
```

### 3.2 负向 Prompt（Base Negative）

```
low poly, papercraft, origami, flat 2D illustration, anime style, realistic human, photorealistic, cinematic lighting, complex background, landscape, text, typography, watermark, logo, dark horror, scary, violent, NSFW, multiple characters, split view, frame border, speech bubble, comic panel, pixel art, sketch, line art, ink wash, traditional painting

不要低多边形，不要纸艺，不要折纸，不要扁平2D插画，不要动漫风，不要写实人物，不要电影感灯光，不要复杂背景，不要文字，不要标题，不要水印，不要恐怖，不要多个角色，不要分割画面，不要对话框，不要像素风，不要素描线稿，不要水墨
```

### 3.3 Prompt 构建函数

```javascript
function buildWtftiClassicPrompt({ characterConcept, expression, outfit, props, accentColor }) {
  const BASE = `3D render style, chibi vinyl figure character, matte vinyl finish, designer toy aesthetic, 2-2.5 head body ratio, big round head, chubby short limbs, white background, centered full body, soft studio lighting, clean silhouette, emotionally readable exaggerated face`;
  
  const TONE = `self-deprecating meme energy, cute but slightly pathetic, like a collectible figure of "${characterConcept}", NOT elegant NOT perfect NOT glamorous`;
  
  const VISUAL = `${expression}, wearing ${outfit}, surrounded by floating miniature props: ${props}, main accent color ${accentColor}, pastel tones`;
  
  return `${BASE}, ${TONE}, ${VISUAL}`;
}
```

## 五、图片生成执行计划

### 5.1 生成策略

**方案 A（推荐）：txt2img 直接生成**

因为是全新风格，不需要参考图作为风格锚点。直接用文字 prompt 生成。

流程：
1. 先用 Base Positive + 种子角色描述生成 3-5 张种子图
2. 从中选出风格最符合的 1 张作为"风格基准图"
3. 用基准图做 img2img 参考 + 每个人格的详细 prompt 批量生成
4. 质检 → 微调 → 部署

**方案 B：如果 RunningHub 的 img2img 质量更稳定**

用方案 A 生成的基准图作为 ref，走现有 img2img pipeline：
- 修改 `scripts/runninghub-prompts.mjs` 中的 BASE_VISUAL_STYLE
- 新建 `scripts/image-generation/modules/wtfti-classic.mjs`
- 每个 type 提供详细的角色描述 prompt
