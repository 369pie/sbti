## 0. 一句话定义

**SBTI 人格卡 = 「自嘲 × 抽象 × 玩梗」的互联网人设图鉴，不是严肃心理学报告。**

用户拿到结果的第一反应应该是：「哈哈哈说的就是我」→ 截图 → 转发。

---

## 1. 命名公式

每张人格卡包含 **5 段核心文案**，缺一不可：

| 段位 | 名称 | 字数 | 示例 |
|------|------|------|------|
| ① 中文名 | 人格类型名 | 3-8 字 | 纯爱打工人、谜语老蜜蜂、操心破产户 |
| ② 英文代号 | Code / 缩写 | 3-5 字母 | S.I.G.H、B.O.S.S、F.A.K.E |
| ③ 搞笑展开 | Backronym | 英文短句 | Single Irritated Greasy Hater |
| ④ 一句话描述 | 核心人设速写 | 15-35 字 | 你是那种表面阴阳怪气，实则背负一切的顶级打工人。 |
| ⑤ 三标签 | emoji + 短语 | 每条 2-6 字 | 🦇 走路带风大蝙蝠 / 🧴 洗发水绝缘体 / 💔 永远的Always |
| ⑥ 金句 | 经典台词/自嘲名言 | 10-25 字 | "扣十分，你呼吸吵到我回忆初恋了。" |

## 2. 中文名设计规则

### 2.1 命名逻辑

**公式 = 前缀修饰 + 核心身份**

| 前缀类型 | 示例 | 效果 |
|---------|------|------|
| 程度夸张 | 纯血~、终极~、究极~ | 拉满纯度感 |
| 状态描述 | 破防~、佛系~、上头~ | 瞬间代入 |
| 动作化 | 降维打击~、狂野越狱~ | 画面感强 |
| 反差 | 高冷猫系~、谜语老~ | 制造意外 |

| 核心身份 | 示例 | 效果 |
|---------|------|------|
| 职业/角色 | 打工人、班主任、救世主 | 打工人共鸣 |
| 动物化 | 纸老虎、蜜蜂、发胶狂魔 | 画面感、萌感 |
| 状态化 | 破产户、大冤种、永动机 | 自嘲到位 |
| 梗化 | 卷王之王本王、酒后真人 | 互联网原生感 |

### 2.2 命名风格光谱

从轻到重，根据产品线选择合适区间：

```
[轻度自嘲]                                              [极致抽象]
  人间收藏夹  →  操心破产户  →  纯爱打工人  →  纯血纸老虎  →  无鼻狂怒尊者
  ↑                                                        ↑
  经典版/恋TI 适用                                  mmck/极端梗版 适用
```

### 2.3 好名字的 5 个检验标准

1. **一秒看懂** — 不需要解释就知道说的是什么人
2. **有画面感** — 读完脑子里能浮现一个具体画面
3. **想截图** — 看到就想发给朋友说"这是你"
4. **能自嘲** — 被贴这个标签不会生气反而想认领
5. **有梗感** — 包含互联网语言DNA（如"破产"、"社死"、"原地去世"）

### 2.4 命名禁区

| 禁止 | 原因 | 正面示例 |
|------|------|---------|
| ❌ 正经心理学术语（如"高敏感人格"） | 没有娱乐感 | ✅ 情绪核弹 |
| ❌ 纯英文直译（如"控制者"） | 无中文梗感 | ✅ 人形KPI |
| ❌ 太长 > 8字 | 不利于截图传播 | ✅ 3-6字最佳 |
| ❌ 正能量鸡汤（如"温暖守护者"） | 和品牌调性冲突 | ✅ 操心破产户 |
| ❌ 真正冒犯性词语 | 自嘲≠辱骂 | ✅ 大冤种（自嘲）≠ 侮辱 |

## 3. 英文代号（Code）设计规则

### 3.1 Backronym 技法

**核心手法：让一个看起来正经/常见的英文单词，展开后变成自嘲/搞笑的句子。**

| 代号 | 看起来像 | 实际展开 | 效果 |
|------|---------|---------|------|
| S.I.G.H | 叹气 sigh | Single Irritated Greasy Hater | 完美对应"纯爱打工人"的叹气感 |
| B.O.S.S | 老板 boss | Bearded Old Secret Schemer | 用"老头秘密策划者"解构"boss"一词 |
| F.A.K.E | 假的 fake | Father Always Knows Everything | 纸老虎的"假"和"永远知道一切"形成反差 |
| H.E.R.O | 英雄 hero | Hardships Every Ridiculous Occasion | 英雄的本质是每次荒唐场合都倒霉 |
| N.E.R.D | 书呆子 nerd | Never Ever Rest Day | 卷王的本质是永远没有休息日 |
| D.O.G.E | 狗狗 doge | Dog Outta Great Escape | 越狱的狗=叛逆的灵魂 |
| P.A.I.N | 疼痛 pain | Poor Always Injured Nobody | 救世主的本质是永远受伤的可怜人 |
| N.O.S.E | 鼻子 nose | No One Smells Everything | 无鼻和"闻一切"的自我矛盾 |
| C.A.T | 猫 cat | Cool And Tough | 高冷猫系名副其实 |
| R.E.A.D | 阅读 read | Relentless Educated Alpha Dominator | 学霸=无情的受教育支配者 |

### 3.2 Code 设计检查清单

- [ ] 3-5 个字母，组成一个可发音的英文单词
- [ ] 展开后的英文句子本身要有搞笑感/自嘲感
- [ ] 英文展开须和中文名的核心人设吻合
- [ ] 避免和已有 Code 撞车（参考下方 Code 占用表）
- [ ] 展开句中尽量不出现难懂生僻词

### 3.3 Code 格式规范

| 格式 | 适用场景 | 示例 |
|------|---------|------|
| X.X.X.X（带点） | 班TI 职场版、三角洲、王者 等正式子品牌 | B.O.S.S、N.E.R.D |
| XXXX（无点） | WTFTI 经典版简洁模式 | BOSS、NERD |
| XXX-X（带连字符） | 特殊创意型，打破阅读节奏 | JOKE-R、GAME-R、OH-NO |
| X!（带感叹号） | 情绪型人格 | CAT! |

## 4. 一句话描述写法

### 4.1 句式模板

**黄金句式 = "你是那种 [反差/夸张描述] 的人/XX。"**

| 模板 | 示例 |
|------|------|
| 你是那种 A，实则 B 的人 | 你是那种表面阴阳怪气，实则背负一切的顶级打工人。 |
| 你是那种 A，却 B 的人 | 你是那种明明只想安静上学，却总被迫拯救世界的人。 |
| 你是那种…就算 A 也要 B 的人 | 你是那种就算没有鼻子也要把别人的空气吸干的人。 |
| 你是那种 A 到 B 的人 | 你是那种每天被气到想辞职但还在默默加班的人。 |
| 你是那种遇到 A 都 B 的人 | 你是那种遇到任何问题都想先发朋友圈@老爸的人。 |

### 4.2 关键技巧

1. **必须有反差** — 前半句和后半句形成冲突（表面 vs 内心、想做 vs 实际）
2. **要有具体细节** — 不说"有控制力"，说"已经把甘特图排完了"
3. **口语化** — 像朋友吐槽你，不像心理咨询师分析你
4. **15-35 字** — 太短没画面感，太长读不完

## 6. 金句设计

### 6.1 金句来源类型

| 类型 | 手法 | 示例 |
|------|------|------|
| IP 台词改编 | 取原台词，替换关键词为自嘲内容 | "扣十分，你呼吸吵到我回忆初恋了。" |
| 人设独白 | 用第一人称说出最"该人格"的话 | "一切在计划中，除了我掉没的头发。" |
| 反差吐槽 | 看似正经实则自黑 | "我本来可以很拽，如果波特不在。" |
| 经典格式梗 | 套用互联网经典句式 | "我没惹任何人，是黑魔王先动的手。" |
| 自问自答 | 提问后给出离谱回答 | "来颗柠檬雪宝吗？" |

### 6.2 金句质量检查

- [ ] 读完想笑或想转发
- [ ] 和人格核心人设强相关
- [ ] 15-25 字，一口气读完
- [ ] 如果是 IP 改编，原句辨识度够高
- [ ] 不会让人觉得被冒犯（自嘲 ≠ 攻击）

## 7. IP 宇宙换皮规则

SBTI 的核心架构是 **同一套底层人格 × 不同 IP 宇宙的皮肤**。
换皮时遵循以下规则：

### 7.1 保持不变的

| 元素 | 说明 |
|------|------|
| 底层 slug | boss、nerd、ctrl、mum 等 14 型 slug 全宇宙复用 |
| 核心人设内核 | boss = 控场指挥型，不管在哪个宇宙都是这个性格内核 |
| 维度映射逻辑 | 15 维度体系和计分公式不变 |

### 7.2 必须换皮的

| 元素 | 经典版 | 班TI 职场版 | 三角洲版 | 王者版 | 新 IP（示例）|
|------|--------|-----------|---------|-------|------------|
| 中文名 | 人形指挥部 | 人形甘特图 | 战术指挥部 | 峡谷指挥官 | {IP语境名} |
| Code 展开 | Born Organizing... | Born Organizing Sloppy... | (同) | (同) | {IP定制展开} |
| 一句话描述 | 散了吧，我来 | 散了吧，这个会我来主持 | 都别动，听我指挥 | 团战前先开语音 | {IP场景化} |
| 三标签 | 日常场景 | 职场场景 | 战术场景 | 峡谷场景 | {IP场景} |
| 金句 | 通用自嘲 | 职场段子 | 游戏语录 | 峡谷名言 | {IP语录} |
| 视觉 | 编辑插画 | 职场杂志风 | 战术风 | 游戏皮肤风 | {IP美术风格} |

### 7.3 换皮质量检查

- [ ] 中文名听起来属于该IP世界（不能在三角洲里出现"打工人"）
- [ ] 一句话描述用了该IP的典型场景/术语
- [ ] 三标签引用了该IP的梗/装备/角色
- [ ] 金句如果改编自IP台词，原句要有辨识度
- [ ] 整体读起来像这个IP世界里的人在自嘲

## 10. 文案语气调性矩阵

| 维度 | 目标值 | 说明 |
|------|--------|------|
| 口语化 | 8-9/10 | 像朋友聊天不像写报告 |
| 戏谑/玩梗 | 7-8/10 | 每句话都有一个小梗或节奏感 |
| 自嘲感 | 8/10 | 是"我知道自己是这样"而非"你被诊断为" |
| 精悍度 | 8/10 | 字不多但字字有画面 |
| 冒犯度 | 3-4/10 | 玩笑可以大但绝不让人真的不舒服 |
| 共鸣感 | 9/10 | 看完第一反应："说的不就是我吗" |
| 截图冲动 | 8/10 | 想发给朋友 @他说"这是你" |

## 11. 新 IP 宇宙启动清单

当需要创建一个新的 IP 宇宙皮肤时，按以下步骤执行：

### Step 1：定义 IP 世界观
- [ ] IP 名称（如"三角洲"、"王者荣耀"）
- [ ] IP 核心场景（战场、峡谷、学校、修仙界…）
- [ ] IP 专属术语库（武器名、技能名、角色名…）
- [ ] IP 经典台词/梗库

### Step 2：14 型人格换皮
对照上方 §8 的对照表，为每个 slug 设计：
- [ ] 新中文名（符合 §2 命名规则）
- [ ] Code 展开（符合 §3 Backronym 规则，可沿用经典版也可重新设计）
- [ ] 一句话描述（符合 §4 反差句式）
- [ ] 三标签（符合 §5 黄金三角，使用 IP 专属术语）
- [ ] 金句（符合 §6，优先改编该IP的经典台词）

### Step 3：质量检查
- [ ] 14 个中文名放在一起读，风格统一吗？
- [ ] 有没有撞车名（和其他宇宙太像）？
- [ ] 金句辨识度够不够（不看人格名也知道对应谁）？
- [ ] 截图传播测试：给 3 个朋友看，能秒懂吗？

### Step 4：物料生成
- [ ] 在 `src/lib/{universe}/personalities.ts` 中录入数据
- [ ] 生成 prompt 脚本到 `scripts/{universe}-prompts.mjs`
- [ ] 生成图片到 `public/images/types/{universe}/`
- [ ] 更新 sitemap 和 types 画廊
