# WTFTI 首页重设计 Spec v2

## 设计目标

把首页从「多宇宙人格测试平台的产品目录」改造成「18–32 岁女性每天会打开的灵魂生活入口」。

新首页必须在 6 秒内回答：
1. 这是给谁的？→ 给「她」
2. 能做什么？→ 人格宇宙 / 灵魂陪伴 / 灵魂碰撞
3. 为什么明天回来？→ 今日运势 / 她财富一句 / 极光时刻

---

## Section 0 · Hero

### 文案

- **Eyebrow**: `A Field Guide to Her · 写给 18–32 岁女生的灵魂生活指南`
- **H1**: 
  ```
  人格宇宙
  灵魂陪伴
  灵魂碰撞
  ```
  或一行：`人格宇宙 · 灵魂陪伴 · 灵魂碰撞`
- **Sub**: `测一次，看见自己；每天打开，有一点 sign；和无数「她」一起，把生活过成想要的样子。`
- **CTA Row**:
  - Primary: `90 秒看见自己` → `/start/`
  - Secondary: `今日运势` → `/mysti/daily/`
  - Tertiary: `走进极光` → `/her-voice/`

### 视觉

- 左侧文字，右侧人格卡拼贴（保留现有 hero card）
- 背景：暮紫底 +  subtle 星屑/轨道纹理
- 色调：玫瑰陶土 `#C07A8E` / 金箔 `#C9A676` / 鼠尾草绿

## Section 1 · 她的每日善门

### 概念

参考菩提苑「九大善门」，但做女性友好、现代感、不迷信的版本。每个「善门」都是一个轻入口，点击后进入对应功能或落地页。

### 9 个善门

| 图标 | 名称 | 路由 | 说明 |
|---|---|---|---|
| 🔮 | 测人格 | `/start/` | 90 秒召唤你的主神 |
| 🌙 | 今日运势 | `/mysti/daily/` | 每天一句 sign |
| 💞 | 关系深测 | `/cpti/` | 24 题双人关系雷达 |
| 👶 | 宝宝起名 | `/mysti/naming/` (新) | 八字喜忌 + 音韵 + 典故 |
| 🌙 | 周公解梦 | `/mysti/dream/` (新) | 输入梦境，女性视角解读 |
| 🎋 | 每日一签 | `/mysti/gacha/` | 今日灵签 |
| 💰 | 她财富 | `/her-wealth/` (新) | AI 市场情绪 + 投资意识 |
| 📖 | 她读书 | `/her-books/` (新) | 每周一本女性成长书 |
| ✨ | 走进极光 | `/her-voice/` | 本周问题 + 接光 |

### 视觉

- 3×3 网格（移动端 2 列）
- 每个卡片：图标 + 名称 + 一句说明
- hover：卡片轻微上浮 + accent 色边框
- 背景：比 Hero 稍浅的色块或卡片式布局

## Section 2 · 三支柱

### 文案刷新

| 支柱 | 标题 | 副标题 | CTA |
|---|---|---|---|
| Ⅰ 人格宇宙 | 把「我是谁」翻译成 17 种语言 | 同一个你，在人格神域、灵魂镜像、关系深测、恋爱 XP 里有不同翻译 | 90 秒看见自己 → |
| Ⅱ 灵魂陪伴 | 每天有一点 sign，有一点成长 | Mysti 玄学 + 她财富 + 她读书，陪她过不确定的日常 | 今日运势 → |
| Ⅲ 灵魂碰撞 | 找到同频的她，一起写下这个时代 | HER AURORA 接光、回声链、她词条 | 走进极光 → |

### 视觉

- 三列卡片（移动端单列）
- 每个卡片顶部有罗马数字 + accent 色
- 保留现有 hairline 分隔线风格

## Section 3 · 今日陪伴

### 结构

三栏卡片：

1. **Mysti 今日抽牌**
   - 显示今日牌名 + 一句解读
   - CTA: `抽一张牌`
   
2. **她财富每日一句**
   - 今日市场情绪温度 + 一句投资意识提醒
   - CTA: `看她财富`
   
3. **极光时刻**
   - 本周 HER AURORA 问题
   - 3 条最新接光摘录
   - CTA: `我也接光`

### 视觉

- 三栏等高卡片
- 每张卡片有 subtle 顶部色条（sage / gold / rose）

## Section 4 · 社区之声

### 结构

- 左侧：本周极光时刻问题 + 编辑部主持卡
- 右侧：3 条接光摘录，带 Sigil 印记 + 昵称

### 文案示例

- 问题：「你最近一次为自己花钱，是什么时候？」
- 接光 1：「给自己买了张演唱会门票，突然觉得我值得。」
- 接光 2：「报了一个很贵的课，不是为了转行，是为了确认我还能学。」
- 接光 3：「买了一束花放在工位，没人知道为什么。」

## Section 5 · Social Proof + 边界

### Social Proof

- 数字带：`17 个宇宙 · 100+ 种人格 · X 万+ 女生的选择`
- 一句真实用户感：「三个月后回头看这张档案，发现我已经不是当时那个人了。」

### 适合 / 不适合

保留现有设计，文案刷新为 v3.1。

## 设计系统约束

- 字体：`var(--font-display)` = Cormorant Garamond + Noto Serif SC
- 颜色：暮紫底 `#1a1530` / 玫瑰 `#C07A8E` / 金箔 `#C9A676` / 米白 `#F5F0E8`
- 圆角：卡片 `rounded-[1.2rem]`，按钮现有 `btn` 类
- 动效：hover 轻微上浮 + 色块过渡，不炫技
- 移动端：单列堆叠，善门 2 列，CTA 全宽

---

## 技术实现要点

1. 改造 `src/app/HomeContent.tsx`
2. 新增 `DailyGatesSection`、`TodayCompanionSection`、`CommunityVoicesSection` 组件（可内联或拆文件）
3. 更新 `src/app/page.tsx` metadata
4. 新功能路由先用 `/mysti/naming/`、`/mysti/dream/`、`/her-wealth/`、`/her-books/` 占位，后续实现
5. 保留现有 `TodaySection` 能力，重命名为或融入「今日陪伴」
