## 第一部分：SBTI 爆火的底层拆解

### 1.1 表层因素（大多数人看到的）

- 低多边形搞怪人格图
- 有趣的题目和结果文案
- 朋友圈刷屏效应

### 1.2 深层因素（真正的引擎）

结合 Jaden 文章和传播学框架，SBTI 爆火的底层是 **四力叠加**：

| 力 | 机制 | SBTI 怎么做到的 |
|---|------|----------------|
| **标签力** | 给模糊的自我一个可抓住的锚点 | 36 种人格 = 36 种"这就是我"的身份标签 |
| **许可力** | 允许用户承认不完美 | "sb" 谐音梗 + "imsb" 自嘲 = 分享零羞耻 |
| **货币力** | 截图即完成一次低成本社交表演 | 图鉴图本身就是社交货币，不需要附加说明 |
| **裹挟力** | FOMO 把内容事件变成社交事件 | "所有人都测了你还没测" = 社交压力驱动 |

### 1.3 隐藏的第五力：语言病毒

这一点你的直觉非常准——**"sb" 在中文语境中是自带传播加速器的**。

- "sbti" 本身就是一个禁忌词的变体，天然引发好奇和点击
- "imsb"（I am sb）是一种精准的自嘲标签——用户贴上这个标签的那一刻，完成了一次"我敢承认自己是傻逼"的情绪释放
- 禁忌词 + 自嘲 = 传播学中最强的 social currency 组合

这意味着：**任何后来者如果不能找到同等级别的语言病毒，仅靠内容质量很难达到同体量的初始引爆**。

## 第二部分：你的核心问题诊断

### 2.1 当前状态

你已经有了：
- 完整的 36 人格体系 + 15 维度评分系统
- 多条产品线（人格/职场/恋爱/CP/酒局/日常/修仙）
- 高质量的荒诞文学风格文案
- 修仙 2.0 的视觉方向探索

### 2.2 但你面临的核心矛盾

**原作者赢在"第一次"，你不可能再赢一次"第一次"。**

心理学叫 primacy effect（首因效应）：用户第一次接触 SBTI 的那个"哇"时刻已经被原作者拿走了。你做同品类的东西，哪怕比他好 30%，用户也会说"哦，这不是那个 xx 的仿版吗"。

所以 —— **不能做"更好的 SBTI"，要做"SBTI 没做到的事"。**

### 2.3 原作者做不到的事（你的突破口）

| 原作者的局限 | 你的机会 |
|-------------|---------|
| 一次测试，一张图，用完即走 | **多风格图鉴系统** → 用户有理由回来 |
| 36 种人格只有一套视觉 | **同一人格 × N 种风格** → 收集欲 + 分享欲 |
| 结果页是终点 | **结果页是起点** → 图鉴是个持续生长的世界 |
| 单人体验 | **社交互动体验** → CP/闺蜜/团队组合效应 |
| 风格固化在低多边形 | **风格本身成为内容** → 每次换皮都是一次新的传播事件 |

## 第三部分："宇宙 TI" 产品定义

### 3.1 一句话定义

> **宇宙 TI = 一个人格测试 × 无限风格图鉴 × 社交收集游戏**

用户测一次，获得一个人格身份。但这个身份在不同"宇宙"中有不同的形象——仙侠的你、赛博朋克的你、萌物的你、泼墨水彩的你、地狱笑话的你。

**核心比喻：你不是在做人格测试，你是在解锁平行宇宙里的自己。**

### 3.2 产品结构

```
宇宙 TI
├── 人格核心（不变）
│   ├── 36 种人格定义
│   ├── 15 维度评分系统
│   └── 题库（可按主题出不同版本的题）
│
├── 图鉴宇宙（持续扩展，核心留存机制）
│   ├── 🎭 经典宇宙 — 自嘲搞怪风（当前默认风格，必须比原作者更狠更好笑）
│   ├── ⚔️ 仙门宇宙 — 古风仙侠怪可爱（修仙 2.0）
│   ├── 🌸 萌物宇宙 — 软萌动物拟人 / 棉花娃娃感
│   ├── 💀 发疯宇宙 — 地狱笑话 × 丧系 × 纯黑幽默
│   ├── 🌃 赛博宇宙 — 霓虹 × 故障风 × 数据人格
│   ├── 🎨 美术馆宇宙 — 纯抽象艺术 / 波普 / 极简线条
│   ├── 🎮 游戏宇宙 — 像素风 / RPG 职业卡 / 属性面板
│   ├── 🌈 Y2K 宇宙 — 千禧辣妹 × 亮片 × 少女心
│   ├── 🔮 塔罗宇宙 — 神秘学 × 星座 × 占卜美学
│   └── 📸 真人宇宙 — AI 生成"如果你是这种人的写真"
│
└── 社交系统（传播引擎）
    ├── CP 图鉴 — 两个人格的组合图
    ├── 闺蜜团图鉴 — 三五人组合图
    ├── 今日人设 — 每日随机解锁一张不同宇宙的图
    └── 图鉴墙 — 用户的收集展示页
```

### 3.3 为什么"图鉴宇宙"是杀手级特性

**对比原作者的一次性体验：**

| 维度 | 原作者 SBTI | 宇宙 TI |
|------|------------|---------|
| 测试完成后 | 分享截图，关闭页面 | 解锁第一张图鉴，开始收集 |
| 第二天 | 没有理由回来 | "今天解锁了仙门宇宙的我" |
| 第三天 | 完全遗忘 | "赛博朋克版的我也太帅了吧" |
| 一周后 | 流量归零 | 新宇宙上线 = 新一轮传播 |
| 分享动机 | 一次性截图 | 每个宇宙都是新的分享素材 |

**关键洞察：每上线一个新宇宙 = 一次免费的营销事件。**

因为用户会主动分享新风格的图鉴，而不需要你去投流。

### 4.2 描述文案升级方向

当前文案已经是荒诞文学风格，水准很高。升级方向不是改文案质量，而是 **增加"嘴替密度"**：

- 每段描述里至少有 3 句可以直接截出来当朋友圈文案的金句
- 增加"别人眼中的你 vs 你自己眼中的你"的对比结构（女性用户特别吃这个）
- 增加"你的隐藏人格症状"清单（列表体裁，更容易截图传播）

示例结构：

```
标题：内耗永动机
副标：脑子里开了八个会议室，每个都在加班

第一段：精准戳穿（一句话说中你）
"你的大脑不是在思考，是在开年度复盘会——
而且会议内容是'为什么上周三说了那句话'。"

第二段：翻译情绪机制（让你觉得被理解）
别人的脑子是工具，你的脑子是房东——
它不仅不听你的，还三天两头涨租。

第三段：隐藏症状清单（截图素材）
✓ 睡前在脑内预演明天所有可能翻车的对话
✓ 发完消息立刻后悔用词
✓ 替还没发生的事先难过了一轮
✓ 别人说"没事"你能分析出 12 种"有事"

第四段：轻收口（不给建议，给共鸣）
所以你不是玻璃心，你只是把心装了 4K 高清摄像头。
看得太清楚，累就累在这里。
```

### 4.3 题库升级：从"测维度"到"测情绪"

当前题库设计规范已经很好（情景题/玩梗题/荒诞题等），但要再往 **女性高频微场景** 方向推：

**高传播潜力的题目方向：**

1. **已读不回系列** — "对方消息秒回变小时回，你会？"
2. **闺蜜站队系列** — "闺蜜和她对象吵架来找你，你？"
3. **职场面具系列** — "领导发了个':)'，你解读为？"
4. **深夜emo系列** — "凌晨两点刷到前任动态，你会？"
5. **社恐求生系列** — "电梯里遇到不太熟的同事，你会？"
6. **恋爱脑测试系列** — "暗恋对象给你点了个赞，你的反应是？"

题目本身要好笑到让人想截图 —— **题目就是传播素材，不仅仅是测量工具**。

## 第五部分：针对女性用户的深度策略

### 5.1 为什么女性用户是关键

数据层面：
- 人格测试、星座、塔罗、MBTI 的核心用户 70%+ 是女性
- 小红书（人格测试传播主阵地）用户 80%+ 是女性
- 朋友圈转发人格测试的行为，女性 > 男性

心理层面：
- 女性用户更需要"被理解"的确认感
- 女性用户更乐意用标签进行社交互动（给自己和朋友贴标签）
- 女性用户对视觉质量的要求更高 —— 图片必须"值得保存"

### 5.2 针对女性偏好的产品调整

#### 视觉风格

| 优先级 | 宇宙风格 | 女性吸引力分析 |
|--------|---------|--------------|
| ★★★★★ | 仙门怪可爱 | 古风 + 自嘲 = 小红书爆款公式 |
| ★★★★★ | 萌物/棉花娃娃 | 女性向收集欲最强的风格 |
| ★★★★☆ | 塔罗/神秘学 | 天然吸引女性用户 + 占卜属性加持 |
| ★★★★☆ | Y2K/千禧辣妹 | 审美共鸣 + 拍照发圈动机 |
| ★★★☆☆ | 赛博朋克 | 酷 + 中性帅，部分风格女性也爱 |
| ★★★☆☆ | 抽象艺术/波普 | 高级感 + 独特 = 区分度 |
| ★★☆☆☆ | 像素游戏风 | 偏男性向，但可以做少女向像素 |

#### 社交功能

- **CP 图鉴**：两人组合图（情侣/闺蜜），女性用户最爱的社交互动方式
- **闺蜜团图鉴**：3-5 人组合，小红书 / 朋友圈天然传播素材
- **"你是哪种女主"系列**：把人格映射到各种电视剧/小说的角色
- **"恋爱中的你"系列**：同一人格在恋爱场景中的不同表现

#### 内容切入点

- 从"你是什么人格"升级为"你在关系里是什么角色"
- 从"你的性格特点"升级为"你的情绪模式"
- 从"人格标签"升级为"人设标签"（更网感、更女性向）

### 5.3 与星座/塔罗的结合点

这是一个巨大的未开发空间：

- **"你的人格 × 你的星座"**：36 种人格 × 12 星座 = 432 种组合标签
- **"每周人格运势"**：结合塔罗元素，给用户一个每周回来的理由
- **"水逆期间你的人格会变成什么"**：制造传播话题

这些不需要有任何科学依据 —— SBTI 本身就没有。但它创造了 **"不得不点进来看看"的 FOMO**。

## 第六部分：超越原作者的核心战略

### 6.1 不要打"更好"这张牌，打"更多"

原作者做了一个产品，你要做一个 **平台**。

```
原作者的产品生命周期：
测试 → 看结果 → 分享 → 结束

你的产品生命周期：
测试 → 看结果 → 分享 → 解锁新宇宙 → 收集图鉴 → 新宇宙上线 → 再分享 → 闺蜜来测 → CP配对 → 再分享...
```

### 6.2 语言病毒深度分析：寻找你自己的 "sb"

SBTI 的 "sb" 谐音梗是天然病毒。你需要一个同等级别的钩子。

#### 6.2.1 先拆清楚 "sb" 到底赢在哪

"sb" 之所以是顶级语言病毒，不只是因为是脏话，而是满足了 **五层传播加速器**：

| 层 | 机制 | 为什么有效 |
|----|------|-----------|
| **第一层：禁忌好奇** | "等等，这名字是不是那个意思？" | 大脑天然会被禁忌词吸引注意力，这是进化遗留——和"危险信号"走同一条神经通路 |
| **第二层：解码快感** | "哈哈果然是那个意思" | 解码成功会产生一种"我懂了"的聪明感，这个小快感本身就值得分享 |
| **第三层：自嘲许可** | "我是 imsb 哈哈哈" | 脏话+自嘲 = 双重情绪释放，就像拆了两层包装的惊喜 |
| **第四层：社交安全** | "反正这是个测试名，又不是我主动骂自己" | 人格测试充当"免责声明"——不是我说的，是测试说的 |
| **第五层：口耳相传** | "你测过 sb 那个吗？" | 两个字母，口语传播零摩擦，打字搜索也零摩擦 |

**结论：一个好的语言病毒需要同时满足"禁忌好奇 + 解码快感 + 情绪释放 + 社交安全 + 口耳便捷"这五层中的至少三层。**

#### 6.2.2 候选名逐个深度打分

用上面的五层模型打分，每层 0-2 分，满分 10 分：

---

##### ① WTFTI (wtfti.com ✅ 可用)

| 层 | 得分 | 分析 |
|----|------|------|
| 禁忌好奇 | ★★ | WTF 全球公认的脏话缩写，问号感很强 |
| 解码快感 | ★☆ | 在中国年轻人中解码率约 70%，不如 sb 的 99% |
| 情绪释放 | ★★ | "What The Fuck" 本身就是一种高频情绪出口——震惊、无语、好笑都能用 |
| 社交安全 | ★★ | 英文缩写比直接的中文脏话更安全，朋友圈发"我测了 WTFTI"不会被屏蔽 |
| 口耳便捷 | ★☆ | 5 个字母比 sbti 的 4 个多一个，但"WTF 那个"口语也能传播 |

**总分：8.5 / 10**

**额外优势：**
- 域名可用（这一条就很关键）
- WTF 的情绪色彩极其丰富——可以是震惊、好笑、无语、发疯，和人格测试"看到结果的那一刻"完美匹配
- 天然的结果页 slogan："WTF，我居然是这种人？"
- 国际化潜力：WTF 是全球通用的互联网语言，如果未来做英文版，品牌无需切换
- 可衍生梗：`wtf-type`（你的 wtf 类型）、人格名可以叫 `WTF-001` 到 `WTF-036`
- 小红书/微博话题天然带感：`#WTFTI` `#WTF我居然是这种人`

**潜在风险：**
- 微信传播可能被风控（WTF 在部分平台算敏感词），需要测试
- 对 35+ 岁用户可能需要解释
- 比 sb 少了一层"中文本土梗"的亲切感

**总评：A 级候选。最接近 sb 的禁忌传播力，又有自己独立的品牌身份。**

| 口耳便捷 | ★★ | "666 那个测试" 非常好说、非常好记 |

**额外优势：**
- 极度好记，甚至可以口头传播 "六六六 TI"
- 纯数字在域名里很醒目
- 对中国用户 100% 无门槛

**致命问题：**
- 缺乏"禁忌+自嘲"的双核引擎，传播只有便捷性没有情绪劲
- "666" 更像夸赞，和人格测试"被说中→自嘲→分享"的链路不匹配
- 用户做完测试说"我是 666TI 的 XX 人格"——没有梗感
- 缺乏讨论度，不会有人因为名字本身而好奇

**总评：C+ 级。好记但没劲，可以做备用域名/短链，不适合做主品牌。**

### 6.3 留存飞轮：从"一次性病毒"到"持续性上瘾"

你说得非常对 —— **一次性测试的问题是用户再好也是一次性的**。

解决方案是建立一个 **收集 + 社交 + 内容更新** 的飞轮：

```
              ┌──── 新宇宙上线 ────┐
              │                    │
              ▼                    │
用户回来解锁新图鉴 ──→ 分享新图鉴 ──→ 新用户看到来测 ──→ 测完获得第一张图鉴
              │                    │                          │
              ▼                    │                          ▼
         收集更多宇宙的图鉴    传播新一轮    发现还有 N 个宇宙没解锁
              │                    │                          │
              └──── 留存闭环 ──────┘          ┌── 回来继续收集 ◄──┘
                                              │
                                              ▼
                                        图鉴墙越来越满
                                        （沉没成本 + 展示欲）
```

具体留存机制：

1. **每周解锁**：每周上线一个新宇宙风格，朋友圈 / 小红书自然传播
2. **限时图鉴**：某些图鉴只在特定时间可获得（制造紧迫感）
3. **隐藏款**：每个宇宙有 1-2 个"隐藏人格"需要特殊条件解锁
4. **图鉴墙**：用户个人页面展示已收集的所有图鉴（满足展示欲）
5. **好友图鉴对比**：看你和闺蜜在不同宇宙里的形象差异

### 6.4 传播公式

**每次传播的素材 = 人格标签 + 自嘲文案 + 一张值得保存的图**

这三件事必须在一张截图里完成，不能要求用户做任何额外动作。

具体来说，分享图要满足：

- **3 秒内看懂**：人格名 + 一句话标签 + 角色图
- **看完想笑**：自嘲感拉满
- **看完想发**：图片好看到值得保存
- **看完想 @**：让用户想到某个朋友

## 第九部分：核心结论

### 你的竞争优势不在某一个风格上，在于"风格本身是内容"这个模式

原作者做的是"一件好看的衣服"，你要做的是"一个衣柜"。

一件衣服再好看，穿过一次就不新鲜了。
一个衣柜，每次打开都有新东西，才让人舍不得离开。

### 三个必须做对的事

1. **经典宇宙必须比原作者更好笑、更自嘲、更值得截图** — 这是打底，不能弱
2. **第二个宇宙必须足够惊艳到让人觉得"这和 SBTI 不是一个东西"** — 仙门是好方向
3. **图鉴收集机制必须让用户有理由回来** — 不是"你应该回来"而是"你忍不住回来"

### 一句话战略总结

> **不做更好的 SBTI，做 SBTI 做不到的事 —— 把一次性的人格测试，变成一个持续生长的人格图鉴宇宙。**
