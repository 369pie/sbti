## 〇、战略背景：为什么必须 UGC

### 现状瓶颈

| 指标 | 当前值 | 问题 |
|------|--------|------|
| 宇宙数量 | 15 个已上线 | 团队产能天花板：每个宇宙需 2-4 周（文案 + 设计 + 开发） |
| 人格卡总量 | 270+ 张 | 虽多但全部自产，创意疲劳 + 审美同质化风险 |
| 内容更新频率 | ~2 个宇宙/月 | 无法支撑"每周新鲜感"的留存要求 |
| 覆盖场景 | 以女性兴趣为主 | 缺乏垂类深度（二次元/电竞/宠物/职业细分） |
| 传播渠道 | 自己发小红书笔记 | 无法借助 KOL 的粉丝杠杆 |

### 核心矛盾

> **内容供给的线性增长** vs. **用户注意力的指数竞争**
>
> 你一个月做 2 个宇宙，竞品（趣测/测测/AI 生成测试）一天能上线 20 个。
> 不是"做得更快"能解决的问题——需要把"造宇宙"这件事开放给所有人。

### UGC 时机判断

| 维度 | 评估 | 状态 |
|------|------|------|
| 底层引擎成熟度 | 29 型人格系统 + 评分引擎 + Canvas 分享图生成器均已稳定 | ✅ 就绪 |
| 内容模板可复制性 | 每个宇宙本质是：人格映射表 + 命名 + 文案 + 视觉风格 | ✅ 可模板化 |
| 市场需求信号 | 小红书已有 KOL 自发做"XX 版 MBTI"内容，搜索量巨大 | ✅ 强信号 |
| 创作者变现诉求 | 小红书 300M MAU、70% 女性、95% UGC，创作者急需变现工具 | ✅ 强需求 |
| 技术可行性 | 需要创作者后台 + 审核流 + 分成系统 | 🟡 需 3-6 个月建设 |

## 一、Phase 1: 定位与市场语境

### 1.1 Geoffrey Moore 定位声明（UGC 平台版）

#### 现定位（v1.0 — 自建内容平台）

```
给那些 想在社交场景中展示"有趣的自我认知"的 22-30 岁城市女性，
WTFTI 是一个 多宇宙人格图鉴收藏平台，
它能 每周用全新叙事语言重新定义"你是谁"。
不同于 16Personalities 和 准了/测测，
WTFTI 提供 无限风格的人格衣橱 + 病毒式自嘲叙事。
```

#### 新定位（v2.0 — 创作者驱动平台）

```
For   想通过"人格内容"获取粉丝、变现收入的小红书 KOL/创作者
      和  想要无限新鲜人格图鉴体验的 18-30 岁用户

WTFTI 是一个  人格图鉴创作与消费平台

它能  让任何人在 30 分钟内创建一个完整的主题人格宇宙
     （题目 × 人格映射 × 文案 × 分享图），
     并通过小红书分发触达用户、获得收益分成。

不同于  趣测（纯工具、无创作者生态、无品牌 IP）
       测测（重玄学、创作门槛高、变现路径模糊）
       uQuiz（纯 UGC 但零变现、零品控、无中文优化）

WTFTI 提供  「半开放创作框架」——
           创作者不需要从零搭系统，只需在 29 型人格底盘上
           填充自己的主题创意（映射 + 命名 + 文案 + 配图），
           平台保证引擎质量 + 分享图精美度 + 分发渠道，
           创作者保证内容创意 + 粉丝流量 + 垂类专业度。
```

### 1.2 Proto-Personas（双边市场）

#### 供给侧 Persona S1: "小红书人格测试博主" — 占创作者 60%

| 维度 | 描述 |
|------|------|
| **画像** | 25 岁，杭州，小红书 2 万粉，主营生活方式 + 测试类内容 |
| **当前痛点** | 每次做测试类内容都要手动 P 图、做 H5、找小程序，成本高、效果参差 |
| **理想状态** | "给我一个模板，我填上我的创意，自动生成好看的测试 + 分享图，用户测完我有数据也有收入" |
| **核心 JTBD** | 用最低成本产出最高质量的互动测试内容，获得粉丝增长 + 变现收入 |
| **变现现状** | 品牌合作 ¥500-2000/条笔记，但测试类内容难接广告 |
| **付费意愿** | 平台免费创建 + 收入分成模式（不愿预付） |
| **成功标准** | 创建的宇宙被 1000+ 人测试 → 获得 ¥100+ 收入 → 用收入截图发小红书 → 吸引更多创作者入驻 |

#### 供给侧 Persona S2: "垂类 IP 博主" — 占创作者 30%

| 维度 | 描述 |
|------|------|
| **画像** | 22 岁，大学生，B 站/小红书双平台，主营二次元/游戏/追星内容，5 千粉 |
| **当前痛点** | 有很多 "XX 版人格测试" 的创意，但没有技术能力实现 |
| **理想状态** | "我只需要写 29 个角色的名字和描述，平台帮我搞定剩下的一切" |
| **核心 JTBD** | 把粉丝圈层的内容需求变成可互动的产品，强化自己在圈层内的 IP 地位 |
| **变现现状** | 几乎为零（学生身份，粉丝量不够接品牌） |
| **付费意愿** | 完全不愿付费，但愿意投入时间创作 |
| **成功标准** | 在自己的圈子里"我做了一个 XX 人格测试" 成为话题，收获粉丝增长 |

#### 供给侧 Persona S3: "专业内容机构/MCN" — 占创作者 10%

| 维度 | 描述 |
|------|------|
| **画像** | MCN 旗下矩阵号运营团队，批量产出互动内容 |
| **当前痛点** | H5 测试外包一个 ¥3000-8000，周期 2 周，ROI 不可控 |
| **理想状态** | "一天做 3 个不同主题的测试，每个成本 < ¥100" |
| **核心 JTBD** | 降低互动内容生产成本，提高投放 ROI |
| **变现现状** | 品牌投放费用覆盖，利润来自效率差 |
| **付费意愿** | 愿意为 Pro 功能付费（品牌定制、白标、数据看板） |
| **成功标准** | 单个测试 CPC < ¥0.5，粉丝增量 > 500/测试 |

#### 需求侧（用户）— 继承 v1.0 的三类 Persona

| Persona | 核心变化 |
|---------|---------|
| A "社交货币猎人" (45%) | 从"官方出什么测什么"变成"刷到 KOL 推荐的宇宙就测" |
| B "深度自我探索者" (35%) | 从"等官方更新"变成"自己收藏的博主不断出新宇宙" |
| C "关系解码者" (20%) | 变化最小，仍以 CPTI 配对为核心 |

### 1.3 JTBD 分析（双边）

#### 创作者侧 Jobs-to-be-Done

**功能性任务（Functional Jobs）**

| Job | 当前满足度 | WTFTI UGC 解法 |
|-----|-----------|---------------|
| 制作一个好看的互动测试 | 🔴 10%（需技术/设计能力） | 半开放模板：填充创意 → 自动渲染 |
| 通过测试内容涨粉 | 🟡 30%（自己做 H5 传播不稳定） | 平台内置分享图 + 小红书 SEO 标签 |
| 通过测试内容变现 | 🔴 5%（几乎无变现路径） | 收入分成 + Premium 解锁 |
| 了解测试数据（多少人测、完成率、分享率） | 🔴 0%（自己做的无数据） | 创作者数据面板 |
| 保护自己的创意不被抄袭 | 🔴 5% | 平台审核 + 创作者署名 + 原创标识 |

**社交性任务（Social Jobs）**

| Job | 重要度 |
|-----|--------|
| "我不只是博主，我是测试创作者" | ⭐⭐⭐⭐⭐ 身份升级 |
| "粉丝因为我的测试内容关注我" | ⭐⭐⭐⭐⭐ 内容锚点 |
| "看到自己创建的宇宙被几万人测了" | ⭐⭐⭐⭐ 成就感 |

**情感性任务（Emotional Jobs）**

| Job | 重要度 |
|-----|--------|
| "我的创意被认可了" | ⭐⭐⭐⭐⭐ 核心情感驱动 |
| "我可以把我懂的圈子做成产品" | ⭐⭐⭐⭐ 专业感 |
| "不用求技术也能做出好东西" | ⭐⭐⭐⭐ 赋能感 |

**Pains（创作者痛点）**

1. **"做一个测试太难了"**：需要出题、做设计、搞 H5、买域名、配小程序——99% 的 KOL 在第一步就放弃
2. **"做出来也没人看"**：自建 H5 没有 SEO、没有推荐流量、传播全靠自己发笔记
3. **"做了也没钱赚"**：免费 H5 测试无法商业化，品牌合作又不认测试类内容
4. **"我的创意会被人抄"**：小红书无法保护创意 IP，做出来立刻被模仿

**Gains（创作者收益期望）**

1. **30 分钟建一个宇宙**：只做创意部分（映射表 + 命名 + 一句话描述），技术/设计/引擎交给平台
2. **1 条笔记 = 持续被动收入**：用户测一次 = 创作者分一次，测试越火收入越高
3. **数据洞察**：看到"我的宇宙今天被 500 人测了，完成率 87%，最高分享的人格是 XX"
4. **创作者身份认证**：平台认证标识 + 创作者排行榜 + 粉丝互动

## 二、Phase 2: 问题框架与验证（MITRE Canvas）

### 2.1 向内看（Look Inward）

**核心假设清单**

| # | 假设 | 风险等级 | 验证方法 |
|---|------|----------|---------|
| H1 | 小红书 KOL 愿意在我们平台上创建宇宙 | 🔴 高 | 邀请 10 个 KOL 内测 |
| H2 | 创作者的内容质量能达到平台标准 | 🔴 高 | 模板约束 + 审核流 |
| H3 | 用户愿意为 UGC 宇宙付费/UGC 宇宙分享率不低于自建 | 🟡 中 | A/B 对比官方 vs. UGC 分享率 |
| H4 | 收入分成能吸引创作者持续产出 | 🟡 中 | 对比 Notion/Canva 分成模型 |
| H5 | 平台能有效控制内容质量、防止低质灌水 | 🟡 中 | 审核 + 评分系统 |
| H6 | UGC 不会稀释 WTFTI 品牌调性 | 🔴 高 | 品牌指南 + 模板约束 + 分层展示 |

**为什么这个问题至今没被解决？**

1. **技术壁垒**：做一个"能让非技术人员创建人格测试"的编辑器本身就很难——需要在"灵活性"和"品控"之间找到平衡
2. **双边冷启动**：创作者生态需要同时有创作者和用户，鸡生蛋问题
3. **质量控制**：uQuiz 模式（完全开放）导致大量低质内容，品牌无法建立；趣测模式（完全封闭）导致内容供给受限
4. **变现模型模糊**：Buzzfeed 靠广告、Typeform 靠 SaaS、uQuiz 不赚钱——人格测试 UGC 的最优变现模型未被证明

**我们的偏见**

1. **平台自恋偏见**：认为"用户一定更喜欢我们自己做的宇宙"——需要用数据验证
2. **技术至上偏见**：认为"编辑器功能越多越好"——实际上越简单越好
3. **完美主义偏见**：想做一个"完美的创作者后台"——应该先做 MVP 验证需求

### 2.2 向外看（Look Outward）

**UGC 测试市场竞争格局**

**谁被忽略了？**

- **小红书中腰部博主（1000-5 万粉）**：没有品牌合作机会，但有创意有粉丝——他们是 UGC 的核心供给
- **二次元/游戏/追星垂类创作者**：有圈层影响力但缺乏技术变现工具
- **海外中文创作者**：留学生/海外华人群体，有文化共鸣但缺乏平台

## 三、Phase 3: 解决方案探索（Teresa Torres 机会解决方案树）

### 3.1 目标成果（Desired Outcome）

**北极星指标**：月活跃创作者数 × 平均宇宙完成测试人数

- **Phase 0 (验证期)**：10 个创作者 × 500 人/宇宙 = 5,000 月测试量
- **Phase 1 (冷启动)**：100 个创作者 × 1,000 人/宇宙 = 100,000 月测试量
- **Phase 2 (规模期)**：1,000 个创作者 × 2,000 人/宇宙 = 2,000,000 月测试量

### 3.2 机会树

```
北极星：月活跃创作者数 × 平均宇宙完成测试人数
│
├── 机会 1: 创建宇宙的门槛太高（创作者侧最大痛点）
│   ├── 方案 A1: 「半开放模板」— 29 型底盘 + 创作者只填映射/命名/文案
│   ├── 方案 A2: 「AI 辅助创作」— 输入主题关键词 → AI 自动生成映射表 + 文案草稿
│   └── 方案 A3: 「克隆 + 改编」— 以官方宇宙为基础 fork，只改名字和描述
│
├── 机会 2: UGC 内容质量参差不齐（品牌风险）
│   ├── 方案 B1: 「三级质量门控」— 自动校验 + 社区评审 + 编辑精选
│   ├── 方案 B2: 「模板约束」— 限定文案长度 / 格式 / 分享图模板，保证最低品质
│   └── 方案 B3: 「创作者认证体系」— 认证创作者的宇宙获得更多曝光
│
├── 机会 3: 创作者的宇宙没人测（冷启动问题）
│   ├── 方案 C1: 「首发推荐池」— 新宇宙上线 72h 内获得平台推荐流量
│   ├── 方案 C2: 「创作者 × KOL 联名」— 邀请头部 KOL 创建首批宇宙，形成示范效应
│   └── 方案 C3: 「WTF Card 集成」— UGC 宇宙也纳入 WTF Card 图鉴收集，用收藏机制导流
│
├── 机会 4: 创作者无法从测试中获得收入（变现动力不足）
│   ├── 方案 D1: 「测试分成」— 每次付费解锁深度报告，创作者分 70%
│   ├── 方案 D2: 「打赏 + 赞助」— 用户测完后可打赏创作者
│   └── 方案 D3: 「品牌定制入口」— 品牌找创作者做"联名宇宙"，平台撮合抽佣
```

### 6.2 UGC 宇宙 JSON Schema（技术预设计）

```typescript
interface UGCUniverseConfig {
  // 基本信息
  id: string;                    // 自动生成的唯一 ID
  slug: string;                  // URL-safe 标识（如 "harry-potter"）
  name: string;                  // 宇宙名称（如 "霍格沃茨版"）
  shortName: string;             // 简称（如 "魔法TI"）
  emoji: string;                 // 宇宙 emoji
  description: string;           // 一句话描述
  
  // 创作者信息
  creatorId: string;             // Supabase Auth UID
  creatorName: string;           // 显示名
  creatorAvatar?: string;        // 头像 URL
  
  // 视觉风格
  theme: {
    primaryColor: string;        // 主题色（hex）
    secondaryColor: string;      // 辅助色
    bgGradient: [string, string]; // 背景渐变
    cardStyle: 'default' | 'dark' | 'neon' | 'pastel'; // 预设分享图风格
  };
  
  // 人格映射（核心！29 型 slug → 自定义名称 + 描述）
  personalities: Record<string, {
    name: string;                // 自定义名称（如 "邓布利多"）
    emoji: string;               // 代表 emoji
    tagline: string;             // 一句话标签（如 "永远温柔但永远在下棋"）
    description?: string;        // 可选：更长的描述段落
    imageUrl?: string;           // 可选：自定义配图
  }>;
  
  // 元数据
  status: 'draft' | 'pending' | 'approved' | 'rejected';
  createdAt: string;
  publishedAt?: string;
  testCount: number;             // 被测试次数
  shareCount: number;            // 被分享次数
  rating: number;                // 用户评分 (0-5)
}
```

## 九、核心架构决策

### 9.1 "半开放" vs. "全开放" vs. "全封闭"

| 维度 | 全封闭（现状） | 半开放（推荐） | 全开放（uQuiz 模式） |
|------|:-----------:|:-----------:|:----------------:|
| 内容质量 | ⭐⭐⭐⭐⭐ | ⭐⭐⭐⭐ | ⭐⭐ |
| 内容供给量 | ⭐ | ⭐⭐⭐⭐ | ⭐⭐⭐⭐⭐ |
| 品牌一致性 | ⭐⭐⭐⭐⭐ | ⭐⭐⭐⭐ | ⭐ |
| 创作者门槛 | N/A | ⭐⭐⭐（适中） | ⭐⭐⭐⭐⭐（极低） |
| 变现潜力 | ⭐⭐ | ⭐⭐⭐⭐ | ⭐ |
| 适合阶段 | 0→1 验证 | **1→100 规模化** | 规模化后的长尾 |

**决策：Phase 0-2 采用"半开放"模式**

核心约束：
1. **底盘不变**：29 型人格 + 评分引擎 + 分享图模板 = 平台提供
2. **皮肤可变**：映射名 + emoji + 文案 + 配色 = 创作者提供
3. **题目半变**：创作者可选择"使用官方题库"或"自定义 5-10 道场景题"（混入官方核心题）
4. **审核门控**：所有 UGC 宇宙需通过自动校验 + 人工审核才能发布
