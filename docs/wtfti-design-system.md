# WTFTI 多宇宙设计系统

> 品牌：WTFTI — What's The F* Type Inside
> 定位：多宇宙多维度可扩展 TI 测试平台
> Slogan："WTF，我居然是这种人？"

---

## 一、品牌核心

### 1.1 品牌识别

| 元素 | 规范 |
|------|------|
| 品牌名 | **WTFTI** |
| 品牌锚点色 | `#ff4d6d`（WTF 红粉）— "WTF" 三个字母永远用此色 |
| 全局背景 | `#FAF8F5`（暖米白）— 所有宇宙共享底色 |
| 全局文字 | `#2D2A26`（暖深棕）/ `#6B6560`（次要）/ `#9C9590`（灰） |
| 默认字体 | Geist Sans（西文）+ PingFang SC / Noto Sans SC（中文） |
| 等宽字体 | Geist Mono（人格编码、维度代号） |
| 衬线字体 | 保留为宇宙专属（如SoulTI 用 Georgia + Noto Serif SC） |

### 1.2 品牌语言

- **震惊感先行**：标题以 "WTF" 或惊叹/疑问句开头
- **自嘲落点**：结果描述以"被说中的尴尬感"收尾
- **可截可 @**：每段文案里至少一句能直接发给朋友

## 二、多宇宙主题体系

### 2.1 设计原则

**"同一个家族的不同性格"** — 每个宇宙模块既独立又统一。

统一层（不可改）：
- 页面底色 `#FAF8F5`
- 导航组件（全局 Navigation）
- 卡片圆角 `xl`（12px）
- 渐入动画 `animate-fade-up`
- 布局骨架：Hero → 维度/模型 → 人格卡 → CTA

宇宙自定义层（必须改）：
- **主题色**：每个宇宙的识别色
- **字体风格**：可引入独立字体，但需注明 fallback
- **文案调性**：匹配宇宙定位
- **视觉 trick**：磨砂玻璃、渐变、dark 对比区等

| 宇宙 | 主题色 | 字体策略 | 调性 | 视觉关键词 |

### 2.3 新宇宙上线 Checklist

新增一个宇宙模块时，必须完成：

1. **`universes.ts` 注册** — id / name / emoji / accent / testPath / resultPrefix
2. **Landing Page** — `src/app/{slug}/XxxHomeContent.tsx`
   - Hero 区带 badge + 大标题 + 副标题 + CTA 按钮
   - 维度/轴说明区（4-5 组维度卡）
   - 人格卡预览区（grid 展示）
   - FAQ（可选）
3. **主题色系** — 该宇宙的完整色阶：base / light / bg
4. **字体决策** — 默认 Geist Sans 或引入宇宙专属字体
5. **文案** — 一句 slogan + badge 文案 + CTA 按钮文案 + 维度描述
6. **人格图** — `public/images/types/{slug}/` + thumbnails
7. **导航自动更新** — 无需手动改导航，注册后自动出现

## 三、Landing Page 设计规范

### 3.1 页面结构（所有宇宙通用骨架）

```
┌─────────────────────────────────────┐
│ [Badge] ✦ 宇宙名称                  │
│                                     │
│ 大标题（2-3行，渐变或主题色高亮）      │
│ 副标题（1-2行简介）                  │
│                                     │
│ [CTA 按钮 — 主题色渐变圆角胶囊]      │
│ "预计用时 x 分钟 · x 道题 · x 种结果"│
├─────────────────────────────────────┤
│ 维度轴卡片 × 4~5                    │
│ （每张卡片：轴名 + 两极 + 一句话问题） │
├─────────────────────────────────────┤
│ 人格卡 grid（4~8 张预览）            │
│ 点击跳转到该人格结果页               │
├─────────────────────────────────────┤
│ CTA 区域（重复底部入口）             │
└─────────────────────────────────────┘
```

### 3.2 文案层级

| 层级 | 字号 | 用途 | 示例 |
|------|------|------|------|
| Badge | xs + tracking-wider | 宇宙标签 | "✦ 仙门宇宙" |
| H1 | 3xl~4xl | 核心问句/slogan | "WTF 你在仙门居然是什么仙" |
| Sub | lg~xl | 1-2 行补充 | "同样 27 种人格，但换了个修炼体系" |
| Meta | xs | 补充信息 | "预计 3 分钟 · 32 道题" |
| CTA | base/lg | 按钮文案 | "开始修炼 →" |

### 3.3 CTA 按钮样式

```css
/* 通用 CTA 按钮骨架 */
.cta-button {
  display: inline-flex;
  align-items: center;
  gap: 0.5rem;
  padding: 1rem 2.5rem;
  border-radius: 9999px;           /* 胶囊形 */
  font-weight: 500;
  color: white;
  background: linear-gradient(135deg, {accent-base}, {accent-light});
  box-shadow: 0 8px 32px {accent-base}40;
  transition: all 0.3s;
}
```

每个宇宙替换 `{accent-base}` 和 `{accent-light}`。

## 五、各宇宙视觉详细参考

### SoulTI — 文艺内省范本

**做对了什么：**
- 全衬线字体（Georgia + Noto Serif SC）与平台默认无衬线形成强烈区隔
- 色调是暖烟棕，不是科技感的冷色，暗示"向内看"
- 留白大方，不拥挤
- 引文用斜体 + 破折号（"— 不是标签，是一面安静的镜子"）
- 维度名用单字隐喻（涌/静、根/风、融/壁、焰/烬）

**设计启发：** 每个宇宙都应该有自己的"字体人格" + "配色情绪" + "文案声音"。

### 花TI — 温暖治愈范本

**做对了什么：**
- 极光色背景渐变（不是单色）
- 磨砂玻璃卡片（`backdrop-filter: blur(8px)`）→ 柔和优雅
- 植物隐喻贯穿所有维度名（光合作用/花期/根系/铠甲）
- 色温偏暖，但用了红玫瑰 accent，形成温暖中的张力

### 恋爱XP — 撩人暧昧范本

**做对了什么：**
- 紫→粉渐变 = 暧昧/浪漫的色彩心理暗示
- 删除线幽默（划掉"SBTI"暗示升级版）
- 文案带挑逗性（"你在牛排面前能不能保持纯爱"）
- Excel 梗（"你的理想型在脑子里还是 Excel 里"）→ 精准打击用户笑点

## 六、扩展原则

1. **"新宇宙 = 新事件"** — 每个宇宙上线应像一个独立产品发布
2. **视觉先行** — 确定主题色 + 字体 + 一张概念图后再写文案/代码
3. **一致性底线** — 必须用全局底色 + 导航 + 动画骨架 + 卡片圆角
4. **差异化上限** — 鼓励大胆的字体/色彩/文案跳跃，但不能破坏可读性
5. **SEO 友好** — 每个宇宙 landing page 独立 metadata + canonical
