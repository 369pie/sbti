## Phase 1：定位与市场上下文

### 1.1 Geoffrey Moore 定位声明

```
对于 18-30 岁、在小红书上活跃、对塔罗/玄学/人格测试感兴趣的中国年轻女性，
她们需要一种既有「神秘学仪式感」又能「精准定义自我」的内容产品。

灵鉴 是一个「塔罗人格解读平台」，
它用大阿卡纳的古老符号系统，为你的人格提供一个神秘学视角的灵魂镜像。

不同于 准了App（太专业太重）和 测测星座（太娱乐太泛），
灵鉴 提供的是「MBTI 的精准 + 塔罗的浪漫 + 社交传播的病毒性」三合一的独特体验。
```

### 1.2 目标用户画像

#### P0 核心用户：小红书 Z 世代女性（18-24 岁）
- **占比**：45%
- **特征**：学生群体，时间充裕，追求社交货币
- **核心驱动力**：好玩 → 分享 → 获得认同
- **典型场景**：闺蜜聚会、睡前刷手机、朋友圈社交素材
- **关键洞察**：她们不关心塔罗「准不准」，关心的是「这个结果能不能发朋友圈」和「闺蜜看了会不会也想测」

#### P1 高价值用户：轻熟女（25-30 岁）
- **占比**：35%
- **特征**：职场初中层，经济独立，面临婚恋/职业关键期
- **核心驱动力**：自我探索 → 情感决策支持 → 深度认同
- **典型场景**：情感困惑、职业选择、独处时的自我对话
- **关键洞察**：她们要的不是「答案」，而是「帮我想清楚」。塔罗是外化的思考工具。

## Phase 2：问题框架（MITRE Canvas）

### 往内看（Look Inward）
- **假设**：年轻女性用户会因为「仪式感」和「社交货币」而使用塔罗产品
- **偏见**：我们倾向于用「功能完整度」衡量产品，但用户用「情感共鸣度」衡量
- **未解决原因**：现有产品要么太重（需要下载 App、注册、付费），要么太轻（只有一张图没有深度），缺乏「恰到好处的深度」

### 往外看（Look Outward）
- **谁在经历这个问题**：所有在小红书刷塔罗内容的用户（月搜索量 1000 万+）
- **谁不在经历**：对玄学完全排斥的理性派（但他们可能被「人格测试」的框架吸引进来）
- **谁被遗漏了**：想做双人测试但找不到好产品的用户（情侣/闺蜜场景）
- **谁受益**：小红书博主（好的测试产品是他们的内容素材）

### 重构问题
**原问题**：做一个塔罗人格测试产品

**重构后**：如何让每一个年轻女性在做完测试后，都觉得「这张牌说的就是我」，并且忍不住截图发给闺蜜？

**HMW 问题**：How might we create a tarot-personality experience that feels so personally true and visually beautiful that users can't help but share it?

## Phase 3：机会解题树（Teresa Torres OST）

### 期望成果
**核心指标**：分享率（分享数 / 浏览数）> 15%
**次要指标**：双人测试完成率 > 40%，回访率（7 日）> 20%

### 机会 1：让分享图本身成为内容产品
用户在小红书/朋友圈看到的不是「测试链接」，而是一张本身就完整的、有信息量的、有美感的「灵魂卡片」。

**方案**：
1. 单人分享图加入神谕解读段落（3-4 句精准描述）
2. 双人分享图加入关系类型 + bondTagline
3. 分享图自带「你的灵魂牌是 XX」信息，不需要点进来就能传播

### 机会 2：让双人测试成为社交货币
「测测你和 TA 的灵魂绑定」—— 这不只是一个功能，而是一个社交事件。

**方案**：
1. 分享链接带 slug 参数，打开自动进入合盘模式
2. 「TA 是 XX 牌，你是谁？」的回流体验
3. 双人结果页的解读内容足够深度，值得两个人反复看

### 机会 3：让测试过程成为仪式
塔罗的魅力在于「仪式感」。从点击「开始测试」到看到结果，整个过程应该像「抽牌」，不是像「填问卷」。

**方案**：
1. Quiz 模式加入塔罗主题 UI（暗色背景、星尘特效）
2. 答题卡牌翻转效果
3. 结果揭晓前的「洗牌」等待动画
4. 3D 翻牌揭晓（已完成）

## Phase 5：Amazon Working Backwards 新闻稿

### 新闻稿

**灵鉴：让每个女孩都拥有一张属于自己的灵魂塔罗牌**

北京，2025 年 —— 今天，WTFTI 正式推出「灵鉴」模块，一个将 29 种 WTFTI 人格与 22 张大阿卡纳塔罗牌深度融合的全新体验。

「很多女孩在做完 MBTI 之后会问：然后呢？」灵鉴的产品负责人说，「灵鉴回答的就是这个'然后'。我们不是在做另一个测试，我们是在给已经认识自己的人一面更神秘的镜子。」

灵鉴的核心功能是「灵魂卡牌」：每个 WTFTI 人格对应一张大阿卡纳牌和一张 Shadow 牌。用户不仅能看到自己的牌，还能看到这张牌在塔罗体系中的位置、关键词、以及一段精准到「准到哭」的神谕解读。

但灵鉴最令人兴奋的功能是「双人合盘」：用户可以选择另一个人格，生成专属的合盘结果。系统会自动判断两人的关系类型（如同频共振、天作之合、火花四射等 11 种关系原型），并给出深度的互动解读。

「我们内测的时候，很多用户做完合盘之后直接截图发给对方看，」产品负责人说，「不需要任何引导，分享是自然发生的。因为内容本身就有传播力。」

灵鉴的分享图设计也经过精心打磨：竖版神谕卡风格，双主题（星夜秘典/苍白圣痕），1080px 高清输出，适配小红书/微信的图片规格。每张分享图本身就是一个完整的内容产品——看到图的人不需要点进来就能被触动。

灵鉴今天已在 WTFTI 平台上线，用户可直接访问 wtfti.com/mysti 使用。
