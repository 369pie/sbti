# 狗TI × 猫TI — 双宇宙产品设计方案

> **核心原则：跟现有 10 个宇宙拉开视觉断层，保持 WTFTI 自嘲内核，制造新鲜感。**

---

|------|-------------|------|
| 经典版 | 低多边形纸艺 | 自嘲荒诞 |
| 毒舌版 | 高对比暗色块 | 辛辣讽刺 |
| 修仙 2.0 | 古风 Q 偶人形 | 仙门怪可爱 |

## 二、狗TI — 「犬格觉醒」

### 2.1 方向对比分析

我列了 **4 条视觉路线**，各有利弊，最终推荐方案 A+B 的混合路线：

---

#### 方案 A：「暗黑少年漫」— Jujutsu Kaisen / Chainsaw Man 风

一句话：用咒术回战的画风画一只在追自己尾巴的哈士奇。

| 维度 | 评价 |
|------|------|
| 新鲜感 | ★★★★★ 全站没有任何暗线条风格 |
| 帅气度 | ★★★★★ 暗黑少年漫 = 当代年轻人的"酷"天花板 |
| 反差笑点 | ★★★★★ 越帅的画风 × 越狗的行为 = 越 WTF |
| 女性吸引力 | ★★★★ 咒术回战女性粉丝占比极高 |
| 生图难度 | ★★★ 暗线条风格 AI 出图质量不稳定 |
| 与现有宇宙差异 | ★★★★★ 全站最暗、最有「力量感」的风格 |

**视觉关键词：** 粗笔触线稿、动态速度线、暗调高对比、墨渍飞溅、犬齿尖牙、瞳孔特写、manga screentone

**核心反差公式：**
```
画面 = 帅到窒息的暗黑少年漫立绘
内容 = "你听到主人拿塑料袋的声音就条件反射跑过去"
         ↑ 这个反差就是 WTF 的精髓
```

---

#### 方案 B：「浮世绘 × 赛博」— Ukiyo-e Cyberpunk 犬武士

一句话：用葛饰北斋的笔触画一只穿机械铠甲的柴犬武士。

| 维度 | 评价 |
|------|------|
| 新鲜感 | ★★★★★ 浮世绘 + 赛博 = 前所未见的视觉混搭 |
| 帅气度 | ★★★★★ 武士道美学 + 霓虹光 = 审美天花板 |
| 另类感 | ★★★★★ 这是最"天马行空"的方案 |
| 女性吸引力 | ★★★★ 审美独特，有收藏欲 |
| 生图难度 | ★★★★ 风格融合有难度但 AI 对浮世绘理解好 |
| 传播记忆点 | ★★★★★ "那个浮世绘赛博柴犬测试" — 一句话就记住 |

**视觉关键词：** 浮世绘线描 + 霓虹渐变 + 数码雨 + 武士甲胄 + 犬种拟人 + typography 用竖排「犬格」

#### 方案 C：「JoJo 犬格 STAND」— JoJo's Bizarre Adventure 风

一句话：每个人格的「替身」(Stand) 是一只狗。

| 维度 | 评价 |
|------|------|
| 新鲜感 | ★★★★★ |
| 帅气度 | ★★★★★ JoJo 立绘 = 帅+怪+力量感 |
| meme 基因 | ★★★★★ JoJo meme 本身就是顶级文化现象 |
| 生图难度 | ★★★★★ JoJo 风格 AI 出图极不稳定，人体比例容易崩 |
| 受众宽度 | ★★★ 太核圈，非 JoJo 粉可能不 get |

**评估：** 概念满分但执行风险太高，AI 生图很难稳定复现 JoJo 比例。建议作为备选或局部借鉴。

---

#### 方案 D：「犬系彼氏图鉴」— 乙女游戏 CG 美男子

一句话：每个人格是一个带犬种特征的美男子立绘，像恋与制作人的人物卡。

| 维度 | 评价 |
|------|------|
| 新鲜感 | ★★★ 乙女风不算新，但 WTFTI 没有 |
| 女性吸引力 | ★★★★★ 直击靶心 |
| 帅气度 | ★★★★ 标准帅，但不"酷" |
| 传播力 | ★★★★ 女生爱存图 |
| 差异化 | ★★ 跟市面上"你是什么动漫男友"类测试太像 |
| WTF 感 | ★★ 太正经了，不够 WTF |

**评估：** 安全牌但不够另类。如果核心诉求是"帅"可以考虑，但缺乏 WTFTI 的荒诞 DNA。

### 2.2 推荐方案：「犬格觉醒」暗黑少年漫路线

**最终推荐方案 A 为主体，融合方案 B 的部分配色思路。**

理由：
1. 与全站所有宇宙拉开最大视觉断层（唯一的暗黑漫画风格）
2. 反差公式 = 帅气画风 × 狗行为 = WTF 炸裂
3. 咒术回战/电锯人风格是当下年轻人（尤其 Gen-Z）的审美主流
4. 犬种拟人在日漫圈有成熟受众基础

#### 品牌定义

| 要素 | 内容 |
|------|------|
| **子品牌名** | **犬TI / 犬格觉醒** |
| **英文** | DOGTI / DOG SPIRIT AWAKENING |
| **Slogan** | "WTF 我的犬格居然觉醒了？" |
| **一句话** | 你以为你是正常人？不，你骨子里是一只狗。 |
| **调性** | 帅气 × 中二 × 自嘲 — "画面越帅，内容越狗" |
| **slug** | `dog` |

#### 主题色系

| Token | 色值 | 说明 |
|-------|------|------|
| 主题色 | `#1a1a2e` | 暗夜藏蓝 — 暗黑少年漫底色 |
| 强调色 | `#e94560` | 血焰红 — 犬格觉醒的"眼"色 |
| 辅助色 | `#0f3460` | 深海蓝 — 冷峻映衬 |
| 光效色 | `#00d2ff` | 灵能青 — 犬格能量光效 |
| 文字色 | `#eaeaea` | 灰白 — 漫画对白框 |

**注意：** 这是 WTFTI 第一个采用暗色系着陆页的宇宙（其他全是 `#FAF8F5` 暖米白底），这个差异本身就是记忆点。

#### 视觉系统

**画面构成：**
```
┌──────────────────────────────────────┐
│  暗色背景 + 微弱速度线/墨渍飞溅       │
│                                      │
│     [犬种拟人角色 · 半身像]            │
│      - 人形主体，带犬种特征            │
│        (耳朵/尾巴/犬齿/瞳孔)          │
│      - 粗线条 manga 风格              │
│      - 动态感十足的姿态               │
│      - 身后隐现对应真实犬种的「灵体」   │
│                                      │
│     [底部信息区]                      │
│      犬格名称 + 犬种 + 一句话          │
└──────────────────────────────────────┘
```

**角色设计规则：**
- 主体是**人形**（不是画真狗），带犬种特征的拟人角色
- 身后浮现对应犬种的半透明「犬灵」(类似替身/灵体)
- 线条感强调速度线、manga screentone 网点纸
- 每个角色有一个「觉醒瞬间」的戏剧化姿态
- 配色跟随犬种天然色系（柴犬=橙棕、哈士奇=灰白蓝、金毛=暖金…）

#### 29 犬种 × 人格映射设计思路

**映射原则：**
1. **犬种真实习性优先** — 柴犬真的倔、哈士奇真的拆家、边牧真的控制欲强
2. **全民梗优先** — 优先选有网红犬种梗的（二哈拆家、柴犬微笑、金毛暖男）
3. **反差幽默** — 把犬种的严肃特性用自嘲语言翻译成人格
4. **覆盖热门犬种** — 柴犬、哈士奇、金毛、边牧、柯基、萨摩耶、拉布拉多…

- **图鉴预览：** 暗底 + 犬种卡牌 grid，hover 时眼睛发光
- **CTA：** "唤醒你的犬格 →"

### 3.2 推荐方案：「喵格图鉴」猫 meme 路线 + 方案 E 理念融合

**核心推荐方案 A 为主，融合方案 E 的叙事思路（在分享图里加一格"名场面"）。**

理由：
1. 猫 meme 是 2024-2026 互联网最大公约数，传播力碾压级
2. "WTF 我是委屈猫" 天然就是 WTFTI 品牌语言
3. 猫 meme 的情绪类型（委屈/高冷/发疯/粘人/懵逼…）和 29 人格天然对应
4. 视觉上和全站所有风格都有断层——这是第一次用"meme 情绪表情"作为核心美术
5. 加一格"名场面"小漫画让分享图信息密度更高、更有故事感

**核心创新：「meme 情绪表情」作主视觉**

不画完整角色立绘，而是以**猫的表情特写**（大脸 + 夸张情绪）为核心视觉。

- 核心是表情：每只猫的表情必须能直接当表情包用
- 身体比例：大头小身体（头身比约 1:1.5）
- 每只猫有独特的「名场面」mini 场景（如：橘猫趴在称上不看数字、英短坐在高处俯视众生）
- 画面暖色调为主，用色软糯但不寡淡

#### 29 猫种 × 人格映射设计思路

**映射原则：**
1. **猫种真实性格优先** — 橘猫真的贪吃、布偶真的粘人、狸花真的野
2. **meme 表情先行** — 先确定每个人格对应什么表情/情绪，再匹配猫种
3. **全民梗优先** — 优先用有网络梗的猫种（橘猫=胖、英短=冷、布偶=美但傻）
4. **反差毒舌** — 看起来可爱，描述起来都是吐槽

## 七、总结对比

| 维度 | 犬TI「犬格觉醒」 | 喵TI「猫格图鉴」 |
|------|-----------------|-----------------|
| 视觉风格 | 暗黑少年漫 manga | 软糯水彩 meme 猫 |
| 色调 | 暗夜藏蓝 + 血焰红 | 奶油粉 + 猫爪粉 |
| 角色构成 | 犬种拟人半身像 + 犬灵 | 猫脸大特写 + 名场面小格 |
| 文案视角 | 第三人称描述（"你是…"） | 猫第一人称自述（"本猫…"） |
| 情绪标的 | 帅 → 但做的事很狗 = WTF | 萌 → 但嘴很毒 = WTF |
| 核心受众 | 男女通吃（偏日漫受众） | 偏女性（猫奴/云吸猫） |
| 传播语句 | "WTF 我的犬格居然觉醒了" | "WTF 我居然是这种猫" |
| 差异化程度 | ★★★★★（全站唯一暗色系） | ★★★★★（全站唯一 meme 表情系） |
| 与对方的对照 | 暗 vs 亮 | 酷 vs 萌 |

**双宇宙的终极卖点：**

> 同一个人，在犬TI 里是帅到爆炸的暗黑犬灵觉醒者，在猫TI 里是瘫在沙发上一脸"关我屁事"的猫——
> **这个反差本身就是最大的 WTF。**
