# Logo V3 设计思考 — W × 灵眼

## W 的多层含义

| 层面 | 含义 |
|------|------|
| 品牌 | **W**TFTI 首字母 |
| 用户 | **W**oman — 女性力量 |
| 视觉 | W = 3 座山峰 = 万千法相的起伏 |
| 神秘 | W = 展开的书页 = 图鉴在翻阅 |
| 花瓣 | W = 3 片花瓣 = 自然有机形态 |

## 设计方向

**W 不是硬朗的字母，而是一笔写成的、有呼吸的、像花枝又像山脊的曲线。**

三个笔画节点上各有一颗小星（代表万相中的光点）。
W 的正下方/正中央，嵌入灵魂之眼。

整体感觉：一个优雅的 W 字母徽章，同时是眼睛、是花、是山。
